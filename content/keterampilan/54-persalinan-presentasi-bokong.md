## Kenapa Keterampilan Ini Penting

Meskipun **Sektio Caesar Elektif adalah Standar** untuk Presentasi Bokong Term (Term Breech Trial 2000, ACOG/RCOG/POGI: Sektio Caesar Mengurangi Kematian & Morbiditas Neonatal), **Persalinan Bokong Vaginal Tetap Perlu Dikuasai** karena:

1.  **Kehamilan Bokong Ditemukan Saat Kala II (Undiagnosed Antenatal)** — Tidak ada waktu/wilayah untuk Sektio.
2.  **Kedua Kembar (Twin 2) Bokong** — Sering dilahirkan vaginal setelah Twin 1 Kepala.
3.  **Kehamilan Preterm (<34-36 mgg) Bokong** — Sektio Caesar Klasik (Inserio Fundus) Risiko Tinggi untuk Kehamilan Mendatang; Persalinan Vaginal Sering Dipilih Jika EFW Kecil & Progres Baik.
4.  **IUFD (Kematian Intrauterin) Bokong** — Sektio Caesar Tidak Diindikasikan (Risiko Ibu > Manfaat Janin).
5.  **Pasien Menolak Sektio Caesar** (Setelah Konseling Lengkap Risiko) — Hak Pasien, Butuh Dokter Yg Kompeten.

**Kompetensi Inti**: **Seleksi Pasien Ketat (Kriteria Term Breech Trial), Teknik "Hands-off the Breech" (Jangan Tarik), Maneuver Lahirkan Badan (Lovset) & Kepala (Mauriceau/MSV/Prague), Neonatolog Siaga, Anestesi Siaga, Ambang Batas Waktu (Time Limits) Ketat.**

## Indikasi & Kriteria Seleksi Pasien (Kriteria Term Breech Trial / PREMODA / ACOG / POGI)

### **INDIKASI (Semua Harus Terpenuhi → "Kandidat Ideal")**

| Kriteria                                            | Standar                                                                                                                    | Alasan                                                                                                               |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Usia Gestasi**                                    | **≥ 37 Minggu (Term)**                                                                                                     | Preterm < 36 mgg: Sektio Pilihan (Kepala Relatif Besar, Risiko Trauma ↑).                                            |
| **Tipe Presentasi**                                 | **Frank Breech (Paha Fleksi, Lutut Ekstensi) ATAU Complete Breech (Paha & Lutut Fleksi)**                                  | **Footling/Incomplete (Kaki Turun Dulu) = KONTRAINDIKASI** (Risiko Prolapsus Tali Pusat & Kompresi Kepala Tinggi).   |
| **Estimasi Berat Lahir (EFW USG)**                  | **2500 - 3800 gram**                                                                                                       | < 2500g: Preterm/KEK (Risiko Asfiksia/Hipoglikemia). > 3800-4000g: Makrosomia → CPD & Distosia Kepala Risiko Tinggi. |
| **Kepadatan Kepala (HC/AC Ratio, BPD)**             | **Normal (Tidak Makrosefali, Tidak Hidrosefalus, Tidak IUGR Asimetri Berat)**                                              | Makrosefali → Entrapment Kepala. IUGR → Asfiksia Risiko Tinggi.                                                      |
| **KPD (Clinical Pelvimetry / MRI / CT Pelvimetri)** | **Adekuat (Gynekoid, Interspinous ≥ 10 cm, Intertuberous ≥ 8,5 cm, Konjugata Vera ≥ 11 cm)**                               | KPD → Distosia Kepala Tidak Terduga.                                                                                 |
| **Kondisi Janin (CTG)**                             | **Normal (Kategori I: Baseline 110-160, Variabilitas Normal, Akselerasi Ada, Tidak Ada Deselerasi Tardif/Variabel Berat)** | Hipoksia Awal → Risiko Asfiksia Saat Distosia.                                                                       |
| **Kondisi Ibu**                                     | **Sehat, Tidak Preeklampsia Berat, Tidak DM Tidak Terkontrol, Tidak Korioamnionitis**                                      | Komplikasi Maternal → Butuh Lahir Cepat (Sektio).                                                                    |
| **Fasilitas & Tim**                                 | **SpOG Penyelia, Anestesi Regional/GA Siap, Neonatolog/Anak Siaga, Alat Resusitasi Lengkap, OR Siap Sektio < 30 Menit**    | **NON-NEGOTIABLE**. Jika Tidak Ada → **RUJUK / SEKTIO ELEKTIF**.                                                     |

### **KONTRAINDIKASI ABSOLUT (HANYA SEKTIO CAESAR)**

- **Footling / Incomplete / Knee Breech Presentasi**.
- **EFW < 2500g (Preterm < 36 mgg) ATAU > 3800-4000g (Makrosomia)**.
- **KPD / CPD Terbukti / Disproorsi Kepala-Panggul (Klinis/USG/MRI)**.
- **Hipoksia Janin (CTG Kategori II Berat / III)**.
- **Plasenta Previa / Vasa Previa**.
- **Kehamilan Ganda Monokorionik (Risiko Locking/Interlocking)**.
- **Riwayat Sektio Caesar Klasik / Mioektomi Fundus / Ruptur Uterus**.
- **Ibu Menolak / Tidak Kooperatif / Tidak Ada Fasilitas Lengkap**.

## Persiapan Alat, Bahan & Tim

**Tim (Minimal):**

1.  **SpOG (Penyelia Utama)** — Wajib Hadir Selama Kala II.
2.  **Dokter Umum / Bidan Terlatih (Asisten 1 & 2)** — Satu bantu lahirkan badan, satu bantu kepala/neonatus.
3.  **Anestesiolog** — **Epidural/Spinal Siap (Ideal) / GA Standby**. _Anestesi Regional Mempermudah Manipulasi & Mengurangi Push Ibu Terlalu Cepat_.
4.  **Dokter Anak / Neonatolog** — **Hadir Saat Lahir** (Resusitasi Siap).
5.  **Perawat/Instrumenter** — Alat Sektio Caesar **Sudah Dibuka & Disteril (Open Tray)** di Ruang Operasi Berdekatan.

**Alat Khusus (Tambahan dari Set Persalinan Normal):**

- **Piper Forceps** (Khusus Kepala Bokong - Aftercoming Head) — **Wajib Tersedia** (Meski Jarang Dipakai Jika Maneuver Manual Sukses).
- **Wrigley Forceps** (Alternatif Kecil).
- **Doppler/Pinard/USG Portable** — Konfirmasi DJJ Sebelum & Sesudah Manipulasi.
- **Stopwatch / Timer** — **Catat Waktu: Lahir Bokong → Lahir Kepala (Target < 3-5 Menit)**.
- **Kateter Foley** — Kosongkan Kandung Kemih (Wajib).

**Obat:**

- **Oksitosin 10-20 IU IV/IM** (Profilaksis Atoni Pasca Lahir — _Hati-hati Jika Belum Lahir Bahu/Kepala, Bisa Bikin Kontraksi Kuat Mendorong Kepala ke Pelvis Sebelum Waktunya → Gunakan Pasca Lahir Total_).
- **Ergometrin/Misoprostol** (Second Line PPH).
- **Vitamin K 1 mg IM** (Bayi Bokong Risiko Trauma Kepala → Pendarahan Intrakranial).

## Langkah-Langkah Prosedur (Maneuver Standar: **Mauriceau-Smellie-Veit / Modified Prague / Lovset**)

### **PRINSIP EMAS: "HANDS-OFF THE BREECH" (JANGAN TARIK BOKONG)**

> **Biarkan Bokong Lahir Spontan Hingga Ke Pinggang/Scapula (Bone Prominence Terlihat). JANGAN TARIK. JANGAN DORONG FUNDUS. HANYA DUKUNG & ARAHKAN.**

### **KALA I & AWAL KALA II: MONITORING & PERSIAPAN**

1.  **Kontraksi & Progres**: Pantau Seperti Normal (Partograf). **Jangan Augmentasi Oksitosin Rutin** (Risiko Hiperstimulasi & Kepala Masuk Pelvis Terlalu Cepat Sebelum Bokong Lahir). Hanya Jika Hipokontraksi Jelas & Progres Lambat.
2.  **Pembukaan Lengkap (10 cm)**: **Verifikasi PV: Presentasi Bokong Tetap, Tidak Ada Prolapsus Tali Pusat, Kepala Masih Di Atas (Station -3 s.d. -1)**.
3.  **Anestesi Regional/GA Diberikan** (Jika Belum).
4.  **Posisi Ibu: Lithotomy Tinggi / McRoberts (Paha Ditekan Ke Dada)** — Memaksimalkan Diameter Pelvis.
5.  **Kateterisasi KK**.
6.  **Episiotomi Mediolateral (Wajib Hampir Selalu)** — Dilakukan **SEBELUM** Lahir Bokong (Saat Kontraksi, Anestesi Lokal/Regional Sudah Kerja). Memperlebar Keluar, Memudahkan Manipulasi Bahu & Kepala, Mencegah Robekan Derajat 3-4.

### **LAHIRAN BOKONG & BADAN (HINGGA SCAPULA/BAHU)**

7.  **Tunggu Kontraksi**. Bantu Lahirkan **Bokong Hingga Pinggang (Iliac Crest)** → **Spontan**. **Dukung Bokong dengan Tangan (Hand Cradle) — JANGAN TARIK**.
8.  **Lahirkan Badan Hingga Scapula (Tulang Belikat)**:
    - Saat Bokong Keluar, **Rotasi Bokong 90° (Anterior → Transversal)** → Membantu Bahu Masuk Diameter Oblique Pelvis.
    - **Maneuver Lovset (Untuk Lahirkan Bahu)**:
      - Pegang Bokong Bayi (Telapak Tangan Menutupi Pinggang, Jari-jari Menggenggam Paha).
      - **Rotasi Badan 180° (Belakang → Depan)** → Bahu Anterior Turun → Lahirkan Bahu Anterior (Di Bawah Simfisis) → **Rotasi Kembali 180° (Depan → Belakang)** → Bahu Posterior Turun → Lahirkan Bahu Posterior.
      - **Alternatif: Modified Prague** — Pegang Paha, Angkat Naik (Elevasi) + Rotasi Sedikit → Bahu Anterior Lahir → Turunkan → Bahu Posterior Lahir.
    - **PENTING**: **JANGAN TARIK BADAN**. Hanya **Rotasi & Elevasi/Depresi Terkontrol**. Biarkan Kontraksi Uterus Mendorong.

### **LAHIRAN KEPALA (AFTERCOMING HEAD) — PALING BERBAHAYA**

> **WAKTU Kritis: Lahir Bokong → Lahir Kepala Target < 3-5 Menit.** Lebih Lama = Asfiksia / Kompresi Tali Pusat.

9.  **Posisi Kepala**: Biasanya **Occiput Anterior (OA)** atau **Occiput Transverse (OT)**. Butuh **Flexi Maksimal (Chin-to-Chest)** untuk Diameter Terkecil (Suboccipitobregmatic 9.5 cm).
10. **Maneuver Mauriceau-Smellie-Veit (MSV) — Standar Global**:
    - **Tangan Kanan (Operator)**: Telunjuk & Tengah **Masuk Vagina**, Ujung Jari **Tekan Dagu (Mandibula) Bayi** → **Memaksa Flexi Kepala (Chin-to-Chest)**. Ibu Jari di Dada Bayi (Stabilisasi).
    - **Tangan Kiri (Operator)**: **Pegang Bahu Bayi** (Atau Pergelangan Tangan) → **Tarik Perlahan Ke Bawah & Depan (Mengikuti Kurva Carus)**.
    - **Asisten (Suprapubik/ Fundus)**: **Tekanan Suprapubik (Fundal Pressure) RINGAN & TERKONTROL** (Mendorong Kepala Ke Pelvis) — **JANGAN KERAS** (Risiko Ruptur Uterus/Pendarahan).
    - **Koordinasi**: **Flexi Kepala (Tangan Kanan) + Tarikan Terarah (Tangan Kiri) + Dorongan Suprapubik (Asisten)** = Kepala Lahir Dengan Flexi Terjaga.
11. **Alternatif: Maneuver Bracht (Jika MSV Gagal / Kepala Terjebak Di Pelvis Atas)**:
    - Angkat Badan Bayi **Vertikal Ke Atas (Mengarah Ke Perut Ibu)** → Kepala Masuk Pelvis Lebih Mudah (Diameter Anteroposterior Lebih Besar) → Lalu Turunkan Ke Bawah (Mengikuti Kurva Carus) Sambil Flexi Dagu.
    - **Hati-hati: Risiko Fraktur Klavikula/Humerus Jika Terlalu Keras**.
12. **Piper Forceps (Jika Maneuver Manual Gagal / Kepala Tidak Flexi / Ibu Tidak Bisa Push / Anestesi Tidak Adekuat)**:
    - Aplikasi **Piper Forceps** Khusus Kepala Bokong (Blade Melengkung Panjang, Tidak Ada Gapas/Articulation).
    - Butuh **Anestesi Regional/GA Penuh & Episiotomi Luas**.
    - **Hanya Oleh SpOG Berpengalaman**.

### **PASCA LAHIR TOTAL**

12. **Resusitasi Neonatal Segera** (Bayi Bokong Risiko Tinggi: Asfiksia, Trauma, Hipoglikemia, Pneumotoraks). **APGAR 1 & 5 Menit**.
13. **Oksitosin 10-20 IU IV/IM** (Sekarang Boleh, Plasenta Belum Lahir Tapi Bayi Sudah Keluar Total).
14. **Pengambilan Plasenta (Kontrol Tali Pusat / Brandt-Andrews)**.
15. **Inspeksi Saluran Lahir & Perineum** (Episiotomi, Robekan). Jahit (Lihat Modul Menjahit Laserasi / Menjahit Laserasi Derajat).
16. **Vitamin K 1 mg IM Bayi** (Risiko Pendarahan Intrakranial).
17. **Observasi Ibu & Bayi Ketat 2 Jam (PPH, Asfiksia Tunda, Trauma)**.

## Interpretasi & Peringatan Kritis (Red Flags)

> [!warning] **"HANDS-OFF THE BREECH" ADALAH HUKUM MUTLAK**. **Menarik Bokong/Badan Sebelum Waktunya = Mendorong Kepala Masuk Pelvis Tanpa Flexi (Deflexi) → ENTRAPMENT KEPALA (HEAD ENTRAPMENT) = KEMATIAN JANIN / CEREBRAL PALSY / FRAKTUR SKULL**. **SABAR. BIARKAN KONTRAKSI MENDORONG.**
> [!warning] **WAKTU LAHIR BOKONG → KEPALA > 5-10 MENIT = ASFIKSIA BERAT**. **SIAP SIAP SEKTIO CAESAR / PIPER FORCEPS JIKA MANEUVER MANUAL GAGAL 2-3 KALI / WAKTU > 3 MENIT**. Neonatolog Harus Siap Intubasi.
> [!warning] **FOOTLING/INCOMPLETE BREECH = KONTRAINDIKASI MUTLAK**. Kaki Turun Dulu → Tali Pusat Terkompresi Antara Kaki & Pelvis → Asfiksia Mendadak. **SEKTIO CAESAR SAJA**.
> [!warning] **AUGMENTASI OKSITOSIN RUTIN PADA PERSALINAN BOKONG = BERBAHAYA**. Kontraksi Terlalu Kuat Mendorong Kepala ke Pelvis Sebelum Bokong/Badan Lahir → Entrapment. **HANYA JIKA HIPOKONTRAKSI JELAS & DENGAN MONITORING IUPC/TE (IUPC Ideal)**.
> [!warning] **EPISIOTOMI MEDIOLATERAL WAJIB SEBELUM LAHIR BOKONG**. Tanpa Episiotomi → Robekan Derajat 3-4 Hampir Pasti Saat Manipulasi Bahu/Kepala → Inkontinensia Feses Ibu.
> [!warning] **ANESTESI REGIONAL (EPIDURAL/SPINAL) ADALAH STANDAR**. Ibu Harus Tenang, Tidak Push Sembarangan, Otot Perineum Relaks. GA Hanya Jika Kontraindikasi Regional.
> [!warning] **BAYI BOKONG RISIKO TINGGI: TRAUMA (Fraktur Klavikula/Humerus, Plexus Brachialis, Intrakranial Hemorrhage), ASFIKSIA, HIPOTERMIA, HIPONATRIEMIA, SEPSIS**. **Resusitasi & Observasi NICU Standar**.
> [!warning] **KEPUTUSAN SECTIO CAESAR HARUS CEPAT (Decision-to-Incision < 30 Menit)**. Jika Progres Berhenti (Arrest Descent), CTG Abnormal, Entrapment Kepala → **JANGAN PAKSA MANEUVER BERULANG**. **SEKTIO STAT**.

## Kesalahan Sering Terjadi

1.  **MENARIK BOKONG/BADAN (TRACTION) SEBELUM WAKTUNYA** → **#1 PENYEBAB ENTRAPMENT KEPALA & KEMATIAN JANIN**. **JANGAN TARIK. HANYA ROTASI & ELEVASI/DEPRESI TERKONTROL.**
2.  **MELAKUKAN PERSALINAN BOKONG VAGINAL PADA FOOTLING/INCOMPLETE BREECH** → Prolapsus Tali Pusat, Asfiksia, Kematian. **KONTRAINDIKASI MUTLAK.**
3.  **TIDAK MELAKUKAN EPISIOTOMI MEDIOLATERAL SEBELUM LAHIR BOKONG** → Robekan Derajat 3-4 Parah Saat Manipulasi Bahu/Kepala → Inkontinensia Feses Permanen.
4.  **TIDAK MEMPERHATIKAN FLEKSI KEPALA (CHIN-TO-CHEST) SAAT LAHIR KEPALA** → Kepala Lahir Deflexi (Occiput Posterior/Face Presentation) → Diameter Besar (13-14 cm) → Entrapment / Fraktur Skull / Plexus Brachialis.
5.  **MELAKUKAN AUGMENTASI OKSITOSIN RUTIN / DOSIS TINGGI TANPA IUPC** → Hiperstimulasi → Kepala Masuk Pelvis Terlalu Cepat → Entrapment / Ruptur Uterus.
6.  **TIDAK MENYIAPKAN PIPER FORCEPS / SEKTIO CAESAR STANDBY** → Gagal Manual → Waktu Tercemar → Asfiksia Janin.
7.  **TIDAK ADA NEONATOLOG/DOKTER ANAK HADIR SAAT LAHIR** → Resusitasi Tunda → HIE (Hypoxic-Ischemic Encephalopathy).
8.  **MENGABAIKAN KRITERIA SELEKSI (EFW > 3800g, KPD Tidak Pasti, CTG Tidak Normal, Preterm < 36 mgg)** → Mencoba Vaginal pada Kasus Berisiko Tinggi → Outcome Buruk.
9.  **TIDAK MENCATAT WAKTU: LAHIR BOKONG, LAHIR BAHU, LAHIR KEPALA, APGAR, KOMPLIKASI** → Medikolegal Lemah (Kasus Cerebral Palsy/Death).
10. **MENDORONG FUNDUS (FUNDAL PRESSURE) KERAS SAAT LAHIR KEPALA** → Ruptur Uterus, Pendarahan Maternal, Trauma Janin. **HANYA TEKANAN SUPRAPUBIK RINGAN TERKONTROL OLEH ASISTEN TERLATIH**.

## Dipakai Untuk Penyakit

- Malpresentasi Intrapartal — Indikasi Utama (Presentasi Bokong Term/Preterm/IUFD)
- Kehamilan Ganda — Twin 2 Bokong (Serum Vaginal Umum)
- Kehamilan Ektopik — _Bukan Indikasi (Diagnosis USG/hCG)_
- Plasenta Previa / Vasa Previa — **KONTRAINDIKASI**
- Abrupsio Plasenta — Jika Janin Bokong & Ibu Stabil, Bisa Induksi/Vaginal (Tergantung Kondisi)
- Ctg — Monitoring Ketat Wajib (CTG Kategori I Prasyarat)
- Ekstraksi Vakum Rendah — _Tidak Dipakai Kepala Bokong (Gunakan Piper Forceps/MSV)_
- Pertolongan Distosia Bahu — Bahu Bokong Bisa Distosia (Lovset/Prague)
- Pengambilan Plasenta Manual — Pasca Lahir (Risiko Atoni Tinggi)
- Menjahit Laserasi Derajat — Episiotomi Mediolaterus + Manipulasi → Risiko OASI Tinggi
- Resusitasi Neonatal — Bayi Bokong Prioritas Resusitasi & Observasi NICU
