## 🔗 Cross-Reference (Penyakit ↔ Keterampilan)

Setiap file keterampilan memiliki bagian **"Dipakai untuk Penyakit Apa Saja"** berisi wikilink ke file-file di folder `penyakit/` yang memerlukan keterampilan tersebut.

Contoh:

- Menolong Persalinan Fisiologis (APN) → dipakai untuk: Kehamilan Normal, KPD, Distosia Bahu, Partus Lama, dst.
- Pemeriksaan Tinggi Fundus Postpartum → dipakai untuk: PPH, Retensio Plasenta, Endometritis, Subinvolusio, dst.

> [!tip] **Navigasi Cepat**
>
> 1. Buka file keterampilan → scroll ke **"Dipakai untuk Penyakit Apa Saja"**
> 2. Klik wikilink → langsung ke file penyakit yang relevan
> 3. Di file penyakit, lihat bagian **"Keterampilan Terkait"** untuk balik lagi
