| Level | Jumlah | Arti bagi KOAS |

| **4A** | 44 | **WAJIB MAHIR** mandiri di akhir stase — lakukan sendiri tanpa supervisor |

## 🔗 Cross-Reference (Penyakit ↔ Keterampilan)

Setiap file keterampilan memiliki bagian **"Dipakai untuk Penyakit Apa Saja"** berisi wikilink ke file-file di folder `penyakit/` yang memerlukan keterampilan tersebut.

Contoh:
- [[27-menolong-persalinan-fisiologis-apn|Menolong Persalinan Fisiologis (APN)]] → dipakai untuk: [[07-kehamilan-normal|Kehamilan Normal]], [[18-ketuban-pecah-dini|KPD]], [[37-distosia-bahu|Distosia Bahu]], [[38-partus-lama|Partus Lama]], dst.
- [[31-postpartum-pemeriksaan-fundus|Pemeriksaan Tinggi Fundus Postpartum]] → dipakai untuk: [[45-perdarahan-postpartum|PPH]], [[43-retensio-plasenta|Retensio Plasenta]], [[46-endometritis-nifas|Endometritis]], [[47-subinvolusio-uteri|Subinvolusio]], dst.

> [!tip] **Navigasi Cepat**
> 1. Buka file keterampilan → scroll ke **"Dipakai untuk Penyakit Apa Saja"**
> 2. Klik wikilink → langsung ke file penyakit yang relevan
> 3. Di file penyakit, lihat bagian **"Keterampilan Terkait"** untuk balik lagi
