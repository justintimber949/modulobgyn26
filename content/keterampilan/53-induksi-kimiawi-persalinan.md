## Kenapa Keterampilan Ini Penting

**Induksi persalinan** dilakukan pada **20-25% kehamilan** di negara berkembang & maju. Alasan utama: **Post-term (≥ 41 mgg), Preeklampsia, Diabetes Gestasional, IUGR, PROM Tanpa Kontraksi, Kematian Intrauterin, Korioamnionitis**. Menguasai **protokol induksi berbasis bukti (Bishop Score, Prostaglandin vs Oksitosin, Amniotomi, Monitoring Ketat)** adalah **kompetensi wajib** untuk:

- **Mengurangi Sektio Caesar Tidak Perlu** (Induksi gagal = #1 indikasi sektio primer).
- **Mencegah Komplikasi Iatrogenik**: Hiperstimulasi Uterus (Terjadi 1-5% Oksitosin, 5-15% Prostaglandin), Ruptur Uterus (VBAC + Prostaglandin = Risiko Tinggi), Asfiksia Janin, Infeksi, PPH.
- **Optimalisasi Hasil**: Persalinan Vaginal Aman, APGAR Baik, Neonatal ICU Minimal.

## Indikasi & Kontraindikasi

### Indikasi Umum (ACOG/POGI/WHO)

| Indikasi                                                     | Usia Gestasi Minimal                                                   | Catatan                                                                         |
| ------------------------------------------------------------ | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **Post-term**                                                | **≥ 41+0 mgg** (Rekomendasi Kuat) / ≥ 40+6 (Pertimbangkan)             | **Indikasi #1**. USG dating akurat wajib.                                       |
| **Preeklampsia / Eklampsia**                                 | **≥ 37 mgg** (Jika stabil) / < 37 mgg (Individalisasi, butuh steroids) | Hipertensi Gestasional ≥ 38-39 mgg.                                             |
| **Diabetes Gestasional (A2/Insulin) / DM Pra-gestasi**       | **38-39 mgg** (Jika kontrol baik, tidak makrosomia)                    | Makrosomia > 4500g → Pertimbangkan Sectio Elektif.                              |
| **IUGR / Insufisiensi Plasenta**                             | **≥ 34-37 mgg** (Bergantung Doppler UA/UV/CTG)                         | Butuh Betamethason < 37 mgg. CTG/Doppler Ketat.                                 |
| **PROM (Premature Rupture of Membranes) Term**               | **≥ 37 mgg**                                                           | Induksi Segera (Oksitosin) = Kurangi Infeksi vs Expectant Management 12-24 jam. |
| **Korioamnionitis**                                          | Setiap Usia (Jika Janin Viable)                                        | **Induksi/Ekselerasi Cepat + Antibiotik IV**.                                   |
| **Kematian Intrauterin (IUFD)**                              | Setiap Usia                                                            | Induksi Prostaglandin (Misoprostol) + Oksitosin. Butuh Dukungan Psikososial.    |
| **Logistik / Sosial (Jarak Jauh, Riwayat Persalinan Cepat)** | **≥ 39 mgg** (WHO: ≥ 39 mgg tanpa indikasi medis)                      | **Hanya Jika Serviks Menguntungkan (Bishop ≥ 6)**.                              |

### Kontraindikasi Absolut (Tidak Boleh Diinduksi → Sektio Caesar)

1.  **Plasenta Previa / Vasa Previa**.
2.  **Presentasi Abnormal** (Bokong, Transversal, Muka, Dahi) — _Kecuali Eksternal Kephalik Version (ECV) sukses lalu induksi_.
3.  **Ruptur Uterus Sebelumnya / Mioektomi Klasik (Inserio Fundus) / Histerektomi Subtotal**.
4.  **Kontraindikasi Persalinan Vaginal**: KPD Cepat, Cefalopelvik Disproportion (CPD) Terbukti, Herpes Genital Aktif, HIV Viral Load Tinggi (>1000), Kanker Serviks Invasif.
5.  **Hipersensitivas Oksitosin/Prostaglandin** (Langka).
6.  **Kehamilan Ganda Monokorionik** (Risiko TTTS/Interlocking) — _Konsul SpOG MFM_.
7.  **Janin Tidak Viable / Anomali Letal** (Konseling Opsi Lain).

### Kontraindikasi Relatif (Hati-hati, Perlu Evaluasi Mendalam)

- **VBAC (Vaginal Birth After Cesarean)**: **JANGAN GUNAKAN PROSTAGLANDIN (Misoprostol/Dinoprostone)** → Risiko Ruptur Uterus Naik 2-3x. **Hanya Oksitosin Dosis Rendah + Monitoring Ketat (CTG Kontinu, IUPC Ideal)**.
- **Operasi Uterus Lain (Mioektomi Laparoskopik, Septum Reseksi)** → Risiko Ruptur (Rendah tapi ada).
- **Makrosomia Estimasi > 4500g (DM) / > 5000g (Non-DM)** → CPD Risiko Tinggi.
- **PROM > 24 Jam / Korioamnionitis Ringan** → Induksi Cepat Oksitosin (Prioritas) vs Prostaglandin (Lebih Lama).
- **Bishop Score < 4 (Serviks Tidak Siap)** → Butuh **Ripening Dulu (Prostaglandin/Balon)** sebelum Oksitosin. Oksitosin saja pada Bishop < 4 = **Gagal Induksi Tinggi & Hiperstimulasi**.

## Persiapan Alat & Bahan

### A. Agen Ripening Serviks (Cervical Ripening) — _Jika Bishop Score < 6_

| Agen                                                                       | Dosis & Cara                                                                                                                                        | Keuntungan                                                                              | Kerugian/Kontraindikasi                                                                                                                                            |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Misoprostol (PGE1) Oral / Vaginal / Sublingual**                         | **Vaginal 25 mcg (1/4 tablet 100mcg) 4-6 jam sekali** (Maks 6 dosis/24 jam). **Oral 25-50 mcg 2-4 jam sekali** (Absorpsi Cepat, Efek Samping GI ↑). | **Murah, Tersedia Luas, Stabil Suhu Ruang, Efektif (Ripening + Kontraksi)**.            | **Hiperstimulasi Risiko Tinggi (5-15%)**. **KONTRAINDIKASI VBAC**. Dosis > 25 mcg Vaginal = Risiko ↑. Butuh Pil 100mcg Dibagi 4 (Off-label tapi Standar WHO/FIGO). |
| **Dinoprostone (PGE2) Vaginal Insert (Propess/Cervidil) / Gel (Prepidil)** | **Insert 10 mg (Propess) 24 Jam / Gel 0,5-1 mg 6 Jam**.                                                                                             | **Dosis Terkontrol, Lepas Lambat (Insert), Bisa Dicabut (Insert) Jika Hiperstimulasi**. | **Mahal, Harus Dingin (2-8°C), Tersedia Terbatas (RS Rujukan)**.                                                                                                   |
| **Balon Foley (Mechanical)**                                               | **30-50 mL Air Steril** (Double Balloon Cook / Single Foley 16-18Fr) di Kanalis Serviks + Trakinsi Periodik.                                        | **Tanpa Obat (Aman VBAC), Murah, Bisa Dicabut Kapan Saja**.                             | **Nyeri Pasang, Risiko Infeksi (PROM), Butuh Pembukaan ≥ 1-2 cm**.                                                                                                 |

### B. Agen Induksi/Augmentasi Kontraksi (Setelah Ripening / Bishop ≥ 6)

| Agen                                                      | Protokol Standar (Indonesia/POGI/ACOG)                                                                                                                                                                                                                                                 |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Oksitosin (Syntocinon/Pitocin) IV Infus**               | **Konsentrasi: 10-30 IU dalam 500-1000 mL RL/NS**. **Mulai: 0,5-1 mIU/menit (1-3 mL/jam)**. **Naik 1-2 mIU/menit (2-6 mL/jam) tiap 20-40 menit** hingga kontraksi adekuat (3-5/10 menit, durasi 40-60 detik). **Maks: 20-40 mIU/menit**. **Gunakan Pompa Infus (Syringe Pump) WAJIB**. |
| **Prostaglandin (Jika Sudah Ripening & Kontraksi Mulai)** | **Biasanya Tidak Perlu Oksitosin Tambahan** Jika Misoprostol/Dinoprostone Sudah Menimbulkan Kontraksi Rutin. Jika Kontraksi Kurang → Bisa Tambah Oksitosin **SETelah 4-6 Jam Terakhir Dosis Prostaglandin**.                                                                           |

### C. Amniotomi (Artificial Rupture of Membranes - ARM)

- **Alat**: **Amnihook (Kait Amnion) Steril** / **Amnicot (Kancing Amnion)** / **Jarum Hipodermik 18G Dibuka** (Khusus).
- **Syarat**: **Pembukaan ≥ 3-4 cm**, **Kepala Terapung/Station -2 s.d. 0**, **Presentasi Kepala**, **Ketuban Utuh**. **JANGAN Amniotomi Jika Kepala Tinggi (Station -3) → Risiko Prolapsus Tali Pusat**.
- **Teknik**: Saat Kontraksi (Ketuban Tegak), Masukkan Amnihook via Vagina, **Kait Membran Amnion**, **Robek Pelan (Tearing)**. Biarkan Aliran Terendah (Hindari Gush Besar → Prolapsus Tali Pusat / Abrupsio).

### D. Monitoring WAJIB Selama Induksi

- **CTG Kontinu (External FSE/IUPC Ideal)** — Mulai sebelum Oksitosin / Setelah Prostaglandin.
- **Vital Signs Ibu**: TD, Nadi, Suhu, Urine Output (Setiap 1-2 Jam).
- **Kontraksi**: Frekuensi, Durasi, Intensitas (Palpasi/Toco/IUPC). **Hitung MVU Jika IUPC**.
- **Pembukaan Serviks**: Evaluasi **4-6 Jam sekali** (Jangan Terlalu Sering → Infeksi).
- **DJJ**: Auskultasi/CTG. **Deselerasi Tardif/Variabel Berat → Stop Oksitosin, Intervensi**.

## Langkah-Langkah Prosedur (Alur Klinis Standar)

### 1. Evaluasi Kelayakan Induksi (Pre-Induksi Checklist)

1.  **Konfirmasi Usia Gestasi (USG Dating Akurat)** — Hindari Induksi Preterm Tak Sengaja.
2.  **Bishop Score** (PV: Dilatasi, Penghapusan, Station, Konsistensi, Posisi Serviks).
    - **≥ 6 (Menguntungkan)** → Langsung **Oksitosin + Amniotomi** (Jika Ketuban Utuh).
    - **< 6 (Tidak Menguntungkan)** → **Ripening Dulu (Misoprostol/Dinoprostone/Balon)** → Re-evaluasi Bishop 12-24 Jam → Jika ≥ 6 → Oksitosin + Amniotomi.
3.  **CTG Baseline (20 Menit)** — Pastikan **Normal (Kategori I)** sebelum mulai.
4.  **USG (Jika Perlu)**: Presentasi, AFI, EFW, Plasenta, Doppler (IUGR/Hipertensi).
5.  **Konsentemen Informed Consent**: Indikasi, Prosedur, Risiko (Hiperstimulasi, Ruptur Uterus, Sectio Caesar, Infeksi, Asfiksia Janin), Alternatif (Sektio Elektif/Expectant).

### 2. Inisiasi Induksi (Berdasarkan Bishop Score)

#### **Skenario A: Bishop ≥ 6 (Serviks Siap) → Oksitosin + Amniotomi**

6.  **Pasang IV Line (18-20G)**, Bolus RL 500 mL (Preload).
7.  **Mulai Oksitosin IV Pompa Infus**: 0,5-1 mIU/menit (1-3 mL/jam konsentrasi 10 IU/500mL = 20 mIU/mL → 1 mL/jam = 0,33 mIU/menit. **Hitung Cermat!**). **Standar: 10 IU dalam 500 mL = 20 mIU/mL. Mulai 1 mL/jam (0,33 mIU/menit). Naik 1-2 mL/jam tiap 20-40 menit.**
8.  **Amniotomi** (Jika Ketuban Utuh & Kepala Terapung/Station ≥ -2) — **Bisa Sebelum/Sesudah Oksitosin Mulai**. Amniotomi Mempercepat Induksi (Rilis Prostaglandin Endogen).
9.  **Titrasi Oksitosin**: Naik 1-2 mIU/menit tiap 20-40 menit → Target Kontraksi **3-5/10 menit, Durasi 40-60 detik, MVU > 200 (Jika IUPC)**.
10. **Evaluasi Progres**: PV 4-6 Jam sekali. **Aktif Kala I: Dilatasi ≥ 1 cm/jam (Primipara) / ≥ 1,5 cm/jam (Multipara)**. Kala II: Turunan Kepala.

#### **Skenario B: Bishop < 6 (Serviks Tidak Siap) → Ripening Dulu**

6.  **Pilih Agen Ripening** (Misoprostol Vaginal 25 mcg 4-6 Jam / Dinoprostone Insert 24 Jam / Balon Foley).
7.  **Pasang CTG 30-60 Menit Pasca Prostaglandin** (Monitor Hiperstimulasi Awal).
8.  **Re-evaluasi Bishop 12-24 Jam** (Atau Sebelumnya Jika Kontraksi Rutin / Pembukaan ≥ 4 cm).
9.  **Jika Bishop ≥ 6 / Kontraksi Rutin / Pembukaan ≥ 4 cm** → Lanjut **Skenario A (Oksitosin + Amniotomi)**.
10. **Jika Tetap Bishop < 6 & Tidak Ada Kontraksi 24 Jam** → **Gagal Ripening**. Pertimbangkan: Ulangi Ripening (Jika Aman), Sectio Caesar, Atau Expectant (Jika Indikasi Tidak Mendesak).

### 3. Monitoring & Manajemen Intra-Induksi (KRITIS)

11. **CTG Kontinu** — Evaluasi Setiap 15-30 Menit (Atau Real-time).
12. **HIPERSTIMULASI (Definisi: > 5 Kontraksi/10 menit ATAU Durasi > 90 detik ATAU Interval < 60 detik ATAU MVU > 300-400)**:
    - **LANGKAH 1: HENTIKAN OKSITOSIN SEKETIKA** (Jika Prostaglandin → Cabut Insert / Amniotomi Jika Belum).
    - **LANGKAH 2: O2 10 L/menit Masker Non-Rebreathing + Posisi Left Lateral + Bolus IV Fluida 500-1000 mL RL**.
    - **LANGKAH 3: Terbutalin 0,25 mg SC / Nifedipin 10 mg PO / MgSO4 2-4g IV (Jika Preeklampsia)** — Tocolysis Darurat.
    - **LANGKAH 4: Evaluasi CTG 10 Menit Pasca Intervensi**. Jika Normal → Mulai Kembali Oksitosin **Dosis 50% Lebih Rendah**. Jika Tetap Abnormal → **Sektio Caesar**.
13. **DESELERASI TARDIF / VARIABEL BERAT / BRADIKARDIA** → **Stop Oksitosin, O2, Posisi, Fluida, Siap Sektio** (Lihat Modul Ctg).
14. **INFEKSI (Korioamnionitis: Demam > 38°C, Takikardia Ibu/Janin, Nyeri Uterus, Leukositosis, Bau Busuk)** → **Antibiotik IV Segera (Ampisilin + Gentamisin + Klindamisin / Kefalosporin + Metronidazol), Ekspedisi Persalinan (Oksitosin Maksimal / Sektio)**.
15. **GAGAL INDUKSI (Definisi ACOG/POGI)**:
    - **Kala I**: **Tidak Masuk Kala I Aktif (Pembukaan < 6 cm) setelah 12-18 Jam Oksitosin Adekuat (MVU > 200 / Kontraksi 3-5/10 menit) + Amniotomi**.
    - **Kala I Aktif**: **Tidak Ada Progres Dilatasi ≥ 6 Jam** (Meski Oksitosin Maksimal + Amniotomi).
    - **Kala II**: **Tidak Ada Turunan Kepala ≥ 3-4 Jam (Primipara) / 2-3 Jam (Multipara)**.
    - **Tindakan**: **Sektio Caesar** (Jika Janin Viable & Ibu Stabil). _Jangan Paksa Oksitosin Melebihi Batas Aman_.

### 4. Pasca Persalinan (Manajemen Kala III & PPH Profilaksis)

16. **Oksitosin 10-20 IU IV/IM Segera Pasca Lahir Bayi** (Profilaksis Atoni Utama).
17. **Pengambilan Plasenta (Kontrol Tali Pusat / Brandt-Andrews)**.
18. **Inspeksi Saluran Lahir (Luka, Retensio)**.
19. **Observasi 2 Jam (PPH Risiko Tinggi Pasca Induksi Oksitosin Panjang / Makrosomia / Kelahiran Cepat)**.

## Interpretasi & Peringatan Kritis

> [!warning] **HIPERSTIMULASI ADALAH KOMPLIKASI PALING BERBAHAYA & PALING SERING** (1-5% Oksitosin, 5-15% Prostaglandin). **GEJALA: Kontraksi > 5/10 menit, Durasi > 90 detik, Interval < 60 detik, MVU > 300, Deselerasi Tardif/Variabel Berat, Fetal Distress**. **TINDAKAN PERTAMA & PALING CEPAT: HENTIKAN OKSITOSIN (ATAU CABUT PROSTAGLANDIN INSERT). JANGAN TUNGGU DOKTER SP.OG.**
> [!warning] **RUPTUR UTERUS RISIKO TINGGI PADA VBAC + PROSTAGLANDIN (Misoprostol/Dinoprostone)**. **ABSOLUT JANGAN GUNAKAN PROSTAGLANDIN PADA VBAC**. Hanya Oksitosin Dosis Rendah + CTG Kontinu + IUPC Ideal. Tanda: Nyeri Tiba-tiba, Hilang Kontraksi, Hemodinamik Turun, DJJ Anomali, Perdarahan Vagina. **LAPAROTOMI STAT**.
> [!warning] **AMNIOTOMI PADA KEPALA TINGGI (STATION -3 ATAU LEBIH TINGGI) = RISIKO PROLAPSUS TALI PUSAT (CORD PROLAPSE)**. **HANYA LAKUKAN AMNIOTOMI JIKA KEPALA TERAPUNG/STATION ≥ -2 DAN TERAPUNG BAIK (ENGAGED)**.
> [!warning] **DOSIS OKSITOSIN HARUS DITITRASI PERLHAN (Mulai Rendah, Naik Bertahap)**. **POMPA INFUS (SYRINGE PUMP) WAJIB**. Manual Drip (Titik/Tetes) **TIDAK AMAN** (Dosis Tidak Terkontrol → Hiperstimulasi/Overdose).
> [!warning] **GAGAL INDUKSI DEFINISI HARUS KETAT** (ACOG: 12-18 Jam Kala I Latent + Oksitosin Adekuat + Amniotomi). **JANGAN SEBUT "GAGAL" SEBELUM WAKTU & DOSIS ADEKUAT TERCAPAI**. Sektio Caesar Prematur = Morbiditas Ibu-Janin Tidak Perlu.
> [!warning] **PROSTAGLANDIN (MISOPROSTOL/DINOPROSTONE) + OKSITOSIN BERSAMAAN = RISIKO HIPERSTIMULASI SANGAT TINGGI**. **JEDA MINIMAL 4-6 JAM SETELAH DOSIS TERAKHIR PROSTAGLANDIN SEBELUM MULAI OKSITOSIN**. (Kecuali Dinoprostone Insert Dicabut & Kontraksi Sudah Ada).
> [!warning] **PROM > 24 JAM / KORIOAMNIONITIS → INDUKSI CEPAT (OKSITOSIN PRIORITAS) + ANTIBIOTIK IV**. Prostaglandin Memperlama Waktu → Infeksi Meningkat.

## Kesalahan Sering Terjadi

1.  **MULAI OKSITOSIN PADA BISHOP < 4 TANPA RIPENING** → Gagal Induksi Tinggi, Hiperstimulasi, Lama, Sektio Caesar Bisa Dihindari.
2.  **MENGGUNAKAN PROSTAGLANDIN (MISOPROSTOL/DINOPROSTONE) PADA VBAC** → **RUPTUR UTERUS**. **KONTRAINDIKASI MUTLAK**.
3.  **TIDAK MENGGUNAKAN POMPA INFUS UNTUK OKSITOSIN (Manual Drip)** → Dosis Tidak Akurat → Hiperstimulasi / Underdose → Gagal Induksi.
4.  **MELAKUKAN AMNIOTOMI PADA KEPALA TINGGI (STATION -3/-4)** → **PROLAPSUS TALI PUSAT** → Asfiksia Janin Mendadak → Sektio Caesar Darurat.
5.  **TIDAK MELAKUKAN CTG KONTINU SELAMA INDUKSI/AUGMENTASI** → Lewat Deselerasi Tardif/Hiperstimulasi → Asfiksia Janin.
6.  **TIDAK MENGHENTIKAN OKSITOSIN SEKETIKA SAAT HIPERSTIMULASI / DESELERASI TARDIF** → **#1 PENYEBAB ASFIKSIA IATROGENIK**.
7.  **MENGGUNAKAN DOSIS MISOPROSTOL > 25 MCG VAGINAL (50/100 MCG)** → Hiperstimulasi & Ruptur Uterus Risiko ↑ Drastis. **STANDAR WHO/FIGO: 25 MCG**.
8.  **TIDAK MEMBERIKAN BETAMETHASON PADA INDUKSI < 37 MGG (IUGR/Preeklampsia/PROM Preterm)** → Komplikasi Prematuritas (RDS/IVH/NEC) Tidak Diminimalkan.
9.  **MENILAI "GAGAL INDUKSI" SEBELUM 12-18 JAM KALA I LATENT / SEBELUM OKSITOSIN ADEKUAT + AMNIOTOMI** → Sektio Caesar Tidak Perlu.
10. **TIDAK MENCATAT WAKTU MULAI OKSITOSIN, DOSIS SETIAP KENAIKAN, WAKTU AMNIOTOMI, WAKTU HIPERSTIMULASI/DESELERASI, WAKTU KEPUTUSAN SECTIO** → Medikolegal Tidak Terlindungi.

## Dipakai Untuk Penyakit

- Kehamilan Posterm — Indikasi #1 Induksi (≥ 41 mgg)
- Hipertensi Kehamilan / Diabetes Gestasional — Indikasi Medis Induksi (37-39 mgg)
- Insufisiensi Plasenta / Polihidramnion — IUGR, Makrosomia, Polihidramnios
- Plasenta Previa / Vasa Previa — **KONTRAINDIKASI INDUKSI (Sektio Caesar)**
- Abrupsio Plasenta — Induksi Darurat (Jika Janin Hidup & Ibu Stabil)
- Kehamilan Ganda — Induksi Khusus (Monokorionik Kontraindikasi Prostaglandin)
- Malpresentasi Intrapartal — **KONTRAINDIKASI INDUKSI (Kecuali ECV Sukses)**
- Operasi Caesar — Hasil Akhir Jika Induksi Gagal / Kontraindikasi
- Ctg — Monitoring Wajib Selama Induksi
- Ekstraksi Vakum Rendah / Pertolongan Distosia Bahu — Persalinan Operatif Pasca Induksi
- Pengambilan Plasenta Manual — Risiko PPH Pasca Induksi Oksitosin Panjang
