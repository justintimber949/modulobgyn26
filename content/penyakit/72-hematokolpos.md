# Hematokolpos & Hematometra (Kelainan Kongenital Saluran Genital Obstruktif)

## Cerita Pembuka

Anak Perempuan, 14 tahun, belum menarche. Keluhan: **nyeri perut bawah siklik seitan 6 bulan**, 때마다 meningkat, disertai mual, muntah, tanda tekanan ke kandung kemih (sering BAK). Pemeriksaan: **Himen imperforata (tidak ada orifis, bulatan biru-ungu di introitus)**. USG: **Hematometra (uterus 8×4×5 cm, endometrium tebal 15 mm, cairan hiperekoik di rongga) + Hematokolpos (vagina didistensi cairan hiperekoik 6×4 cm) + Kedua ovarium normal**. Diagnosis: **Imperforate Hymen + Hematometra + Hematokolpos**. Operasi: **Himenotomi Silang (Cruciate Incision) + Evakuasi Hematometra & Hematokolpos + Pemasangan Stent Vaginal (Foley 16 Fr) 4-6 Minggu**. Outcome: Menarche normal, siklus teratur, tidak dysmenorrhea, stent lepas 6 minggu, vagina paten.

## Definisi & Patogenesis

| Istilah                    | Definisi                                                                                         |
| -------------------------- | ------------------------------------------------------------------------------------------------ |
| **Hematokolpos**           | Akumulasi darah menstruasi di **vagina** akibat obstruksi keluar                                 |
| **Hematometra**            | Akumulasi darah menstruasi di **rongga uterus** (sekunder obstruksi serviks/vagina)              |
| **Hematosalpinx**          | Akumulasi darah di **tuba fallopi** (retrograde menstruasi via tuba)                             |
| **Endometriosis Sekunder** | Implantasi endometrial dari darah retrograde → ovarium, peritoneum, ligamen, rektovaginal septum |

> **Patogenesis:** Obstruksi saluran genital ↓ → Tekanan intrauterin ↑ → Retrograde menstruasi ke tuba & peritoneum → Endometriosis + Adhezi + Infertilitas + Nyeri Pelvik Kronik.

## Klasifikasi Kelainan Kongenital Obstruktif (ASRM / AFS)

| Anomali                                                                                        | Deskripsi                                                                                                  | Insidensi                     | Presentasi Klinis                                                          |
| ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ----------------------------- | -------------------------------------------------------------------------- |
| **1. Imperforate Hymen**                                                                       | Himen tanpa orifis (tidak ada perforasi fisiologis)                                                        | **1:1000-2000** (paling umum) | Menarche tertunda, nyeri siklik, massa pelvis, retense urin                |
| **2. Transverse Vaginal Septum**                                                               | Septum horizontal membagi vagina (bisa total/parsial, dengan/fenestrasi)                                   | 1:70.000                      | Sama imperforate tapi himen normal, orifice mungkin ada (fenestrasi)       |
| **3. Longitudinal Vaginal Septum**                                                             | Septum vertikal (bisa didouble uterus/cervix)                                                              | 1:3000                        | Dyspareunia, tampon tidak masuk, retensi tampon                            |
| **4. Cervical Agenesis / Hypoplasia**                                                          | Serviks tidak terbentuk / hipoplastik (uterus bisa normal)                                                 | Jarang                        | Hematometra tanpa hematokolpos (jika vagina paten)                         |
| **5. Vaginal Agenesis / Atresia (MRKH Syndrome)**                                              | Vagina tidak terbentuk / atresia, uterus rudimen/absent, ovarium normal                                    | 1:4500-5000                   | Primer amenorea, vagina pendek/absent, ovarium normal, reni/anomali tulang |
| **6. Uterus Didelphys / Bicornuate + Obstruksi Satu Sisi (OHVIRA / Herlyn-Werner-Wunderlich)** | Satu hemi-uterus obstruksi (serviks atresia/vaginal septum) + Satu sisi paten + Renal agenesis ipsilateral | 1:100.000                     | Nyeri siklik satu sisi, masa depan infertilitas, infeksi berulang          |

## Gejala & Tanda

| Gejala                                                                                          | Tanda Pemeriksaan                                                                                                                                        |
| ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Primer Amenorea (Usia > 15-16 th) + Karakter Seksual Sekunder Normal** (Teor: B2-3, Pubarche) | **Inspeksi Vulva/Introitus:** Himen imperforata (bulatan biru-ungu, tidak ada lubang) / Septum transversal / Vagina pendek/atresia                       |
| **Nyeri Perut Bawah Siklik (Bulan-bulan/Bertambah)**                                            | **Abdomenn:** Massa pelvis tengah (uterus didistensi), nyeri tekan suprapubik                                                                            |
| **Tanda Tekanan Kandung Kemih:** Sering BAK, Urgensi, Retensi Urin Akut                         | **Rektal:** Massa anterior (hematometra/kolpos) mendorong rektum ke posterior                                                                            |
| **Nyeri Punggung, Mual, Muntah, Konstipasi**                                                    | **USG: Hematometra (Uterus besar, endometrium tebal, cairan hiperekoik), Hematokolpos (Vagina didistensi), Hematosalpinx, Ovarium normal, Endometrioma** |
| **Riwayat Infeksi Pelvik / PID Berulang** (jika fenestrasi kecil → stasis)                      | **MRI (Jika USG Ragu / Anatomi Kompleks):** Anatomi detail septum, serviks, uterus, ovarium, ginjal                                                      |

## Diagnosis & Workup

### 1. USG (First-Line, Non-Invasif)

| Parameter   | Temuan Khusus                                                                                        |
| ----------- | ---------------------------------------------------------------------------------------------------- |
| **Uterus**  | Diperbesar, endometrium tebal (> 10-15 mm), rongga berisi cairan hiperekoik (darah beku/endometrium) |
| **Vagina**  | Didistensi cairan hiperekoik proximal ke obstruksi                                                   |
| **Serviks** | Bisa dilihat terpisah / tidak (agenesis)                                                             |
| **Tuba**    | Hematosalpinx (kista hiperekoik adneksa bilateral)                                                   |
| **Ovarium** | Normal / Endometrioma (kista coklat) sekunder                                                        |
| **Ginjal**  | **WAJIB CEK** — Asosiasi renal agenesis/ektopia (MRKH, OHVIRA)                                       |

### 2. MRI Panggul (Gold Standard Anatomi)

- **Indikasi:** USG ragu, anatomi kompleks (septum, didelphys, MRKH), planning operasi
- **Keunggulan:** Visualisasi septum, serviks, vagina, uterus, ovarium, ginjal, ureter, vaskularitas — **planning operasi presisi**

### 3. Histeroskopi / Vaginaskopi (Intraoperatif / Diagnostik)

- Konfirmasi anatomi, panjang septum, lokasi serviks, kondisi endometrium

### 4. Karyotip & Hormon (Jika MRKH / Gonadal Dysgenesis Dicurigai)

- **Karyotip 46,XX** (MRKH) / **45,X / 46,XY** (Gonadal dysgenesis)
- **FSH, LH, Estradiol, AMH, Testosteron** — ovarium fungsional (normal di MRKH/Imperforate)

## Tata Laksana Operatif (Prinsip: **Drainase + Rekonstruksi + Stenting**)

### A. Imperforate Hymen (Palang Umum)

| Langkah                                           | Detail                                                                                                                                                                       |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Anestesi**                                   | Umum / Regional (Spinal)                                                                                                                                                     |
| **2. Himenotomi (Cruciate / X-Incision / Elips)** | **Insisi Silang (Cruciate) di himen** — 4 sayatan ke arah lateral, **HINDARI SAYATAN RADIAL KE ARTERI VAGINAL** — ekskisi jaringan himen hingga mukosa vagina segar terlihat |
| **3. Evakuasi**                                   | **Hematokolpos + Hematometra** (dengan kateter histerektomi / kanul / sondan) — **IRIGASI SALIN 0,9% HINGGA BERSIH**                                                         |
| **4. Inspeksi Serviks & Uterus**                  | Histeroskopi jika memungkinkan — cek patensi serviks, endometrium                                                                                                            |
| **5. Stenting Vaginal (KRITIS)**                  | **Kateter Foley 16-18 Fr / Stent Vaginal Silikon (Mold) 4-6 Minggu** — **MENCEGAH READHESI (STENOSIS)**                                                                      |
| **6. Antibiotik**                                 | Sefazolin 1g IV intraop → cefalexin 500 mg 6 jam × 5 hari                                                                                                                    |
| **7. Analgesia & Stool Softener**                 |                                                                                                                                                                              |

> **Sukses Rate Imperforate Hymen: > 95%** jika stenting benar. **Komplikasi Utama: Stenosis Vagina (Readhesi) 10-20% jika stenting < 4 minggu / tidak ada.**

### B. Transverse Vaginal Septum

| Variabel                                 | Detail                                                                                                                                                                                                       |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Septum Tipis + Fenestrasi**            | Insisi septum (cruciate/elips) + evakuasi + stenting 4-6 mgg — mirip imperforate                                                                                                                             |
| **Septe Tebal / Total Tanpa Fenestrasi** | **Vaginoplasti (Vecchietti / Davydov / McIndoe / Laparoskopik Vecchietti / Robotic)** — butuh konstruksi vagina baru dari peritoneum / kulit / usus (sigmoid) — **Rujuk SpOG Uroginekologi / Bedah Plastik** |
| **MRI Pre-Op WAJIB**                     | Ukuran septum, jarak ke serviks, panjang vagina proximal & distal                                                                                                                                            |

### C. Cervical Agenesis / Hypoplasia

| Opsi                                              | Indikasi                                                                                                                                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Histerektomi (Laparoskopik/Abdominal)**         | **Standar** — uterus tidak bisa drainase, risiko endometriosis berat, pyometra, infertilitas. **Ovarium DISELAMATKAN** (oophoropeksi ke dinding perut) untuk hormon & fertilitas (IVF + Surrogat) |
| **Uterovaginal Anastomosis (Neovagina + Uterus)** | **Eksperimental / Pusat Tertentu** — risiko stenose tinggi, endometriosis berulang, infertilitas. Hanya kasus terpilih, usia muda, keinginan kuat simpan uterus.                                  |

### D. MRKH (Mayer-Rokitansky-Küster-Hauser) — Vaginal Agenesis

| Tahap                                                                   | Tindakan                                                                                                                                                                                                                                           |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Diagnosis & Konseling**                                            | Karyotip 46,XX, Hormon normal, USG/MRI: Uterus rudimen/absent, Vagina atresia/pendek, Ovarium normal, Cek Ginjal (USG/MRI) + Tulang (X-ray) + Audio                                                                                                |
| **2. Non-Operatif (First-Line, Usia < 18-20 th / Belum Siap Seks)**     | **Dilator Vaginal (Frank / Ingram / Heidger) — Self-dilation 15-30 menit 1-2×/hari** — **Sukses 80-90%** jika compliant, butuh 6-18 bulan. **Dukungan Psikolog WAJIB**                                                                             |
| **3. Operatif (Jika Gagal Dilator / Dewasa & Siap Seks / Ingin Cepat)** | **Vecchietti (Laparoskopik) — Olive + Tali + Traksi Harian → Vagina Baru dari Peritoneum (4-6 minggu)** — Sukses 90%+, vagina 8-10 cm, fungsi seks baik. **Davydov (Peritoneal Flap) / McIndoe (Skin Graft) / Sigmoid Vaginoplasti** — alternatif. |
| **4. Fertilitas**                                                       | **Oosit Sitologis (IVF) + Surrogat (Gestational Carrier)** — ovarium normal, uterus absent. **Uterus Transplant (Eksperimental, Pusat Tertentu)**                                                                                                  |

### E. OHVIRA (Herlyn-Werner-Wunderlich) — Obstruksi Hemi-Uterus

| Tindakan                                                                                                    | Detail                                                                                                                                              |
| ----------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hemi-Histerektomi (Sisi Obstruksi) + Vaginoplasti (Jika Septum Total) / Septum Resection (Jika Parsial)** | **Preservasi Hemi-Uterus & Ovarium Normal (Sisi Paten)** untuk fertilitas alami/IVF. **Nefrektomi JIKA Ginjal Ipsilateral Tidak Berfungsi (< 10%)** |
| **Timing**                                                                                                  | Diagnosis dini (remaja) → operasi sebelum endometriosis berat                                                                                       |

## Pasca Operatif & Follow-up

| Waktu                 | Tindakan                                                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| **Hari 1-2**          | Lepas kateter urin (jika dipasang), kontrol Hb, nyeri, infeksi                                                            |
| **Minggu 2**          | Lepas Stent Vaginal (Foley) → **Mulai Dilator Vaginal (Ukuran Kecil → Besar) 15-20 menit 2×/hari** — **WAJIB 6-12 Bulan** |
| **Bulan 1, 3, 6, 12** | Pemeriksaan vagina (patensi, stenosis, granuloma), USG (endometrioma, adhezi), Hormon (FSH, LH, E2, AMH)                  |
| **Tahunan**           | Fungsi seks (FSFI), Kualitas hidup, Fertilitas counseling                                                                 |

## Komplikasi

| Komplikasi                                         | Pencegahan                                                             |
| -------------------------------------------------- | ---------------------------------------------------------------------- |
| **Stenosis / Readhesi Vagina**                     | **Stenting 4-6 Minggu + Dilator Rutin 6-12 Bulan** — #1 Komplikasi     |
| **Endometriosis / Adhezi Berulang**                | Drainase total, irigasi bersih, stenting, OCP kontinu 3-6 bln pasca-op |
| **Pyometra / Hematometra Rekurren**                | Patensi serviks & vagina pastikan, stenting adekuat                    |
| **Infertilitas**                                   | Preservasi ovarium, hindari adhezi, endometriosis kontrol              |
| **Fungsi Seks Gangguan (Dispareunia, Vaginismus)** | Dilator rutin, konseling seks, peluru vaginal, estrogen topikal        |
| **Infeksi Luka / Abses**                           | Antibiotik profilaksis, drainase bersih                                |

## Ringkasan untuk Dokter Umum

1. **Remaja + Primer Amenorea + Karakter Seksual Normal + Nyeri Perut Siklik = Kelainan Kongenital Obstruktif (Imperforate Hymen #1)**
2. **Diagnosis: Inspeksi Vulva (Himen Imperforata/Septum) + USG (Hematometra + Hematokolpos + Ovarium Normal) + MRI (Anatomi Detail)**
3. **Ginjal WAJIB Dicek (USG/MRI)** — Asosiasi Renal Agenesis/Ektopia (MRKH, OHVIRA)
4. **Operasi Prinsip: Himenotomi/Septum Resection + Evakuasi Total + IRIGASI BERSIH + STENTING 4-6 MINGGU + DILATOR 6-12 BULAN**
5. **Imperforate Hymen: Himenotomi Cruciate + Foley Stent → Sukses > 95%**
6. **Transverse Septum Tipis: Sama Imperforate. Septum Tebal/Total → Vaginoplasti (Vecchietti/Davydov/McIndoe/Sigmoid) — Rujuk SpOG Uroginekologi**
7. **Cervical Agenesis: Histerektomi + Ovarium Diselamatkan (IVF + Surrogat)**
8. **MRKH: Dilator First-Line (80-90% Sukses). Gagal/Dewasa → Vecchietti Laparoskopik (Gold Standard Operatif)**
9. **OHVIRA: Hemi-Histerektomi Sisi Obstruksi + Preservasi Sisi Normal + Cek Ginjal**
10. **Follow-up Jangka Panjang: Patensi Vagina, Endometriosis, Fertilitas, Fungsi Seks, Psikologis**
