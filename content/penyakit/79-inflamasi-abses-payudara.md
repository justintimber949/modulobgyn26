# Inflamasi & Abses Payudara

## Cerita Pembuka

Ny. Sari, 28 tahun, G2P2A0, bayi usia 3 minggu (menyusui). Keluhan: **payudara kiri bengkak, merah, panas, nyeri hebat seitan 2 hari, demam 38,5°C**. Pemeriksaan: **Payudara kiri: Eritema luas, edema, fluktuasi di kuadran luar atas, nyeri tekan hebat, limfadenopati aksila kiri**. USG: **Koleksi hiperekoik 4×3 cm di kuadran luar atas (abses), vaskularitas dinding ↑**. WBC 18.000, neutrofil 85%. Diagnosis: **Mastitis Puerperal + Abses Payudara Kiri**. Manajemen: **I&D (Incision & Drainage) di Ruang Tindak Kecil + Antibiotik IV (Cefazolin 1g 8 jam + Metronidazol 500 mg 8 jam) + Analgesik + Kompres Hangat + LANJUTKAN MENYUSUI (Bayi di payudara kanan, kiri dipompa/diblas saja)**. 2 hari: demam turun, nyeri ↓, drainase bersih. Kontrol 1 minggu: sembuh total.

## Definisi & Klasifikasi

| Jenis                                 | Definisi                                                                                         | Kelompok Sasaran                      |
| ------------------------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------- |
| **Mastitis Puerperal (Laktasional)**  | Inflamasi payudara pada ibu menyusui (biasanya minggu 2-6 postpartum)                            | Ibu menyusui (10-20%)                 |
| **Mastitis Non-Puerperal**            | Inflamasi payudara tidak berhubungan dengan laktasi                                              | Wanita dewasa (20-50 th), jarang pria |
| **Abses Payudara**                    | Koleksi nanah terlokalisasi di jaringan payudara (komplikasi mastitis)                           | 3-11% mastitis puerperal              |
| **Fistula Payudara**                  | Trakt abnormal antara saluran kelenjar/dilatasi ke kulit (sekunder abses/operasi/infeksi kronik) | Jarang (< 1%)                         |
| **Duct Ectasia**                      | Dilatasi & peradangan saluran kelenjar subareolar (biasanya usia > 40 th)                        | Perimenopause                         |
| **Mastitis Granulomatos (Idiopatik)** | Inflamasi granulomatosa non-kaseosa, etiologi tidak jelas, mirip TB/Sarkoidosis                  | Wanita muda (30-40 th)                |

## Etiologi & Patogenesis

| Faktor                                               | Mekanisme                                                                                                              |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Staphylococcus aureus (MSSA/MRSA)**                | **#1 Patogen Mastitis & Abses** — Masuk via retak puting (fissura) → kolonisasi saluran → infeksi interstisial → abses |
| **Streptokokus, E. coli, Klebsiella, Anaerob**       | Koinfeksi / Non-puerperal                                                                                              |
| **Stasis Susu (Milk Stasis)**                        | **Faktor Risiko Utama Puerperal** — Emptying tidak lengkap, jadwal menyusui kaku, bayi tidak latch baik, oversupply    |
| **Retak Puting (Nipple Fissure/Cracked Nipple)**     | Pintu masuk bakteri → **Mastitis Puerperal Klasik**                                                                    |
| **Kontraksi Payudara (Binding, Bra Ketat, Trauma)**  | Aliran susu terhalang → stasis                                                                                         |
| **Immunokompromised (DM, HIV, Steroid, Kemoterapi)** | Risiko infeksi berat & atypical organism ↑                                                                             |
| **Rokok**                                            | Risiko Abses Subareolar & Fistula ↑↑ (Vasokonstriksi, kerusakan saluran)                                               |

## Gejala & Tanda

| Stadium                        | Gejala & Tanda                                                                                                                                        |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Mastitis Awal (Infiltrasi)** | Nyeri, bengkak, merah, panas **lokal** (1 kuadran), demam ringan (38-38,5°C), malaise, susu keluar normal/kurang                                      |
| **Mastitis Berat / Sistemik**  | Demam tinggi > 38,5°C, kapungan, tachycardia, nyeri hebat, eritema luas > 5 cm, **Red Streaks (Lymphangitis)**                                        |
| **Abses Payudara**             | **Fluktuasi** (palpasi), kulit di atas tipis & biru-ungu, **Pointing** (nanah mau keluar), nyeri tekan hebat, demam persist > 48 jam trotz antibiotik |
| **Fistula Payudara**           | **Sinus/Orifis di kulit/areola**, keluar nanah/susu berkala, riwayat abses/operasi berulang, nyeri ringan                                             |
| **Duct Ectasia**               | Nyeri subareolar, retak puting, sekret kental hijau-kuning/coklat, retaksional areola, bisa massa subareolar                                          |
| **Mastitis Granulomatos**      | Massa payudara keras, tidak nyeri/ringan, kulit di atas bisa merah/ulserasi, mirip kanker (butuh biopsi)                                              |

## Diagnosis & Workup

### 1. Klinis (Cukup untuk Mastitis Awal)

- **Mastitis:** Eritema segitiga/luas, panas, nyeri, demam, riwayat menyusui/retak puting
- **Abses:** **Fluktuasi + Pointing + Demam Persist > 48 jam** — **Tanda Kunci: Fluktuasi**

### 2. USG (Gold Standard Abses & Diferensial)

| Temuan                                                                       | Signifikansi                                                                  |
| ---------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **Koleksi Hiperekoik/Anekoik dengan Dinding Tebal + Vaskularitas Dinding ↑** | **Abses (Sensitivitas 95%, Spesifisitas 90%)**                                |
| **Edema Jaringan Difus, Kelenjar Diperbesar, Vaskularitas ↑**                | Mastitis (tanpa abses)                                                        |
| **Massa Solid Heterogen, Vaskularitas ↑, Mikrokalsifikasi**                  | **Curiga Karsinoma Inflamatori / Phyllodes / TB Payudara** — **Biopsi WAJIB** |
| **Dilatasi Saluran Subareolar + Debris**                                     | Duct Ectasia                                                                  |
| **Trakt Hiperekoik dari Massa ke Kulit**                                     | Fistula / Sinus                                                               |

### 3. Lab

| Pemeriksaan                                       | Kegunaan                                                                                 |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **WBC + Diff**                                    | Leukositosis + Neutrofilia (Infeksi Bakteri)                                             |
| **Prokalsitonin / CRP**                           | Seviritas sepsis / monitoring respons                                                    |
| **Kultur Nanah (Swab I&D)**                       | **Identifikasi Patogen + Sensitivity (S + Sensitivity** — **WAJIB untuk MRSA Screening** |
| **Gula Darah (Jika DM Tidak Diketahui)**          | Rule out DM (risiko abses berulang)                                                      |
| **Prolaktin, TSH (Jika Non-Puerperal/Recurrent)** | Rule out Hiperprolaktinemia / Hipotiroid                                                 |

### 4. Biopsi (Core Needle / Incisional)

- **Indikasi:** Massa solid tidak typical abses, tidak respons antibiotik 48-72 jam, curiga Karsinoma Inflamatori / Phyllodes / TB / Granulomatous Mastitis
- **WAJIB Sebelum Operasi Definitif Jika Ragu Malignancy**

## Tata Laksana

### A. Mastitis Puerperal (Tanpa Abses) — **Konservatif**

| Intervensi                                               | Detail                                                                                                                                                                                             |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **LANJUTKAN MENYUSUI / POMPA SUSU**                      | **#1 Terapi** — Emptying payudara penuh setiap 2-3 jam (bayi langsung / pompa). **JANGAN STOP ASI** (Stasis → Abses ↑)                                                                             |
| **Antibiotik Empiris (10-14 Hari)**                      | **Dicloxacillin 500 mg 6 jam PO** (MSSA) / **Cefazolin 1g 8 jam IV** (Inpatient/Severe) / **Clindamycin 300 mg 6 jam PO** (Alergi Penisilin / MRCA Risiko) / **TMP-SMX DS 2 tablet 12 jam** (MRSA) |
| **Analgesik**                                            | Paracetamol 500-1000 mg 6 jam / Ibuprofen 400-600 mg 6 jam (Aman Menyusui)                                                                                                                         |
| **Kompres Hangat (Sebelum Menyusui) + Dingin (Sesudah)** | Hangat: aliran susu. Dingin: edema/nyeri                                                                                                                                                           |
| **Posisi Menyusui Variasi**                              | Drainase semua kuadran                                                                                                                                                                             |
| **Konseling Latch & Posisi**                             | Koreksi latch, hindari jadwal kaku, feed on demand                                                                                                                                                 |

> **Review 24-48 Jam:** Jika demam turun, nyeri ↓, eritema mengecil → Lanjutkan. **Jika Tidak Membaik / Memburuk → USG Cek Abses**

### B. Abses Payudara — **I&D (Incision & Drainage) WAJIB**

| Tahap                                 | Tindakan                                                                                                                                                                                                                                                                                                          |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Stabilisasi**                    | IV Fluids, Analgesik, Antibiotik IV Empiris (Cefazolin + Metronidazol / Pip-Tazo / Meropenem jika Sepsis)                                                                                                                                                                                                         |
| **2. I&D (Prosedur Utama)**           | **Anestesi Lokal (Lidokain 1% + Epinefrin) / Blok Region / GA** — **Insisi Radial (Mengikuti Garis Langer) di Area Fluktuasi/Pointing** — **HINDARI Insisi Sirkumareolar (Risiko Fistula & Deformitas Areola)** — Drainase Total, Irigasi Salin 0,9% Bersih, **Penghilangan Lokulasi (Jari/Penghancur Lokulasi)** |
| **3. Drainase Pasif**                 | **Pen Drain (Penrose) / Kateter Pigtail (USG-Guided Jika Dalam)** — 3-5 Hari                                                                                                                                                                                                                                      |
| **4. Kultur Nanah**                   | **WAJIB** (Aerob + Anaerob) — Target Terapi 48-72 Jam                                                                                                                                                                                                                                                             |
| **5. Antibiotik Terapi (10-14 Hari)** | Sesuai Sensitivity: MSSA → Dicloxacillin/Cefazolin. MRSA → Clindamycin/TMP-SMX/Linezolid/Vancomisin (IV). Anaerob → Metronidazol/Clindamycin                                                                                                                                                                      |
| **6. Lanjutkan Menyusui/Pompa**       | **Payudara Terinfeksi: Pompa/Diblasi (Buang Susu Jika Nanah Banyak / Sepsis) — Bayi Diberi Susu Payudara Satu Sisi / Formula Sementara**. Payudara Satu Sisi Normal: Lanjut Menyusui.                                                                                                                             |

### C. Fistula Payudara

| Tahap                                                         | Tindakan                                                                                                                              |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Kontrol Infeksi**                                        | Antibiotik, Drainase Jika Abses Aktif                                                                                                 |
| **2. Evaluasi Anatomi**                                       | **USG / MRI / Fistulogram / Methylene Blue Injection** — Panjang, Cawangan, Hubungan Saluran Kelenjar                                 |
| **3. Operasi Definitif (Elektif, Setelah Sejuk 6-12 Minggu)** | **Fistulektomi (Eksisi Trakt Fistula Total) + Primary Closure / Flap (Jika Defek Besar)** — **Preservasi Areola-Puting Jika Mungkin** |
| **4. Biopsi**                                                 | **WAJIB** Rule out Karsinoma (Paget, Infiltratif) / TB                                                                                |

### D. Duct Ectasia

- **Konservatif:** Kompres Hangat, NSAID, Antibiotik Jika Infeksi Sekunder (Periductal Mastitis)
- **Operasi (Jika Gagal Konservatif / Fistula / Massa):** **Mikrodoktotomi / Eksisi Saluran Subareolar (Hadfield's Operation)** — Preservasi Puting

### E. Mastitis Granulomatos

- **Diagnosis:** Biopsi (Non-kaseating Granuloma, Negatif AFB/TB PCR, Negatif Sarkoidosis)
- **Terapi:** **Prednison 0,5-1 mg/kg/hari (4-8 Minggu) + Tapering** — Respons Baik. Jika Gagal: MTX / Azathioprin. **Operasi (Wide Excision) Jika Gagal Medis / Rule Out Kanker**

## Tanda Bahaya (Red Flags → Rujuk SpOG/Bedah Onkologi SEGERA)

| Red Flag                                                                           | Artinya                                                                                  |
| ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **Massa Payudara Keras, Tidak Bergerak, Kulit Di Atas Ultrasonik (Peau d'Orange)** | **Karsinoma Inflamatori (T4d)** — Butuh Biopsi + PET-CT + Neoadjuvant Chemo              |
| **Abses / Massa Tidak Respons Antibiotik + I&D 72 Jam**                            | Atypical Organism / TB / Malignancy / Imunosupresi                                       |
| **Fistula Berulang / Multiple Fistula / Fistula Tanpa Riwayat Abses Jelas**        | **TB Payudara / Karsinoma / Actinomyces / Hidradenitis Suppurativa**                     |
| **Pria + Massa Payudara / Abses**                                                  | **Karsinoma Payudara Pria (Rare tapi Agresif) / Ginekomastia Komplikasi** — Biopsi WAJIB |
| **Demam Tinggi + Sepsis + Hemodinamik Tidak Stabil**                               | **Sepsis Payudara** — ICU, Broad Spectrum Abx, Source Control (I&D/Debridement)          |

## Pencegahan Mastitis Puerperal

| Upaya                                                | Target                                        |
| ---------------------------------------------------- | --------------------------------------------- |
| **Latch & Posisi Benar**                             | Hindari Retak Puting (Pintu Masuk Bakteri #1) |
| **Feed On Demand (Bukan Jadwal Kaku)**               | Hindari Stasis Susu                           |
| **Variasi Posisi Menyusui**                          | Drainase Semua Kuadran                        |
| **Hindali Bra Ketat / Binding**                      | Aliran Susu Lancar                            |
| **Hygiene Puting (Air Bersih, Hindari Sabun Keras)** | Integritas Kulit Puting                       |
| **Konseling Antenatal Menyusui**                     | Siapkan Ibu Mental & Teknis                   |

## Ringkasan untuk Dokter Umum

1. **Mastitis Puerperal = Infeksi Payudara Ibu Menyusui (S. aureus #1)** — **LANJUTKAN MENYUSUI/POMPA (#1 Terapi!)** + Antibiotik 10-14 Hari
2. **Abses = Fluktuasi + Demam Persist > 48 Jam** → **I&D WAJIB (Insisi Radial, Hindari Sirkumareolar) + Drainase + Kultur + Abx Target**
3. **Red Flags:** Massa Keras Tidak Bergerak (Karsinoma Inflamatori), Tidak Respons 72 Jam (TB/Malignancy), Fistula Berulang (TB/Kanker), Sepsis (ICU)
4. **Non-Puerperal / Pria:** **Biopsi WAJIB** Rule Out Kanker (Gynekomastia ≠ Diagnosis Enforce Tanpa Biopsi)
5. **Fistula:** Elektif Setelah Sejuk (6-12 Mgg), Fistulektomi + Flap, Biopsi
6. **Duct Ectasia:** Konservatif Dulu (Kompres, NSAID), Operasi (Mikrodoktotomi) Jika Gagal
7. **Pencegahan:** Latch Benar + Feed On Demand + Variasi Posisi + Hindari Bra Ketat
