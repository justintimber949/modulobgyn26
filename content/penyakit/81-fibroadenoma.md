# Fibroadenoma Mammae (FAM)

## Cerita Pembuka

Ny. Sari, 22 tahun, mahasiswi, G0, keluhan: **benjolan payudara kiri luar atas seitan 6 bulan, lambat membesar, tidak nyeri**. Pemeriksaan: **Massa soliter 3×2,5 cm, batas tegas, licin, lentur, mudah digerakkan ("mouse"), tidak melekat kulit/dinding dada, puting normal, limfa aksila tidak teraba**. USG: **Massa hiperekoik, oval, margin tegas, orientasi paralel kulit, posterior acoustic enhancement, tanpa vaskularitas internal (BIRADS 2)**. FNAB: **Sel epitel kelenjar berbaris + stroma fibromiksoid (C2 Benign)**. Diagnosis: **Fibroadenoma Mammae Kiri**. Manajemen: **Follow-up USG 6 bulanan (pasien menolak operasi)**. 12 bulan: stabil 3 cm, tidak membesar. 24 bulan: mengecil 2 cm.

## Definisi & Epidemiologi

**Fibroadenoma (FAM)** = **Tumor Jinak Payudara #1** — Neoplasia **Biphasik** (Komponen **Epitel Kelenjar** + **Stroma Konjunktif**) — **Klonik (Monoklonal)** tapi **Bukan Kanker**.

| Parameter       | Data                                                                               |
| --------------- | ---------------------------------------------------------------------------------- |
| **Usia Puncak** | **15-35 Tahun** (Remaja & Dewasa Muda)                                             |
| **Insidensi**   | **10-15% Wanita** (Autopsi: hingga 20%)                                            |
| **Lokasi**      | Kuadran Luar Atas (50%), Bisa Bilateral (10-15%), Multifokal (15%)                 |
| **Ukuran**      | **1-3 cm (Kebanyakan)**, Bisa > 5 cm (Giant), Bisa Regresi Spontan (Postmenopause) |
| **Perilaku**    | **Hormon-Dependent** (Membesar: Kehamilan, OCP, HRT; Mengecil: Menopause, GnRHa)   |

## Jenis-jenis Fibroadenoma

| Tipe                                          | Karakteristik                                                                                                                 | Signifikansi                                                    |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| **Simple FAM (Classic)**                      | < 3 cm, Histologi Seragam, Tanpa Komponen Kompleks                                                                            | **Palting Umum (90%)**, Risiko Kanker = Pop Umum (RR 1.0)       |
| **Complex FAM**                               | **Mempunyai ≥ 1: Sklerosis Adenosis, Kalsifikasi Mikro, Kista > 3 mm, Papillary Apocrine Metaplasia, Epithelial Hyperplasia** | **RR Kanker 1.5-2×** (Mirip UDH) — Follow-up Ketat              |
| **Giant FAM**                                 | **> 5 cm (Atau > 500 g)** — Remaja/Dewasa Muda                                                                                | Cepat Membesar, Bisa Kompresi Kulit/Nekrosis — **Eksisi WAJIB** |
| **Juvenile FAM**                              | **Remaja (10-18 Th), Cepat Membesar, Bisa > 10 cm**, Hipervaskuler                                                            | Bisa Jadi Giant — **Eksisi Jika > 3-4 cm / Cepat Membesar**     |
| **FAM dengan Atypical Hyperplasia (ADH/ALH)** | Komponen ADH/ALH di dalam FAM                                                                                                 | **RR Kanker 4-5×** — **Eksisi Lengkap + Surveillance Ketat**    |

## Gejala & Tanda

| Gejala                        | Frekuensi                                                               |
| ----------------------------- | ----------------------------------------------------------------------- |
| **Massa Palpabel (Benjolan)** | **100%** — Soliter, Tegas, Lentur, "Mouse" (Bisa Diggeser), Tidak Nyeri |
| **Nyeri (Mastalgia)**         | < 10% (Biasanya Premenstrual / Kompresi Saraf)                          |
| **Perubahan Kulit / Puting**  | **Jarang** (Jika Ada → Curiga Phyllodes / Kanker)                       |
| **Cepat Membesar**            | **Red Flag** — Phyllodes / Kanker / Giant FAM                           |

## Diagnosis & Workup

### 1. Klinis (Anamnesis + Pemeriksaan)

- **Massa Soliter, Tegas, Lentur, Bisa Diggeser ("Mouse"), Tidak Nyeri, Batas Tegas** → **Khusus FAM (PPV > 90% Usia < 30 Th)**

### 2. USG (First-Line, Wajib)

| Temuan USG Khusus FAM                                                                                                                                                                                     | BIRADS                             |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------- |
| **Massa Hiperekoik / Isoekoik, Oval/Bulat, Margin Tegas (Sirkumskrip), Orientasi Paralel Kulit (Wider-than-Tall), Posterior Acoustic Enhancement, Tanpa Vaskularitas Internal (Atau Minimal Di Perifer)** | **BIRADS 2 (Benign) — Khusus FAM** |
| **Heterogen, Lobo-lobo, Vaskularitas ↑, Cepat Membesar**                                                                                                                                                  | **BIRADS 3/4 — Curiga Phyllodes**  |

> **USG Spesifisitas FAM: 95%+ Jika Kriteria Lengkap Terpenuhi** — FNAB/Core Biopsy **TIDAK WAJIB** Usia < 25 Th + Klinis + USG Khusus FAM (BIRADS 2). **Usia ≥ 25 Th / Ragu / Kompleks → Biopsy WAJIB.**

### 3. Mammografi (Usia ≥ 35-40 Th / Screening)

- **Massa Oval/Bulat, Margin Tegas/Sirkumskrip, Densitas Sama/Leih Tinggi, Bisa Kalsifikasi Popcorn/Coarse (Stroma Hialinisasi)** — BIRADS 2
- **Jika Ragu (Margin Tidak Tegas, Spikulasi) → BIRADS 4 → Biopsi**

### 4. Biopsi (Konfirmasi Histopatologis)

| Metode                                         | Indikasi                                                                                                                                              |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FNAB (Fine Needle Aspiration Biopsy)**       | **Screening Cepat, Murah** — Sensitivitas 85-90%, Spesifisitas 95%+ — **Tidak Bisa Beda Simple vs Complex vs Phyllodes**                              |
| **Core Needle Biopsy (CNB / Tru-Cut 14G/16G)** | **Gold Standard Non-Operatif** — Bisa Grading (Simple/Complex), Bisa Beda FAM vs Phyllodes (Stroma Seluleritas, Mitosis) — **Preferred Usia ≥ 25 Th** |
| **Vacuum-Assisted Biopsy (VAB / Mammotome)**   | **Eksisi Lengkap Lump Kecil (< 2 cm) Tanpa Operasi** — Terapi + Diagnosis                                                                             |
| **Eksisi Operatif (Lumpektomi)**               | **Definitif** — Giant, Phyllodes, Complex + ADH, Keinginan Pasien                                                                                     |

## Tata Laksana

### A. Observasi (Watchful Waiting) — **First-Line Usia < 25 Th / Simple FAM < 3 cm**

| Kriteria Observasi                                               | Protokol                                                                             |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **Usia < 25 Th + Klinis Khusus FAM + USG BIRADS 2**              | **Tidak Perlu Biopsi** — Edukasi, Reassurance, **USG 6 Bulanan × 2 Tahun → Tahunan** |
| **Usia 25-35 Th + Simple FAM < 2-3 cm + Pasien Menolak Operasi** | **CNB Konfirmasi → Jika Simple FAM → Observasi USG 6 Bulanan**                       |
| **Postmenopause / HRT Stop**                                     | **Regresi Spontan Umum** — Observasi Saja                                            |

> **Kapan Observasi BERHENTI → Operasi:** Membesar > 20% dalam 6 bln / > 3 cm / Gejala / Kompleks / Atipia / Phyllodes / Keinginan Pasien.

### B. Eksisi Operatif (Lumpektomi) — **Indikasi**

| Indikasi                                    | Detail                                              |
| ------------------------------------------- | --------------------------------------------------- |
| **Ukuran > 3 cm (Atau > 2 cm Usia Remaja)** | Risiko Giant, Kompresi, Kosmetik                    |
| **Cepat Membesar (> 20% / 6 Bln)**          | Curiga Phyllodes / Kanker                           |
| **Complex FAM (Histopat)**                  | RR Kanker ↑, Follow-up Sulit                        |
| **FAM + ADH/ALH**                           | Rule Out DCIS/Invasif, Chemoprevention              |
| **Giant / Juvenile FAM**                    | WAJIB Eksisi                                        |
| **Phyllodes Tumor (Curiga/Konfirm)**        | **Eksisi Margin Lebar (1-2 cm) — Tidak Enukleasi!** |
| **Keinginan Pasien (Kosmetik / Kecemasan)** | Informed Consent, Shared Decision                   |
| **Kehamilan Direncanakan + FAM > 2 cm**     | Eksisi Sebelum Hamil (Membesar Saat Hamil)          |

### C. Teknik Operasi

| Teknik                                                                  | Keuntungan                                                                                                            |
| ----------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| **Lumpektomi (Open Excision)**                                          | **Gold Standard** — Margin Jelas, Histopat Lengkap, Kosmetik Baik (Insisi Periareolar / Inframamari / Sirkumareolar)  |
| **Vacuum-Assisted Excision (VAE / Mammotome)**                          | **Minimal Invasif, Tidak Jahitan, Kosmetik Terbaik** — Hanya FAM < 2-3 cm, Simple, BIRADS 2/3                         |
| **Cryoablation**                                                        | **Tanpa Insisi, Dingin (-170°C), Lumpektomi Virtual** — FAM < 2 cm, Simple, USG-Visible — **Belum Standar Indonesia** |
| **Enukleasi (Hanya Untuk FAM Simple Kecil < 2 cm, Kosmetik Prioritas)** | **Margin Tidak Diambil** — Risiko Rekurensi Sedikit Lebih Tinggi, **TIDAK Untuk Phyllodes/Complex**                   |

### D. Follow-up Pasca Operasi / Observasi

| Situasi                                     | Interval                                                                       |
| ------------------------------------------- | ------------------------------------------------------------------------------ |
| **Simple FAM Observasi**                    | **USG 6 Bulanan × 2 Th → Tahunan Hingga Menopause**                            |
| **Post-Eksisi Simple FAM (Margin Negatif)** | **USG 6 Bln × 1 Th → Tahunan** (Rekurensi < 5%)                                |
| **Complex FAM / ADH/ALH**                   | **USG + Mammografi 6 Bulan SELAMANYA** + Chemoprevention (Tamoxifen/Raloxifen) |
| **Phyllodes Benign**                        | **USG + Klinis 6 Bln × 2 Th → Tahunan 5 Th** (Rekurensi 10-15%)                |
| **Phyllodes Borderline/Malignant**          | **Onkologi: CT Thoraks/Abdomen, USG 3-6 Bln, Pertimbangkan Mastektomi/RT**     |

## Diferensial Diagnosis (Yang Harus Dikeluarkan)

| Kondisi                | Beda Kunci vs FAM                                                                                      |
| ---------------------- | ------------------------------------------------------------------------------------------------------ |
| **Phyllodes Tumor**    | **Cepat Membesar, > 3-5 cm, Lobo-lobo, Vaskularitas Tinggi, Stroma Seluler, Mitosis** — **BISA GANAS** |
| **Karsinoma Payudara** | **Keras, Tidak Bergerak, Margin Tidak Tegas, Retraksi Kulit/Puting, Limfa Keras** — Usia > 35 Th       |
| **Kista Sederhana**    | **Anekoik, Fluktuasi, USG: Anekoik Murni** — Bisa Koeksis                                              |
| **Fat Necrosis**       | **Riwayat Trauma/Operasi, Keras, Bisa Mirip Kanker, USG: Minyak/Cystic Hiperekoik + Shadowing**        |
| **Abses**              | **Nyeri, Merah, Panas, Demam, Fluktuasi**                                                              |
| **Lipoma**             | **Lembut, Subkutan, Bukan Di Parenkim Payudara**                                                       |

## Ringkasan untuk Dokter Umum

1. **FAM = Tumor Jinak Payudara #1 (Usia 15-35 Th)** — **Massa "Mouse": Soliter, Tegas, Lentur, Bisa Diggeser, Tidak Nyeri**
2. **USG Khusus: Hiperekoik, Oval, Margin Tegas, Paralel Kulit, Enhancement Posterior = BIRADS 2 (Benign)**
3. **Usia < 25 Th + Klinis + USG Khusus = Bisa Tanpa Biopsi (Observasi Saja)** — Usia ≥ 25 Th / Ragu → **Core Needle Biopsy WAJIB**
4. **Simple FAM < 3 cm: Observasi USG 6 Bulanan (First-Line)** — **Indikasi Operasi: > 3 cm, Cepat Membesar, Gejala, Kompleks, Atipia, Phyllodes, Keinginan Pasien**
5. **Complex FAM = Risiko Kanker 1.5-2× → Surveillance Ketat (USG+Mammo 6 Bln) + Chemoprevention**
6. **Phyllodes = Beda Entitas! Cepat Membesar, Vaskular, Lobo-lobo → Eksisi Margin Lebar (1-2 cm), BUKAN Enukleasi**
7. **Giant FAM (> 5 cm) / Juvenile → Eksisi WAJIB**
8. **Rekurensi Post-Eksisi Simple FAM < 5% | Complex/Phyllodes 10-20%+**
