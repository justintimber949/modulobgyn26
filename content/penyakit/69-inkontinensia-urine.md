# Inkontinensia Urine (Urinary Incontinence)

## Cerita Pembuka

Ny. Sari, 42 tahun, G3P3A0, keluhan "kencing tidak tahan saat batuk/tersedak/ollehraga" seitan 2 tahun. Riwayat: 3× persalinan normal, bayi terbesar 3800 g. Pemeriksaan: POP-Q stadium 1 (sistokel ringan), stres test positif (kencing keluar saat Valsalva). Urodinamika: **Inkontinensia Stres Urodinamik (USI)** — tekanan leak point 65 cmH2O, detrusor stabil. Pengobatan: Pelvic floor muscle training (Kegel) 3×/hari 3 bulan + lifestyle (kurangi kafein, BB turun 5 kg). Hasil: gejala membaik 70%, tidak butuh operasi.

## Definisi & Klasifikasi

**Inkontinensia Urine** = **keluarnya urin tidak kehendak** yang mengganggu kualitas hidup / higiene / sosial.

| Tipe                                                           | Definisi                                                                                           | Mekanisme                                                                                                   | Prevalensi               |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ------------------------ |
| **Inkontinensia Stres (SUI)**                                  | Kencing keluar saat **tekanan intra-abdomen naik** (batuk, tersedak, tawa, olahraga, angkat beban) | **Hipermobilitas uretra / defek sphincter intrinsik** → uretra tidak tertutup saat tekanan naik             | **50-60%** (paling umum) |
| **Inkontinensia Urgensi (UUI) / Overactive Bladder (OAB) Wet** | **Dorongan kencing mendadak & kuat (urgency)** diikuti kebocoran sebelum mencapai toilet           | **Overactive Detrusor** (kontraksi tidak terinhibisi, neurogenik / idiopatik / iritasi)                     | 20-30%                   |
| **Inkontinensia Campuran (MUI)**                               | Kombinasi SUI + UUI                                                                                | Kombinasi mekanisme di atas                                                                                 | 20-30%                   |
| **Inkontinensia Overflow**                                     | Kencing tetes-tetes / tidak tahan karena **kejenuhan kandungka** (retensi urin kronik)             | **Obstruksi keluar (uretra striktur, prostatic hyperplasia, fecal impaction) / Detrusor arefliek/hipotoni** | < 5%                     |
| **Inkontinensia Fungsional**                                   | Sistem urin normal tapi **tidak bisa mencapai toilet** (mobilitas, kognitif, lingkungan)           | Eksternal                                                                                                   | Lanjut usia              |
| **Inkontinensia Kontinu**                                      | Kebocoran terus-menerus                                                                            | **Fistula (VVF, UVF), ektropi uretra, anomali kongenital**                                                  | Jarang                   |

## Epidemiologi & Faktor Risiko

| Faktor Risiko                                                           | Mekanisme                                                   |
| ----------------------------------------------------------------------- | ----------------------------------------------------------- |
| **Persalinan Vaginal (terutama instrumental, bayi besar, fase 2 lama)** | Trauma otot pelvic floor, pudendal nerve, fascia endopelvik |
| **Usia / Menopause**                                                    | Hipestrogenisme → atrofi uretra, kolagen ↓, elastisitas ↓   |
| **Obesitas (BMI > 30)**                                                 | Tekanan intra-abdomen kronik ↑                              |
| **Kebiasaan: Batuk kronik (ASMA/COPD), Konstipasi, Angkat beban berat** | Tekanan berulang pada pelvic floor                          |
| **Histerektomi / Operasi Pelvik**                                       | Denervasi / kerusakan struktur pendukung                    |
| **Genetik / Kolagenopati**                                              | Jaringan ikat lemah (Ehlers-Danlos, Marfan)                 |
| **Obat: Diuretik, Alfa-bloker, Antidepressan, Sedatif**                 | Efek farmakologis                                           |

## Diagnosis

### 1. Anamnesis Terstruktur (WAJIB)

| Pertanyaan Kunci                                                    | Tujuan                   |
| ------------------------------------------------------------------- | ------------------------ |
| **Kapan kencing keluar?** (Saat batuk/olahraga vs mendadak urgency) | Beda SUI vs UUI          |
| **Berapa sering? Volume berapa?** (Tetes vs cup)                    | Keparahan                |
| **Berapa kali BAK siang/malam?** (Frekuensi, nocturia)              | OAB / Polyguria          |
| **Rasa tidak habis BAK? Aliran lemah? Perlu push?**                 | Obstruksi / Overflow     |
| **Nyeri BAK / Darah urine / Infeksi berulang?**                     | Patologi lain            |
| **Kualitas hidup (ICIQ-UI SF / I-QOL / Pad Test)**                  | Skor keparahan & outcome |
| **Riwayat persalinan, operasi, obat, komorbid**                     | Etiologi                 |

### 2. Pemeriksaan Fisik

| Pemeriksaan                              | Temuan Khusus                                                                            |
| ---------------------------------------- | ---------------------------------------------------------------------------------------- |
| **Inspeksi Vulva/Perineum**              | Atrofi estrogen (kusam, tipis), ektropi uretra, fistula, luka                            |
| **Stres Test (Valsalva/Cough)**          | **Positif = Urin keluar saat batuk/Valsalva** (SUI) — lakukan kandungga penuh 200-300 mL |
| **Q-tip Test**                           | Mobilitas uretra > 30° dari horizontal = hypermobility                                   |
| **Pelvic Floor Muscle (PFM) Assessment** | Kekuatan (Oxford 0-5), endurance, fast contraction, koordinasi                           |
| **POP-Q**                                | Prolaps (sistokel, retokel, uterin, vault) — sering comorbidity                          |
| **Neurologis**                           | Refleks anal, saddle anesthesia, lower motor neuron signs                                |

### 3. Investigasi Pendukung

| Pemeriksaan                                                     | Indikasi                                                                                                                                                                   |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Urin Analisis + Kultur**                                      | WAJIB — rule out UTI, hematuria, glikosuria                                                                                                                                |
| **Post-Void Residual (PVR) USG / Kateter**                      | **WAJIB** — rule out overflow (> 100 mL abnormal)                                                                                                                          |
| **Bladder Diary 3 Hari**                                        | Volume, frekuensi, urgency, kebocoran, cairan masuk — **Gold Standard Non-Invasif**                                                                                        |
| **Pad Test (1 jam / 24 jam)**                                   | Kuantifikasi kebocoran objektif                                                                                                                                            |
| **Urodinamika (Multichannel Cystometry + Pressure-Flow Study)** | **Sebelum operasi / Diagnosis ragu / Gagal terapi konservatif / MUI / Neurogenic** — SUI: Valsalva leak point pressure (VLPP), UUI: Detrusor overactivity, Obstruksi: BOOI |
| **USG Kandung Kemih / Uretra**                                  | Anatomi, divertikulum, massa, sisa urine                                                                                                                                   |
| **Sistoskopi**                                                  | Jika hematuria / UTI berulang / anomali urodinamika / pra-operasi sling                                                                                                    |

## Tata Laksana Berbasis Tipe

### A. Inkontinensia Stres (SUI) — **First-Line: Konservatif**

| Modalitas                                       | Detail                                                                                                                                                                                               | Evidensi                                            |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| **Pelvic Floor Muscle Training (PFMT / Kegel)** | **First-line Level 1A** — 3 set × 8-12 reps × 3×/hari (kontraksi 6-8 detik, istirahat 6-8 detik) + fast contractions. **Supervised oleh fisioterapis pelvic floor > home alone**. Minimal 3-6 bulan. | **Kurangi episodes 50-70%, Cure 17-30%** (Cochrane) |
| **Lifestyle Modification**                      | BB turun 5-10% (jika obesitas), kurangi kafein/alkohol/asam, stop rokok, atasi konstipasi (serat, air), atasi batuk kronik                                                                           | Modest benefit, synergis PFMT                       |
| **Pessarium (Ring/Kubus/Inkontinensia)**        | Device intravaginal menopang uretra/bladder neck — untuk yang tidak mau/boleh operasi                                                                                                                | Sementara, adherence ~ 50%                          |
| **Estrogen Topikal Vaginal (Krim/Tablet/Ring)** | Jika atrofi postmenopause — perbaiki mukosa uretra & vascularitas                                                                                                                                    | Adyuvan, bukan monotherapy SUI                      |
| **Kontrasepsi/Device Eksternal**                | Inkontinensia clamp, penile clamp (pria), external collector                                                                                                                                         | Paliatif                                            |

> **Jika Gagal Konservatif 3-6 Bulan → Rujuk SpOG/Urologi untuk Operasi**

#### Operasi SUI (Gold Standard: Mid-Urethral Sling)

| Prosedur                                               | Indikasi                                                                          | Sukses Rate                | Komplikasi Utama                                                                              |
| ------------------------------------------------------ | --------------------------------------------------------------------------------- | -------------------------- | --------------------------------------------------------------------------------------------- |
| **Retropubic MUS (TVT / TVT-O / Monarc)**              | **SUI murni / dominan, urodinamika konfirmasi**                                   | **85-95% (5-10 th)**       | Vaginal erosion (1-3%), retensi urin (2-5%), groin pain (TOT), vaskuler/visceral injury (TVT) |
| **Transobturator MUS (TOT / TVT-O / Monarc)**          | Sama, lebih aman vaskuler                                                         | 80-90%                     | Groin pain (5-15%), vaginal erosion (1-2%)                                                    |
| **Single-Incision Sling (Mini-sling)**                 | Pilihan minim invasif                                                             | 70-80% (data lebih pendek) | Kurang data long-term                                                                         |
| **Bulking Agent (Macroplastique, Bulkamid, Coaptite)** | SUI ringan, intrinsic sphincter deficiency (ISD), usia lanjut, high risk anestesi | 50-70% (butuh repeat)      | Migrasi, abses, retensi                                                                       |
| **Burch Colposuspension (Open/Laparoskopik)**          | SUI + Prolaps (kombinasi) / Gagal sling                                           | 80-85%                     | Lebih invasif, retensi ↑                                                                      |
| **Pubovaginal Sling (Autologus Fascia / Allograft)**   | Gagal MUS, ISD berat, radiasi pelvik                                              | 85-90%                     | Autologus: morbidity donor site; Allograft: erosie ↑                                          |

> **Urodinamika WAJIB SEBELUM OPERASI SUI** (POGI/IUGA) — konfirmasi USI, rule out detrusor overactivity, VLPP, BOOI.

### B. Inkontinensia Urgensi (UUI) / Overactive Bladder (OAB) Wet

| Tahap                                           | Terapi                                                                                                                                                                                                                                                    | Dosis & Catatan                                                                                                                   |
| ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **1. Behavioral (First-Line)**                  | **Bladder Training** (scheduled voiding, urge suppression techniques: pelvic floor contraction, distraction, breathing), **Fluid Management** (1,5-2 L/hari, kurangi iritan: kafein, alkohol, asam, buatan), **Constipation Management**, **Weight Loss** | 6-12 minggu trial                                                                                                                 |
| **2. PFMT + Biofeedback**                       | Pelvic floor training khusus urge suppression ("The Knack" — kontraksi PFM sebelum/during urgency)                                                                                                                                                        | Adyuvan behavioral                                                                                                                |
| **3. Farmakologi (Second-Line)**                |                                                                                                                                                                                                                                                           |                                                                                                                                   |
| **Antimuskarinik (Non-selektif / M3-selektif)** | **Oksibutinin IR 5 mg 2-3× / ER 10-30 mg 1×** (selektif M3: **Solifenasin 5-10 mg, Tolterodin ER 4 mg, Darifenasin 7,5-15 mg, Fesoterodin 4-8 mg**)                                                                                                       | **Efek samping: Dry mouth, konstipasi, kognitif (usia lanjut), retensi urin** — pilih M3-selektif & ER untuk kurangi CNS          |
| **Beta-3 Agonist**                              | **Mirabegron 25-50 mg 1×** (selektif β3 → relaksasi detrusor)                                                                                                                                                                                             | **First-choice elderly / antimuskarinik gagal / kontraindikasi** — tidak kognitif, tidak dry mouth signifikan, hipertensi monitor |
| **Kombinasi**                                   | Mirabegron + Solifenasin (SYNERGY trial)                                                                                                                                                                                                                  | Lebih efektif monotherapy                                                                                                         |
| **4. Third-Line (Refraktter)**                  | **OnabotulinumtoxinA (Botox) 100 U intra-detrusor** (sistoskopi, repeat 6-12 bln) — **FDA approved OAB refraktter**                                                                                                                                       | Retensi urin risiko (butuh CIC), UTI ↑                                                                                            |
|                                                 | **Sacral Neuromodulation (InterStim) / PTNS (Percutaneous Tibial Nerve Stimulation)**                                                                                                                                                                     | Neuromodulasi saraf sakral/tibialis — invasif/minim invasif, mahal                                                                |
|                                                 | **Augmentation Cystoplasty / Urinary Diversion**                                                                                                                                                                                                          | Last resort, major surgery                                                                                                        |

### C. Inkontinensia Campuran (MUI)

- **Tata laksana tipe dominan dulu** (SUI → operasi sling; UUI → obat/behavioral)
- **Jika SUI dominan + operasi sling** → 50-70% UUI membaik (urethral stabilization), tapi 10-20% _de novo_ UUI
- **Jika UUI dominan** → obat dulu, evaluasi ulang SUI residual

### D. Inkontinensia Overflow

- **Penanganan Penyebab:** Kateter bersih intermittent (CIC) / indwelling / operasi obstruksi (urethrotomi, TURP pria, feses impaction evacuation)
- **Detrusor Hipotoni/Arefleksik:** CIC jangka panjang, kolinergik (betanechol — evidence lemah), neuromodulasi

### E. Inkontinensia Kontinu (Fistula)

- **VVF (Vesicovaginal Fistula):** Operasi repair (vaginal/abdominal/laparoskopik/robotik) — lihat modul Fistula
- **UVF (Ureterovaginal):** Reimplantasi ureter / stent / nefrostomi

## Ringkasan untuk Dokter Umum

1. **Tanya Tipe:** Stres (batuk/olahraga) vs Urgensi (mendadak butuh toilet) vs Campuran vs Overflow (tetes-tetes, tidak habis BAK)
2. **WAJIB:** Urin analisis + kultur, PVR (USG/kateter), Bladder Diary 3 hari, Stres Test, PFM Assessment
3. **SUI First-Line: PFMT (Kegel) terstruktur 3-6 bulan + Lifestyle (BB, kafein, konstipasi, rokok)** — rujuk fisioterapis pelvic floor
4. **UUI First-Line: Bladder Training + Fluid Management + PFMT** → gagal → **Mirabegron (Beta-3 agonist) first-choice elderly / Oksibutinin/Solifenasin (Antimuskarinik)**
5. **Gagal Konservatif 3-6 bln / Ingin Cepat / Keparahan Berat → Rujuk SpOG/Urologi** untuk Urodinamika & Operasi (MUS = Gold Standard SUI)
6. **PVR > 100 mL = Overflow / Retensi** — rule out obstruksi / detrusor gagal → CIC / Kateter / Rujuk
7. **Kontinu = Fistula / Anomali** — Rujuk SpOG Uroginekologi
8. **Estrogen Vaginal Topikal** adyuvan postmenopause (atrofi uretra)
9. **Kualitas Hidup (ICIQ-UI SF / I-QOL / Pad Test)** — dokumentasi baseline & outcome
