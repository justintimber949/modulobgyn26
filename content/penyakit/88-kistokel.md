# Kistokel (Cystocele / Anterior Vaginal Wall Prolapse)

## Cerita Pembuka

Ny. Siti, 58 tahun, G4P4A0, menopause 8 tahun. Keluhan: **rasa ada benjolan di vagina seitan 2 tahun, semakin besar saat berdiri lama/angkat berat, keluar masuk sendiri saat berbaring, sering BAK (frekuensi 8-10×/hari), kadang kebocoran saat batuk/tersengak (stress UI), NYT**. Pemeriksaan: **POP-Q: Aa +2, Ba +3, C -3, D -7, Ap -2, Bp -2, Genital Hiatus 4 cm, Perineal Body 3 cm → Stadium III Anterior (Kistokel) + Stress UI**. Urodinamika: **Stress UI (VLPP 65 cmH2O), Detrusor Overactivity Tidak Ada, PVR 30 mL**. Manajemen: **Pesarium Ring (Ukuran 70 mm) + Latihan Kegel + Lifestyle (BB Turun 5 kg, Hindari Angkat Berat, Mencegah Sembelit) → 6 Bulan: Gejala ↓, POP-Q Ba +1, Stress UI ↓, Nyaman**. Pilihan Operatif Jika Gagal Konservatif: **Anterior Colporrhaphy + Midurethral Sling (TOT/TVT) Jika Stress UI Terbukti**.

## Definisi & Anatomi

**Kistokel (Cystocele)** = **Prolaps Dinding Anterior Vagina (Front Wall) Sehingga Kandung Kemih (Bladder) Mendesis ke Dalam/Bawah Vagina** — Karena **Kelemahan Fasia Puboservikal (Pubocervical Fascia) & Ligamen Puboservikal** + **Kelemahan Lantai Panggul (Levator Ani)**.

| Struktur Pendukung Normal                                                                                                                                  | Kelemahan → Kistokel                                                                                     |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Fasia Puboservikal (Pubocervical Fascia)** — Menghubungkan Dinding Anterior Vagina ke **Tendinous Arch of Pelvic Fascia (White Line) & Symphysis Pubis** | **Defek Fasia Sentral (Midline) / Lateral (Paravaginal) / Kombinasi** → Bladder Hernia ke Vagina         |
| **Ligamen Puboservikal (Pubocervical Ligaments)** — Stabilisasi Serviks & Vagina Anterior                                                                  | **Pengeroposan/ Putus** → Desensus Serviks + Vagina Anterior                                             |
| **Levator Ani (Puborektalis, Pubokoksigeus, Iliokoksigeus)** — Lantai Panggul Aktif                                                                        | **Denervasi (Pudendal Nerve Injury), Trauma Persalinan, Usia, Hipostrogenisme** → Hiatus Lebar, Desensus |

## Klasifikasi (POP-Q / ICS) — Stadium Anterior (Titik Ba)

| Stadium         | Titik Ba (Poin Paling Depan Dinding Anterior) | Deskripsi Klinis                                                            |
| --------------- | --------------------------------------------- | --------------------------------------------------------------------------- |
| **Stadium 0**   | Ba ≤ -3 cm (Di Atas Himen)                    | Tidak Ada Prolaps                                                           |
| **Stadium I**   | -3 cm < Ba ≤ -1 cm                            | Prolaps Masih Di Atas Himen (Dalam Vagina)                                  |
| **Stadium II**  | -1 cm < Ba ≤ +1 cm                            | **Prolaps Sampai Himen (± 1 cm Atas/Bawah Himen)**                          |
| **Stadium III** | +1 cm < Ba ≤ +(tvL - 2) cm                    | **Prolaps Melebihi Himen Ke Luar (> 1 cm), Tapi Masih Ada Vagina Di Dalam** |
| **Stadium IV**  | Ba > +(tvL - 2) cm                            | **Eversi Total (Procidentia) — Seluruh Vagina Keluar**                      |

> **tvL = Total Vaginal Length (Titik D ke Himen)** — Biasanya 8-10 cm.

### Jenis Defek Fasia (Penting untuk Planning Operasi)

| Jenis Defek                               | Lokasi                                                                                     | Ciri Klinis                                                                                  | Operasi Pilihan                                                                 |
| ----------------------------------------- | ------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **Sentral (Midline / Cystocele Sentral)** | Fasia Puboservikal Putus di Midline (Dehisensi)                                            | **Kistokel Simetris, Bulat, Di Midline**                                                     | **Anterior Colporrhaphy (Plicatura Fasial Midline)**                            |
| **Lateral (Paravaginal)**                 | Fasia Melepas dari **Tendinous Arch (White Line) / Arcus Tendineus Fasciae Pelvis (ATFP)** | **Kistokel Asimetris, Cenderung Satu Sisi, Sering Disertai Stress UI (Urethra Turut Turun)** | **Paravaginal Repair (Abdominal/Laparoskopik/Robot) — Reattach Fascia ke ATFP** |
| **Kombinasi (Sentral + Lateral)**         | Keduanya                                                                                   | **Kistokel Besar, Kompleks**                                                                 | **Kombinasi Anterior Colporrhaphy + Paravaginal Repair**                        |

## Etiologi & Faktor Risiko

| Faktor                                           | Mekanisme                                                                                                                                         |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Persalinan Vaginal (Vaginal Delivery) #1**     | **Trauma Otot/Fasia Levator Ani (Avulsion), Pudendal Neuropati, Peregangan Fascia** — Risiko ↑: Partus Lama, Bayi Besar, Vakum/Forceps, Multipara |
| **Usia & Menopause**                             | **Hipostrogenisme → Kolagen & Elastin ↓, Fascia & Otot Atrofi**                                                                                   |
| **Obesitas (BMI > 30)**                          | **Tekanan Intra-Abdominal Kronik ↑ → Overload Lantai Panggul**                                                                                    |
| **Sembelit Kronik / Batuk Kronik (KOPD/Asma)**   | **Tekanan Intra-Abdominal Repetitif (Valsalva) → Fatigue Jaringan**                                                                               |
| **Angkat Berat Berulang**                        | **Tekanan Tiba-tiba & Berulang**                                                                                                                  |
| **Operasi Panggul Sebelumnya (Histerektomi)**    | **Hilangnya Dukungan Serviks/Uterus (Apical Support) → Kistokel Sekunder (Vault Prolapse → Anterior)**                                            |
| **Genetik / Kolagenopati**                       | **Ehlers-Danlos, Marfan, Kolagen Tipe I/III Ratio Berubah**                                                                                       |
| **Hipotiroid, Diabetes, Steroid Jangka Panjang** | **Jaringan Ikat Lemah**                                                                                                                           |

## Gejala & Tanda

| Gejala Subjektif                                                                     | Tanda Objektif (Inspeksi Spekulum/Bimanual + POP-Q)                                                      |
| ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| **Rasa Ada Benjolan/ Bola di Vagina (Keluar Masuk Saat Berdiri/Berbaring)**          | **Dinding Anterior Vagina Membulut ke Luar (Ba > -1 cm)** — Bisa Dilihat Tanpa Spekulum (Stadium III/IV) |
| **Keluhan BAK: Frekuensi, Urgensi, Nokturia, Ras Tidak Habis (Incomplete Emptying)** | **Uretra & Leher Kandung Kemih Turun (Urethral Hypermobility) — Q-Tip Test > 30°**                       |
| **Inkontinensia Urin Stres (SUI): Kebocoran Saat Batuk/Tersengak/Olahraga**          | **Stress UI Terbukti (Urodinamika / Pad Test) — Sering Disertai Kistokel**                               |
| **Retensi Urin / Sulit BAK / Harus Dorong Benjolan (Splinting) Untuk BAK**           | **Kistokel Besar → Kangling Uretra / Obstruksi Output → PVR ↑**                                          |
| **Dispareunia / Rasa Tidak Nyaman Saat Seks**                                        | **Dinding Anterior Tipis, Erosi / Ulserasi (Jika Stadium IV Keluar Terus)**                              |
| **Nyeri Punggung Bawah / Perut Bawah (Sakit Tarik)**                                 | **Traksi Ligamen & Fascia**                                                                              |

## Diagnosis & Workup

### 1. Klinis (POP-Q Examination — Gold Standard)

- **Posisi Litotomi, Spekulum Simms / Graves (Satu Sisi Saja Untuk Melihat Dinding Anterior Jelas)**
- **Valsalva Maksimal (Tahan Napas, Dorong Seperti BAK)** — Ukur **Titik Aa (3 cm Proksimal Himen), Ba (Titik Paling Depan Dinding Anterior), C (Serviks/Vault), D (Posterior Fornix), Ap, Bp, Gh, Pb**
- **Q-Tip Test (Urethral Hypermobility):** **Sudut > 30° Dari Horizontal = Hipermetropolitan → Risiko SUI & Butuh Sling Jika Operasi**

### 2. Urodinamika (WAJIB Jika Akan Operasi / Gejala BAK Kompleks)

| Parameter                                                        | Signifikansi                                                                           |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **Stress UI (Detrusor Pressure < Abdominal Pressure Saat Leak)** | **Butuh Midurethral Sling (TOT/TVT) Bersama Rekonstruksi**                             |
| **Detrusor Overactivity (DO)**                                   | **Antikolinergik / Beta-3 Agonis Sebelum/Sesudah Operasi**                             |
| **Obstruksi (VOIDING Pressure Tinggi, Flow Rendah)**             | **Kistokel Besar → Kangling Uretra — Perlu Koreksi Anatomi Dulu**                      |
| **PVR (Post Void Residual) > 100 mL**                            | **Retensi → Risiko UTI, Gagal Operasi Jika Tidak Dikoreksi**                           |
| **VLPP (Valsalva Leak Point Pressure) < 60 cmH2O**               | **Intrinsic Sphincter Deficiency (ISD) → Sling Lebih Penting / TOT Lebih Baik vs TVT** |

### 3. Penunjang Lain

| Pemeriksaan                                                   | Indikasi                                                                        |
| ------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| **USG Kandung Kemih (PVR, Batu, Tumor)**                      | **PVR > 100 mL / Hematuria / Gejala Irritatif**                                 |
| **Urin Analisis + Kultur**                                    | **UTI / Hematuria**                                                             |
| **Defekografi / MRI Defekografi (Jika Kompleks / Reoperasi)** | **Evaluasi Kompartemen Lain (Rektokel, Enterokel, Sigmoidokel) Secara Dinamis** |

## Tata Laksana

### A. Konservatif (First-Line: Stadium I-II, Gejala Ringan, Pasien Menolak Operasi, Tidak Layak Anestesi)

| Intervensi                                                                  | Detail & Evidensi                                                                                                                                                                                                                        |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Pesarium (Ring, Gelatin Ring, Cube, Gellhorn, Shaatz, Donut)**            | **First-Line Device — Sukses 60-80% Stadium II-III** — **Fitting Uji Coba (Trial) → Edukasi Pasien Lepas Pasang Bersih Sendiri (Ring/Gelatin) / Kontrol Bulanan (Cube/Gellhorn)** — **Estrogen Vaginal (Estriol 0,5 mg 2×/Mgg) Sinergi** |
| **Latihan Otot Lantai Panggul (PFMT / Kegel)**                              | **Level 1A Evidensi** — **Supervised PFMT 3-6 Bulan → Gejala ↓, Stadium ↓ (Khusus Stadium I-II)** — **Biofeedback / Elektrostimulasi Tambahan Jika Sulit Isolasi Otot**                                                                  |
| **Estrogen Vaginal (Estriol Krim/Ovula/Tablet/Ring)**                       | **Atrofi Vaginal → Mukosa Tebal, Vaskularisasi ↑, Mikrobioma Normal, Pesarium Lebih Nyaman** — **Kontraindikasi: CA Payudara Aktif (Konsul Onkolog)**                                                                                    |
| **Modifikasi Gaya Hidup**                                                   | **BB Turun 5-10% (Jika Obesitas) → Gejala ↓ Signifikan** — **Hindari Angkat Berat > 5-10 kg, Mencegah Sembelit (Serat 25-30 g/hari, Air 2-3 L, Olahraga), Berhenti Rokok (Batuk Kronik), Manejemen Batuk (KOPD/Asma)**                   |
| **Pessarium + PFMT + Estrogen + Lifestyle = Kombinasi Terbaik Konservatif** |                                                                                                                                                                                                                                          |

### B. Operatif (Indikasi: Gagal Konservatif 3-6 Bulan, Stadium III-IV, Gejala Berat, Retensi, Ulserasi, Keinginan Pasien)

| Prosedur                                                                                | Indikasi Spesifik                                                                              | Keuntungan / Catatan                                                                                                                                                                                                                                             |
| --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Anterior Colporrhaphy (Native Tissue Repair / Plicatura Fasial Midline)**             | **Defek Sentral (Midline Cystocele)**                                                          | **Standar Emas Tradisional** — **Residiv 20-30% (5-10 Th)** — **Tanpa Mesh**                                                                                                                                                                                     |
| **Paravaginal Repair (Abdominal / Laparoskopik / Robotik)**                             | **Defek Lateral (Paravaginal) — Sering + Stress UI**                                           | **Reattach Fascia ke ATFP (White Line)** — **Laparoskopik: Visualisasi Lebih Baik, Morbiditas Rendah**                                                                                                                                                           |
| **Anterior Colporrhaphy + Paravaginal Repair (Kombinasi)**                              | **Defek Kombinasi (Sentral + Lateral)**                                                        | **Lebih Komprehensif**                                                                                                                                                                                                                                           |
| **Midurethral Sling (TOT / TVT / Mini-Sling) + Rekonstruksi Anterior**                  | **Stress UI Terbukti (Urodinamika) + Kistokel**                                                | **Sling Diletakkan DULU/SEBELUM Colporrhaphy (Hindari Obstruksi)** — **TOT Lebih Aman Jika ISD / Radiasi / Radiasi Panggul**                                                                                                                                     |
| **Mesh Anterior (Graft Biologis / Sintetis / Komposit) — _KONTROVERSIAL_**              | **Residiv Berulang / Jaringan Sangat Lemah / Pasien Tinggi Risiko Anestesi Untuk Abdominal**   | **FDA Warning 2011/2019: Mesh Transvaginal Anterior Komplikasi Tinggi (Eroosi, Nyeri, Dispareunia, Kontraksi) — **HANYA PUSAT TERAMPIL, INFORMED CONSENT KETAT, REGISTRI** — **Biologis (SIS, Dermis) Residiv Lebih Tinggi Tapi Komplikasi Mesh Lebih Rendah\*\* |
| **Sacrocolpopeksi (Abdominal/Laparoskopik/Robot) + Mesh (Y-Mesh Anterior + Posterior)** | **Prolaps Apical (Vault/Uterus) + Anterior + Posterior (Multikompartemen) / Residiv Berulang** | **Gold Standard Apical Support — Durabilitas Terbaik (90%+ 10 Th)** — **Bisa Dikombinasi Anterior Colporrhaphy Native Tissue**                                                                                                                                   |
| **Histerektomi (Vaginal/Laparoskopik) + Anterior Repair**                               | **Uterus Masih Ada + Prolaps Apical + Anterior**                                               | **Histerektomi Vaginal + Anterior Colporrhaphy = Standar Jika Uterus Ada & Selesai Keturunan**                                                                                                                                                                   |
| **Kolpokleisis (Le Fort / Colpocleisis Total)**                                         | **Lansia (> 75-80 Th), Komorbid Tinggi, Tidak Aktif Seks, Gagal Rekonstruksi Berulang**        | **Obliterasi Vagina (Tutup) — Sukses > 95%, Morbiditas Terendah, Tidak Bisa Seks Penetratif**                                                                                                                                                                    |

## Pasca Operatif & Follow-up

| Waktu                 | Evaluasi                                                                                    |
| --------------------- | ------------------------------------------------------------------------------------------- |
| **Hari 1-2**          | Lepas Kateter (Uretra/Kandung Kemih), Cek PVR (< 100 mL), Mobilisasi, Analgesia             |
| **Minggu 2**          | Cek Luka Vagina, PVR, Gejala BAK, Keluhan Nyeri/Dispareunia                                 |
| **Bulan 1, 3, 6, 12** | **POP-Q, Urodinamika (Jika Gejala BAK Persisten), Kualitas Hidup (PFDI-20, PFIQ-7, PGI-I)** |
| **Tahunan**           | **POP-Q, Screening Residiv, SUI, Disfungsi Seksual, Inkontinensia Fekal**                   |

## Komplikasi Operasi

| Komplikasi                                               | Pencegahan / Penanganan                                                                                                |
| -------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **Residiv Kistokel (20-30% Native Tissue, 10-15% Mesh)** | **PFMT Panjang, Hindari Faktor Risiko, Pessarium Jika Residiv Ringan, Reoperasi Jika Berat**                           |
| **Stress UI Baru / Persisten**                           | **Urodinamika Pre-Op WAJIB → Sling Jika SUI / ISD**                                                                    |
| **Retensi Urin / Obstruksi Uretra**                      | **Hindari Over-Plication, Cek Intraop Uretra Kalibrasi (16-18 Fr), Sling Tension-Free**                                |
| **Eroesi Mesh / Vaginal Exposure (5-15% Mesh Sintetis)** | **Estrogen Vaginal Pre/Post-Op, Hindari Mesh Jika Mungkin, Ekshisi Mesh Kecil + Tutup Vagina, Revisi Besar Jika Luas** |
| **Dispareunia / Nyeri Pelvik Kronik**                    | **Preservasi Vagina Panjang & Lebar, Hindari Over-Tightening, Estrogen, Fisioterapi Pelvik**                           |
| **Fistula Vesikovaginal / Ureterovaginal**               | **Identifikasi Ureter Intraop (Stent/Visual), Hindari Jahitan Mendekati Ureter**                                       |

## Ringkasan untuk Dokter Umum

1. **Kistokel = Prolaps Dinding Anterior Vagina (Bladder Turun) — POP-Q Ba > -1 cm = Stadium ≥ II**
2. **Gejala: Benjolan Vagina, Frekuensi/Urgensi BAK, Stress UI, Retensi, Splinting, Dispareunia**
3. **Diagnosis: POP-Q (Spekulum Simms + Valsalva) + Urodinamika (WAJIB Pre-Op Jika Gejala BAK / Akan Operasi)**
4. **Defek: Sentral (Midline) vs Lateral (Paravaginal) vs Kombinasi — Menentukan Jenis Operasi**
5. **First-Line: Pesarium (Ring/Gelatin/Cube) + PFMT (Kegel) + Estrogen Vaginal + Lifestyle (BB Turun, Hindari Sembelit/Batuk/Berat, Stop Rokok)**
6. **Operasi: Anterior Colporrhaphy (Sentral), Paravaginal Repair (Lateral), Kombinasi, + Sling Jika SUI, Sacrocolpopeksi Jika Apical + Multikompartemen, Kolpokleisis Jika Lansia Tidak Aktif Seks**
7. **Mesh Transvaginal Anterior: **HANYA KASUS TERPILIH (Residiv Berulang, Jaringan Sangat Lemah), PUSAT TERAMPIL, INFORMED CONSENT KETAT, REGISTRI** — Biologis Alternatif Tapi Residiv Lebih Tinggi**
8. **Follow-up: POP-Q + Urodinamika + Kualitas Hidup 1, 3, 6, 12 Bln Lalu Tahunan**
9. **Pencegahan: PFMT Sejak Hamil/Postpartum, Kontrol BB, Hindari Sembelit/Batuk Kronik, Stop Rokok, Estrogen Vaginal Postmenopause**
