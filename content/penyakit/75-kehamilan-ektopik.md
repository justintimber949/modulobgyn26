# Kehamilan Ektopik (Ectopic Pregnancy)

## Cerita Pembuka

Ny. Dewi, 28 tahun, G2P1A0, HPHT 8 minggu lalu. Keluhan: **nyeri perut kanan bawah seitan 2 hari, spotting pervaginam 1 hari, tidak merasa gerakan janin**. TD 110/70, HR 98, suhu normal. Pemeriksaan: dolor perut kanan bawah, adneksa kanan teraba massa dolor, serviks tidak erosi. **β-hCG Kualitatif (+), Kuantitatif 2.450 mIU/mL. USG TV: Endometrium tipis (5 mm), tidak ada kantung gestasional intrauterin, adneksa kanan: kantung gestasial 2,3 cm dengan yolk sac, DJJ (+) 135 bpm, cairan bebas pelvik sedang (anechoik). Diagnostik: Kehamilan Ektopik Tubal Kanan (Ampula) UK ~ 6-7 mg, β-hCG 2.450, Stabil Hemodinamik.** Manajemen: **Metotreksat Single Dosis 50 mg/m2 IM (BSA 1,6 m2 = 80 mg)**. Monitoring β-hCG Hari 0, 4, 7: 2.450 → 1.800 (↓26%) → 950 (↓47% dari H4) — **Sukses (Penurunan ≥ 15% H4-7)**. Kontrol β-hCG mingguan hingga < 5 mIU/mL (minggu ke-5). USG TV kontrol: adneksa normal, tidak ada massa.

## Definisi & Epidemiologi

**Kehamilan Ektopik** = **Implantasi & pertumbuhan blastokista di luar rongga uterus (endometrium)**.

| Lokasi | Persentase | Catatan |
|--------|------------|---------|
| **Tubal (Salpingeal)** | **95-98%** | Ampula (70%), Isthmus (12%), Fimbria (11%), Interstisial (2-3%) |
| **Ovarium** | 0,5-3% | Spiegelberg Criteria: Tuba normal, kista ovarium terlepas, ligamen ovarium proper |
| **Abdominal (Peritoneal, Omentum, Usus, Rahim Broad Ligament)** | 0,1-1% | Sekunder dari tubal abortus / implantasi primer (jarang) |
| **Serviks (Cervical)** | < 0,1% | Risiko perdarahan masif (vaskularisasi serviks) |
| **Cesarean Scar Pregnancy (CSP)** | 0,1-0,2% (↑ dengan SC berulang) | **Implantasi di bekas sayatan SC** — Tipe 1 (endogenik, ke rongga uterus), Tipe 2 (eksogenik, ke vesiko-uterin/serosa) |
| **Heterotrof (Bilokular)** | 1:30.000 spontan, 1:100-500 IVF | **Kehamilan Intrauterin + Ektopik Bersamaan** — Harus dicari USG jika IVF / ovulasi terstimulasi |

**Insidensi:** 1-2% kehamilan (↑ dengan IVF, IUD, riwayat ektopik, PID, operasi tuba).
**Mortalitas Maternal:** ~ 0,05-0,1% (negara maju) — **Penyebab #1 Maternar Death Trimester 1**.

## Faktor Risiko

| Faktor Risiko | OR / Mekanisme |
|---------------|----------------|
| **Riwayat Kehamilan Ektopik Sebelumnya** | **OR 10-20×** (kerusakan silia tuba, adhezi) |
| **PID / Infeksi Salpingitis (Klamidia, Gonore, TB, Non-Spesifik)** | Kerusakan silia & lumen tuba, adhezi peritubal |
| **Operasi Tuba Sebelumnya** (Salpingostomi, Salpingektomi, Sterilisasi, Reanastomosis) | Adhezi, luminal narrowing |
| **IUD Aktif (Kopper/Hormonal)** | **Jika Hamil dengan IUD → Risiko Ektopik ↑ (Absolut jumlah ektopik tidak naik, tapi proporsi di antara kehamilan yg gagal IUD tinggi)** |
| **IVF / Ovulasi Terstimulasi** | **OR 2-4×** (multiple embryo, hyperstimulasi, transfer ke tuba) |
| **Rokok** | Kerusakan silia tuba (nikotin, kadmium) |
| **Endometriosis** | Adhezi peritubal, distorti anatomi |
| **Anomali Kongenital Tuba / Uterus** | Bicornuate, Unicornuate, Rudimentary Horn |
| **Usia > 35 Tahun** | Fungsi tuba menurun |

## Gejala & Tanda (Triad Klasik + Variasi)

| Presentasi | Gejala & Tanda |
|------------|----------------|
| **Klasik (Tubal Ruptur/Impenden Ruptur)** | **Nyeri Perut Tiba-tiba Hebat (Unilateral) + Amenorea/Siklus Terlambat + Perdarahan Vagina (Spotting Coklat/Kuningan) + Tanda Shock (Jika Ruptur)** |
| **Subakut / Tidak Ruptur (Mayoritas Deteksi Dini)** | Nyeri perut pelvik ringan-sedang (unilateral/bilateral), spotting pervaginam, amenorea, gejala kehamilan (mual, payudara tegang) |
| **Ruptur Tubal (Darurat)** | **Nyeri Hebat Tiba-tiba → Nyeri Bahu (Kehr's Sign - Irritasi Diafragma) + Hipotensi + Takikardi + Dingin Keringat + Oliguria + Perut Keras (Guarding) + Cairan Bebas Masif USG** |
| **CSP (Cesarean Scar Pregnancy)** | **Perdarahan Vagina Tanpa Nyeri / Nyeri Ringan** (implantasi di bekas luka SC — vaskularisasi aneh), USG: Kantung gestasial di anterior isthmus, dekat bekas SC, "thin myometrium" di antara kantung & vesika |
| **Kehamilan Serviks** | **Perdarahan Vagina Masif (Tanpa Nyeri Berat)** — Serviks membesar, kelenjar Skene terbuka, darah segar keluar |
| **Kehamilan Ovarium** | Nyeri unilateral, massa adneksa terpisah dari tuba (USG: tuba normal terlihat terpisah) |
| **Kehamilan Abdominal** | Nyeri perut difus, janin teraba superfisial, presentasi abnormal, USG: janin di rongga perut, tidak ada uterus gravid, plasenta pada peritoneum/omentum/usus |

## Diagnosis (Algoritma Terintegrasi)

### 1. **β-hCG Kuantitatif (Serum) — Kunci Diagnosis & Monitoring**
| Pola β-hCG | Interpretasi |
|------------|--------------|
| **Naik < 53% / 48 Jam (atau < 35% / 48 Jam jika > 1500-2000 mIU/mL)** | **Aberan: Ektopik / Aborsi Tidak Lengkap / Kegagalan Kehamilan Intrauterin (Non-viable IUP)** |
| **Naik ≥ 53% / 48 Jam (Normal: Verdubbel ~ 48 Jam di Awal)** | **Kehamilan Intrauterin Normal (IUP)** — TAPI **Heterotrof Bisa Saja Naik Normal** |
| **Plateau / Turun Lambat** | Ektopik / Aborsi Proses / Resolusi Spontan |
| **Diskriminatory Zone (β-hCG Threshold USG TV Bisa Lihat IUP)** | **β-hCG ≥ 1.500-2.000 mIU/mL (Beberapa 3.000-3.500) → Jika USG TV TIDAK ADA IUP = EKTOPIK HINGGA TERBUKTI SEBALIKNYA** |
| **β-hCG < Diskriminatory Zone** | **Tidak Bisa Mengecualikan Ektopik** — Ulangi β-hCG 48 Jam + USG TV Ulang |

### 2. **USG Transvaginal (Gold Standard Anatomi)**
| Temuan USG | Signifikansi |
|------------|--------------|
| **Tidak Ada IUP (Empty Uterus) + β-hCG ≥ Discriminatory Zone** | **Diagnosis Ektopik Presumtif** |
| **Adneksa: Kantung Gestasial + Yolk Sac / Embrion + DJJ** | **Diagnosis Pasti Ektopik (Specificity ~ 100%)** |
| **"Tubal Ring" / "Bagel Sign" / "Doughnut Sign"** | Cincin hiperekoik di adneksa (tuba/ovarium) — Sensitif tapi tidak spesifik (bisa corpus luteum) |
| **Cairan Bebas Pelvik (Anechoik / Hemorrhagic / Echo-debris)** | Hemoperitoneum (Ruptur / Tumpahan) — Volume > 200-300 mL signifikan |
| **Pseudo-gestational Sac (Fluid di Endometrium, Tidak Ada Double Decidual Sign)** | Bisa meniru IUP — **Jangan Salah Diagnosa IUP** |
| **CSP: Kantung Gestasial di Anterior Lower Uterine Segment / Isthmus, Dekat Bekas SC, Myometrium Tipis (< 2-3 mm) Antara Kantung & Vesika** | **Tipe 1 (Endogenik) vs Tipe 2 (Eksogenik)** — Risiko Ruptur Uterus & Perdarahan Masif |
| **Heterotrof: IUP Normal + Adneksa Massa/Kantung Gestasial + DJJ** | **WAJIB Dicari Jika IVF / Stimulasi Ovulasi** |

### 3. **Progesteron Serum (Bantuan)**
- **< 5 ng/mL:** Ektoik / Aborsi Tidak Lengkap / Non-viable IUP (NPV 95%)
- **> 20-25 ng/mL:** IUP Viable (PPV 95%)
- **5-20 ng/mL:** Zona Kelabu — Tidak Diagnostik

### 4. **Laparoskopi (Gold Standard Definitif & Terapeutik)**
- Indikasi: Tidak stabil hemodinamik / Diagnosis ragu / Gagal medis / Persiapan operasi

## Tata Laksana (Berdasarkan Stabilitas & Kriteria)

### A. **Darurat: Shock / Ruptur Tubal / Perdarahan Aktif Masif → LAPAROSKOPI/SC DARURAT SEGERA**
- **Resusitasi ABC:** 2 IV Line 14-16G, Kristaloid 1-2 L Cepat, Darah (PRC) O-Neg/Type-Specific, Traneksam Acid 1 g IV, Vasopresor jika butuh.
- **Operasi:** **Salpingektomi (Preferred — Kurangi Rekuren & Persistensi Trophoblast)** vs **Salpingostomi (Jika Kontraindikasi Salpingektomi: Tuba Kontralateral Hilang/Rusak, Ingin Fertilitas, Tubal Ampula Kecil)**.
- **Otopsia/Histopat:** Konfirmasi produk konsepsi.

### B. **Stabil Hemodinamik: Pilih Medis (MTX) vs Operasi (Laparoskopi)**

#### **Kriteria Metotreksat (MTX) — Single Dose / Multi-Dose**
| Kriteria Inklusi (WAJIB SEMUA) | Kriteria Eksklusi (SATU SAJA CUKUP) |
|--------------------------------|-------------------------------------|
| **Stabil Hemodinamik** | **Shock / Instadilitas / Ruptur Tubal (Cairan Bebas Masif + Tanda Peritonitis)** |
| **β-hCG < 5.000 mIU/mL (Beberapa < 3.500 / < 10.000)** | **β-hCG ≥ 5.000-10.000 mIU/mL (Kegagalan MTX Tinggi)** |
| **Ukuran Massa Ektopik < 3-4 cm (Beberapa < 4-5 cm)** | **Massa ≥ 4-5 cm / DJJ Positif (Kegagalan MTX ↑)** |
| **Tidak Ada Tanda Ruptur / Hemoperitoneum Masif** | **Cairan Bebas Masif / Tanda Peritonitis** |
| **Pasien Kompliance & Bisa Follow-up Ketat (β-hCG H0, H4, H7, Mingguan)** | **Tidak Bisa Follow-up / Non-Compliance / Jarak Jauh Tanpa Akses Lab** |
| **Fungsi Hati & Ginjal Normal (AST/ALT < 2× ULN, Kreatinin Normal)** | **Disfungsi Hati/Ginjal Signifikan** |
| **Trombosit > 100.000, Hb > 9-10 g/dL, WBC > 2.500** | **Sitopenia Signifikan** |
| **Tidak Ada Kontraindikasi MTX Lain** (Infeksi Aktif, Pneumonitis, Peptic Ulcer Aktif, Imunokompromised, Kehamilan Intrauterin Terkonfirmasi) | **Kehamilan Intrauterin Viable Terkonfirmasi (HETEROTROF BISA PAKAI MTX DENGAN HATI-HATI — Risiko Aborsi IUP)** |

#### **Regimen Metotreksat**
| Skema | Dosis & Monitoring |
|-------|-------------------|
| **Single Dose (Paling Umum)** | **MTX 50 mg/m2 BSA IM (atau 1 mg/kg BW IM)** — **Monitoring β-hCG: Hari 0 (Baseline), Hari 4, Hari 7** — **Sukses Jika: Penurunan ≥ 15% dari H4 ke H7** — Jika Tidak → Dosis Ke-2 MTX 50 mg/m2 (Multi-Dose) / Operasi |
| **Multi-Dose (Jika β-hCG Tinggi / Massa Besar / Single Dose Gagal)** | **MTX 1 mg/kg IM Hari 1, 3, 5, 7 + Leukovorin (Folinic Acid) 0,1 mg/kg IV/PO 24 Jam Pascha Setiap Dosis MTX** — Monitoring β-hCG H1, H3, H5, H7, Mingguan |
| **Lokal (USG-Guided) — Jarang** | MTX / KCl / PGF2α / Hipertonik Glukosa ke dalam kantung ektopik — Khusus kasus terpilih, operator berpengalaman |

#### **Kriteria Operasi Laparoskopi (Elektif) pada Stabil**
- Gagal MTX (β-hCG tidak turun ≥ 15% H4-7, atau naik, atau platou > 3 minggu)
- β-hCG Awal > 5.000-10.000 / Massa > 4-5 cm / DJJ Positif
- Ingin Fertilitas & Tuba Kontralateral Normal → **Salpingostomi (Konservatif)** vs **Salpingektomi (Radikal — Disarankan Karena Rekuren Ektopik & Persistensi Trophoblast Lebih Rendah)**
- **Salpingektomi: Rekuren Ektopik 5-10%, Persistensi 3-5% | Salpingostomi: Rekuren 15-20%, Persistensi 10-20% (Butuh MTX Adjuvant Sering)**

### C. **Kasus Khusus**

| Jenis | Khusus Manajemen |
|-------|-----------------|
| **CSP (Cesarean Scar Pregnancy)** | **MTX Sistemik (Single/Multi) + MTX Lokal (USG-Guided) + Embolisasi Arteri Uterin (UAE) + Histeroskopi + Laparoskopi + Histerektomi (Last Resort)** — **JANGAN KURETASE SLEMBA (Risiko Perdarahan Masif & Ruptur Uterus)** |
| **Kehamilan Serviks** | **MTX Sistemik + Lokal + UAE + Histeroskopi + Servikotomi (Shirodkar) + Histerektomi (Jika Perdarahan Tidak Terkendali)** |
| **Kehamilan Ovarian** | **Laparoskopi: Ooforektomi / Kistektomi + Ovariopeksi (Jika Ingin Fertilitas)** — Risiko Perdarahan Tinggi (Vaskularisasi Ovarium Kaya) |
| **Kehamilan Abdominal** | **Laparotomi / Laparoskopi: Ekstraksi Janin + Plasenta (Jika Plasenta Bisa Dipisahkan Aman) / Plasenta In Situ (Jika Tidak Aman — Risiko Perdarahan Masif, Butuh UAE/Embolisasi Pre-Op) + Histerektomi Sering Diperlukan** |
| **Heterotrof** | **Prioritaskan Kehamilan Intrauterin (Jika Viable)** — **Laparoskopi Salpingektomi Sisi Ektopik (Hindari MTX Sistemik — Risiko Teratogenik & Aborsi IUP)** — Jika IUP Non-Viable → Bisa MTX / Laparoskopi |

## Pasca Tata Laksana & Monitoring

| Intervensi | Monitoring |
|------------|------------|
| **MTX** | **β-hCG H0, H4, H7 → Jika Sukses (≥ 15% Turun H4-7) → Mingguan Hingga < 5-10 mIU/mL** (Rata-rata 4-6 Minggu). **CBC, Liver, Renal Mingguan Selama MTX Aktif**. Hindari: NSAID, Penisilin, Sulfa, PPI, Vit A, Folic Acid, Alkohol, Sinar Matahari, Kehamilan (Kontraporsi 3-6 Bulan Pasca MTX). |
| **Laparoskopi (Salpingektomi/Salpingostomi)** | **β-hCG H1, H4, H7, Mingguan Hingga Negatif** (Persistensi Trophoblast → MTX Adjuvant). **Anti-D (Jika Rh Negatif)**. Konseling Fertilitas & Risiko Rekuren. |
| **Semua Kasus** | **Kontraksi 3-6 Bulan (OCP/Progestin/IUD)** — Waktu Ideal Next Pregnancy: 3 Bulan Pasca MTX (Folat Normal), 2-3 Bulan Pasca Operasi. **Risiko Rekuren Ektopik: 10-15% (Salpingektomi) / 15-25% (Salpingostomi) / 10-20% (MTX)**. |

## Pencegahan

| Upaya | Target |
|-------|--------|
| **Pencegahan & Penatalaksanaan PID (Klamidia/Gonore/TB) Dini & Adekuat** | Kurangi Kerusakan Tuba |
| **Hindari Rokok** | Proteksi Silia Tuba |
| **Kontraksi Efektif (Hindari Kehamilan Tidak Diinginkan & IUD Jika Risiko Tinggi Ektopik)** | IUD: Jika Pasang IUD → Pastikan Bukan Hamil Dulu (β-hCG/USG) |
| **Evaluasi Tuba Sebelum IVF (HSG / HyCoSy / Laparoskopi)** | Pilih Embrio Transfer Tunggal (eSET) Kurangi Heterotrof |
| **Konseling Pasca Ektopik: Risiko Rekuren, Pemeriksaan Dini Kehamilan Berikutnya (β-hCG + USG TV 5-6 Minggu)** | Deteksi Dini Kehamilan Berikutnya |

## Ringkasan untuk Dokter Umum

1. **Kehamilan Ektopik = Implantasi di Luar Uterus (95% Tubal)** — **Penyebab #1 Maternal Death Trimester 1**
2. **Triad: Nyeri Perut Unilateral + Amenorea + Spotting** — TAPI Bisa Atipik (Hanya Nyeri / Hanya Spotting / Shock Tanpa Nyeri Besar Jika Ruptur Cepat)
3. **Diagnosis: β-hCG Kuantitatif Serial + USG TV (Discriminatory Zone 1.500-2.000 mIU/mL)** — **Empty Uterus + β-hCG ≥ DZ = Ektopik Hingga Terbukti Sebaliknya**
4. **Stabil Hemodinamik + Kriteria MTX Terpenuhi → MTX Single Dose 50 mg/m2 IM (Monitoring β-hCG H0, H4, H7 — Sukses Jika Turun ≥ 15% H4-7)**
5. **Tidak Stabil / Ruptur / Gagal MTX / Kriteria MTX Tidak Terpenuhi → LAPAROSKOPI DARURAT/ELEKTIF: Salpingektomi (Preferred) vs Salpingostomi (Konservatif Fertilitas)**
6. **Kasus Khusus (CSP, Serviks, Ovarium, Abdominal, Heterotrof) → Rujuk SpOG Terpadu (UAE, Histeroskopi, Laparoskopi, Histerektomi)**
7. **Pasca: Monitoring β-hCG Mingguan Hingga Negatif, Anti-D (Rh Neg), Kontraksi 3-6 Bulan, Konseling Risiko Rekuren 10-25%**
8. **Pencegahan: Cegah PID, Stop Rokok, Evaluasi Tuba Pra-IVF, Deteksi Dini Kehamilan Berikutnya (USG TV 5-6 Mg)**
