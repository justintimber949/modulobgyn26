# Penyakit Radang Panggul (Pelvic Inflammatory Disease / PID)

## Cerita Pembuka

Ny. Rina, 24 tahun, G0P0A0, datang ke IGD RSKH dengan nyeri perut bawah hebat seitan 3 hari, demam 38,5°C, keputihan kuning bau. Riwayat: ganti pasangan 2 bulan lalu, tidak pakai kondom. Pemeriksaan: tekanan perut bawah (+), rebounding (-), cervical motion tenderness (CMT) ++, adneksa tenderness bilateral, massa tidak teraba. Darah lengkap: leukosit 14.000, neutrofil 85%, CRP 45. USG: free fluid pelvis sedang, tidak ada abses. Diagnosis: PID akut sedang. Rawat inap: seftriakson 2 g IV 1× + doksisiklin 100 mg IV/PO 2× + metronidazol 500 mg IV 3×. Hari ke-3: afebril, nyeri turun, CRP 12. Pulang: doksisiklin 100 mg PO 2× 14 hari + metronidazol 500 mg PO 3× 14 hari. Suami diobati EPT.

## Definisi

PID adalah **infeksi ascending** dari vagina/serviks ke **endometrium, tuba Fallopi (salpingitis), ovarium (ooforitis), parametrium, dan peritoneum panggul**. Spektrum: endometritis ringan → salpingitis → abses tubo-ovarium (TOA) → peritonitis panggul → sepsis.

## Etiologi & Patogenesis

### Patogen Utama (Ascending dari Serviks)

| Tingkat                     | Organisme                                              | Catatan                     |
| --------------------------- | ------------------------------------------------------ | --------------------------- |
| **STI (Primary)**           | _N. gonorrhoeae_, _C. trachomatis_                     | 30-50% kasus                |
| **Non-STI / Komensal**      | _M. genitalium_, _T. vaginalis_                        | Naik peran                  |
| **Polimikroba (Secondary)** | Anaerob: _Bacteroides, Prevotella, Peptostreptococcus_ | > 60% kasus (mixed)         |
|                             | Aerob: _E. coli, Strep, GBS, Haemophilus_              | Sering ikut                 |
|                             | _Mycoplasma hominis, Ureaplasma_                       | Kontroversial patogenisitas |

### Patogenesis

1. Infeksi serviks (STI) → **hilangnya barrier mukus serviks** (menstruasi, ovulasi, IUD, prosedur invasif)
2. Bakteri naik ke **endometrium** → endometritis
3. Naik ke **tuba** → salpingitis (kerusakan silia, adhezi, oklusi fimbria)
4. ke **ovarium** → ooforitis / abses tubo-ovarium
5. ke **peritoneum panggul** → peritonitis panggul

## Faktor Risiko

| Faktor                                                | OR / Risiko                        |
| ----------------------------------------------------- | ---------------------------------- |
| Usia < 25 th                                          | 3-5×                               |
| Multiple partner / partner baru < 6 bln               | 4×                                 |
| Tidak pakai kondom                                    | 3×                                 |
| Riwayat PID sebelumnya                                | 20-25% recurrence                  |
| IUD (3-4 bln pertama pasca pasang)                    | 2-3× (lalu normal)                 |
| Douching vagina                                       | 1,5-2×                             |
| Prosedur invasif (kuretase, HSG, histerskopi, aborsi) | Transien ↑                         |
| HIV positif                                           | Severitas ↑, anaerob lebih dominan |

## Diagnosis Klinis (CDC/POGI Criteria)

### Kriteria Mayor (Minimal 1 wajib untuk diagnosis pasti)

1. **Cervical Motion Tenderness (CMT)** — nyeri saat serviks digerakkan
2. **Adnexal Tenderness** — nyeri tekan adneksa unilateral/bilateral
3. **Uterine Tenderness** — nyeri tekan uterus

### Kriteria Minor (Mendukung, ≥ 1 diperlukan jika mayor ada)

1. Demam > 38,3°C
2. Keputihan abnormal (purulen/mukopurulen)
3. Lab: Leukositosis > 10.000, CRP ↑, ESR ↑
4. Bukti infeksi GC/CT (NAAT/ Kultur positif)
5. USG: free fluid pelvis, penebalan tuba, abses TOA

> **Diagnosis KLINIS cukup:** CMT + Adnexal tenderness + (gejala/pendukung). **Jangan tunggu lab/USG untuk mulai antibiotik!** Keterlambatan 24-48 jam → risiko infertilitas ↑ signifikan.

### Diagnosis Pasti (Gold Standard — Jarang Dilakukan Rutin)

- **Laparoskopi:** Visualisasi tuba merah, edematosa, purulen, adhezi
- **Endometrial biopsy:** Plasmin sel neutrophils > 5/HPF
- **Transvaginal USG + Doppler:** Sensitivity 85-90% untuk TOA, specific untuk salpingitis < 70%

## Klasifikasi Keparahan (Untuk Menentukan Rawat Jalan vs Inap)

| Tingkat    | Kriteria                                                                                                                                             | Tempat Rawat                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| **Ringan** | Gejala ringan, afebril, CMT/adnexal tenderness +, bisa minum/makan, compliance baik                                                                  | **Rawat jalan** (bisa jika follow-up 48-72 jam pasti)                                    |
| **Sedang** | Demam 38-39°C, nyeri moderat, leukositosis, CRP ↑, tidak toleran oral, compliance ragu                                                               | **Rawat inap** (parenteral 24-48 jam lalu switch oral)                                   |
| **Berat**  | Demam > 39°C, sepsis (hipotensi, takikardi, confusional), peritonitis (rebounding, guarding), TOA > 5 cm, imunosupresi, kehamilan, gagal rawat jalan | **Rawat inap ICU/HCU** (IV antibiotic, monitoring vital, pertimbangkan drainase/operasi) |

> [!warning] Red Flag — **WAJIB RAWAT INAP / RUJUK SPESIALIS**
>
> - Demam > 39°C + tanda sepsis
> - Peritonitis (guarding, rebounding, ileus)
> - **Abses tubo-ovarium (TOA) > 5-6 cm** — risiko ruptur → sepsis fatal
> - Kehamilan (ektopik vs PID — USG wajib!)
> - Imunosupresi (HIV CD4 < 200, steroid, kemoterapi)
> - Gagap rawat jalan 48-72 jam (gejala tidak membaik)
> - Usia < 18 th / compliance ragu (anak yatim, DV, dsb)

## Tata Laksana Antibiotik (Sesuai POGI/Kemenkes/WHO/CDC 2021)

### A. Rawat Jalan (Ringan) — Regimen Oral 14 Hari

| Obat                  | Dosis                       | Durasi      | Coverage                   |
| --------------------- | --------------------------- | ----------- | -------------------------- |
| **Seftriakson**       | **500 mg IM sekali** (awal) | Single dose | GC (parenteral wajib)      |
| **PLUS Doksisiklin**  | **100 mg PO 2× sehari**     | **14 hari** | CT, M.gen, anaerob parsial |
| **PLUS Metronidazol** | **500 mg PO 3× sehari**     | **14 hari** | Anaerob (Bacteroides, dll) |

> **Alternatif jika alergi doksisiklin:** Azitromisin 1 g PO mingguan × 2 minggu (tapi kurang anaerob & M.genitalium).
> **Alternatif parenteral awal (jika tidak toleran oral):** Seftriakson 1-2 g IV 1× + Metronidazol 500 mg IV 3× 24-48 jam, lalu switch oral.

### B. Rawat Inap (Sedang-Berat) — Parenteral 24-48 Jam Lalu Switch Oral

| Regimen Pilihan (Pilih 1)                                        | Dosis IV                                                                             |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **1. Seftriakson + Doksisiklin + Metronidazol**                  | Seftriakson 2 g IV 1×/24j + Doksisiklin 100 mg IV/PO 2× + Metronidazol 500 mg IV 3×  |
| **2. Seftotaksim + Doksisiklin + Metronidazol**                  | Seftotaksim 2 g IV 6-8 jam + Doksisiklin 100 mg IV/PO 2× + Metronidazol 500 mg IV 3× |
| **3. Ampisilin-Sulbaktam + Doksisiklin**                         | Ampisilin-sulbaktam 3 g IV 6 jam + Doksisiklin 100 mg IV/PO 2×                       |
| **4. Kloramfenikol + Metronidazol** (jika β-lactam alergi berat) | Kloramfenikol 500 mg IV 6 jam + Metronidazol 500 mg IV 3×                            |

> **Durasi parenteral:** Minimal 24-48 jam **AFTER** afebril 24 jam + clinical improvement, lalu **switch ke oral (doksisiklin + metronidazol) total 14 hari**.

### C. Abses Tubo-Ovarium (TOA)

- **Antibiotik IV sama PID berat** (regimen 1 atau 2)
- **Drainase perkutaneous (USG/CT-guided)** jika TOA > 5-6 cm ATAU tidak membaik 48-72 jam IV abx
- **Laparoskopi drainase/ salpingo-ooferektomi** jika:
  - Ruptur TOA (peritonitis generalisata)
  - Gagal drainase perkutaneous
  - Keraguan malignancy
  - Peritonitis tidak membaik 48-72 jam

## Pasangan (EPT)

- **WAJIB** diobati pasangan seksual 60 hari terakhir
- Regimen: Seftriakson 500 mg IM + Azitromisin 1 g PO (sama servisitis)
- Edukasi: tidak seks sampai keduanya selesai terapi + gejala hilang

## Follow-up & Monitoring

| Waktu                       | Tindakan                                                                     |
| --------------------------- | ---------------------------------------------------------------------------- |
| **48-72 jam**               | Evaluasi klinis: afebril, nyeri ↓, CMT/adnexal tenderness ↓, WBC/CRP trend ↓ |
| **1 minggu**                | Cek compliance, efek samping obat                                            |
| **2 minggu (selesai obat)** | Evaluasi keluhan, pemeriksaan VT, swab uji sembuh (NAAT GC/CT)               |
| **1-3 bulan**               | Screening reinfeksi (NAAT GC/CT) — risiko tinggi 3-6 bln                     |
| **6-12 bulan**              | Evaluasi fertilitas (HSG/laparoskopi) jika ingin hamil                       |

## Komplikasi Jangka Panjang

| Komplikasi                   | Risiko                                       | Pencegahan                                             |
| ---------------------------- | -------------------------------------------- | ------------------------------------------------------ |
| **Infertilitas tubal**       | 10-15% post 1 episode, 35-50% post 3 episode | Terapi CEPAT & ADEKUAT, rujuk fertilitas dini          |
| **Kehamilan ektopik**        | 7-10× lipat                                  | Konseling prekonsepsi, USG dini kehamilan              |
| **Nyeri panggul kronis**     | 15-30%                                       | Manajemen nyeri, fisio panggul, rujuk spesialis nyeri  |
| **Adhezi panggul**           | Umum post-PID berat                          | Laparoskopi adhesiolisis jika infertilitas/nyeri berat |
| **Abses tubo-ovarium (TOA)** | 5-10% PID akut                               | Early treatment, drainase tepat waktu                  |

## Pencegahan

- Kondom konsisten
- Screening GC/CT rutin (sekunder tahunan < 25 th / berisiko)
- **JANGAN douching** — mengganggu flora normal, naikkan risiko PID 2-3×
- IUD: screening STI sebelum pasang, antibiotik profilaksis tidak rutin (hanya jika berisiko tinggi)
- Vaksinasi HPV (indirect)

## Ringkasan untuk Dokter Umum

1. **PID = klinis diagnosis** — CMT + adnexal tenderness = mulai antibiotik SEGERA. Jangan tunggu lab/USG.
2. **Regimen standar:** Seftriakson 500 mg IM + Doksisiklin 100 mg 2× 14h + Metronidazol 500 mg 3× 14h
3. **Rawat inap jika:** demam tinggi, sepsis, peritonitis, TOA > 5 cm, hamil, imunosupresi, gagal rawat jalan 48-72j
4. **TOA > 5 cm / tidak membaik 48-72j IV abx → drainase (USG-guided) / laporoskopi**
5. **Pasangan WAJIB diobati (EPT)** — hindari reinfeksi
6. **Follow-up 48-72 jam KRUSIAL** — cek respons, compliance
7. **Komplikasi jangka panjang:** infertilitas, ektopik, nyeri kronis → konseling prekonsepsi
