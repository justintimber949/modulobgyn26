# Diabetes Gestasional (GDM)

## Cerita Pembuka

Ny. Ani, 34 tahun, G2P1A0, usia kehamilan 26 minggu. BMI prahamil 28 (overweight), ibu kandung DM tipe 2. OGTT 75 g: FPG 98, 1-jam 195, 2-jam 165 mg/dL. Diagnosis: GDM. Mulai MNT (medical nutrition therapy) + aktivitas 30 menit/hari. Minggu ke-2: FPG masih 105, 2-jam postprandial 145. Mulai metformin 500 mg 2× sehari. Kontrol mingguan: glikemia terkendali. USG serial: janin normal, tidak makrosomia. Di 38+6 minggu: induksi persalinan, lahir bayi 3600 g, APGAR 9/10. Glukosa bayi normal. Ny. Ani OGTT 6 minggu pasca persalinan: normal.

## Definisi

**GDM (Gestational Diabetes Mellitus)** = **intoleransi glukosa dengan onset atau diagnosis pertama pada kehamilan** (bukan DM tipe 1/2 prahamil, bukan DM tipe 1 yang debut saat hamil). Termasuk juga "Diabetes Mellitus in Pregnancy (DIP)" jika glukosa memenuhi kriteria DM overt saat kehamilan.

## Klasifikasi (ADA/WHO/POGI 2021)

| Kategori                                        | Kriteria                                                                     |
| ----------------------------------------------- | ---------------------------------------------------------------------------- |
| **DM Overt (DM Prahamil yang baru terdeteksi)** | FPG ≥ 126 **ATAU** HbA1c ≥ 6,5% **ATAU** PG 2-jam OGTT ≥ 200 + gejala klasik |
| **GDM**                                         | **Tidak memenuhi DM Overt** TAPI memenuhi **OGTT 75 g** (lihat bawah)        |
| **DM Tipe 1/2 Prahamil (Known)**                | Sudah diagnosis sebelum hamil, pada terapi insulin/obat oral                 |

## Screening & Diagnosis GDM (Standar Indonesia/POGI/WHO 2013)

### 1. Screening Risiko (ANC Kunjungan Pertama)

| Risiko Tinggi → **Langsung OGTT** (tidak perlu GCT)   | Risiko Rendah → **GCT 50 g (non-fasting)** 24-28 mg |
| ----------------------------------------------------- | --------------------------------------------------- |
| BMI ≥ 25 / Obesitas                                   | Usia < 25 th, BMI normal                            |
| Usia ≥ 35 th                                          | Tidak ada faktor risiko                             |
| Riwayat GDM / Makrosomia / IUFD                       |                                                     |
| Riwayat keluarga DM tipe 2 (orang tua/saudara)        |                                                     |
| PCOS, Hipertensi, Dislipidemia                        |                                                     |
| Etnis risiko tinggi (Asia, Hispanic, Afrika, Pasifik) |                                                     |
| Glukosuria / HbA1c ≥ 5,7% di ANC awal                 |                                                     |

### 2. **GCT 50 g (Glucose Challenge Test)** — Screening

- 50 g glukosa oral, **non-fasting**, cek glukosa darah 1 jam
- **Cut-off ≥ 140 mg/dL (7,8 mmol/L)** → positif → lanjut **OGTT 75 g**
- Sensitivitas ~80%, spesifisitas ~85%

### 3. **OGTT 75 g (Diagnostik) — Gold Standard**

- **Puasa 8-14 jam**, air boleh
- 75 g glukosa anhydrous dalam 250-300 mL air, diminum < 5 menit
- Cek glukosa: **Puasa (0'), 1 jam, 2 jam**

**Kriteria Diagnosis GDM (IADPSG/WHO 2013/POGI) — SATU SAJA CUKUP:**
| Waktu | Cut-off (mg/dL) | Cut-off (mmol/L) |
|-------|-----------------|------------------|
| **Puasa (FPG)** | **≥ 92** | **≥ 5,1** |
| **1 jam** | **≥ 180** | **≥ 10,0** |
| **2 jam** | **≥ 153** | **≥ 8,5** |

> **Catatan:** Kriteria Carpenter-Coustan (lama, 2/3 abnormal) **TIDAK LAGI DIPAKAI** — sensitivitas terlalu rendah.

### 4. HbA1c

- **Tidak direkomendasikan untuk diagnosis GDM** (sensitivitas rendah trimester 2-3 karena fisiologi kehamilan: turnover eritrosit ↑, HbA1c falsely low)
- Bisa dipakai **screening awal** (HbA1c ≥ 5,7% → risiko tinggi, lanjut OGTT)

## Target Glikemia (GDM)

| Waktu                           | Target (mg/dL) | Target (mmol/L) |
| ------------------------------- | -------------- | --------------- |
| **Puasa / Preprandial**         | **< 95**       | **< 5,3**       |
| **1 jam postprandial**          | **< 140**      | **< 7,8**       |
| **2 jam postprandial**          | **< 120**      | **< 6,7**       |
| **Rata-rata harian (jika CGM)** | **< 100**      | **< 5,6**       |

> **HbA1c target kehamilan:** **< 6,0%** (ideal < 5,7%) — tapi HbA1c tidak akurat monitoring harian GDM.

## Tata Laksana Bertahap

### Tahap 1: Medical Nutrition Therapy (MNT) + Aktivitas Fisik (2 minggu)

- **Konseling gizi** (ahli gizi/SpOG): 30-35 kcal/kg BB ideal/hari (min 1800 kkal), karbohidrat 40-45%, protein 20%, lemak 30-35%
- **Pola makan:** 3 makan utama + 2-3 snack (malam wajib — hindari hipoglikemia malam & ketosis)
- **Indeks Glikemik Rendah:** Nasi merah/gandum, sayur, protein, lemak sehat — hindari gula rafinat, minuman manis, roti putih
- **Aktivitas:** 30 menit/hari aktivitas aerobik ringan (jalan cepat, senam hamil, renang) — **hindari supin > 5 menit trimester 3**
- **Monitoring:** SMBG (Self-Monitoring Blood Glucose) **4×/hari** (puasa, 2 jam post M, S, M) — minimal 1×/minggu jika terkendali

> [!tip] Yang Sering Jadi Jebakan
> **Puasa terlalu lama / skip snack malam** → ketosis bintang (bisa berbahaya janin) + rebound hyperglycemia pagi (Somogyi). **Snack malam WAJIB** (susua/roti gandum + keju/kacang).

### Tahap 2: Farmakologi (Jika GDM Tidak Terkendali 2 Minggu MNT)

| Obat          | Dosis                                                            | Kelebihan                                                                                            | Kekurangan                                                                                               |
| ------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **Metformin** | 500 mg 1× → naik 500 mg/mgg sampai 1000-2000 mg 2× (max 2500 mg) | Oral, tidak hipoglikemia, tidak naik BB, lintas plasenta tapi data janin aman (MiG TOFU, RCTs)       | GI side effect (mual, diare), butuh eGFR > 45, **off-label** (banyak negara approve tapi FDA kategori B) |
| **Insulin**   | **Gold standard** — tidak lintas plasenta, dose fleksibel        | Basal: NPH/Glargin/Detemir malam; Prandial: Aspart/Lispro/Glulisin sebelum makan; Campuran: 70/30 2× | Injeksi, hipoglikemia risiko, naik BB, butuh edukasi & SMBG ketat                                        |

**Algoritma POGI/ACOG:**

1. **MNT 2 mgg** → jika target tercapai → lanjut MNT
2. **Jika FPG ≥ 95 ATAU 2-jam PP ≥ 120** → **Metformin first-line** (khusus Indonesia & banyak guideline Asia/UK) **ATAU Insulin** (jika FPG > 110 / HbA1c > 7% / makrosomia USG / kegagalan metformin)
3. **Jika metformin max dose tidak cukup** → tambah insulin basal / prandial / ganti insulin total
4. **Insulin wajib** jika: GDM tipe A2 (butuh obat), makrosomia USG, polihidramnion, ketosis, non-compliance MNT

> [!warning] Red Flag
> **Hipoglikemia < 70 mg/dL** pada ibu GDM insulin → risiko hipoglikemia neonatal & asfiksia. Edukasi: bawa gula/permen, cek glukosa sebelum driving, atur dose insulin jika pola hipoglikemia.
> **Ketoasidosis (DKA) pada GDM** — jarang tapi bisa (infeksi, steroid, puasa). Cek keton darah/urine jika sakit/glukosa > 250.

## Monitoring Kehamilan GDM

| Pemeriksaan                            | Frekuensi                                                                                 |
| -------------------------------------- | ----------------------------------------------------------------------------------------- |
| **ANC + SMBG review**                  | 1-2×/minggu (insulin), 2×/bulan (MNT/metformin terkendali)                                |
| **USG Pertumbuhan + AFI + Doppler UA** | 4 minggu sekali (28, 32, 36, 38 mg) — cari makrosomia, polihidramnion, IUGR (vaskulopati) |
| **NST / BPP**                          | Mulai 32-34 mg mingguan (jika insulin / tidak terkendali / komplikasi)                    |
| **HbA1c**                              | Setiap trimester (monitoring jangka panjang)                                              |
| **Fungsi Ginjal / Hati / Lipid**       | Awal & trimester 3                                                                        |

## Timing & Mode Persalinan

| Kondisi                                                                       | Rekomendasi                                                               |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| **GDM terkontrol MNT (A1), tidak makrosomia (EFW < 4000g), tidak komplikasi** | **Expectant hingga 39-40 mg** → induksi 39-40 mg / persalinan spontaneous |
| **GDM butuh obat (A2), terkendali, EFW < 4000g**                              | **Induksi 38-39 mg** (hindari stillbirth risiko ↑ GDM)                    |
| **GDM tidak terkendali / Makrosomia (EFW ≥ 4000-4500g) / Polihidramnion**     | **Induksi 37-38 mg / SC elektif 38-39 mg** (diskusi SpOG KFM)             |
| **Makrosomia > 4500g (GDM) / > 5000g (non-GDM)**                              | **SC elektif 38-39 mg** (risiko distosia bahu ↑ 2-3×)                     |
| **Preeklampsia / IUGR / Oligohidramnion / Doppler abnormal**                  | Sesuai indikasi obstetri (bisa < 37 mg)                                   |

## Pasca Persalinan

| Waktu                 | Tindakan                                                                                          |
| --------------------- | ------------------------------------------------------------------------------------------------- |
| **Segera lahir**      | Cek glukosa bayi 1, 2, 3 jam (target > 45 mg/dL) — ASI dini < 1 jam                               |
| **Ibu**               | **Hentikan semua obat DM** (metformin/insulin) — glukosa biasanya normal instan                   |
| **Hari 1-2**          | Monitoring glukosa ibu 2×/hari (puasa + 2 jam PP) — pastikan normal                               |
| **6-12 minggu pasca** | **OGTT 75 g WAJIB** (screening DM tipe 2 / prediabetes) — 50% GDM jadi DM tipe 2 dalam 5-10 th    |
| **Tahunan**           | HbA1c / FPG / OGTT — screening DM tipe 2 seumur hidup                                             |
| **KB**                | Pil/Implan/IUD/Injeksi — semua aman post-GDM. Metformin bisa lanjut jika PCOS/insulin resistance. |

## Komplikasi

| Maternal                                 | Fetal/Neonatal                                             |
| ---------------------------------------- | ---------------------------------------------------------- |
| Preeklampsia (2-4× risiko)               | **Makrosomia** (BB > 4000g) → distosia bahu, laserasi, SC  |
| SC darurat (2-3× risiko)                 | **Hipoglikemia neonatal** (hiperinsulinisme janin)         |
| Polihidramnion                           | Hipoksia/Asfiksia (plasenta insufficiency)                 |
| Infeksi (URI, UTI, vulvovaginitis)       | **IUFD** (risiko ↑ 2-3× jika tidak terkendali trimester 3) |
| DM Tipe 2 masa depan (50% dalam 5-10 th) | Hiperbilirubinemia, Hipokalcemia, Hipomagnesemia           |
| Kardiovaskular jangka panjang            | **Obesitas & DM Tipe 2 anak** (programming metabolik)      |

## Ringkasan untuk Dokter Umum

1. **Screening GDM:** Risiko tinggi → langsung OGTT 24-28 mg; Risiko rendah → GCT 50 g → OGTT jika ≥ 140
2. **Diagnosis OGTT 75 g:** **FPG ≥ 92 / 1-jam ≥ 180 / 2-jam ≥ 153** — **SATU SAJA CUKUP**
3. **Target glikemia ketat:** Puasa < 95, 2-jam PP < 120 mg/dL
4. **MNT 2 mgg dulu** → jika gagal → **Metformin first-line (Indonesia)** / Insulin
5. **USG serial** cari makrosomia, polihidramnion, IUGR, Doppler
6. **Persalinan:** A1 (MNT only) → 39-40 mg; A2 (obat) → 38-39 mg; Makrosomia > 4000-4500g → SC elektif 38-39 mg
7. **Pasca:** OGTT 6-12 mgg WAJIB, screening tahunan DM tipe 2 seumur hidup
8. **ASI dini & eksklusif** — protektif untuk bayi & ibu (kurangi risiko DM tipe 2)
