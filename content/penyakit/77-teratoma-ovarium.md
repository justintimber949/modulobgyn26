# Teratoma Ovarium (Kista Dermoid)

## Cerita Pembuka

Ny. Rina, 24 tahun, G0, keluhan nyeri perut kanan bawah seitan 2 hari (akut, mual, muntah). Suhu 37,8°C. USG: Kista kanan 7×5 cm, dinding tipis, isi heterogen: **R2 (Retikuler / "Rokok Sign" / "Tip Sign") — area hiperekoik (lemak/gigi/rambut) + area hiperekoik solid (Rokok/Gigi) + line-line hiperekoik (rambut)**, tidak ada vaskularitas di dalam massa. Diagnosis: **Teratoma Ovarium Kanan (Mature Cystic Teratoma) + Torsio Parsial**. CT Scan Abdomen: konfirmasi kista dermoid + torsi ovarium (whirlpool sign) + ovarium kanan edema. Laparoskopi: Kista dermoid kanan 7 cm dengan torsi 360° pada ovarium kanan → **Kistektomi Laparoskopik + Untwisting Ovarium** (Preservasi Ovarium). Histopat: Mature cystic teratoma (rambut, lemak, tulang, kulit, neuroglia, jaringan ektopik).

## Definisi & Patogenesis

**Teratoma Ovarium** = **Tumor germinal paling umum (> 95% germinal tumors ovarium)** — mengandung **derivative dari 1-3 lapisan胚芽 (ektoderm, mesoderm, endoderm)** — kulit, rambut, lemak, tulang, gigi, jaringan neuro, usus, kelenjar.

| Tipe | Deskripsi | Persentase | Risiko |
|------|-----------|------------|--------|
| **Mature Cystic Teratoma (MCT / Kista Dermoid)** | **Jaringan Matang** (diferensiasi sempurna) | **95-98%** | Risiko keganasan rendah (< 1%) |
| **Mature Solid Teratoma** | Jaringan Matang tapi padat (solid), kurang diferensiasi sempurna | < 1% | Risiko malignant transformation lebih tinggi |
| **Immature Teratoma** | **Jaringan Imatur (Embrional / Fetal) — grading 1-3** | 1-3% | **Germinal Malignant #3** — grading histologis (Grade 1-3 berdasarkan jumlah neural tissue imatur), AFP ↑ |
| **Monodermal / Specialized Teratoma** | Spesifik: **Struma Ovarii** (95%+ Jaringan Tiroid), Karsinoid Ovarium, Neuroendokrin, Sebaceous | Variabel | Struma: Hipertiroid 5-15%, Malignant 3-5%. Karsinoid: Sindrom Karsinoid 10% |

## Epidemiologi

- **Tumor Ovarium #1 pada Usia Muda (Remaja & Young Adult, 10-35 Th)**
- **Bilateral: 10-15%** (Harus cek kista lain di ovarektomi kistektomi)
- **15-20% Torsi** (Paling sering torsi di antara kista ovarium lain karena BB berat / asimetri)
- **BB Rata-rata: 5-10 cm (bisa > 20 cm jarang)**

## Gejala & Tanda

| Gejala | Frekuensi | Keterangan |
|--------|-----------|------------|
| **Nyeri Perut Pelvik** | 50-60% | Tumpul kronik / Akut (torsi!) |
| **Torsi Ovarium (Akut)** | 15-20% | **Nyeri Hebat Tiba-tiba, Mual, Muntah, Demam** — USG: Whirlpool Sign, Absen Vaskular Doppler Ovarium |
| **Bowel Obstruction** | < 5% | Kista besar kompresi usus |
| **Asimtomatik** | 30-40% | Ditemukan insidenal USG |
| **Masa Abdomen** | 10-20% | Kista besar (> 10 cm) |
| **Paraneoplastik** | < 1% | Struma Ovarii: Hipertiroid. Karsinoid: Sindrom Karsinoid. Hemolytic anemia (anti-eritrosit dari jaringan kista) |

## Diagnosis & Workup

### 1. USG (First-Line — Sangat Spesifik)
| Temuan USG | Signifikansi |
|------------|--------------|
| **"R2 Sign" (Retikuler) — Area Hiperekoik + Anekoik + Fibrillar Lines** | **Sangat Spesifik (> 95%) untuk Kista Dermoid** |
| **Rokok Sign (Cigarette Sign) — Line Hiperekoik Panjang di Dalam Kista** | Rambut/Jaringan Solid Terapung |
| **Tip Sign (Tooth Sign) — Titik/Serpihan Hiperekoik Hard + Shadowing** | Gigi / Tulang |
| **Fat-Fluid Level (Level Air-Lemak)** | Cairan Lemak (Sebum) |
| **Hair Fluid Level (Hairball)** | Rambut Menggumpal |
| **Doppler:** Vaskularitas Minim di Dinding, Vaskularitas Di dalam Massa: **Hati-Hati Immature / Malignant Transformation** | |

### 2. Marker Tumor
| Marker | Tipe | Keterangan |
|--------|------|------------|
| **CA-125** | Bisa ↑ (20-30%) — non-spesifik | Jika sangat tinggi (> 200) → curiga keganasan |
| **AFP (Alpha-fetoprotein)** | ↑ pada Immature Teratoma (Grade 1-3) | **Monitoring respons terapi Immature** |
| **β-hCG** | ↑ pada Choriokarsinoma Mixed Germ Cell | Jika ada komponen trophoblastic |
| **LDH** | ↑ pada Germinoma | Non-spesifik |
| **Thyroid Function (TSH, FT4)** | ↑ pada Struma Ovarii Hipertiroid | Cek jika Struma Ovarii / Hipertiroid |
| **Inhibin, HE4, CEA** | Non-diagnostik | Jika ragu Karsinoma Epitel (differentiated) |

### 3. CT Scan (Jika Kompleks)
- Torsio: Whirlpool sign, ovarian enlargement, fat attenuation
- Malignant transformation: Solid component ↑, vaskularitas ↑, nekrosis, invasi

## Diferensial Diagnosis

| Kista Lain | Beda dengan Dermoid |
|------------|---------------------|
| **Kista Endometrioma** | "Ground glass" homogen, tidak R2/sign gigi, CA-125 ↑ |
| **Kista Fungsional (Folikuler/Korpus Luteum)** | Anekoik murni, dinding tipis, regresi spontan 1-3 siklus |
| **Kista Serous/Mucinous** | Unilokuler/multilokuler, dinding tipis-tebal, tidak ada komponen hiperekoik R2 |
| **Fibroma Ovarium** | Solid hiperekoik, posterior shadowing, ascites (Meigs Syndrome) |
| **Abses Ovarium/PID** | Dinding tebal, debris, klinis: demam, WBC ↑, nyeri, leukorea |
| **Tumor Germinal Malignant** | Massa solid dominant, vaskularitas ↑, marker ↑ (AFP, β-hCG) |
| **Hidatid Cyst (Echinococcus)** | Daerah endemik, "Water Lily Sign" / "Wheel Sign" |

## Tata Laksana

### A. Kista Dermoid (Mature Cystic Teratoma) — **ELEKTIF**
| Pilihan Operasi | Indikasi | Teknik |
|------------------|----------|--------|
| **Kistektomi Laparoskopik** | **Pilihan Utama** — Usia muda, Ingin Fertilitas, Kista < 10 cm, Tidak curiga malignancy | **Endobag untuk ekstraksi** (HINDARI ruptur isi ke rongga perut — chemical peritonitis dari lemak/sebum!). **Hemostasis bipsia parenchyma ovarium dengan bipolar/harmonic.** |
| **Kistektomi Abdominal (Laparotomi)** | Kista > 10-15 cm, Suspici Malignancy, Bilateral Kompleks | Incisi Pfannenstiel/Midline. Eksplorasi menyeluruh. Frozen section jika ragu. |
| **Ovarektomi** | Usia Post-Menopause / Tumor Besar / Ovarium Rusak Total / Immature Teratoma | Preservasi ovarium satunya jika muda |
| **Bilateral Kistektomi** | 10-15% bilateral — **Cek kontralateral!** | Laparoskopik kedua ovarium |

### B. TORSIO OVARIUM — **DARURAT**
| Tahap | Tindakan |
|-------|----------|
| **1. Stabilisasi** | Resusitasi: IV, Analgesia, Antiemetik, Antibiotik (jika demam/curiga infeksi) |
| **2. SC Darurat / Laparoskopi Darurat** | **Untwisting (Detorsi) + Kistektomi** — Preservasi ovarium jika ovarium masih viable (tidak nekrotik/hitam total). **Jika ovarium sudah nekrotik total: Ovarektomi** |
| **3. Jika Kista Kecil + Torsi Parsial + Ovarium Viable** | Detorsi + Kistektomi elektif setelah stabil (3-6 minggu) — Hemostasis, cek kedua ovarium |
| **Pasca Detorsi** | Monitoring Doppler ovarium 1-2 minggu (bisa pulih meski awalnya tidak vascular) |

### C. Immature Teratoma
| Stadium | Terapi |
|---------|--------|
| **IA** | **Ovarektomi + Kemoterapi (BEP: Bleomycin + Etoposide + Cisplatin × 3-4 siklus)** — Grade 1: Observation bisa (jika young & want fertility) |
| **IC-II** | Ovarektomi + Adjuvant BEP × 3-4 |
| **III-IV** | **Debulking Surgery + BEP × 3-4** — AFP monitoring (Marker Tumor Residual) |

### D. Struma Ovarii
- **Hipertiroid (5-15%):** Terapi: Kistektomi/Ovarektomi. **TIDAK pakai Radioiodine (I-131) karena Struma Ovarii TIDAK mengambil iodine dari darah)**. **Metimazol hanya jika hipertiroid pre-op.**
- **Malignant Struma Ovarii (3-5%):** Thyroidectomy total + I-131 + TSH suppression — **Pusat Rujukan**

## Follow-up Pasca Operasi

| Tipe | Follow-up |
|------|-----------|
| **Mature Cystic Teratoma (MCT)** | **TIDAK BUTUH USG RUTIN** jika histopat konfirmasi matang & margin negatif. Jika ragu → USG 1 th |
| **Immature Teratoma** | **AFP 1-3 bulanan** (marker residual/recurrent) + USG pelvis 3-6 bln + CT abdomen 6-12 bln |
| **Struma Ovarii** | **FT4/TSH 3-6 bulan** (evaluasi tiroid residual) + USG Tiroid |

## Ringkasan untuk Dokter Umum

1. **Teratoma Ovarium = Tumor Germinal #1 pada Usia Muda (10-35 Th)** — 95% Mature Cystic (Dermoid), Bilateral 10-15%
2. **USG SANGAT SPESIFIK:** R2 Sign, Rokok Sign, Tip Sign, Fat-Fluid Level → **Diagnosis Klinis Cukup (95%+)**
3. **Torsi 15-20% — Darurat:** Nyeri Hebat + Mual + Muntah + USG: Whirlpool / Absen Doppler → **Laparoskopi/SC Darurat (Untwisting + Kistektomi)**
4. **Operasi Elektif: Kistektomi Laparoskopik + ENDBAG Ekstraksi** (Jangan Ruptur — Chemical Peritonitis) + Cek Kedua Ovarium (Bilateral 10-15%)
5. **Immature Teratoma:** AFP ↑, BEP Chemo, Pusat Rujukan
6. **Struma Ovarii:** Hipertiroid 5-15%, Kistektomi + PTU/Metimazol Pre-Op (TIDAK Radioiodine), Cek Tiroid Post-Op
7. **Follow-up MCT: Tidak Rutin Jika Histopat Matang | Immature: AFP + USG + CT Serial**
