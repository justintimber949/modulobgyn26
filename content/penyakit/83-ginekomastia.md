# Ginekomastia (Gynecomastia)

## Cerita Pembuka

Pak Budi, 24 tahun, mahasiswa, keluhan: **payudara kiri membesar seitan 6 bulan, nyeri tekam ringan, malu berenang**. Riwayat: **Konsumsu suplemen kebugaran (whey protein, creatine, "testosterone booster" herbal) seitan 1 tahun, tidak rokok, tidak alkohol, tidak obat lain**. Pemeriksaan: **Payudara kiri: Jaringan kelenjar 4×3 cm di retroareolar, lentur, bisa digerakkan, nyeri tekam, puting normal, tidak ada sekret. Kanan: Kecil < 2 cm. Tidak ada massa testis, penis normal, rambut wajah/jenggot normal**. Lab: **Testosteron Total 450 ng/dL (Normal), LH 5, FSH 4, Estradiol 35 pg/mL (Sedikit Tinggi), Prolaktin 15, TSH 2, Fungsi Hati/Ginjal Normal**. USG Payudara: **Jaringan Hiperekoik Retroareolar (Kelenjar) Bukan Lemak, BIRADS 2**. Diagnosis: **Ginekomastia Puber/Kasus Idiopatik (Kemungkinan Suplemen Herbal/Androgenik) Derajat IIa (Tanpa Kulit Lebih)**. Manajemen: **Stop Suplemen, Observasi 6 Bulan (Regresi Spontan Bisa), Tamoxifen 10 mg/hari 3-6 Bulan Jika Tidak Membaik / Nyeri / Kosmetik Ganggu**. 4 Bulan: Ukuran mengecil 50%, nyeri hilang.

## Definisi & Patogenesis

**Ginekomastia** = **Pertumbuhan Benar Jaringan Kelenjar Payudara (Glandular Proliferation) pada Pria** — **Bukan Lemak (Pseudogynecomastia)**.

**Mekanisme Utama:** **Rasio Estrogen : Androgen ↑** (Estrogen Relatif Tinggi / Androgen Relatif Rendah) → Stimulasi Proliferasi Epitel Duktal Payudara.

| Jalan Patogenesis                             | Contoh                                                                                                                                                                                        |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Estrogen ↑ (Absolut/Relatif)**              | Obesitas (Aromatase ↑ di Lemak → Testosteron → Estradiol), Tumor Sel Leydig/Adrenal (Estrogen Sekresi), Hipertiroid (SHBG ↑ + Estrogen ↑), Sirots Hati (Metabolisme Estrogen ↓), Gagal Ginjal |
| **Androgen ↓ (Absolut/Relatif)**              | Hipogonadisme Primer (Klinefelter, Kallmann), Sekunder (Prolaktinoma, Obat, Usia Lanjut/Andropause), Obat Anti-Androgen                                                                       |
| **Reseptor Estrogen Sensitif / Polimorfisme** | Variasi Individual (Kenapa Beda Orang Pakai Obat Sama Beda Respon)                                                                                                                            |
| **Fase Fisiologis (Normal Transien)**         | **Bayi Baru Lahir (Estrogen Ibu), Pubertas (12-16 Th, 50-60% Pria), Lansia (> 60 Th, Andropause + Lemak ↑)**                                                                                  |

## Etiologi (Daftar Lengkap)

### 1. Fisiologis (Normal, Transien, Regresi Spontan)

| Fase                    | Prevalensi                   | Durasi                         |
| ----------------------- | ---------------------------- | ------------------------------ |
| **Neonatal**            | 60-90%                       | Mingguan (Estrogen Ibu)        |
| **Pubertas**            | **50-65% (Puncak 13-14 Th)** | **6-24 Bulan (Bisa Bertahun)** |
| **Lansia / Andropause** | **30-40% (> 60 Th)**         | Kronik (Perlu Evaluasi)        |

### 2. Patologis — Obat (20-25% Kasus Dewasa)

| Kelas Obat                     | Contoh Khusus                                                                                                                      |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Anti-Androgen**              | **Spironolacton, Finasteride, Dutasteride, Bicalutamide, Flutamide, Sitostat (Cyproteron)**                                        |
| **Estrogen / Agonis Estrogen** | **DES, Estradiol, Feminizing Hormone Therapy**                                                                                     |
| **Kardiovaskular**             | **Digoxin, Bloker Beta (Lama), Bloker Alfa (Non-Uroselektif), Spironolacton**                                                      |
| **Psikotropik**                | **Antipsikotik (Risperidon, Haloperidol, Olanzapin — Prolaktin ↑), Trikasiklik, SSRI (Jarang), Lithium**                           |
| **Antimikroba**                | **Isoniazid, Ketokonazol, Metronidazol, Griseofulvin**                                                                             |
| **Lainnya**                    | **Cimetidin, Ranitidin (H2 Bloker), Omeprazol (PPI), Penisilin, Alopurinol, Sitotoksik, Kanabis, Heroin, Metadon, Alkohol Kronik** |

### 3. Patologis — Penyakit Sistemik

| Penyakit                           | Mekanisme                                                                                                                                             |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hipogonadisme Primer**           | **Klinefelter (47,XXY) #1 Genetik**, Anorchia, Kallmann, Mumps Orchitis, Radiasi/Kemo Testis                                                          |
| **Hipogonadisme Sekunder**         | **Prolaktinoma (Prolaktin ↑ → GnRH ↓), Tumor Hipofisis Lain, Obat Dopamin Antagonis, Sarkoidosis, Hemokromatosis**                                    |
| **Tumor Produsen Hormon**          | **Sel Leydig Testis (Estrogen/Testosteron), Sel Sertoli, Karsinoma Adrenal, Koriokarsinoma (hCG → Leydig Stim), Tumor Paraneoplastik (hCG/Estrogen)** |
| **Hipertiroid**                    | **SHBG ↑ + Konversi Perifer Androgen → Estrogen ↑ (Aromatase)**                                                                                       |
| **Sirots Hati / Gagal Hati**       | **Metabolisme Estrogen ↓ + SHBG ↓ + Androgen ↓**                                                                                                      |
| **Gagal Ginjal Kronik / Dialisis** | **Hormon Gonadal Gangguan + Obat + Nutrisi**                                                                                                          |
| **Malnutrisi / Refeeding**         | **Katabolisme → Hipogonadisme → Refeeding → Estrogen Relatif ↑**                                                                                      |

### 4. Idiopatik

- **25-30% Kasus** — Tidak Ditemukan Penyebab Jelas (Setelah Workup Lengkap)

## Gejala & Tanda

| Parameter        | Ginekomastia (Benar)                                    | Pseudogynecomastia (Lemak)                                    |
| ---------------- | ------------------------------------------------------- | ------------------------------------------------------------- |
| **Jaringan**     | **Kelenjar (Keras, Rubbery, Retroareolar, Konsentris)** | **Lemak (Lembut, Difus, Bukan Konsentris di Areola)**         |
| **Palpasi**      | **Diskus/Butir di Bawah Areola/Puting, Batas Tegas**    | **Lapisan Lemak Tipis Merata, Tidak Ada Massa Terlokalisasi** |
| **Nyeri**        | **Sering (Nyeri Tekam/Ringaan)**                        | **Tidak Nyeri**                                               |
| **Kulit/Puting** | Normal / Bisa Retraksi Jika Parah                       | Normal                                                        |

## Diagnosis & Workup

### 1. Klinis (Anamnesis + Pemeriksaan)

- **Palpasi Diskus Kelenjar Retroareolar (> 2 cm = Ginekomastia) vs Lemak Difus**
- **Anamnesis Lengkap: Obat (3-6 Bulan Mundur), Riwayat Penyakit, Suplemen, Herbal, Rokok, Alkohol, Narkoba**

### 2. Laboratorium (Panel Minimum)

| Pemeriksaan                                         | Kegunaan                                                                                                  |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Testosteron Total (Pagi 7-10 AM, Puasa)**         | **< 300 ng/dL = Hipogonadisme, 300-350 = Borderline (Ulangi + Free T)**                                   |
| **LH, FSH**                                         | **Beda Primer (↑) vs Sekunder (Normal/↓)**                                                                |
| **Estradiol (E2)**                                  | **Estrogen ↑ Relatif/Absolut**                                                                            |
| **Prolaktin**                                       | **> 50-100 ng/mL → MRI Hipofisis (Prolaktinoma)**                                                         |
| **TSH, FT4**                                        | **Hipertiroid (SHBG ↑ + Aromatase ↑)**                                                                    |
| **β-hCG**                                           | **Tumor Sel Leydig/Sertoli/Koriokarsinoma/Adrenal (hCG → Leydig Stim → Estrogen)**                        |
| **Fungsi Hati (AST, ALT, Albumin, Bilirubin, INR)** | **Sirots/Gagal Hati → Estrogen Metabolisme ↓**                                                            |
| **Fungsi Ginjal (Kreatinin, eGFR, Elektrolit)**     | **Gagal Ginjal Kronik**                                                                                   |
| **Karyotip (46,XY / 47,XXY)**                       | **WAJIB Jika Hipogonadisme Primer / Klinefelter Dicurigai (Testis Kecil, FSH/LH ↑, Ginjal/Anomali Lain)** |

### 3. Imaging

| Modality                    | Indikasi                                                                                               |
| --------------------------- | ------------------------------------------------------------------------------------------------------ |
| **USG Payudara**            | **First-Line: Beda Kelenjar (Hiperekoik, Retroareolar) vs Lemak (Hipoekoik, Difus) — BIRADS 2**        |
| **MRI Hipofisis (Kontras)** | **Prolaktin > 100 ng/mL / Prolaktin 50-100 + Gejala Massa / Hipogonadisme Sekunder Tidak Jelas Sebab** |
| **USG Skrotum**             | **Massa Testis / Atrofi / Klinefelter (Testis Kecil, Hiperekoik)**                                     |
| **CT Abdomen/Adrenal**      | **Tumor Adrenal / Karsinoma Adrenal (Jika DHEAS/Testosteron/Estrogen Sangat Tinggi)**                  |

## Derajat Ginekomastia (Simon Classification / Modified)

| Derajat | Deskripsi                                                                      |
| ------- | ------------------------------------------------------------------------------ |
| **I**   | **Pembesaran Kelenjar Kecil (< 2-3 cm), Tanpa Kulit Lebih, Hanya Area Areola** |
| **IIa** | **Sedang (3-5 cm), Tanpa Kulit Lebih (Kulit Elastis)**                         |
| **IIb** | **Sedang, Dengan Kulit Lebih (Redundansi Kulit Sedang)**                       |
| **III** | **Besar (> 5 cm), Kulit Lebih Signifikan, Ptosis Payudara**                    |

## Tata Laksana

### A. Fisiologis / Ringan / Baru < 12 Bulan — **Observasi & Penghapusan Pemicu**

| Tindakan                                                                                  | Detail                                                                                                                                                                              |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Identifikasi & Hentikan Obat Pemicu**                                                   | **Review Obat 3-6 Bulan Mundur — Ganti Ke Alternatif Non-Ginekomastia (Contoh: Spironolacton → Amiloride/Eplerenon; Finasteride → Stop/Topical; Bloker Beta Lama → Nebivolol/ARB)** |
| **Stop Suplemen Herbal/Androgenik/Prohormon**                                             | **Whey/Creative Biasanya Aman, Tapi "Testosterone Booster" Herbal Sering Kontaminan/Steroid/Prohormon**                                                                             |
| **Lifestyle: BB Turun Jika Obesitas (Aromatase ↓), Stop Alkohol/Narkoba**                 | **5-10% BB Turun → Estradiol ↓, Testosteron ↑**                                                                                                                                     |
| **Observasi 6-12 Bulan (Jika < 12 Bulan Durasi, Derajat I-IIa, Usia < 25 Th / Pubertas)** | **Regresi Spontan 70-90% Puber, 30-50% Dewasa Idiopatik**                                                                                                                           |
| **Reassurance & Edukasi**                                                                 | **"Bukan Kanker, Bukan Infeksi, Sering Sembuh Sendiri"**                                                                                                                            |

### B. Medis (Jika > 12 Bulan / Tidak Regresi / Nyeri / Kosmetik Ganggu / Derajat IIb-III)

| Obat                                      | Dosis & Durasi                                       | Mekanisme & Evidensi                                                                                                                                |
| ----------------------------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Tamoxifen (SERM)**                      | **10-20 mg/hari (Biasanya 10 mg Cukup) × 3-6 Bulan** | **First-Line Medis — Blokir Reseptor Estrogen Payudara — Sukses 70-90% (Mengecilkan Ukuran & Nyeri) — RCT Dukung**                                  |
| **Raloksifen (SERM)**                     | **60 mg/hari × 3-6 Bulan**                           | **Alternatif Tamoxifen (Kurang Data Ginekomastia, Lebih Untuk Osteoporosis/Praventif)**                                                             |
| **Anastrozol (AI - Aromatase Inhibitor)** | **1 mg/hari × 3-6 Bulan**                            | **Blokir Konversi Androgen → Estrogen — Efektif Tapi **Tidak FDA Approved Ginekomastia**, Data Kurang RCT vs Tamoxifen, Risiko Osteoporosis/Lipid** |
| **Letrozol (AI)**                         | **2,5 mg/hari × 3-6 Bulan**                          | **Lebih Kuat Anastrozol, Data Kasus Kecil**                                                                                                         |
| **Danazol (Androgen Sintetis)**           | **100-200 mg 2×/hari × 3-6 Bulan**                   | **Lama, SE Androgenik Berat (Jerawat, Suara, Lipid, Hati) — Jarang Dipakai Sekarang**                                                               |

> **Penting: Terapi Medis Paling Efektif Jika Durasi < 12 Bulan (Jaringan Masih Aktif Proliferatif). > 12-24 Bulan → Fibrosis Dominan → Medis Kurang Efektif → Operasi.**

### C. Operasi (Definitif — Jika Medis Gagal / Durasi > 1-2 Th / Derajat IIb-III / Fibrosis / Kosmetik)

| Teknik                                                                                 | Indikasi & Detail                                                                                                                                                                                                                                                          |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Mastektomi Subkutan (Webster / Concentric / Periareolar Incision)**                  | **Gold Standard Jaringan Kelenjar > 2 cm / Fibrosis / Derajat IIb-III** — Eksisi Jaringan Kelenjar Melalui Insisi Periareolar Bawah (Semi-Sirkuler) — **Preservasi Areola-Puting (Pedicle) / Free Nipple Graft Jika Besar/Jauh** — **Liposuksi Adjunct Jika Lemak Campur** |
| **Liposuksi Saja (VASER / Power-Assisted / Laser)**                                    | **Hanya Pseudogynecomastia (Lemak Murni) ATAU Ginekomastia Dominan Lemak (Kelenjar < 20%)** — **TIDAK Cukup Jika Kelenjar Dominan (Butuh Eksisi)**                                                                                                                         |
| **Kombinasi (Liposuksi + Eksisi Kelenjar Via Insisi Kecil / Pull-Through)**            | **Kasus Campur (Kelenjar + Lemak) — Kosmetik Terbaik, Minimal Scar**                                                                                                                                                                                                       |
| **Skin Redaction (Pola Wise / Inverted-T / Vertical) Jika Ptosis Berat (Derajat III)** | **Kulit Lebih Banyak → Pola Reduksi Seperti Mastektomi Perempuan**                                                                                                                                                                                                         |

### D. Pasca Operasi

| Tindakan                                              | Durasi                                                        |
| ----------------------------------------------------- | ------------------------------------------------------------- |
| **Kompresi Garmen (Vest Kompresi Payudara Pria)**     | **4-6 Minggu (24/7 2 Minggu, Lalu 12 Jam/Malam)**             |
| **Drain (Jika Eksisi Luas / Liposuksi Volume Besar)** | **3-5 Hari (Hingga < 30 mL/hari)**                            |
| **Antibiotik Profilaksis**                            | **Sefazolin 1g IV Intraop → Kefalexin 500 mg 6 Jam × 5 Hari** |
| **Kontrol Luka & Seroma**                             | **Minggu 1, 2, 4, 8, 12**                                     |
| **Hasil Kosmetik Final**                              | **3-6 Bulan (Pemataran Jaringan, Hilangnya Edema)**           |

## Diferensial Diagnosis

| Kondisi                                      | Beda Kunci                                                                                                                                         |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Pseudogynecomastia (Lemak)**               | **Lembut, Difus, Bukan Konsentris di Areola, Tidak Nyeri, Obesitas**                                                                               |
| **Karsinoma Payudara Pria**                  | **Massa Keras, Tidak Bergerak, Batas Tidak Tegas, Retraksi Kulit/Puting, Ulserasi, Sekret Berdarah, Limfa Aksila Keras Matted — **BIOSPI WAJIB\*\* |
| **Abses Payudara**                           | **Nyeri Hebat, Merah, Panas, Fluktuasi, Demam, WBC ↑**                                                                                             |
| **Lipoma**                                   | **Lembut, Bisa Diggeser, Batas Tegas, Bukan Retroareolar Khusus**                                                                                  |
| **Metastase Payudara (Paru, Melanoma, dll)** | **Riwayat Kanker Primer, Massa Keras, Bisa Multiple**                                                                                              |

## Ringkasan untuk Dokter Umum

1. **Ginekomastia = Jaringan Kelenjar (Keras/Rubbery, Retroareolar) BUKAN Lemak — Palpasi Diskus > 2 cm = Positif**
2. **Anamnesis Obat WAJIB (3-6 Bulan Mundur) — 25% Kasus Obat-Induced (Spironolacton, Finasteride, Antipsikotik, Anti-HT Lama)**
3. **Fisiologis: Bayi, Pubertas (50-65%, 6-24 Bln), Lansia — Observasi Saja Jika Ringan & < 12 Bln**
4. **Lab Minimum: Testosteron Total (Pagi), LH, FSH, Estradiol, Prolaktin, TSH, β-hCG, Fungsi Hati/Ginjal, Karyotip (Jika Hipogonadisme Primer)**
5. **USG Payudara: Beda Kelenjar (Hiperekoik) vs Lemak (Hipoekoik) — BIRADS 2**
6. **Medis First-Line: **Tamoxifen 10 mg/hari 3-6 Bln** (Efektif 70-90% Jika < 12 Bln Durasi) — Anastrozol Alternatif**
7. **Operasi (Mastektomi Subkutan + Liposuksi) = Definitif Jika Medis Gagal / > 1-2 Th / Fibrosis / Derajat IIb-III / Kosmetik**
8. **Karsinoma Payudara Pria: Massa Keras, Tidak Bergerak, Retraksi Kulit/Puting, Limfa Keras → **CORE BIOPSI WAJIB** (Jangan Enukleasi Tanpa Biopsi!)**
9. **Klinefelter (47,XXY): Testis Kecil, FSH/LH ↑, Ginekomastia, Infertilitas → Karyotip, Konseling Genetik, Testosteron Seumur Hidup**
