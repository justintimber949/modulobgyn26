SpOG: operasi rekonstruktif, defekografi, manajemen multikompartemen.

# Rektokel (Rectocele / Posterior Vaginal Wall Prolapse)

## Cerita Pembuka

Ny. Sri, 62 tahun, G3P3A0, menopause 12 tahun. Keluhan: **rasa ada benjolan di vagina seitan 3 tahun, sembelit kronik (BAK 2-3×/minggu), harus jari ke vagina (splinting/digitisasi) untuk membantu BAK, kadang kebocoran tinja saat batuk/tersengak**. Pemeriksaan: **POP-Q: Ap -2, Bp +3, C -4, D -8, Aa -1, Ba 0 → Stadium III Posterior (Rektokel) + Inkontinensia Feses Ringan (Wexner 6)**. Defekografi: **Rektokel Besar (Herniasi Rektum > 4 cm ke Vagina Saat Defekasi), Enterokel Tidak Ada, Perineal Body Pendek (2 cm)**. Urodinamika: Normal. Manajemen: **Posterior Colporrhaphy + Perineorrhaphy (Rehabilitasi Perineal Body) + Levatorplasty**. 6 Bulan: BAK Teratur Harian Tanpa Splinting, Inkontinensia Feses Hilang, POP-Q Bp -1, Puas.

## Definisi & Anatomi

**Rektokel (Rectocele)** = **Prolaps Dinding Posterior Vagina (Back Wall) Sehingga Rektum (Atau Sigmoid/Intestinum Tenue = Enterokel/Sigmoidokel) Mendesis ke Dalam/Bawah Vagina** — Karena **Kelemahan Fasia Rektovaginal (Rectovaginal Fascia / Denonvilliers' Fascia) & Lantai Panggul (Levator Ani, Puborektalis)**.

| Struktur Pendukung Normal                                                                                                                                                                                      | Kelemahan → Rektokel                                                                                                         |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Fasia Rektovaginal (Rectovaginal Fascia / Denonvilliers' Fascia)** — Membran Fibrosis Tipis Antara Vagina & Rektum, Melekat ke **Perineal Body** Distal & **Sacrouterine Ligaments / Uterosacral** Proksimal | **Defek Fasia (Midline / Lateral) + Perineal Body Pendek/Rusak** → Rektum Hernia ke Vagina Posterior                         |
| **Levator Ani (Puborektalis, Iliokoksigeus)** — **Sling Puborektalis** Membuat Angulasi Ano-Rektal (Kontinenensia)                                                                                             | **Avulsi Puborektalis / Denervasi Pudendal / Hiatus Lebar** → Loss of Anorectal Angle, Desensus Rektum                       |
| **Sfinkter Ani Eksternal & Intern** — Kontinenensia Feses                                                                                                                                                      | **Trauma Persalinan (Episiotomi Derajat 3-4, Forceps, Vakum) → Sfinkter Putus / Neuropati** → Inkontinensia Feses + Rektokel |

## Klasifikasi (POP-Q / ICS) — Stadium Posterior (Titik Bp)

| Stadium         | Titik Bp (Poin Paling Depan Dinding Posterior) | Deskripsi Klinis                                   |
| --------------- | ---------------------------------------------- | -------------------------------------------------- |
| **Stadium 0**   | Bp ≤ -3 cm                                     | Tidak Ada Prolaps                                  |
| **Stadium I**   | -3 cm < Bp ≤ -1 cm                             | Prolaps Di Atas Himen (Dalam Vagina)               |
| **Stadium II**  | -1 cm < Bp ≤ +1 cm                             | **Prolaps Sampai Himen (± 1 cm Atas/Bawah Himen)** |
| **Stadium III** | +1 cm < Bp ≤ +(tvL - 2) cm                     | **Prolaps Melebihi Himen Ke Luar (> 1 cm)**        |
| **Stadium IV**  | Bp > +(tvL - 2) cm                             | **Eversi Total (Procidentia)**                     |

> **Catatan:** **Enterokel (Herniasi Intestinum Tenue/Sigmoid ke Vagina Apex) & Sigmoidokel** Sering Bersamaan — Perlu Defekografi/MRI Beda.

## Etiologi & Faktor Risiko (Sama Kistokel + Khusus)

| Faktor                                                          | Mekanisme Khusus Rektokel                                                                                                               |
| --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **Trauma Persalinan (Obstetric Trauma) #1**                     | **Episiotomi Derajat 3-4 (Sfinkter & Perineal Body Putus), Forceps/Vakum (Avulsi Levator), Bayi Besar, Partus Lama, Presentasi Bokong** |
| **Sembelit Kronik (Straining Berulang)**                        | **Tekanan Intra-Abdominal & Intra-Rektal Kronik → Fatigue Fasia Rektovaginal & Puborektalis**                                           |
| **Obesitas & Angkat Berat**                                     | **Tekanan Intra-Abdominal Kronik & Tiba-tiba**                                                                                          |
| **Histerektomi (Apical Support Hilang)**                        | **Vault Prolapse → Enterokel + Rektokel Sekunder (Apical Desensus Menarik Dinding Posterior)**                                          |
| **Usia & Menopause**                                            | **Hipostrogenisme → Kolagen/Elastin ↓, Otot Atrofi**                                                                                    |
| **Operasi Rektum/Anus Sebelumnya**                              | **Hemoroidektomi, Fistulektomi, Sfinkterotomi → Jaringan Lemah**                                                                        |
| **Saraf: Pudendal Neuropati, Cauda Equina, Sclerosis Multipel** | **Denervasi Puborektalis & Sfinkter → Loss of Tone**                                                                                    |

## Gejala & Tanda (Khas Rektokel)

| Gejala Subjektif                                                                                            | Tanda Objektif (POP-Q + Defekografi)                                                               |
| ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Rasa Benjolan Vagina (Posterior) — Keluar Masuk Saat Berdiri/Berbaring**                                  | **Dinding Posterior Vagina Membulut (Bp > -1 cm)** — Bisa Dilihat Spekulum Simms Posterior         |
| **Sembelit Kronik: BAK Sulit, Keras, Tidak Habis, Frekuensi < 3×/Mgg**                                      | **Rektokel Bertindak Seperti "Reservoir" — Feses Terjebak di Hernia, Tidak Terangsang Defekasi**   |
| **Splinting / Digitisasi (Jari Ke Vagina/Perineum Dorong Untuk BAK) — **Patognomonik Rektokel Besar\*\*\*\* | **PVR Feses (Post-Defecation Residual) di Rektokel — Defekografi: Hernia > 3-4 cm Saat Straining** |
| **Inkontinensia Feses / Kebocoran Tinja / Gas (Flatus Inkontinen)**                                         | **Sfinkter Lemah / Perineal Body Pendek / Puborektalis Avulsi — Wexner Score**                     |
| **Nyeri Perut Bawah / Punggung / Perineum (Sakit Tarik)**                                                   | **Traksi Ligamen Uterosakral/Sacrouterine + Fasia**                                                |
| **Dispareunia / Rasa Tidak Nyaman Seks**                                                                    | **Dinding Posterior Tipis, Erosi (Stadium IV)**                                                    |
| **Vaginisme / Ketakutan Seks Karena Kebocoran**                                                             | **Psikogenik Sekunder**                                                                            |

## Diagnosis & Workup

### 1. Klinis (POP-Q + Inspeksi Perineum)

- **POP-Q: Fokus Bp (Titik Paling Depan Dinding Posterior), Perineal Body (Panjang Normal 3-4 cm, Pendek < 2 cm = Risiko Inkontinensia & Rektokel), Genital Hiatus (Normal 2-3 cm, Lebar > 4 cm = Levator Hiatus Lebar)**
- **Inspeksi Perineum: Bekas Episiotomi, Atrofi, Hiatus Lebar, Sfinkter Tone (Digital Rectal Exam — Squeeze & Rest Pressure)**
- **Valsalva Maksimal (Duduk/Litotomi) — Amati Bp & Perineal Body**

### 2. Defekografi (Defecography / MRI Defekografi) — **Gold Standard Fungsional & Anatomi Rektokel**

| Temuan                                                                                             | Signifikansi                                                       |
| -------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| **Rektokel: Hernia Anterior Rektum > 3-4 cm ke Vagina Saat Defekasi**                              | **Diagnosis Pasti & Ukuran**                                       |
| **Enterokel: Hernia Intestinum Tenue (Kawal Cecum/Sigmoid) ke Apex Vagina (C/D) Saat Defekasi**    | **Perlu Dibedakan — Operasi Berbeda (Apical Repair vs Posterior)** |
| **Sigmoidokel: Hernia Sigmoid ke Posterior Vagina**                                                | **Sering Bersamaan Rektokel**                                      |
| **Intussuspsi Rektal / Prolaps Rektal Intern / Eksternal**                                         | **Bedah Gastro Domain**                                            |
| **Anorectal Angle: Normal > 90° (Puborektalis Sling) → < 90° = Puborektalis Lemah**                | **Prediktor Inkontinensia & Outcome Operasi**                      |
| **Perineal Descent: > 3-4 cm Di Bawah Lin Coccygeus = Levator Hiatus Lebar / Puborektalis Avulsi** | **Butuh Levatorplasty / Perineorrhaphy**                           |

### 3. Anorektal Manometri (ARM) + Endoanal USG

| Parameter                                                          | Kegunaan                                                                                            |
| ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| **Resting Pressure (Sfinkter Intern)**                             | **< 40 mmHg = Sfinkter Intern Lemah**                                                               |
| **Squeeze Pressure (Sfinkter Eksternal + Puborektalis)**           | **< 100 mmHg = Sfinkter Eksternal/Puborektalis Lemah**                                              |
| **RAIR (Rectoanal Inhibitory Reflex)**                             | **Normal = Aganglionosis Rule Out (Hirschsprung)**                                                  |
| **Rectal Sensation (Volume First Sensation, Urge, Max Tolerated)** | **Hyposensitivitas / Hipersensitivitas**                                                            |
| **Endoanal USG (360°)**                                            | **Visualisasi Defek Sfinkter Intern/Eksternal (Derajat 3-4 Episiotomi Bekas), Puborektalis Avulsi** |

### 4. Urodinamika (Jika Gejala BAK Menyertai / Multikompartemen)

- **Stress UI, DO, Obstruksi, PVR — Sering Bersamaan Kistokel + Rektokel**

## Tata Laksana

### A. Konservatif (First-Line: Stadium I-II, Gejala Ringan, Lansia Komorbid, Menolak Operasi)

| Intervensi                                                                                    | Detail & Evidensi                                                                                                                                                                                                                       |
| --------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Modifikasi Diet & Kebiasaan BAK (First-Line Paling Efektif Rektokel)**                      | **Serat 25-30 g/hari (Psyllium, Ispaghula, Sayur, Buah, Bijian Utuh) + Air 2-3 L/hari + Olahraga Aerobik 30 Min/Hari** → **Konsistensi Feses Lunak (Bristol 3-4), Refleks Gastrokolik Teratur (BAK Pagi/Post-Makan), Hindai Straining** |
| **Latihan Otot Lantai Panggul (PFMT / Kegel) + Biofeedback**                                  | **Level 1B Evidensi Rektokel + Inkontinensia Feses** — **Supervised PFMT + Biofeedback (Manometri/EMG) 3-6 Bulan → Squeeze Pressure ↑, Gejala ↓, Inkontinensia ↓**                                                                      |
| **Pesarium (Ring, Cube, Gellhorn, Shaatz, Donut — Posterior Support)**                        | **Cube/Gellhorn Lebih Baik Posterior (Suction + Support)** — **Fitting Trial, Estrogen Vaginal Sinergi**                                                                                                                                |
| **Estrogen Vaginal (Estriol 0,5 mg 2×/Mgg / Ring 7,5 mg/90 Hari)**                            | **Mukosa Tebal, Vaskularisasi ↑, Pesarium Nyaman, Jaringan Lebih Elastis**                                                                                                                                                              |
| **Laksatif Osmotik (Makrogol/PEG 17-34 g/hari) / Stimulan (Bisakodil/Senna) Jika Diet Gagal** | **Hindai Straining — Tujuan: BAK Teratur Harian Tanpa Usaha**                                                                                                                                                                           |
| **Pelvic Floor Physical Therapy (Terapis Pelvik Terampil)**                                   | **Koordinasi PFMT + Biofeedback + Manual Therapy (Rilis Trigger Point, Mobilisasi Skar Episiotomi)**                                                                                                                                    |

### B. Operatif (Indikasi: Gagal Konservatif 3-6 Bulan, Stadium III-IV, Splinting Rutin, Inkontinensia Feses, Gejala Berat, Keinginan Pasien)

| Prosedur                                                                                                   | Indikasi Spesifik                                                                                          | Detail & Catatan                                                                                                                                              |
| ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Posterior Colporrhaphy (Native Tissue / Plicatura Fasial Rektovaginal Midline)**                         | **Defek Sentral (Midline) Rektokel Murni, Perineal Body Normal**                                           | **Standar Tradisional** — **Residiv 15-25% (5-10 Th)** — **Jahitan Fascia Rektovaginal (Plicatura/Plikasi) + Perineorrhaphy Jika Perineal Body Pendek**       |
| **Perineorrhaphy (Rehabilitasi Perineal Body) + Levatorplasty**                                            | **Perineal Body Pendek (< 2 cm), Genital Hiatus Lebar (> 4 cm), Puborektalis Avulsi, Inkontinensia Feses** | **Kunci Outcome Inkontinensia: Rekonstruksi Perineal Body (Pusat) + Levatorplasty (Lateral: Puborektalis Di Jahit Ke Midline) → Anorectal Angle Normalisasi** |
| **Transanal Repair (STARR / Stapled Transanal Rectal Resection / Altemeier / Delorme)**                    | **Rektokel + Intussuspsi Rektal / Prolaps Rektal Intern / Hiperplasia Mukosa Rektum**                      | **Domain Bedah Gastro — Jika Rektal Prolapse Dominan, Bukan Hanya Rektokel**                                                                                  |
| **Mesh Posterior (Biologis: SIS, Dermis, Porcine / Sintetis: Polypropylene / Komposit) — _KONTROVERSIAL_** | **Residiv Berulang / Jaringan Sangat Lemah / Multikompartemen + Apical**                                   | **FDA Warning Sama Mesh Anterior — **HANYA PUSAT TERAMPIL, INFORMED CONSENT KETAT, REGISTRI** — **Biologis Lebih Aman Tapi Residiv Lebih Tinggi\*\*           |
| **Sacrocolpopeksi (Laparoskopik/Robot/Abdominal) + Posterior Mesh (Y-Mesh)**                               | **Prolaps Apical (Vault/Uterus) + Anterior + Posterior (Multikompartemen) / Residiv Berulang**             | **Gold Standard Apical + Posterior Support — Durabilitas Terbaik**                                                                                            |
| **Histerektomi (Vaginal/Laparoskopik) + Posterior Colporrhaphy + Perineorrhaphy**                          | **Uterus Ada + Apical Prolapse + Posterior Prolapse**                                                      | **Standar Jika Uterus Ada & Selesai Keturunan**                                                                                                               |
| **Kolpokleisis (Le Fort / Total Colpocleisis)**                                                            | **Lansia (> 75-80 Th), Komorbid Tinggi, Tidak Aktif Seks, Gagal Rekonstruksi Berulang**                    | **Obliterasi Vagina — Sukses > 95% Semua Kompartemen, Morbiditas Terendah**                                                                                   |

## Pasca Operatif & Follow-up

| Waktu                 | Evaluasi                                                                                                                                      |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| **Hari 1-3**          | Diet Cair → Lunak, Laksatif Osmotik (Makrogol) Rutin, Hindari Straining, Cek BAK Harian                                                       |
| **Minggu 2**          | Luka Vagina & Perineum, BAK Pola, Nyeri, Inkontinensia                                                                                        |
| **Bulan 1, 3, 6, 12** | **POP-Q, Defekografi (Jika Gejala Persisten), Anorektal Manometri (Jika Inkontinensia), Wexner Score, Kualitas Hidup (PFDI-20, FIQL, PGI-I)** |
| **Tahunan**           | **Screening Residiv, Inkontinensia Feses/Urinary, Disfungsi Seksual, Sembelit**                                                               |

## Komplikasi Operasi

| Komplikasi                                              | Pencegahan / Penanganan                                                                                                                                            |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Residiv Rektokel (15-25% Native, 10-15% Mesh)**       | **PFMT Panjang, Diet Serat, Hindai Straining, Perineorrhaphy & Levatorplasty Jika Hiatus Lebar**                                                                   |
| **Inkontinensia Feses Baru / Persisten / Memburuk**     | **Pre-Op ARM + Endoanal USG WAJIB → Perineorrhaphy + Levatorplasty + Sfinkteroplasty (Jika Defek Sfinkter Eksternal) / Sacral Neuromodulasi (SNM) Jika Neuropati** |
| **Sembelit Parah / Obstruksi Output (Over-Tightening)** | **Hindari Over-Plication Fascia, Intraop Cek Kalibrasi (Jari/Dilator), Laksatif Rutin 2-4 Minggu Pasca-Op**                                                        |
| **Dispareunia / Nyeri Pelvik Kronik / Stenosis Vagina** | **Preservasi Vagina Panjang & Lebar, Estrogen Vaginal, Dilator Jika Perlu, Fisioterapi Pelvik**                                                                    |
| **Fistula Rektovaginal**                                | **Identifikasi Rektum Intraop (Visual/Proktoskopi), Hindari Jahitan Masuk Rektum, Lapisan Dua (Mukosa Rektum + Fascia)**                                           |
| **Eroesi Mesh / Exposure (Mesh Sintetis)**              | **Sama Seperti Mesh Anterior — Hindai Jika Mungkin, Estrogen, Ekshisi Kecil + Tutup**                                                                              |

## Multikompartemen & Keputusan Operasi (Algoritma Sederhana)

| Pola Prolaps                                   | Operasi Pilihan                                                                                                                        |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| **Hanya Anterior (Kistokel)**                  | Anterior Colporrhaphy ± Sling (Jika SUI)                                                                                               |
| **Hanya Posterior (Rektokel)**                 | Posterior Colporrhaphy + Perineorrhaphy ± Levatorplasty                                                                                |
| **Anterior + Posterior (Tanpa Apical)**        | Anterior + Posterior Colporrhaphy (Native Tissue) ± Sling                                                                              |
| **Apical (Vault/Uterus) + Anterior/Posterior** | **Sacrocolpopeksi (Laparoskopik/Robot) + Native Tissue Anterior/Posterior Repair** — **Durabilitas Terbaik**                           |
| **Uterus Ada + Apical + Anterior/Posterior**   | **Histerektomi Vaginal + Anterior/Posterior Repair** ATAU **Histeropeksi (Laparoskopik) + Sacrocolpopeksi** (Jika Ingin Simpan Uterus) |

## Ringkasan untuk Dokter Umum

1. **Rektokel = Prolaps Dinding Posterior (Rektum Turun ke Vagina) — POP-Q Bp > -1 cm = Stadium ≥ II**
2. **Gejala Khas: **Sembelit Kronik + Splinting (Jari Ke Vagina Bantu BAK) + Inkontinensia Feses/Gas** — Berbeda Kistokel (Gejala BAK)**
3. **Diagnosis: POP-Q + **Defekografi (Gold Standard Fungsional) + ARM + Endoanal USG** (Jika Inkontinensia / Akan Operasi)**
4. **First-Line: **Diet Serat 25-30 g + Air 2-3 L + Olahraga + PFMT + Biofeedback + Estrogen Vaginal + Pesarium (Cube/Gellhorn)** — **Lifestyle Paling Efektif Rektokel!\*\*
5. **Operasi: Posterior Colporrhaphy (Midline) + **Perineorrhaphy + Levatorplasty (Kunci Inkontinensia & Hiatus Lebar)** — Mesh Posterior Hanya Kasus Terpilih**
6. **Multikompartemen: Apical + Anterior/Posterior → **Sacrocolpopeksi (Gold Standard Apical) + Native Tissue Anterior/Posterior** — Uterus Ada: Histerektomi Vaginal + Repair / Histeropeksi + Sacrocolpopeksi**
7. **Lansia Tidak Aktif Seks + Komorbid → Kolpokleisis (Obliterasi) — Sukses > 95% Semua Kompartemen**
8. **Follow-up: POP-Q + Defekografi/ARM + Wexner + Kualitas Hidup 1, 3, 6, 12 Bln Lalu Tahunan**
9. **Pencegahan: **PFMT Sejak Hamil/Postpartum, Hindari Episiotomi Rutin (Restriktif), Perbaiki Sembelit Dini, Kontrol BB, Stop Rokok, Estrogen Vaginal Postmenopause\*\*"
