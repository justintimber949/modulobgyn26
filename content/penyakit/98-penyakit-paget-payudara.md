> [!info] Level Kompetensi SKDI: 1
> Dokter umum: mengenali gejala (eksim/erosi puting-areola tidak sembuh > 4-6 minggu, gatal, nyeri, sekret berdarah), diagnosis (biopsi puting/areola + IHC: CK7+, HER2+, GCDFP-15+, ER/PR variabel), pencarian CA payudara bawahnya (USG/MRI + core biopsy), rujuk SpOG Onkologi untuk operasi (mastektomi/BKP + SLNB/ALND) + adjuvant (RT, kemo, hormon, anti-HER2) berdasarkan stadium CA dasar. SpOG Onkologi: manajemen terpadu, sentinel node, breast conservation jika memungkinkan, follow-up ketat.

# Penyakit Paget Payudara (Paget's Disease of the Breast)

## Cerita Pembuka

Ny. Siti, 58 tahun, G3P3A0, menopause 8 tahun. Keluhan: **gatal & terbakar di puting kiri seitan 6 bulan, kulit puting-areola merah, bersisik, erosi, keluar cairan serosanguinolennya (kuning-kemerahan), tidak sembuh pakai salep kortikosteroid/antifungal dari dokter umum**. Pemeriksaan: **Puting Kiri Teriban (Inverted), Areola Merah Eksimatoid Luas 3×2 cm, Erosi, Krusta, Sekret Kuning-Kemerahan, Tidak Ada Massa Palpabel, Limfa Aksila Tidak Teraba**. USG: **Tidak Ada Massa Suspek (BIRADS 1), Puting Retraksi**. Mammografi: **Mikrokalsifikasi Pleomorfik Kluster Di Retroareolar Kiri (BIRADS 4C)**. MRI: **Enhancement Non-Massa Kluster Di Retroareolar 1,5 cm (BIRADS 4)**. Core Biopsy Retroareolar: **Duktal Karsinoma In Situ (DCIS) High Grade, Komedo Nekrosis, ER-, PR-, HER2 3+**. Biopsi Punch Puting: **Sel Paget (Sitoplasma Banyak, Inti Besar, Nukleolus Jelas) Di EpiderMis Areola, IHC: CK7+, HER2+, GCDFP-15+, ER-, PR-** → **Paget Disease + DCIS High Grade HER2+**. Operasi: **Mastektomi Total + SLNB (Negatif) → Rekonstruksi Implant Sekaligus**. Adjuvant: **RT Dinding Dada (Tis/T1 DCIS + Paget, Margin Negatif, SLN-) → Pertimbangkan Kemo (HER2+, High Grade) + Trastuzumab 1 Tahun + Pertuzumab (Jika Node+ / T > 1 cm) — Di Sini DCIS Saja, Node-, Tis → Kemo Kontroversial, Biasanya Hormon Jika ER+ Tapi ER- → Trastuzumab Saja Atau Observasi + RT**. 2 Tahun: NED.

## Definisi & Patogenesis

**Penyakit Paget Payudara** = **Adenokarsinoma Intraepidermal (Sel Paget) Di EpiderMis Puting & Areola** — **Hampir Selalu (≥ 90-95%) Terasosiasi Dengan Karsinoma Payudara In Situ (DCIS) Atau Invasif Di Jaringan Payudara Bawahnya (Retroareolar / Duktal Terminal)**.

| Teori Patogenesis                                                                                        | Penjelasan                                                                                                                                                               |
| -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Teori Migrasi (Transformasi Sel Duktal → Migrasi Ke EpiderMis Puting-Areola Melalui Duktal Lactifer)** | **Teori Paling Diterima** — Sel Karsinoma Duktal (DCIS/Invasif) Migrasi Melalui Duktal Lactifer Ke EpiderMis Puting → Proliferasi Sebagai Sel Paget (CK7+, HER2+, MUC1+) |
| **Teori Transformasi In Situ (Transformasi Malignan Sel Keratinosit / Sel Apokrin Puting)**              | **Minoritas** — Transformasi Primar EpiderMis Tanpa Karsinoma Duktal Bawahnya (Sangat Jarang, < 5%)                                                                      |

> **Sel Paget: Sitoplasma Luas Eosinofilik/Klar, Inti Besar Vesikular, Nukleolus Jelas, Mitosis Bisa Ada — IHC: **CK7+, HER2+ (90-95%), GCDFP-15+ (Gross Cystic Disease Fluid Protein-15), CEA+, EMA+, MUC1+** — **ER/PR Variabel (Sering Negatif Jika HER2+)\*\*"

## Epidemiologi & Asosiasi

| Parameter                                | Data                                                                       |
| ---------------------------------------- | -------------------------------------------------------------------------- | -------------------------------------------------------- | ---------------------------- |
| **Insidensi**                            | **1-4% Semua Kanker Payudara**                                             |
| **Usia Puncak**                          | **50-60 Th (Postmenopause) — Bisa Dewasa Muda**                            |
| **Jenis Kelamin**                        | **Wanita > Pria (1% Kasus Pria)**                                          |
| **Asosiasi Karsinoma Bawahnya**          | \*\*DCIS: 85-90%                                                           | Invasive Ductal Carcinoma (IDC): 50-60% (Bersamaan DCIS) | Invasive Lobular: Jarang\*\* |
| **Subtipe Molekuler Karsinoma Bawahnya** | \*\*HER2+ (Non-Luminal) Sangat Umum (80-90% DCIS/IDC Di Bawah Paget HER2+) | Luminal (ER+/PR+) Bisa Ada                               | TNBC Jarang\*\*              |

## Gejala & Tanda (Khas — Beda Eksim/Kontak Dermatitis)

| Gejala                                     | Karakteristik Paget                                                                                                 |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| **Eksimatoid Lesi Puting-Areola**          | **Merah (Eritema), Bersisik (Deskuamasi), Erosi, Ulserasi, Krusta, Lebar (Bisa Melebihi Areola Ke Kulit Payudara)** |
| **Gatal (Pruritus) & Terbakar**            | **Khas, Sering Komplain Utama — Tidak Responsif Kortikosteroid Topikal**                                            |
| **Nyeri / Sensitivitas**                   | **Sering (Raw EpiderMis + Saraf Puting)**                                                                           |
| **Sekret Puting**                          | **Serosanguinolennya (Kuning-Kemerahan) / Berdarah / Jernih — **Patognomonik Jika + Lesi Eksim\*\*"                 |
| **Puting Teriban / Retraksi / Deformitas** | **Sering (Infiltrasi Duktal + Fibrosis)**                                                                           |
| **Massa Palpabel**                         | **Hanya ~ 50% (Jika IDC Bawahnya Cukup Besar) — **Bisa Tidak Ada Massa (Hanya DCIS/Mikroinvasif)\*\*"               |

> **Red Flag: Lesi "Eksim" Puting-Areola **Tidak Sembuh > 4-6 Minggu** Pakai Terapi Standar (Kortikosteroid/Antifungal/Antibiotik) → **BIOPSI WAJIB** — **Jangan Lama-Lama Pakai Salep Tanpa Diagnosis!"\*\*

## Diagnosis & Workup

### 1. Biopsi (Gold Standard Diagnosis Paget)

| Metode                                                                         | Indikasi & Detail                                                                              |
| ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| **Punch Biopsy Puting/Areola (3-4 mm)**                                        | **First-Line: Diagnosis Sel Paget Di EpiderMis — IHC: CK7+, HER2+, GCDFP-15+, ER/PR Variabel** |
| **Shave Biopsy / Incisional Biopsy**                                           | **Jika Lesi Luas / Ulserasi Dalam**                                                            |
| **Core Needle Biopsy (CNB) Massa Bawahnya (Jika Ada Massa / USG/MRI Positif)** | **Diagnosis Karsinoma Bawahnya (DCIS/IDC) + Grade + IHC (ER, PR, HER2, Ki-67)**                |
| **Vacuum-Assisted Biopsy (VAB) / Mammotome**                                   | **Mikrokalsifikasi Tanpa Massa (BIRADS 4/5) — Bisa Eksisi Lengkap + Diagnosis**"               |

> **IHC Paget: **CK7+ (Sensitif), HER2+ (90-95%), GCDFP-15+ (Spesifik Apokrin), CEA+, MUC1+ — **Beda Melanoma (S100+, HMB45+, MelanA+, CK7-, HER2-) & Eksim (Negatif Semua)**"\*\*

### 2. Imaging (Pencarian Karsinoma Bawahnya — **WAJIB Semua Kasus**)

| Modality                                                                 | Sensitivitas & Peran                                                                                                                                                         |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Mammografi (2D/3D Tomosintesis)**                                      | **Mikrokalsifikasi Pleomorfik Kluster (DCIS) Di Retroareolar — Sensitivitas ~ 50-70% (Bisa Negatif Jika Hanya DCIS Kecil / Payudara Padat)**                                 |
| **USG TVS/Payudara**                                                     | **Massa Hiperekoik/Heterogen / Distorsi Arsitektur / Duktal Dilatasi — Sensitivitas ~ 60-80% (Lebih Baik Massa Invasif)**                                                    |
| **MRI Payudara (Kontras Gadolinium) — **Gold Standard Imaging Paget\*\*" | **Enhancement Non-Massa (Kluster/Linear/Segmental) Di Retroareolar — Sensitivitas **90-95%** Untuk DCIS/IDC Bawahnya — **WAJIB Jika Mammo/USG Negatif Tapi Klinis Paget\*\*" |

### 3. Staging (Jika Karsinoma Invasif Terkonfirmasi / IDC)

| Modality                                                    | Indikasi                                                                                                                                            |
| ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CXR / CT Thoraks, CT Abdomen/Pelvis, Bone Scan / PET-CT** | **Stage III-IV / IDC > 1 cm / Node+ / Gejala Metastasis**                                                                                           |
| **SLNB (Sentinel Lymph Node Biopsy)**                       | **WAJIB Jika IDC / Mikroinvasif / DCIS + Mastektomi (Tidak Bisa SLNB Pasca Mastektomi) / DCIS Besar > 3-5 cm / High Grade / Paget + Massa Klinis**" |

## Tata Laksana (Berdasarkan Karsinoma Bawahnya — **Paget Adalah Manifestasi Kulit, Bukan Entitas Terpisah**)

### A. DCIS Saja (Non-Invasif) — **~ 40-50% Kasus Paget**

| Opsi Operasi                                          | Indikasi & Detail                                                                                                                                                                                                                                            |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Mastektomi Total (Simple) + SLNB**                  | **Standar Jika: DCIS Luas (> 3-5 cm) / Multifokal / Margin Tidak Bisa Negatif Dengan BKP / Paget Luas (Seluruh Areola/Puting) / Keinginan Pasien / Tidak Bisa RT**                                                                                           |
| **Breast Conserving Surgery (BKP / Lumpektomi) + RT** | **Jika: DCIS Terbatas (Unifokal, < 3-4 cm), Margin Negatif Bisa Dicapai (≥ 2 mm), Paget Terbatas Puting-Areola, Bisa RT, Pasien Setuju** — **Eksisi Puting-Areola (Paget) + Eksisi DCIS (Margin ≥ 2 mm) → RT Whole Breast 50 Gy + Boost Tumor Bed 10-16 Gy** |
| **SLNB**                                              | **Direkomendasikan Jika Mastektomi (Tidak Bisa SLNB Nanti) / DCIS High Grade / > 3-5 cm / Palpabel Massa / Paget Luas — **Jika BKP + SLNB Negatif → Tidak Perlu ALND\*\*"                                                                                    |

### B. Invasive Ductal Carcinoma (IDC) + Paget — **~ 50-60% Kasus**

| Opsi Operasi                                          | Indikasi & Detail                                                                                                                                                                                                                               |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **BKP (Lumpektomi) + SLNB + RT**                      | **Jika: IDC Unifokal, Ukuran Memungkinkan (T1-T2), Margin Negatif Bisa, Bisa RT, Pasien Setuju — **Eksisi Puting-Areola (Paget) + Eksisi Tumor (Margin ≥ 1 mm Invasif / ≥ 2 mm DCIS) → SLNB → RT Whole Breast ± Regional Nodal (Jika Node+)\*\* |
| **Mastektomi Total + SLNB/ALND + RT (Jika Indikasi)** | **Jika: IDC Multifokal/Multisentrik, Ukuran Besar (T3-4), Margin Tidak Bisa Negatif, Inflamatori, Tidak Bisa RT, Keinginan Pasien, BRCA Mutasi**                                                                                                |
| **SLNB → ALND Jika SLN+ (Makro)**                     | **Standar: SLNB 1-2 Macrometastasis → ALND / RT Aksila (AMAROS: RT = ALND Low Burden) — **Jika SLN Mikro (≤ 2 mm) → RT Aksila / Observasi\*\*"                                                                                                  |

### C. Terapi Adjuvant (Berdasarkan Subtipe Molekuler Karsinoma Bawahnya — **Paget Ikut Subtipe DCIS/IDC**)

| Subtipe                                             | Terapi Adjuvant                                                                                                                                                                                                                                        |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **DCIS ER+/PR+ (Luminal)**                          | **RT (Jika BKP) + Hormon Terapi (Tamoxifen Pre/AI Post) 5 Tahun — **Kemo Tidak Perlu\*\*"                                                                                                                                                              |
| **DCIS HER2+ (Non-Luminal) — **Sering Di Paget\*\*" | **RT (Jika BKP) — **Kemo Kontroversial (DCIS Saja) — **Trastuzumab Bisa Dipertimbangkan Jika High Grade, Besar, Margin Rapuh / Klinis Trial (NSABP B-43: Trastuzumab + RT vs RT Saja DCIS HER2+ → Ipsilateral Recurrence ↓ Tapi OS Tidak Signifikan)** |
| **IDC Luminal A/B**                                 | **RT + Hormon Terapi 5-10 Th ± Kemo (Berdasarkan Grade, Ki-67, Oncotype/MammaPrint, Ukuran, Node)**                                                                                                                                                    |
| **IDC HER2+**                                       | **RT + Kemo (Carbo/Pakli + Trastuzumab+Pertuzumab / AC-THP) → Trastuzumab+Pertuzumab 1 Th (Adjuvant) — **T-DM1 Jika Residual Pasca Neoadjuvant (KATHERINE)\*\*                                                                                         |
| **IDC TNBC**                                        | **RT + Kemo (Carbo/Pakli → AC / Dose-Dense AC-T / Pembro+Carbo/Pakli → AC KEYNOTE-522) → Pembrolizumab Adjuvant 1 Th (Jika Neoadjuvant Pembro) / Kemo Adjuvant Saja (Jika Tidak Neoadjuvant Pembro)**                                                  |

### D. Mastektomi + Rekonstruksi

- **Skin-Sparing / Nipple-Sparing Mastektomi (NSM) — **KONTRAINDIKASI Jika Paget Luas (Kulit Puting-Areola Terlibat Malignan) — **Jika Paget Terbatas & Margin Proksimal Negatif (Frozen Section) → NSM Bisa Dipertimbangkan Di Pusat Terampil**"\*\*

## Follow-up

| Waktu                                   | Evaluasi                                                                                                                                                                  |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Setiap 3-6 Bulan (Th 1-3)**           | **Klinis (Dinding Dada, Sisa Payudara, Limfa), Mammografi (Ipsilateral 6-12 Bln Post-RT Lalu Tahunan, Kontralateral Tahunan), USG Selektif, CA-125/CEA/CA 15-3 Opsional** |
| **Setiap 6-12 Bulan (Th 4-5)**          | **Sama**                                                                                                                                                                  |
| **Tahunan (Th > 5)**                    | **Klinis + Mammografi + USG Selektif**                                                                                                                                    |
| **BRCA Mutasi / Kuat Riwayat Keluarga** | **MRI Tahunan + Mammografi (Alternating 6 Bln) + Ovarium Screening / RRSO**"                                                                                              |

## Prognosis

| Kondisi                                                  | 5-Year OS                                                                                             | 10-Year OS      |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | --------------- |
| **Paget + DCIS Saja (Non-Invasif)**                      | **> 95-98%**                                                                                          | **> 90-95%**    |
| **Paget + IDC (Invasif)**                                | **Berdasarkan Stage IDC (T, N, Grade, Receptor)** — **Sama Dengan IDC Tanpa Paget (Jika Stage Sama)** | **Sama**        |
| **Paget Tanpa Karsinoma Bawahnya (Sangat Jarang, < 5%)** | **Hampir 100% (Jika Eksisi Lengkap)**                                                                 | **Hampir 100%** |

> **Faktor Prognosis Buruk: IDC (Bukan DCIS), Node+, Grade 3, HER2+ (Tanpa Anti-HER2), TNBC, Margin Positif, Ukuran Besar, LVI+, P53 Aberan**"

## Ringkasan untuk Dokter Umum

1. **Paget Payudara = "Eksim Puting-Areola Tidak Sembuh > 4-6 Minggu" + Sekret Berdarah + Puting Teriban → **BIOPSI PUNCH PUTING/AREOLA WAJIB (IHC CK7, HER2, GCDFP-15) — **JANGAN LAMA-LAMA PAKAI SALEP KORTIKOID/ANTIFUNGAL TANPA DIAGNOSIS!"**
2. **Hampir Selalu (≥ 95%) Ada Karsinoma Bawahnya (DCIS > IDC) — **IMAGING WAJIB: MRI Payudara (Gold Standard) + Mammografi + USG**"**
3. **Diagnosis Definitif: **Biopsi Puting (Sel Paget) + Biopsi Core Massa Bawahnya (DCIS/IDC + Grade + IHC ER/PR/HER2/Ki-67)**"**
4. **Tatalaksana = Berdasarkan Karsinoma Bawahnya (DCIS vs IDC) + Subtipe Molekuler — **Paget Adalah Manifestasi Kulit, Bukan Entitas Terpisah**"**
5. **DCIS Saja: BKP + RT (Jika Terbatas) / Mastektomi (Jika Luas) + SLNB (Jika Mastektomi/High Risk) + Hormon (Jika ER+) ± Trastuzumab (Jika HER2+ High Risk DCIS — Klinis Trial)"**
6. **IDC: BKP + SLNB + RT / Mastektomi + SLNB/ALND + RT + Sisteminik (Kemo/Hormon/Anti-HER2/Imuno) Berdasarkan Subtipe"**
7. **SLNB WAJIB Jika IDC / DCIS High Risk / Mastektomi — **ALND Jika SLN Makro+"\*\*
8. **Follow-up: Mammografi + Klinis Tahunan, MRI Jika BRCA/High Risk — **Prognosis Baik Jika DCIS Saja (> 95% 5-yr OS) — **Jika IDC, Prognosis = Stadium IDC**"\*\*
