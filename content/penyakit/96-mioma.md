# Mioma Uteri (Leiomyoma / Uterine Fibroids)

## Cerita Pembuka

Ny. Ani, 35 tahun, G0, keluhan: **menorrhagia seitan 2 tahun (perpad 8-10/hari, anemia Hb 8,5), tekanan perut bawah, BAK sering, infertilitas primer 3 tahun**. Pemeriksaan: **Massa Perut Tengah Bawah Hingga Atas Umbilikus, Keras, Tidak Nyeri, Bergerak Dengan Nafas, Ukuran 20 Mg**. USG TVS: **Mioma Multiple: Subserosa Anterior 8×7 cm (Pedunkulasi), Intramural Posterior 6×5 cm, Submukosa Posterior 3×3 cm (Jenis 1 FIGO) — Uterus Total 22×14×12 cm**. Lab: **Hb 8,5, Ferritin 8, Tranexamic Acid 500 mg 3×/Hari Haid + Suplemen Besi**. Pre-Op: **GnRHa (Leuprorelin 3,75 mg IM) × 2 Siklus (Volume Mioma ↓ 30%, Hb Naik 11,2)**. Operasi: **Laparoskopik Miomektomi (Enukleasi 3 Mioma, Rekonstruksi Miometrium 3 Lapisan, Barbed Suture, Vasopressin Injeksi Pre-Enukleasi, Adhezi Prophylaks Intercoat) — Blood Loss 300 mL, LOS 2 Hari**. Histopat: **Leiomyoma Sel Spindel Benin, Mitosis < 5/10 HPF, Tidak Ada Atipia/Nekrosis**. 6 Bulan: **Hb 13,5, Siklus Normal, USG Uterus Normal, Hamil Spontan 8 Bln Pasca-Op → CS Elektif 37 Mg (Ruptur Uterus Risiko Rendah Tapi Ada) → Bayi Sehat**.

## Definisi & Epidemiologi

**Mioma (Leiomyoma / Fibroid)** = **Tumor Jinak Monoklonal Berasal Dari Sel Miometrium (Spindle Cell) + Ekstrakelular Matrix (Kolagen, Fibronektin, Proteoglikan)** — **Tumor Paling Umum Wanita Usia Subur**.

| Parameter                        | Data                                                                                                                                                                           |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Prevalensi**                   | **70-80% Wanita Usia 50 Th (Autopsi/USG Screening) — Klinis Simtomatik 20-30%**                                                                                                |
| **Usia Puncak**                  | **35-50 Th (Perimenopause) — Jarang < 20 Th, Regresi Postmenopause (Estrogen ↓)"**                                                                                             |
| **Faktor Risiko**                | **Ras Hitam (3-4× Risiko vs Putih), Nullipara, Menarche Dini, Obesitas, Hipertensi, Riwayat Keluarga, Vitamin D Rendah, Diet Merah Tinggi/Buah Sayur Rendah, Alkohol, Stres"** |
| **Protektif**                    | **Multipara, Menyusui, COC (Kurangi Risiko), Menopausa, Ulipristal/GnRHa (Sementara)"**                                                                                        |
| **Lokasi (FIGO Classification)** | **Submukosa (Tipe 0, 1, 2) — Intramural (Tipe 3, 4) — Subserosa (Tipe 5, 6, 7) — Servikal / Ligamen / Parasitik (Tipe 8)"**                                                    |

## Patogenesis & Molekuler

| Mekanisme                               | Detail                                                                                                                                                            |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Monoklonal (Satu Sel Asal)**          | **Setiap Mioma Berasal Dari Satu Sel Miometrium Yang Mutasi → Proliferasi Klonal**"                                                                               |
| **Mutasi Driver (70-80%)**              | **MED12 (Exon 2) — Paling Umum (60-70%), FH (Fumarate Hydratase — HLRCC Syndrome), HMGA2 (Translokasi 12q15), COL4A5/COL4A6 (Deleksi Xq22), TERT Promoter**"      |
| **Hormon: Estrogen & Progesteron**      | **Receptor ER & PR Tinggi → Proliferasi Siklus (Estrogen) + Anti-Apoptosis/ECM Produksi (Progestin) — **Mioma Tumbuh Saat Haid/Hamil, Menyusut Postmenopause\*\*" |
| **Growth Factors**                      | **TGF-β, VEGF, PDGF, IGF-1, bFGF, WNT/β-Catenin — Autokrin/Parakrin**"                                                                                            |
| **Ekstrakelular Matrix (ECM) Berlebih** | **Kolagen Tipe I/III, Fibronektin, Proteoglikan → Mioma Lebih Keras & Padat vs Miometrium Normal**"                                                               |

## Klasifikasi FIGO (PALM-COEIN System untuk AUB — Mioma = "L" Leiomyoma)

| Tipe FIGO  | Lokasi                                                                          | Karakteristik                                                             | Gejala Utama                                                            |
| ---------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **Tipe 0** | **Submukosa Pedunkulasi (Sepenuhnya Di Rongga)**                                | **Stalk Peduncle, Bisa Keluar Serviks (Mioma Born Out)**                  | **Menorrhagia Berat, Infertilitas, Bisa Infeksi/Nekrosis Jika Keluar**" |
| **Tipe 1** | **Submukosa < 50% Di Miometrium**                                               | **Bulatan, Batas Tegas, Push Endometrium**                                | **Menorrhagia #1, Infertilitas, Aborsi**"                               |
| **Tipe 2** | **Submukosa ≥ 50% Di Miometrium**                                               | **Lebih Dalam, Masih Push Endometrium**                                   | **Menorrhagia, Infertilitas**"                                          |
| **Tipe 3** | **Intramural Kontak Endometrium (Tidak Push)**                                  | **Di Miometrium, Dekat Endometrium**                                      | **Menorrhagia (Kurang vs Tipe 1-2), Tekanan, Infertilitas**"            |
| **Tipe 4** | **Intramural Murni (Tidak Sentuh Endometrium/Serosa)**                          | **Tengah Miometrium**                                                     | **Tekanan, Massa, Infertilitas (Jika Besar > 5 cm Distorsi Uterus)**"   |
| **Tipe 5** | **Subserosa ≥ 50% Di Miometrium**                                               | **Keluar Ke Serosa, Masih Base Di Miometrium**                            | **Tekanan, Massa, BAK Sering, Konstipasi, Dispareunia**"                |
| **Tipe 6** | **Subserosa < 50% Di Miometrium (Hampir Pedunkulasi)**                          | **Hampir Bebas, Stalk Tipis**                                             | **Tekanan, Torsi (Jika Pedunkulasi Panjang), Massa**"                   |
| **Tipe 7** | **Subserosa Pedunkulasi (Sepenuhnya Di Luar, Stalk)**                           | **Bebas Di Peritoneal, Bisa Parasitik (Vaskularisasi Dari Omentum/Usus)** | **Massa, Torsi, Nyeri Akut (Torsi Stalk) — **Emergensi\*\*"             |
| **Tipe 8** | **Lainnya: Servikal, Ligamen Latum (Intraligamen), Parasitik, Retroperitoneal** | **Lokasi Ektopik**                                                        | **Sesuai Lokasi (Ureter Obstruksi, Nyeri Punggung, Massa Pelvik)**"     |

> **PALM-COEIN: Polyp, Adenomyosis, Leiomyoma, Malignancy/Hyperplasia — Coagulopathy, Ovulatory Dysfunction, Endometrial, Iatrogenic, Not Classified**"

## Gejala & Tanda (Bergantung Lokasi, Ukuran, Jumlah)

| Gejala                                                                                                       | Tipe Mioma Yang Sering                                                                                                        | Mekanisme                                                                                    |
| ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| **Menorrhagia / Hipermenorea (Anemia)**                                                                      | **Submukosa (0, 1, 2) > Intramural (3, 4) Besar**                                                                             | **Endometrium Luas, Vaskularitas ↑, Kontraktilitas Uterus Gangguan, Prostaglandin ↑**"       |
| **Tekanan Pelvik / Perut Besar / Massa Teraba**                                                              | **Subserosa (5, 6, 7) Besar, Intramural (4) Besar, Multiple**                                                                 | **Efek Massa Fisik**"                                                                        |
| **Gejala Uriner: Frekuensi, Urgensi, Retensi, Hidronephrosis**                                               | **Anterior Subserosa/Intramural Besar (> 5-6 cm) Tekan Bladder/Ureter**                                                       | **Kompresi Bladder / Ureter (Ureteral Obstruction → Hydroureteronephrosis)"**                |
| **Gejala GI: Konstipasi, Tenesmus, Distensi**                                                                | **Posterior Subserosa/Intramural Besar Tekan Rektum/Sigmoid**                                                                 | **Kompresi Rektum/Sigmoid**"                                                                 |
| **Dispareunia (Nyeri Seks)**                                                                                 | **Posterior/Subserosa/Ligamen (Tekan Saat Penetrasi Mendalam)**                                                               | **Kompresi Ligamen Uterosakral / Cul-de-sac**"                                               |
| **Dismenorea / Nyeri Pelvik Kronik**                                                                         | **Semua Tipe (Degenerasi, Torsi, Ischemia, Adenomiosis Bersamaan)**                                                           | **Degenerasi (Hyalin/Mioksid/Kalsifikasi/Nekrosis Merah), Torsi Pedunkulasi**"               |
| **Infertilitas / Aborsi Spontan / Preterm / Malpresentasi / PPH**                                            | **Submukosa (Distorsi Rongga), Intramural Besar (> 4-5 cm Distorsi Junctional Zone), Subserosa (Jika Distorsi Tuba/Ovarium)** | **Distorsi Anatomi, Vaskularitas Endometrium Gangguan, Inflamasi, Kontraktilitas Abnormal**" |
| **Kehamilan: Degenerasi Mioksid/Nekrosis Merah (Nyeri Akut Trimester 2), Malpresentasi, Preterm, PPH, CS ↑** | **Semua (Estrogen/Progesteron Tinggi → Pertumbuhan Cepat → Iskemia → Degenerasi)**                                            | **"Degenerasi Mioksid (Pain, Fever, Leukositosis, USG: Heterogen, Cystic, Vaskularitas ↓)"** |

## Diagnosis & Workup

### 1. USG Transvaginal (TVS) + Transabdominal — **First-Line Gold Standard (Sens 90-99%, Spec 90-95%)**

| Parameter USG                                                                                         | Deskripsi                                                               |
| ----------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **Jumlah, Lokasi (FIGO Type), Ukuran (3 Dimensi), Volume**                                            | **Mapping Lengkap (Mioma Mapping) — **Wajib Untuk Planning Operasi\*\*" |
| **Ekogenisitas: Hiperekoik (Sel Spindel Padat) / Isoekoik / Hipoekoik (Degenerasi Mioksid/Nekrosis)** | **Karakterisasi**"                                                      |
| **Vaskularitas (Color/Power Doppler): Vaskularitas Perifer (Rim) vs Sentral (Degenerasi)**            | **Vitalitas & Degenerasi**"                                             |
| **Kapsul: Batas Tegas (Mioma) vs Tidak Tegas (Adenomiosis)**                                          | **Beda Adenomiosis**"                                                   |
| **Efek Acoustic Shadowing (Kalsifikasi) / Enhancement (Degenerasi Kistik)"**                          | \*\*"                                                                   |

> **FIGO Type Penting: Submukosa (0, 1, 2) = Histeroskopik Miomektomi Bisa — Intramural/Subserosa = Laparoskopik/Laparotomi"**

### 2. Histeroskopi (Diagnostik + Terapetik) — **Gold Standard Submukosa (Tipe 0, 1, 2)**

- **Visualisasi Langsung Rongga Uterus, Mioma Submukosa, Endometrium, Ostia Tuba**
- **Bisa Resaksi Langsung (Resectoscope / Morcellator Histeroskopik) — Tipe 0 & 1 Mudah, Tipe 2 Butuh 2 Tahap / Laparoskopi Bantuan"**

### 3. MRI Panggul (Jika USG Tidak Jelas / Multiple Mioma Kompleks / Planning Operasi Kompleks / Rule Out Sarkoma / Adenomiosis Bersamaan)

- **Karakterisasi Jaringan (T2W: Mioma Hipointense vs Adenomiosis Hiperintense JZ), Batas Lesi, Vaskularitas, Hubungan Ureter/Bladder/Rectum, Deteksi Sarkoma (T2W Hiperintense, DWI Restricted, Enhancement Heterogen, Necrosis)"**

### 4. Laboratorium

| Pemeriksaan                                                     | Indikasi                                                                                           |
| --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| **Hb, Ht, Ferritin, TIBC, Transferin Saturasi**                 | **Anemia Defisiensi Besi (Menorrhagia) — **WAJIB\*\*"                                              |
| **Koagulasi (PT, APTT, Fibrinogen, Trombosit, Von Willebrand)** | **Rule Out Koagulopati (Von Willebrand Paling Umum) Jika Menorrhagia Parah Remaja**"               |
| **TSH, Prolaktin**                                              | **Rule Out Hipotiroid/Hiperprolaktinemia Sebagai Penyebab AUB**"                                   |
| **CA-125**                                                      | **Bisa Naik Mioma (Bukan Spesifik Kanker) — **Tidak Rutin, Hanya Jika Curiga Malignan/Ovarium\*\*" |
| **LDH, Urik Asid, Kreatinin**                                   | **Jika Degenerasi Nekrosis Merah Akut (LDH ↑) / Obstruksi Ureter (Kreatinin ↑)**"                  |

## Tata Laksana (Individualisasi: Gejala, Ukuran, Lokasi, Usia, Fertilitas, Preferensi)

### A. Observasi (Asimtomatik / Gejala Ringan / Menopause Dekat / Menolak Terapi)

- **USG 6-12 Bulanan Monitoring Ukuran & Gejala Baru — **Mioma Tumbuh Rata-Rata 9-10%/Tahun (Logaritmik), Cepat Saat Hamil/Estrogen Tinggi, Regresi Postmenopause**"**
- **Edukasi: Gejala Peringatan (Nyeri Akut, Blooding Berat, Massa Cepat Membesar → Curiga Sarkoma / Degenerasi / Torsi)**"

### B. Medis (First-Line Gejala Menorrhagia/Nyeri — **Non-Kontra Indikasi Operasi**)

| Obat                                          | Indikasi Utama                                                                                                                         | Dosis & Durasi                                                                                                                     | Catatan                                                                                                     |
| --------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **Tranexamic Acid (TXA)**                     | **Menorrhagia (Volume ↓ 30-50%) — **First-Line Non-Hormonal\*\*"                                                                       | **500 mg 3-4×/Hari Selama Haid (Maks 5 Hari/Siklus)**                                                                              | **Kontra: Trombosis Aktif, Seizure, Warfarin (Hati-Hati)**"                                                 |
| **NSAID (Mefenamat/Ibuprofen/Naproksen)**     | **Dismenorea + Menorrhagia (Prostaglandin ↓)**                                                                                         | **Mefenamat 500 mg 3×/Hari Haid (Maks 5-7 Hari)**                                                                                  | **Kontra: PUD, Ginjal, Kardiovaskular, Asthma NSAID-Sensitif**"                                             |
| **COC (EE 20-30 μg + Progestin)**             | **Siklus Teratur, Volume ↓, Nyeri ↓, Kontra**                                                                                          | **Extended/Continuous Regimen (84/7) Lebih Baik Nyeri**                                                                            | **Kontra: Trombosis Risiko, Rokok > 35 Th, Migren Aura, HT Tidak Terkendali, Obesitas BMI > 35**"           |
| **LNG-IUS (Mirena 52 mg)**                    | **Menorrhagia + Kontra + Nyeri — **First-Line Hormonal (Jika Uterus < 10-12 cm, Tidak Distorsi Berat Rongga)\*\*"                      | **5-8 Tahun — **Volume Haid ↓ 80-90%, Anemia Sembuh\*\*"                                                                           | **Kontra: Uterus Terlalu Besar/Distorsi Rongga (Expulsion Risiko), Infeksi Aktif, CA Serviks/Endometrium**" |
| **GnRHa (Leuprorelin/Triptorelin/Goserelin)** | **Pre-Op (Miomektomi/Histerektomi) → Volume ↓ 30-50%, Hb Naik, Operasi Lebih Mudah — **Short-Term 3-6 Bln (Add-Back Jika > 6 Bln)\*\*" | **3,75 mg IM Bulanan / 11,25 mg 3 Bulanan — **Add-Back: Noretisteron 2,5 mg / Tibolone 2,5 mg / LNG-IUS\*\*"                       | **SE: Hot Flush, Osteoporosis, Atrofi Vagina, Mood — **BUKAN Jangka Panjang Tanpa Add-Back\*\*"             |
| **Ulipristal Acetate (UPA) 5-10 mg/hari**     | **Pre-Op Mioma (EU Approved) / Intermittent (4 Bln On / 4 Bln Off) — **Volume ↓ 40-70%, Blooding Kontrol\*\*"                          | **3-6 Bulan Siklus — **Monitor Liver Fungsi Bulanan (ALT/AST/Bilirubin) — **Hepatotoksisitas Risiko (Black Box Warning FDA/EMA)**" | **Tidak Approved US (FDA) — **EU: Pre-Op Mioma / Intermittent\*\*"                                          |
| **Dienogest 2 mg/hari**                       | **Nyeri (Dismenorea) + Volume Sedikit ↓ — **Alternatif LNG-IUS/COC\*\*"                                                                | **Kontinu — **SE: Spotting, Weight Gain, Mood\*\*"                                                                                 | **Data Mioma Kurang vs Endometriosis**"                                                                     |
| **Mifepriston (Antiprogestin) 5-50 mg/hari**  | **Volume ↓, Blooding ↓ — **Data Terbatas, Endometrial Hyperplasia Risiko (Unopposed Estrogen Effect)\*\*"                              | \*\*"                                                                                                                              | \*\*"                                                                                                       |

### C. Intervensi Minimal Invasif / Organ-Preserving (Ingin Fertilitas / Menolak Histerektomi)

| Prosedur                                                                                          | Indikasi                                                                                                                                                                                                   | Detail & Outcome                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Histeroskopik Miomektomi (Resectoscope / Morcellator Histeroskopik)**                           | **Submukosa Tipe 0, 1, 2 (≤ 3-4 cm, ≤ 3 Lesi) — **Gold Standard Submukosa\*\*"                                                                                                                             | **Sukses 85-95% (Normalisasi Haid, Fertilitas Pulih) — **Komplikasi: Perforasi (1-2%), Cairan Overload (Glycine/Sorbitol — Naik Na+, Hiponatremia), Infeksi, Adhezi (Asherman) — **Second Look Histeroskopi 4-8 Minggu Pasca-Op**" |
| **Laparoskopik Miomektomi**                                                                       | **Intramural/Subserosa (Tipe 3-7) ≤ 10-12 cm, ≤ 4-5 Lesi, Usia < 40 Th, Ingin Fertilitas — **Butuh Skill Tinggi (Enukleasi, Rekonstruksi Miometrium Multi-Lapis, Hemostasis, Morcelasi Dalam Tas/Bag)\*\*" | **Blood Loss < 500 mL (Vasopressin, Turunikat, Gel Hemostatik), LOS 1-3 Hari, Fertilitas Outcome: Hamil 40-60% (Usia < 35) — **CS Elektif 36-37 Mg WAJIB (Ruptur Uterus 0,5-1% vs 0,07% Normal)\*\*"                               |
| **Laparotomi Miomektomi**                                                                         | **Mioma Raksasa (> 12-15 cm), Multiple > 5-6, Adhezi Berat, Skill Laparoskopik Tidak Tersedia, Obesitas BMI > 35**                                                                                         | **Blood Loss Lebih Banyak, LOS 3-5 Hari, Nyeri Post-Op Lebih, Adhezi Risiko Lebih Tinggi — **Tetap Fertility-Sparing\*\*"                                                                                                          |
| **UAE (Uterine Artery Embolization) — Partikel PVA/Embosphere/Tris-acryl 500-700 μm**             | **Menorrhagia Refrakter Medis, Multiple Mioma, Ingin Hindari Operasi, Uterus < 16 Mg, **Fertilitas Kontroversial (Bisa Tapi Risiko Ovarian Failure 5-15%, Aborsi ↑, Preterm ↑, Placenta Abnormal ↑)\*\*"   | **Radiologi Intervensi: Sukses Klinis 80-90% (Volume ↓ 40-60%, Gejala ↓) — **Recurrence 10-20% 5 Th — **Post-Embolization Syndrome (Nyeri, Demam, Nausea, Leukositosis 3-7 Hari) — **Amenorea Risiko Usia > 45 Th\*\*"             |
| **HIFU / MRgFUS (High-Intensity Focused Ultrasound)**                                             | **Mioma Fokal/Intramural/Subserosa ≤ 10 cm, Tidak Dekat Bladder/Bowel/Ureter, Ingin Non-Invasif, Fertilitas Data Terbatas**                                                                                | **Termal Ablasi (65-85°C) → Necrosis Koagulatif — **Volume ↓ 30-50% 6-12 Bln, Gejala ↓ 70-80% — **Mahal, Butuh MRI/USG Guidance, Tidak Semua Tempat**"                                                                             |
| **RFA (Radiofrequency Ablation) — Transvaginal / Laparoskopik / Transcervical (Acessa / Sonata)** | **Mioma Intramural/Subserosa ≤ 10 cm, Multiple, Ingin Minimal Invasif, Fertilitas Data Baru (Sonata: Transcervical RFA + USG Guidance — Fertilitas Bisa Terjaga)**                                         | **Volume ↓ 40-70% 12 Bln, Gejala ↓ 80% — **Lebih Baru, Data Jangka Panjang Kurang\*\*"                                                                                                                                             |

### D. Operasi Definitif (Histerektomi) — **Selesai Keturunan / Gejala Berat Refrakter / Usia > 40-45 Th / Malignancy Curiga (Sarkoma)**

| Jenis                                                                                                  | Indikasi & Keuntungan                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| **Histerektomi Total Laparoskopik (TLH) / Laparoskopik Asist Vaginal (LAVH) / Vaginal (VH) / Robotik** | **Gold Standard Minimal Invasif — **Blood Loss < 200 mL, LOS 1-2 Hari, Recovery 2-3 Minggu, Kurangi Adhezi vs Laparotomi** — **BSO Opsional (Pertahankan Ovarium < 50 Th)"\*\*                                          |
| **Histerektomi Subtotal (Supravaginal / LASH) — Serviks Dipertahankan**                                | **Lebih Cepat, Kurang Blooding, Risiko Ureter/Bladder Lebih Rendah, Fungsi Seksual Mungkin Lebih Baik — **Tidak Bisa Jika CIN/CA Serviks / Endometriosis Serviks / Prolaps Serviks — **Masih Perlu Screening Serviks**" |
| **Histerektomi Total Abdominal (TAH)**                                                                 | **Uterus Raksasa (> 16-18 Mg), Adhezi Berat, Malignancy Curiga (Sarkoma), Skill Minimal Invasif Tidak Tersedia, Obesitas BMI > 40**                                                                                     | \*\*Blood Loss Lebih, LOS 3-5 Hari, Nyeri Lebih, Adhezi Risiko Tinggi, Recovery 4-6 Minggu" |

## Kehamilan & Mioma

| Aspek                                     | Rekomendasi                                                                                                                                                                                                                                                                                                                         |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Pertumbuhan Mioma Saat Hamil**          | **70-80% Tumbuh (Trimester 1-2, Estrogen/Progesteron Tinggi) — Rata-Rata 10-30% Volume ↑ — **Degenerasi Mioksid Paling Umum Komplikasi (Nyeri Akut, Fever, Leukositosis, USG Heterogen Kistik)\*\*"                                                                                                                                 |
| **Degenerasi Mioksid (Red Degeneration)** | **Iskemia → Nekrosis → Inflamasi → Nyeri Hebat Perut Bawah, Fever, Leukositosis, Contraction Uterus → Preterm Risk** — **Konservatif: Analgesia (Paracetamol/Opioid Cek Kondisi), Hidrasi, Tocolysis (Nifedipin/Atosiban) Jika Kontraksi, **TIDAK Operasi (Kecuali Peritonitis/Sepsis)** — **Biasanya Self-Limiting 1-2 Minggu\*\*" |
| **Persalinan**                            | **VBAC Bisa Jika Miomektomi Sebelumnya Hanya Subserosa/Intramural Kecil Tanpa Masuk Rongga Endometrium — **CS Elektif 36-37 Mg WAJIB Jika Miomektomi Masuk Rongga Endometrium (Full-Thickness) / Multiple / Adenomiolektomi / Ruptur Uterus Risiko Tinggi\*\*"                                                                      |
| **PPH Risiko**                            | **Mioma Submukosa/Intramural Besar → Atoni Uterus, Placenta Previa/Accreta Risiko ↑ — **Persiapan: OKSITOSIN Infus, MISOPROSTOL, KARBOPROST, TRANEXAMIC ACID, BAKRI BALLOON, KOMPRESI BIMANUAL, EMBOLISASI ARTERI UTERUS (UAE) EMERGENSI, HISTEREKTOMI SALVAGE\*\*"                                                                 |

## Ringkasan untuk Dokter Umum

1. **Mioma = Tumor Jinak Paling Umum Wanita (70-80%) — Gejala: Menorrhagia (Submukosa), Tekanan/Massa (Subserosa/Intramural Besar), Infertilitas (Distorsi Rongga), Nyeri (Degenerasi/Torsi)"**
2. **Diagnosis: **USG TVS First-Line (Mapping FIGO Type 0-8) — **Histeroskopi Gold Standard Submukosa — **MRI Kompleks/Malignancy Curiga**"**
3. **First-Line Medis: **TXA + NSAID (Menorrhagia+Nyeri) / LNG-IUS (Kontra+Terapi) / COC / GnRHa (Pre-Op Short-Term) / UPA (Pre-Op EU, Monitor Liver)"\*\*
4. **Fertility-Sparing: **Histeroskopik Miomektomi (Submukosa 0,1,2) / Laparoskopik Miomektomi (Intramural/Subserosa ≤ 10 cm, Skill Tinggi) — **CS Elektif 36-37 Mg WAJIB Pasca Miomektomi Full-Thickness**"\*\*
5. **Non-Fertility / Menolak Operasi: **UAE (Embolisasi Arteri Uterus) — Sukses 80-90%, Tapi Fertilitas Risiko — **HIFU/RFA (Non-Invasif/Minimal Invasif Baru) Data Terbatas**"\*\*
6. **Definitif: **Histerektomi Total (TLH/LAVH/VH Preferred) — **Kuratif 100% — **BSO Opsional (Pertahankan Ovarium < 50 Th)**"**
7. **Kehamilan: **Degenerasi Mioksid Komplikasi #1 (Konservatif) — **CS Elektif Jika Miomektomi Full-Thickness / Multiple / Adenomiolektomi — **PPH Persiapan Lengkap**"**
8. **Red Flag Sarkoma: **Mioma Cepat Membesar (> 2 cm/bln) Postmenopause / Usia > 50 Th / Degenerasi Nekrosis Berulang / LDH ↑ / MRI: T2 Hiperintense, DWI Restricted, Necrosis, Enhancement Heterogen → **HISTEREKTOMI TANPA MORSELASI (Kontaminasi Risiko) — **FROZEN SECTION WAJIB**"**
