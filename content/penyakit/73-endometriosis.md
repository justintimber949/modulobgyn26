# Endometriosis

## Cerita Pembuka

Ny. Dewi, 30 tahun, G0P0A0, keluhan: **dysmenorrhea progresif seitan 3 tahun** (skala 8-9/10, butuh obat kuat, absen kerja 2-3 hari/bulan), **dispareunia mendalam**, **infertilitas primer 2 tahun**. USG: **Endometrioma kiri 4×3 cm, kanan 2×2 cm, adenomiosis (junction zone 14 mm), nodul DIE di septum rektovaginal 1,5 cm**. CA-125: 85 U/mL. Laparoskopi: **Stadium IV (rASRM 85)** — eksisi endometrioma bilateral, stripping kista, eksisi DIE septum rektovaginal (shaving/resection), adhesiolysis, chromopertubation paten bilateral. Pasca-op: OCP kontinu 6 bln → dysmenorrhea hilang, dispareunia hilang. 6 bln pasca: hamil spontan.

## Definisi & Patogenesis

**Endometriosis** = **pertumbuhan jaringan endometrial (glandula & stroma) di luar rongga uterus** → peradangan kronik, fibrosis, adhezi, neoangiogenesis, saraf pertumbuhan → nyeri, infertilitas, disfungsi organ.

| Teori Patogenesis                     | Mekanisme                                                                                                    |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| **Retrograde Menstruation (Sampson)** | Darah menstruasi ke tuba & peritoneum → implantasi endometrial — **paling diterima**                         |
| **Koelomik Metaplasia**               | Epitel peritoneal berdiferensiasi jadi endometrial (stimuli hormonal/peradangan)                             |
| **Diseminasi Limfatik/Vaskular**      | Sel endometrial ke jarak jauh (paru, otak, kulit, saraf)                                                     |
| **Stem Cell / Progenitor Cell**       | Sel stem endometrium/peritoneal → lesi endometriosis                                                         |
| **Immunologis**                       | NK cell dysfunction, makrofag tidak clearance, autoantibodi, sitokin pro-inflamasi (TNF-α, IL-6, IL-8, VEGF) |
| **Genetik & Epigenetik**              | Polimorfisme WNT4, GREB1, CDKN2BAS, VEZT — heredabilitas ~ 50%                                               |

## Klasifikasi (rASRM / rAFS 1997 - Tetap Digunakan Klinis)

| Stadium            | Skor  | Deskripsi                                                                                                                      |
| ------------------ | ----- | ------------------------------------------------------------------------------------------------------------------------------ |
| **I (Minimal)**    | 1-5   | Lesi superficial sedikit, tidak adhezi signifikan                                                                              |
| **II (Mild)**      | 6-15  | Lesi superficial & dalam lebih banyak, adhezi filmi/minimal                                                                    |
| **III (Moderate)** | 16-40 | Endometrioma ovarium, adhezi padat (ovarium ke fimbria/uterus/ligamen), lesi dalam                                             |
| **IV (Severe)**    | > 40  | Endometrioma besar bilateral, adhezi padat masif (frozen pelvis), DIE (rektum, ureter, vagina, pangkal kencing), hidronefrosis |

> **Keterbatasan rASRM:** Tidak korelasi baik dengan nyeri / infertilitas / outcome. **ENZIAN / EFI (Endometriosis Fertility Index) / AAGL Classification** lebih baik untuk planning operasi & prognostik infertilitas.

## Gejala & Tanda (Triad Klasik + Lainnya)

| Gejala                                                                            | Prevalensi                    | Karakteristik                                                                                                           |
| --------------------------------------------------------------------------------- | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| **Dysmenorrhea (Nyeri Haid)**                                                     | 70-90%                        | **Progresif, sekunder (mulai normal jadi berat), mulai sebelum haid, berlanjut saat haid, tidak responsif NSAID biasa** |
| **Dispareunia Mendalam (Deep Dyspareunia)**                                       | 40-60%                        | Nyeri saat penetrasi mendalam (utara vagina/fornix) — lesi DIE septum rektovaginal/uterosakral                          |
| **Nyeri Pelvik Kronik (Non-Siklik)**                                              | 30-50%                        | Nyeri harian, tidak hanya haid — sentralisasi saraf, adhezi, adneksa fixed                                              |
| **Infertilitas**                                                                  | 30-50% (di populasi infertil) | Mekanisme: adhezi tuba, kualitas oosit ↓, implantasi ↓, imunologis, DIE                                                 |
| **Gejala GI** (Dischezia, siklik hematochezia, diare/konstipasi siklik, tenesmus) | 10-30%                        | **DIE Rektum/Sigmoid** — nyeri defekasi saat haid, darah tinja siklik                                                   |
| **Gejala Urologi** (Disuria, pola urin siklik, hematosuria, flank pain)           | 5-15%                         | **DIE Ureter/Vejiga** — hidronefrosis (ureter), pola urin siklik (vejiga)                                               |
| **Kista Adneksa (Endometrioma)**                                                  | 20-40%                        | Teraba massa adneksa, USG: "Ground glass" / low-level echoes                                                            |

## Diagnosis

### 1. Klinis (Anamnesis + Pemeriksaan)

| Komponen                  | Temuan Khusus                                                                                                                                                                 |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Anamnesis Terstruktur** | Dysmenorrhea progresif, dispareunia deep, infertilitas, gejala GI/GU siklik, riwayat keluarga                                                                                 |
| **Pemeriksaan Bimanual**  | **Uterus retroversi fixed (tidak mobil), adneksa teraba massa/kaku, nodulitas di ligamen uterosakral / septum rektovaginal (DIE), rektovaginal septum tebal/noduler, tender** |
| **Spekulum**              | Lesi biru-ungu di portio/serviks/vagina (endometriosis servikal/vaginal), retraksi serviks                                                                                    |

### 2. USG Transvaginal (First-Line Imaging)

| Target                                    | Temuan Khusus                                                                                                                                                                                                                           |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Endometrioma**                          | **Kista unilokuler/septated, dinding halus, isi hiperekoik homogen "ground glass" / low-level echoes, tidak ada vascularitas doppler (atau minimal di dinding)** — Sensitivitas 90%, Spesifisitas 95%                                   |
| **Adenomiosis**                           | **Junction Zone (JZ) ≥ 12 mm (atau ≥ 8 mm jika difus), uterus globular, mottled myometrium, kista mionektomi (myometrial cyst), hyperechoic islands**                                                                                   |
| **DIE (Deep Infiltrating Endometriosis)** | **Nodul hiperekoik irregular di: septum rektovaginal (> 5 mm dari permukaan), ligamen uterosakral, torus uterinus, vagina, rektum/sigmoid (serosa/muskularis), pangkal kencing/ureter, vesikouterin pouch** — Butuh USG spesialis / MRI |
| **Adhezi**                                | "Kissing ovaries" (ovariumempel ke uterus/posterior cul-de-sac), mobilitas uterus ↓, sliding sign negatif                                                                                                                               |
| **Hidronefrosis**                         | Dilatasi pelvis ginjal/ureter (DIE ureter)                                                                                                                                                                                              |

### 3. MRI Panggul (Gold Standard DIE & Planning Operasi)

- **Indikasi:** USG ragu DIE, planning laparoskopi kompleks, suspect ureter/rectum involvement, pra-IVF
- **Keunggulan:** Visualisasi DIE rektum/sigmoid (serosa/muskularis/submukosa), ureter, pangkal kencing, vaskularitas, adhezi — **Roadmap Operasi**

### 4. Laparoskopi (Gold Standard Diagnostik & Terapeutik)

- **Indikasi:** Gagal medis 3-6 bln, infertilitas, DIE tersangka, massa adneksa ragu neoplasia, nyeri berat refraktter
- **Visualisasi:** Lesi "powder burn" (hitam), "gunpowder" (hitam kecil), "blueberry" (biru), putih (fibrosis), merah (aktif), kista endometrioma, adhezi, DIE nodul
- **Biopsy Histopatologis (WAJIB)** — Konfirmasi glandula & stroma endometrial (meski visualisasi cukup untuk diagnosis klinis, biopsy untuk riset/medicolegal)

### 5. Marker Tumor (Tidak Diagnostik)

- **CA-125:** Naik di endometriosis (sensitivitas 60-70% stadium III-IV, spesifisitas rendah — naik juga PID, adenomiosis, kista lain, haid, kehamilan) — **Monitoring respons terapi / rekuren**

## Tata Laksana (Stepwise, Individualized)

### A. Manajemen Medis (First-Line) — **Tujuan: Supresi Ovulasi & Menstruasi → Atrofi Lesi & Kurangi Peradangan**

| Obat                                                                                                                                                                          | Dosis & Skema                                                                                                                                                            | Efek Samping Utama                                                                               | Kontraindikasi / Catatan                                                                                |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| **NSAID (Ibuprofen 400-600 mg 6-8 jam / Mefenamat 500 mg 3× / Naproksen 500 mg 2×)**                                                                                          | **First-line nyeri haid** — mulai 1-2 hari sebelum haid prediksi, terus selama haid                                                                                      | Gastropati, renel, kardiovaskular                                                                | Kombinasi dengan PPI jika risiko gastrik                                                                |
| **OCP Kombinasi (EE 20-35 mcg + Progestin) — Kontinu (Tanpa Placebo) / Trisyklik**                                                                                            | **First-line medis endometriosis** — supresi ovulasi, atrofi endometrium, kurangi prostaglandin                                                                          | TEV (risiko ↑ obesitas/rokok/usia>35), nausea, mood, spotting                                    | **Kontraindikasi: TEV history, trombofilia, hipertensi tidak terkendali, rokok > 35 th, migraine aura** |
| **Progestin Saja (Dienogest 2 mg 1× / Noretisteron 5-10 mg 1× / MPA 10-30 mg 1× / LNG-IUS 52 mg)**                                                                            | **Alternatif OCP / Kontraindikasi Estrogen / Lebih Kuat Atrofi Lesi** — **Dienogest 2 mg: Evidence Terbaik (Level 1A)**                                                  | Amenorea/Spotting, mood, berat badan, akne, libido ↓                                             | **Dienogest: Bisa Jangka Panjang (Studi 65 bln aman), tidak TEV risiko signifikan**                     |
| **GnRH Agonist (Leuprorelin 3,75 mg IM 1 bln / Triptorelin 3,75 mg IM 1 bln / Goserelin 3,6 mg SC 1 bln) + Add-Back (Tibolone 2,5 mg / Noretisteron 2,5 mg / E2 1 mg + MPA)** | **Second-Line (Gagal Progestin/OCP) / Pre-Op (Kurangi Ukuran Lesi) / Post-Op (Supresi Rekuren)** — **Maks 6-12 Bulan (tanpa add-back 6 bln, dengan add-back 12-24 bln)** | **Hypoestrogenism: Hot flush, osteoporosis, vagina kering, mood, libido ↓** — **Add-Back WAJIB** | **Kontraindikasi: Osteoporosis, usia > 45-50 th (relatif)**                                             |
| **GnRH Antagonist (Elagolix 150 mg 1× / 200 mg 2× / Relugolix 40 mg 1× + Add-Back E2 1 mg + Noretisteron 0,5 mg)**                                                            | **Oral, Onset Cepat, Reversibel, Dosis Fleksibel** — Baru (FDA 2018/2020)                                                                                                | Sama GnRH Agonist tapi kurang osteoporosis                                                       | **Mahal, Belum Tersedia Luas Indonesia**                                                                |
| **Aromatase Inhibitor (Letrozol 2,5 mg / Anastrozol 1 mg) + OCP/Progestin/GnRHa**                                                                                             | **Refraktter / DIE / Post-Menopause / Penelitian** — Blokasi estrogen lokal lesi                                                                                         | Osteoporosis, hot flush, arthralgia                                                              | **Hanya Kombinasi (monotherapy → kista folikul & ovulasi)**                                             |

> **Durasi Medis: Minimal 6-12 Bulan Evaluasi Respons. Jika Gagal → Rujuk SpOG untuk Laparoskopi.**

### B. Laparoskopi (Operasi Definitif) — **Indikasi: Gagal Medis, Infertilitas, DIE, Massa Ragu Neoplasia, Nyeri Berat Refraktter**

| Prinsip Operasi (Level 1A Evidence)                                     | Detail                                                                                                                                                                                                                                                                                                 |
| ----------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Eksisi (Excision) > Ablasi (Coagulasi/Vaporisasi)**                   | **Eksisi lesi hingga jaringan normal (clear margin) — Recurrence ↓, Nyeri ↓ Lebih Baik vs Ablasi** — Gunakan gunting, monopolar/bipolar scissors, harmonic, laser CO2                                                                                                                                  |
| **Endometrioma: Stripping (Kapsul Keluar) > Drainase + Ablasi Dinding** | **Stripping: Pregnancy Rate ↑, Recurrence ↓** — Risiko: Ovarian reserve ↓ (AMH turun 30-50% temporary), adhezi. **Jika bilateral/besar > 5-6 cm / AMH rendah: Pertimbangkan Drainase + Ablasi / Sclerotherapy (Ethanol 95% / Tetrasiklin) / Fenestrasi**                                               |
| **DIE (Deep Infiltrating Endometriosis)**                               | **Multidisiplin (SpOG + Bedah Gastro + Urologi)** — **Shaving (serosa/muskularis) / Disk Resection (full thickness < 2-3 cm) / Segmental Resection + Anastomosis (> 3 cm / sirkumferensial > 50% / multi-nodul)** — **Protektif Stoma (Loop Ileostomi) Jika Anastomosis Rendah / Risiko Bocor Tinggi** |
| **Adheziolysis**                                                        | **Hidrasi Jaringan, Gunting/Kait Tajam, Hemostasis Bipolar/Harmonic, Anti-Adhesi Barrier (Seprafilm / Interceed / Hyaluronate Gel) — Evidence Moderat**                                                                                                                                                |
| **Chromopertubation (Methylene Blue/Indigo Carmin)**                    | **WAJIB** evaluasi patensi tuba (infertilitas planning)                                                                                                                                                                                                                                                |
| **Preservasi Ovarium**                                                  | **HINDARI Bipolar/Coagulasi Berlebih Di Hilum Ovarium** — AMH & AFC monitoring pasca-op                                                                                                                                                                                                                |

### C. Infertilitas & Endometriosis

| Stadium & Kondisi                              | Rekomendasi                                                                                                                                                                                   |
| ---------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Stadium I-II (Minimal-Mild) + Infertilitas** | **Eksisi Laparoskopi + Chromopertubation → Expectant 6-12 bln / IUI (jika tuba paten & sperma normal) → IVF (jika gagal / usia > 35 / faktor lain)**                                          |
| **Stadium III-IV + Endometrioma**              | **Eksisi Endometrioma (Stripping) + Adheziolysis + Chromopertubation → IVF Langsung (jika usia > 35 / AMH rendah / gagal expectant/IUI) / Expectant 6 bln (jika muda, AMH baik, tuba paten)** |
| **DIE + Infertilitas**                         | **Eksisi DIE (Shaving/Resection) → IVF (Lebih Cepat & Sukses Tinggi vs Expectant)** — DIE sendiri infertilitas factor                                                                         |
| **Gagal IVF + Endometriosis**                  | **Re-evaluasi: Laparoskopi Ulang (Rekuren/Residual) → IVF Ulang / Oosit Donor**                                                                                                               |

### D. Adenomiosis (Sering Komorbid)

- **Medis:** OCP Kontinu / Dienogest / LNG-IUS (First-line) / GnRHa + Add-Back (Second-line)
- **Operasi:** **Adenomiomektomi (Laparoskopik/Abdominal/Histeroskopik)** — Jika infertilitas / nyeri refraktter / massa fokal. **Histerektomi** — Jika selesai keturunan / nyeri refraktter semua / usia > 40-45.

## Pasca Operatif & Pencegahan Rekuren

| Intervensi                                    | Durasi                               | Evidensi                                          |
| --------------------------------------------- | ------------------------------------ | ------------------------------------------------- |
| **OCP Kontinu / Dienogest 2 mg / LNG-IUS**    | **6-24 Bulan (Ideal 12-24 Bln)**     | **Rekuren Nyeri ↓ 50-70%, Rekuren Lesi ↓ 30-50%** |
| **GnRHa + Add-Back (Post-Op Stadium IV/DIE)** | 6-12 Bulan                           | Tambahan untuk DIE berat                          |
| **AMH & AFC Monitoring**                      | 3, 6, 12 Bulan Pasca-Op Endometrioma | Evaluasi ovarian reserve                          |
| **Fertilitas Counseling**                     | Segera Pasca-Op                      | IVF planning jika infertilitas                    |

## Komplikasi & Prognosis

| Aspek                                     | Data                                                                                                                 |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Rekuren Nyeri (5-10 Tahun)**            | 20-40% (medis), 10-20% (operasi + medis maintenance)                                                                 |
| **Rekuren Lesi (Laparoskopi Ulang)**      | 20-30% (5 th), 40-50% (10 th)                                                                                        |
| **Infertilitas Outcome Post-Op**          | PR 30-50% (Stadium III-IV eksisi + IVF), 50-60% (Stadium I-II)                                                       |
| **Ovarian Reserve (AMH) Pasca Stripping** | Turun 30-50% di 3-6 bln, recovery parsial 12-24 bln — **Bilateral > Unilateral**                                     |
| **Malignisasi (Endometriosis → EAOC)**    | **< 1% (Endometrioma → Clear Cell / Endometrioid CA)** — Monitoring USG tahunan endometrioma > 5-6 cm / usia > 45 th |

## Ringkasan untuk Dokter Umum

1. **Triad Klasik: Dysmenorrhea Progresif + Dispareunia Deep + Infertilitas** — Curiga Endometriosis
2. **USG TV First-Line:** Endometrioma "ground glass", Adenomiosis JZ ≥ 12 mm, DIE nodul (butuh USG spesialis/MRI)
3. **First-Line Medis: NSAID + OCP Kontinu / Dienogest 2 mg** — Minimal 6 bln evaluasi
4. **Gagal Medis / Infertilitas / DIE / Massa Ragu → Laparoskopi (Eksisi > Ablasi, Stripping Endometrioma)**
5. **DIE: Tim Multidisiplin (SpOG + Bedah Gastro + Urologi) — Shaving/Resection/Anastomosis + Stoma Protektif Jika Perlu**
6. **Infertilitas + Endometriosis: Eksisi + Chromopertubation → IVF (Stadium III-IV/DIE/Usia>35) / Expectant/IUI (Stadium I-II/Muda)**
7. **Maintenance Pasca-Op: OCP/Dienogest/LNG-IUS 12-24 Bulan** — Kurangi Rekuren
8. **Monitoring AMH Pasca Endometrioma Stripping** — Ovarian Reserve Risiko
9. **Malignisasi Risiko Kecil (< 1%)** — USG Tahunan Endometrioma > 5 cm / Usia > 45 th
