# Mola Hidatidosa (Hydatidiform Mole)

## Cerita Pembuka

Ny. Siti, 38 tahun, G3P2A0, datang ke IGD RSKH dengan keputihan merah seperti "air cucian daging" seitan 2 minggu, nyeri perut bawah, dan hiperemesis berat. USG: "snowstorm appearance" — rongga uterus terisi massa kistik multiple tanpa janin, plasenta kistik. β-hCG: 250.000 mIU/mL (sangat tinggi untuk UK 12 minggu). Diagnosis: Mola hidatidosa komplit. Dilakukan kuretase evakuasi. Jaringan patologi: vili kistik, edema, hiperplasia trofoblas tanpa embrio. Pasca kuretase: β-hCG monitoring mingguan. Minggu ke-8: β-hCG < 5 mIU/mL (normal). Ny. Siti disarankan KB hormon (pil/IUD) 6 bulan, hindari hamil.

## Definisi

Mola hidatidosa adalah **penyakit trofoblas gestasional (GTD) benign** yang ditandai dengan **hiperplasia vili korial** dan **edema vili** membentuk kista-kista berisi cairan (seperti anggur), dengan atau tanpa jembatan embrio. Dua tipe:

- **Mola Komplit (Complete Mole):** 46,XX (diandrik) — **tidak ada jembatan embrio**, semua kromosom dari ayah (duplikasi sperma haploid atau dispermi). Risiko GTN (Gestational Trophoblastic Neoplasia) ~15-20%.
- **Mola Parsial (Partial Mole):** 69,XXY (triploid) — **ada jembatan embrio/genin abnormal** (biasanya tidak viable), 2 set kromosom ayah + 1 set ibu. Risiko GTN ~1-5%.

## Etiologi & Faktor Risiko

| Faktor                                | Risiko                                           |
| ------------------------------------- | ------------------------------------------------ |
| **Usia ibu**                          | < 20 th atau > 35-40 th (U-shape)                |
| **Riwayat mola sebelumnya**           | 1-2% recurrence (naik 10-20×)                    |
| **Defisiensi karetenoid / vitamin A** | Epidemiologis                                    |
| **Kehamilan sebelumnya**              | Tidak konsisten                                  |
| **Genetik**                           | Mutasi _NLRP7_, _KHDC3L_ (mola rekuren familial) |

## Gejala & Tanda

| Gejala                                                          | Frekuensi                                             |
| --------------------------------------------------------------- | ----------------------------------------------------- |
| Perdarahan vagina (merah segar / cokelat / "air cucian daging") | 85-95%                                                |
| Hiperemesis gravidarum berat                                    | 30-50% (β-hCG sangat tinggi → stimulasi reseptor TSH) |
| Perut besar > UK (uterus besar untuk usia kehamilan)            | 50%                                                   |
| Preeklampsia trimester 1/2 (sebelum 20 mg)                      | 20-30% (khusus mola komplit)                          |
| Hipertiroidism klinis (tachikardia, tremor, panas)              | 5-10% (β-hCG cross-react TSH receptor)                |
| Anemia                                                          | Umum (perdarahan kronis)                              |
| Tidak ada DJJ / gerakan janin                                   | 100% mola komplit, parsial bisa ada janin abnormal    |

> [!warning] Red Flag
> **Preeklampsia < 20 minggu** → **PIKIRKAN MOLA HIDATIDOSA**! Preeklampsia normal tidak terjadi < 20 mg.
> **β-hCG sangat tinggi (> 100.000 mIU/mL) + tidak ada janin USG** → mola komplit hingga terbukti sebaliknya.
> **Tiroid storm** bisa terjadi jika hipertiroidism mola tidak dikelola — propranolol + PTU + evakuasi mola segera.

## Diagnosis

### 1. USG Transvaginal (Gold Standard Non-Invasif)

| Tipe             | Tampilan USG                                                                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Mola Komplit** | **"Snowstorm appearance"** — rongga uterus terisi massa ekogenik multiple (kista vili), **tidak ada janin**, tidak ada aktivitas jantung, plasenta kistik vesikuler |
| **Mola Parsial** | **Ada janin/embrio** (sering abnormal, IUGR, kisto amnion), plasenta kistik parsial, kordioamnionik                                                                 |

> **Sensitivitas USG mola komplit ~ 90-95%, mola parsial ~ 60-70%** (sering terlewat, dikira abortus tidak lengkap).

### 2. β-hCG Kuantitatif Serum

- **Mola komplit:** Sangat tinggi, sering > 100.000 mIU/mL (bisa > 1 juta)
- **Mola parsial:** Tinggi tapi biasanya < mola komplit
- **Aborsi tidak lengkap:** β-hCG sesuai UK atau lebih rendah
- **Kehamilan normal:** β-hCG naik 2× tiap 48 jam trimester 1

### 3. Pemeriksaan Patologi (Definitif) — **Pasca Kuretase**

| Tipe        | Patologi                                                                                                                                                                    |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Komplit** | Vili kistik difus, edema stroma, hiperplasia trofoblas sirkumferensial (sirkular), **tidak ada pembuluh darah fetal**, tidak ada jembatan embrio, kariotip 46,XX (diandrik) |
| **Parsial** | Vili kistik fokal (bagian), edema, hiperplasia trofoblas fokal, **ada pembuluh darah fetal**, **ada jembatan embrio/genin** (sering abnormal), kariotip 69,XXY (triploid)   |

### 4. Pemeriksaan Pendukung

- **Darah lengkap:** Anemia, trombositopenia (DIC ringan), fungsi hati, ginjal
- **Koagulasi:** PT, aPTT, fibrinogen, D-dimer (risiko DIC)
- **Tiroid:** TSH, FT4 (cek hipertiroidism)
- **Toraks Foto / CT:** Screening metastase paru (jika β-hCG sangat tinggi / risiko GTN)
- **USG Hati/Limfa:** Screening metastase (jarang pada mola, lebih GTN)

## Tata Laksana

### 1. Evakuasi Uterus (Kuretase) — **Tindakan Utama**

- **Metode:** Vakum aspirasi (manual/elktrik) **DIREKOMENDASIKAN** vs kuretasi tajam (risiko perforasi ↑ pada uterus lembut mola)
- **Persiapan:** Darah crossmatch 2 unit (risiko perdarahan), oksitosin 20 IU IV infus pasca evakuasi, antibiotik profilaksis (sefazolin 2 g IV)
- **Anestesi:** Spinal / Umum (sedasi + blok pudendal)
- **Teknik:** Aspirasi vakum hingga uterus keras, tidak ada tissue tersisa. **JANGAN terlalu agresif** — uterus mola tipis, risiko perforasi.
- **Jaringan:** **KIRIM SEMUA KE ANATOMI PATOLOGI** — wajib untuk konfirmasi tipe (komplit vs parsial) & rule out karsinoma korial.

> [!warning] Red Flag
> **Jika β-hCG > 300.000 mIU/mL ATAU USG plasenta sangat tebal/vascular** → risiko perdarahan masif & perforasi. Siapkan darah, pertimbangkan histerektomi profilik (jika ibu tidak ingin anak lagi / usia > 40 th / β-hCG > 1 juta).
> **JANGAN gunakan misoprostol/oksitosin sebelum evakuasi** untuk "memperkecil uterus" — risiko emboli trofoblas ke paru.

### 2. Pasca Evakuasi — Monitoring β-hCG (KRITIS)

| Jadwal                                          | Target                                                 |
| ----------------------------------------------- | ------------------------------------------------------ |
| **Mingguan**                                    | β-hCG turun ≥ 10% per minggu / turun 50% per 2 minggu  |
| **Hingga 3 β-hCG beruntun NORMAL (< 5 mIU/mL)** | Maka monitoring selesai                                |
| **Bulanan × 6 bulan**                           | Setelah normal (hanya mola komplit)                    |
| **Bulanan × 12 bulan**                          | Jika mola komplit & risiko tinggi / β-hCG turun lambat |

> **Kriteria GTN (Gestational Trophoblastic Neoplasia) — WAJIB RUJUK ONKOLOGI/SpOG:**
>
> - β-hCG **platou** (tidak turun ≥ 10% per minggu) × 3 minggu
> - β-hCG **naik** ≥ 10% × 2 minggu
> - β-hCG **persisten** > 6 bulan
> - Metastase klinis/radiologis (paru, hati, otak, vagina)
> - Histologi: Koriokarsinoma / Placental Site Trophoblastic Tumor (PSTT) / Epithelioid Trophoblastic Tumor (ETT)

### 3. Terapi GTN (Jika Terjadi)

- **Low risk (WHO score ≤ 6):** **Metohtreksat** (MTX) IM/IV single dose / multi-dose / actinomycin-D
- **High risk (WHO score ≥ 7):** **Kemoterapi kombinasi (EMA-CO / EMA-EP)** — rujuk SpOG Onkologi / RS Rujukan Nasional (Dharmais, Cipto)
- **Histerektomi** — opsi adyuvan jika low risk & ibu tidak ingin anak lagi / usia > 40 th

### 4. Kontrasepsi Pasca Mola

- **WAJIB hindari kehamilan** selama monitoring β-hCG (minimal 6 bln mola parsial, 12 bln mola komplit)
- **Pilihan:** IUD (setelah β-hCG normal & uterus bersih), PIL KB kombinasi, Implan, Injeksi
- **JANGAN IUD** saat β-hCG masih tinggi / ada sisa jaringan / infeksi

## Komplikasi

| Komplikasi                           | Frekuensi                        | Penanganan                                                        |
| ------------------------------------ | -------------------------------- | ----------------------------------------------------------------- |
| Perdarahan masif (atonia, perforasi) | 5-10%                            | Oksitosin, ergometrin, kompresi bimanual, histerektomi jika gagal |
| Emboli trofoblas (paru)              | 2-5%                             | Oksigen, ventilasi, steroid, kemoterapi jika persisten            |
| Hipertiroidism / Tiroid storm        | 5-10%                            | Propranolol + PTU, evakuasi mola segera (kurangnya β-hCG)         |
| Preeklampsia < 20 mg                 | 20-30% (komplit)                 | Evakuasi mola = terapi definitif                                  |
| GTN (Koriokarsinoma, PSTT, ETT)      | 15-20% (komplit), 1-5% (parsial) | Kemoterapi, prognosis SANGAT BAIK (> 95% sembuh)                  |
| Sepsis pasca kuretase                | < 1%                             | Antibiotik broad spectrum                                         |

## Prognosis

- **Mola benign (tanpa GTN):** 100% sembuh dengan evakuasi + monitoring
- **GTN Low risk:** > 99% sembuh dengan MTX/Actinomycin-D
- **GTN High risk:** > 90% sembuh dengan EMA-CO (modern chemo)
- **Kehamilan berikutnya:** Normal, risiko mola rekuren 1-2% (naik 10-20×), USG dini + β-hCG monitoring

## Ringkasan untuk Dokter Umum

1. **Mola = β-hCG sangat tinggi + USG "snowstorm" + tidak ada janin (komplit) / janin abnormal (parsial)**
2. **Preeklampsia < 20 mg = pikirkan mola!**
3. **Evakuasi = vakum aspirasi (lebih aman dari kuretasi tajam), kirim jaringan ke PA**
4. **Monitoring β-hCG MINGGUAN sampai 3× normal (< 5 mIU/mL)** — ini WAJIB, tidak bisa ditinggal
5. **GTN criteria:** β-hCG platou/naik/persisten > 6 bln / metastase → RUJUK SEGERA
6. **KB wajib 6-12 bln** (IUD/pil/implan) — hindari hamil saat monitoring
7. **Prognosis GTN SANGAT BAIK** (> 95% sembuh) — jangan panik, rujuk onkologi
