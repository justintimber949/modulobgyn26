# Gangguan Ereksi (Erectile Dysfunction / ED)

## Cerita Pembuka

Pak Agus, 52 tahun, pengusaha, DM Tipe 2 seitan 5 tahun (HbA1c 8,2%), Hipertensi (AMLO 5 mg), Rokok 20 batang/hari seitan 30 tahun. Keluhan: **tidak bisa ereksi penuh saat berhubungan seitan 1 tahun, الصباح erection (pagi) hilang, libido turun**. IIEF-5: **12/25 (ED Sedang)**. Lab: **Testosteron Total 320 ng/dL (Low Normal), LH 4, FSH 3, Prolaktin 18, HbA1c 8,2%, Lipid: LDL 140, TG 220, HDL 35**. Diagnosa: **ED Vaskulogenik + Metabolik + Hipogonadisme Campuran (Fungsi Testis Turun Sekunder Obesitas/Insulin Resistensi) + Psikogenik**. Manajemen: **Lifestyle (Stop Rokok, Diet, Olahraga, BB Turun 5%), Optimasi DM/HT, Sildenafil 50 mg PRN (Sukses 70%), Testosteron Gel 5 g/hari (Usia > 50, Low T + Gejala, Hematokrit & PSA Monitoring) + Konseling Seksual Pasangan**. 6 Bulan: IIEF-5 22/25, HbA1c 7,0%, BB -7 kg, Rokok Stop.

## Definisi & Klasifikasi

**Erectile Dysfunction (ED)** = **Ketidakmampuan Konsisten (≥ 3-6 Bulan) untuk Mencapai dan/atau Mempertahankan Ereksi yang Cukup Keras untuk Hubungan Seksual Memuaskan.**

| Klasifikasi | Penjelasan |
|-------------|------------|
| **Organik (Vaskulogenik, Neurogenik, Hormonal, Anatomi/Struktural, Iatrogenik/Obat)** | **70-80% Kasus** — Ada Patologi Fisik Teridentifikasi |
| **Psikogenik** | **10-20%** — Tidak Ada Patologi Fisik, Ereksi Pagi/Spontan Normal, Situasional (Hanya Pasangan Tertentu / Stres) |
| **Campuran (Mixed)** | **Mayoritas Dewasa > 40 Th** — Kombinasi Organik + Psikogenik (Organik Dasar + Kecemasan Performa Menimbulkan Siklus Vicious) |

### Etiologi Organik (Rincian)

| Kategori | Contoh Khusus |
|----------|---------------|
| **Vaskulogenik (Arterial/Venous) — #1 Organik** | **Aterosklerosis (DM, Hipertensi, Dislipidemia, Rokok) → Arteri Pudendal/Penile Stenosis**, Venous Leak (Tunica Albuginea Dysfunction, Peyronie), Pelvic Trauma/Surgery (RP, TURP, Rectal CA Surgery) |
| **Neurogenik** | **Diabetic Neuropati (Autonomik)**, Sclerosis Multipel, Cedera Medula Spinalis, Sirkumcisi Komplikasi, Operasi Panggul (Nervi Kavernosal) |
| **Hormonal** | **Hipogonadisme (Low T), Hiperprolaktinemia, Hipertiroid/Hipotiroid, Kushing, Akromegali** |
| **Anatomi/Struktural** | **Peyronie (Plak Fibrosis → Lengkungan + Venous Leak)**, Hipospadia, Epispadia, Priapisme Stuttering (Fibrosis Korpus Kavernosa) |
| **Iatrogenik / Obat (25% Kasus)** | **Anti-HT: Tiazid, Bloker Beta (Lama), Bloker Alfa (Non-Uroselektif), Spironolacton. Psikotropik: SSRI, SNRI, Trikasiklik, Antipsikotik, Benzodiazepin. Anti-Androgen: Finasteride, Bicalutamide. Sitotoksik. H2 Bloker, PPI. Opioid.** |

## Epidemiologi & Faktor Risiko

| Parameter | Data |
|-----------|------|
| **Prevalensi Global** | **> 150 Juta Pria (2025), Diperkirakan 322 Juta (2025)** |
| **Usia** | **40 Th: ~40%, 50 Th: ~50%, 60 Th: ~60%, 70 Th: ~70%** (Massachusetts Male Aging Study) |
| **Faktor Risiko Modifiable** | **Rokok (#1), DM (3-5× Risiko), Hipertensi, Dislipidemia, Obesitas (Central), Sedentari, Alkohol Berat, Diet Buruk** |
| **Komorbiditas Kuat** | **ED = "Marker" Penyakit Kardiovaskular Tersembunyi (Endothelial Dysfunction)** — **ED Mendahului Koroner 3-5 Tahun** |

## Anamnesis Terstruktur (Kunci Diagnosis)

### 1. IIEF-5 (International Index of Erectile Function - 5 Items) — **Screening Valid & Cepat**
| Skor | Interpretasi |
|------|--------------|
| **22-25** | **Tidak ED** |
| **17-21** | **ED Ringan** |
| **12-16** | **ED Sedang** |
| **8-11** | **ED Berat** |
| **5-7** | **ED Sangat Berat** |

### 2. Pertanyaan Kunci (SEKS Mnemonic)
| Huruf | Pertanyaan |
|-------|------------|
| **S** (Specific) | **Ereksi Pagi/Spontan/Masturbasi Ada? (Ya = Psikogenik / Hormonal / Venous Leak Ringan)** |
| **E** (Etiology) | **Obat, Penyakit (DM, HT, Dislipid, Jantung, Saraf, Prostata), Operasi Panggul, Trauma, Rokok, Alkohol** |
| **K** (Konteks) | **Dengan Pasangan Saja / Semua Situasi? Hubungan Pasangan Baik? Stres/Kecemasan Performa?** |
| **S** (Severity) | **Sejak Kapan? Progresif / Mendadak? Ereksi Penuh Tidak Bisa Sama Sekali / Bisa Tapi Cepat Luntur?** |

### 3. Sexual Health Inventory for Men (SHIM) = IIEF-5 (Sama)

## Pemeriksaan Fisik (Fokus & Efisien)

| Area | Yang Dilihat |
|------|--------------|
| **Vital Signs** | **TD, HR, BMI, Lingkar Perut (Central Obesity)** |
| **Genitalia** | **Penis: Ukuran, Lengkungan (Peyronie), Hipospadia, Priapisme Bekas. Testis: Volume (Orchidometer/Pruyner), Konsistensi, Massa. Epididimis. Varikocele. Penis Pulse (Dorsalis Pedis → Pudendal Proxy)** |
| **Sekunder Seksual** | **Rambut Wajah/Jenggot, Ginekomsatia, Kulit** |
| **Vaskular** | **Femoral Pulse, Popliteal, Dorsalis Pedis, Posterior Tibialis (ABI Jika Curiga PAD)** |
| **Saraf** | **Refleks Bulbokavernosus (S2-S4), Sensasi Perineum (Saddle), Anal Tone** |
| **Prostat (DRE)** | **Ukuran, Konsistensi, Nodul (Jika > 50 Th / LUTS)** |

## Laboratorium & Penunjang (Minimum Panel)

| Pemeriksaan | Indikasi & Interpretasi |
|-------------|-------------------------|
| **Gula Darah Puasa / HbA1c** | **WAJIB** — DM Screening (ED = Red Flag DM Tersembunyi) |
| **Profil Lipid (Total, LDL, HDL, TG)** | **WAJIB** — Dislipidemia → Aterosklerosis Arteri Penile |
| **Testosteron Total (Pagi 7-10 AM, Puasa)** | **WAJIB** — **< 300 ng/dL = Hipogonadisme, 300-350 = Borderline (Ulangi + Free T)** |
| **LH, FSH** | **Beda Primer (↑) vs Sekunder (Normal/↓)** |
| **Prolaktin** | **> 50-100 ng/mL → MRI Hipofisis (Prolaktinoma)** |
| **TSH, FT4** | **Tiroid (Hipo/Hiper → ED)** |
| **Fungsi Hati/Ginjal** | **Jika Abnormal / Obat Hepatotoksik/Nefrotoksik** |
| **PSA** | **> 50 Th / Akan Diberi Testosteron / DRE Abnormal** |
| **Homosistein / hs-CRP (Opsional)** | **Marker Endothelial Dysfunction / Inflamasi** |

### Penunjang Lanjutan (Rujuk Urologi/Andrologi)
| Modality | Indikasi |
|----------|----------|
| **Penile Doppler Ultrasound (PDU) + Vasoaktif (PGE1/Alprostadil)** | **Gold Standard Vaskular** — Arterial: PSV < 25-30 cm/s (Stenosis), EDV > 5 cm/s (Venous Leak) |
| **Nocturnal Penile Tumescence (NPT) / Rigiscan** | **Beda Psikogenik (Normal NPT) vs Organik (Abnormal NPT)** — Jarang Dipakai Sekarang (Mahal, Repot) |
| **Dynamic Infusion Cavernosometry/Cavernosography (DICC)** | **Venous Leak Quantification (Pre-Op Implant)** |
| **MRI Panggul / Penile MRI** | **Peyronie Kompleks, Trauma, Tumor** |
| **Kavernosografi** | **Venous Leak Anatomi (Pre-Op)** |

## Tata Laksana (Stepwise Algorithm)

### Level 1: Lifestyle & Faktor Risiko (Semua Kasus, Dasar)
| Intervensi | Target |
|------------|--------|
| **Stop Rokok** | **#1 Intervensi Paling Efektif** — Endothelial Recovery 3-12 Bulan |
| **Kontrol DM (HbA1c < 7%)** | Neuropati & Vaskulopati Progression ↓ |
| **Kontrol HT (< 130/80)** | Pilih ARB/ACEi/CCB (Netral/Baik ED) — Hindari Tiazid/Bloker Beta Lama Jika Bisa |
| **Dislipidemia (Statin + Lifestyle)** | LDL < 100 (< 70 Jika CVD) — Endothelial Function ↑ |
| **Penurunan BB (Jika Obesitas)** | **5-10% BB → Testosteron ↑, Endothelial ↑, ED ↑↑** |
| **Olahraga Aerobik 150 Menit/Mgg** | **NO Bioavailability ↑, Endothelial Function ↑** |
| **Diet Mediterranean / DASH** | Antioksidan, Anti-Inflamasi, Endothelial Protektif |
| **Batasi Alkohol (< 2 Unit/Hari)** | Alkohol Kronik → Hipogonadisme + Neuropati |

### Level 2: First-Line Farmako — **PDE5 Inhibitor (PDE5i)**
| Obat | Dosis | Onset | Durasi | Khusus |
|------|-------|-------|--------|--------|
| **Sildenafil** | **25-50-100 mg PRN (1 Jam Sebelum)** | 30-60 Menit | 4-6 Jam | **Makanan Tinggi Lemak → Delay & ↓ Absorpsi** |
| **Tadalafil** | **10-20 mg PRN (1-2 Jam) ATAU 2,5-5 mg Harian (Daily)** | 30-60 Min (PRN) | **36 Jam (PRN) / Kontinu (Daily)** | **Daily = Spontanitas + LUTS BPH (FDA Approved)** |
| **Vardenafil** | **5-10-20 mg PRN (30-60 Min)** | 30-60 Min | 4-6 Jam | **Lebih Selektif PDE5, Kurang Visual Side Effect** |
| **Avanafil** | **50-100-200 mg PRN (15-30 Min)** | **15-30 Min (TerCepat)** | 4-6 Jam | **Kurang Interaksi Makanan, Kurang Side Effect** |

> **Respons Rate PDE5i: 60-70% Umum, 50% DM, 40% Pasca RP (Radical Prostatectomy).**
> **Kontraindikasi ABSOLUT: NITRAT (Organik) & DONOR NO (Amil Nitrit) — Risiko Hipotensi Fatal.**
> **Hati-Hati: Bloker Alfa (Tamsulosin dll) → Sildenafil/Vardenafil 4 Jam Jarak / Tadalafil Daily Dosis Rendah / Avanafil Lebih Aman.**

### Level 3: Second-Line (Gagal / Kontraindikasi / Tidak Toleran PDE5i)
| Terapi | Indikasi & Detail |
|--------|-------------------|
| **Alprostadil (PGE1) Injeksi Intrakavernosal (ICI)** | **Caverject / Edex / Viridal (Kombinasi)** — **Dosis 2,5-20 mcg, Onset 5-15 Min, Durasi 30-60 Min** — **Efektivitas > 85% (Termasuk DM/Pasca RP)** — **SE: Priapisme (> 4 Jam), Fibrosis, Nyeri, Hematom** — **Pelatihan Pasien WAJIB** |
| **Alprostadil Intrauretral (MUSE)** | **Pellet 125-1000 mcg Uretral, Onset 10 Min, Efektivitas ~ 60%** — Kurang Efektif ICI, Lebih Mudah, Nyeri Uretral |
| **Vacuum Erection Device (VED)** | **Non-Invasif, Mekanik: Pompa Vakum → Cincin Konstriksi Basis Penis (Maks 30 Menit)** — **Baik Untuk Semua Etiologi, Pasien Tidak Mau Injeksi/Operasi** — **SE: Pucat, Dingin, Nyeri, Ejakulasi Terhalang, Petechiae** |
| **Testosteron Terapi (Jika Hipogonadisme Terbukti: Low T + Gejala)** | **Gel 5-10 g/hari / Injeksi TU 1000 mg 12-14 Minggu / Patch / Buccal** — **Monitoring: Hematokrit, PSA, Lipid, Liver, Kardiovaskular (RCT: TRAVERSE - CVD Safety Neutral)** — **KONTRAINDIKASI: Kanker Prostat Aktif, Polisitemia, Gagal Jantung Berat, Apnea Tidur Tak Terkendali** |

### Level 4: Third-Line (Gagal Semua Atas / Peyronie / Anatomi) — **Operasi**
| Prosedur | Indikasi |
|----------|----------|
| **Penile Prosthesis Implant (Inflatable 3-Piece / Malleable 2-Piece)** | **Gold Standard Definitif** — **Satisfaction Rate 90-95% (Pasien & Pasangan)** — **Indikasi: Gagal Medis, Peyronie + ED, Priapisme Stuttering, Fibrosis Parenkim** |
| **Revascularisasi Arteri Penile (Microsurgical)** | **Pria Muda (< 45 Th), Trauma Panggul/Perineum, Lesi Arteri Pudendal Proksimal Tunggal, Venous Competent** — **Khusus Pusat Tertentu, Seleksi Ketat** |
| **Ligasi Vena Dorsal Penyelubung (Venous Leak Surgery)** | **Kontroversial, Outcome Jangka Panjang Buruk (< 50% Sukses 2 Th) — Jarang Direkomendasikan** |

## Khusus: ED Psikogenik & Campuran
| Pendekatan | Detail |
|------------|--------|
| **Psikoedukasi & Reassurance** | "ED Umum, Bisa Dirawat, Bukan Kegagalan Pribadi" |
| **Sensate Focus (Masters & Johnson)** | **Non-Demand Pleasuring → Fokus Sensasi, Bukan Performa Ereksi** — Bertahap (Non-Genital → Genital → Penetrasi) |
| **CBT (Cognitive Behavioral Therapy)** | **Performance Anxiety, Spektatoring, Depresi, Kecemasan** |
| **Konseling Pasangan (Sex Therapy)** | **Komunikasi, Ekspektasi, Variasi Seksual, Mengurangi Tekanan** |
| **PDE5i + Konseling** | **PDE5i Sebagai "Jembatan" (Bridge) → Kepercayaan Diri → Tapering Off** |

## Follow-up & Monitoring

| Waktu | Evaluasi |
|-------|----------|
| **4-6 Minggu Awal PDE5i** | **Respons (IIEF-5), Side Effect, Dosis Titrasi (Naik/Turun), Compliance, Lifestyle** |
| **3-6 Bulanan** | **Kontrol Faktor Risiko (HbA1c, Lipid, TD, BB, Rokok), Lab (T, PSA, Hkt Jika T-Th), IIEF-5** |
| **Tahunan** | **Kardiovaskular Risk Assessment (ED = Marker CVD)** |

## Ringkasan untuk Dokter Umum

1. **ED = Gangguan Ereksi Konsisten ≥ 3-6 Bln — Bukan "Tidak Bisa Sekali Dua Kali"**
2. **IIEF-5 (SHIM) 5 Pertanyaan = Screening Cepat Valid — Skor ≤ 21 = ED**
3. **Anamnesis Kunci: Ereksi Pagi/Spontan (Ya = Psikogenik/Hormonal), Obat, DM/HT/Rokok, Hubungan Pasangan**
4. **Pemeriksaan: Testis Volume, Pulse Pudendal (Dorsalis Pedis), Refleks Bulbokavernosus, DRE**
5. **Lab WAJIB: HbA1c, Lipid, Testosteron Total (Pagi), LH, FSH, Prolaktin, TSH, PSA (> 50 Th / T-Th)**
5. **ED = "JENDELA" KE PENYAKIT KARDIOVASKULAR (Endothelial Dysfunction) — ED Mendahului Koroner 3-5 Th!**
6. **First-Line: Lifestyle (Stop Rokok #1, BB Turun, Olahraga, DM/HT/Lipid Kontrol) + PDE5i (Sildenafil/Tadalafil/Vardenafil/Avanafil)**
7. **Second-Line: ICI Alprostadil (> 85% Efektif), MUSE, VED, Testosteron (Jika Low T + Gejala)**
8. **Third-Line: Penile Implant (Inflatable 3-Piece = Gold Standard, Satisfaction 90%+)**
9. **Psikogenik: Sensate Focus + CBT + Konseling Pasangan + PDE5i Sebagai Jembatan**
10. **Rujuk Urologi/Andrologi: Gagal PDE5i, Injeksi/Implant, Peyronie, Trauma, Hormon Kompleks, Pasca RP**
