# Servisitis

## Cerita Pembuka

Ny. Sari, 28 tahun, G1P1A0, datang ke poli ginekologi RSKH dengan keluhan keputihan berwarna kuning kehijauan, bau tidak sedap, dan nyeri saat BAK seitan 2 minggu. Suami baru pulang dari luar negeri 3 minggu lalu. Pemeriksaan spekulum: serviks merah, mudah berdarah (friable), mukus purulen keluar dari os eksternus. Swab dikirim Gram stain: diplokokus intaseluler (+). Diagnosis: Servisitis gonokokus. Diberi seftriakson 250 mg IM sekali + azitromisin 1 g PO sekali. Suami juga ditangani (EPT). Kontrol 2 minggu: gejala hilang, swab negatif.

## Definisi

Servisitis adalah **peradangan serviks uteri**, diklarifikasikan oleh:
- **Mukus purulen** dari kanalis serviks
- **Serviks friable** (mudah berdarah saat disentuh spekulum/swab)
- **Eritema/ektropion** serviks
- **Edema** serviks

Bisa **akut** (infeksi STI) atau **kronik** (irritasi, IUD, perubahan hormon).

## Etiologi

| Kategori | Patogen | Porsi |
|----------|---------|-------|
| **STI (Infeksi Menular Seksual)** | | 50-70% kasus akut |
|  | *Neisseria gonorrhoeae* | 20-30% |
|  | *Chlamydia trachomatis* | 30-40% |
|  | *Mycoplasma genitalium* | 10-20% (naik, resistensi makrolida) |
|  | *Trichomonas vaginalis* | 5-10% |
|  | HSV-2 | < 5% (lesi vesikuler) |
| **Non-STI / Komensal** | | 30-50% |
|  | Bakteri vaginosis-associated (Gardnerella, anaerob) | Umum |
|  | *Streptococcus agalactiae* (GBS) | Kadang |
|  | *E. coli*, *Klebsiella* | Jarang |
| **Non-Infeksius** | | |
|  | IUD (tali Kupfer iritasi) | Sering |
|  | Alat kontrasepsi barrier (spermisida, lateks) | Jarang |
|  | Radioterapi / kemoterapi | Jarang |
|  | Alergi/iritan (douching, sabun, tissue) | Umum |

> [!warning] Red Flag
> **M. genitalium resistensi makrolida (azitromisin) > 50% di Asia** — jika gagal azitromisin, ganti moksifloksasin 400 mg PO 7-14 hari (rujuk SpOG).
> **Servisitis + PID** (nyeri tekan adneksa, demam) → tata laksana PID, bukan servisitis sederhana.
> **Servisitis berulang/ persisten** → cek HIV, sifilis, kolposkopi, biopsi (kecuali malignancy).

## Gejala & Tanda

| Gejala Subjektif | Tanda Objektif (Spekulum) |
|------------------|---------------------------|
| Keputihan (purulen/mukopurulen) | Mukus purulen dari os eksternus |
| Nyeri/perih saat BAK (disuria) | Serviks merah, edematosa, friable (mudah berdarah) |
| Nyeri saat hubungan (dispareunia) | Ektropion (epitel kolumna terlihat merah) |
| Nyeri perut bawah ringan | Nabothian cyst (kista nabothi) — incidental |
| Perdarahan spotting (postkoital) | Polip serviks (jika ada) |
| Sering BAK (frekuensi) | Ulserasi (HSV, sifilis, kanker — waspada!) |

## Diagnosis

### Klinis (Syndromic Approach — WHO/POGI)
Diagnosis **dibuat klinis** jika:
- Mukus purulen dari serviks **ATAU**
- Serviks friable (mudah berdarah) **ATAU**
- Eritema serviks + gejala keputihan/BAK

> Di setting terbatas (puskesmas/RS tipe C) → **beri terapi empirik syndromic** tanpa tunggu lab.

### Laboratorium (Jika Tersedia)
| Pemeriksaan | Indikasi |
|-------------|----------|
| **Gram stain** swab serviks | Diplokokus intaseluler → Gonore; tidak ada tapi PMN > 30/HPF → Chlamydia/M.genitalium |
| **NAAT (PCR)** *C. trachomatis* & *N. gonorrhoeae* | Gold standard, sensitivitas > 95% |
| **NAAT *M. genitalium*** | Jika tersedia, atau jika gagal terapi standar |
| **Wet mount / KOH** | Trichomonas (motile trichomonad), Candida (hyphae) |
| **Kultur** | Jika NAAT tidak tersedia / butuh sensitivitas antibiotik |
| **Serologi HIV, Sifilis, HBsAg** | **WAJIB** screening STI lengkap |

## Tata Laksana (Sesuai POGI/Kemenkes/WHO 2021)

### 1. Servisitis Gonore (atau Campuran Gonore + Chlamydia)
| Obat | Dosis | Catatan |
|------|-------|---------|
| **Seftriakson** | **500 mg IM sekali** (jika BB < 150 kg) / **1 g IM** (BB ≥ 150 kg) | **Pilihan utama** — resistensi kuinolon tinggi |
| **PLUS Azitromisin** | **1 g PO sekali** | Cover chlamydia & M. genitalium |
| **ATAU Doksisiklin** | 100 mg 2× sehari 7 hari | Jika azitromisin kontraindikasi (alergi makrolida) |

> **Catatan:** Seftriakson 250 mg IM lama, sekarang **500 mg** (WHO 2021/POGI 2022) karena resistensi.

### 2. Servisitis Chlamydia (Non-Gonore)
| Obat | Dosis |
|------|-------|
| **Azitromisin** | **1 g PO sekali** (prefer — adherence bagus) |
| **ATAU Doksisiklin** | 100 mg 2× sehari 7 hari |

### 3. Servisitis *M. genitalium* (Persisten/Resisten)
| Obat | Dosis |
|------|-------|
| **Moksifloksasin** | **400 mg PO 1× sehari 7-14 hari** (rujuk SpOG, butuh NAAT resistensi makrolida) |

### 4. Trichomoniasis
| Obat | Dosis |
|------|-------|
| **Metronidazol** | **2 g PO sekali** ATAU 500 mg 2× sehari 7 hari |
| **Tinidazol** | 2 g PO sekali |

### 5. Servisitis Non-Spesifik / BV-Associated
- Terapi BV: Metronidazol 500 mg 2× 7 hari / Metronidazol gel 0,75% intravaginal 5 hari
- Hindari iritan (douching, sabun keras)
- Jika pakai IUD → pertimbangkan ganti metode jika berulang

## Pasangan (EPT - Expedited Partner Therapy)
- **WAJIB** ditangani pasangan (suami/pasangan seks 60 hari terakhir)
- Bisa diberi obat langsung pasien (EPT) jika pasangan tidak mau datang
- Regimen sama: Seftriakson 500 mg IM + Azitromisin 1 g PO
- Edukasi: hindari seks sampai keduanya selesai terapi 7 hari + gejala hilang

## Follow-up
- Kontrol 1-2 minggu: cek gejala, swab ulang (jika NAAT awal positif)
- Jika persisten → cek *M. genitalium* (NAAT + resistensi), HIV, sifilis, kolposkopi
- **Screening berkala** jika berisiko tinggi (CSW, multiple partner, HIV+)

## Komplikasi
- **PID (Pelvic Inflammatory Disease)** — naik ke endometritis, salpingitis, abses tubo-ovarium
- **Infertilitas** (adhezi tuba, hydrosalpinx)
- **Kehamilan ektopik** (risiko ↑ 7-10× post-PID)
- **Korioamnionitis, PROM, preterm** jika hamil
- **Infeksi neonatus** (oftalmia neonatorum, pneumonia *C. trachomatis*)

## Pencegahan
- Kondom konsisten & benar
- Vaksinasi HPV (indirect — cegah kanker serviks, bukan servisitis)
- Screening rutin: Pap smear/IVA + HPV DNA test
- Edukasi kesehatan reproduksi remaja

## Ringkasan untuk Dokter Umum

1. Servisitis = serviks merah, friable, mukus purulen
2. **Etiologi #1: STI (GC, CT, M. genitalium, TV)** — tata laksana syndromic empik
3. **Terapi empirik:** Seftriakson 500 mg IM + Azitromisin 1 g PO (cover GC+CT+M.gen)
4. **Pasangan WAJIB diobati (EPT)** — hindari ping-pong infection
5. **Screening HIV/Sifilis/HBsAg** rutinitas
6. **Persisten/berulang** → cek M. genitalium resistensi, kolposkopi, rujuk SpOG
7. **Jangan lupa edukasi kondom & hindari douching**
