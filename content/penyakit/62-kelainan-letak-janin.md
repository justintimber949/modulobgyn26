# Kelainan Letak Janin Setelah 36 Minggu (Malpresentasi & Malposisi)

## Cerita Pembuka

Ny. Dewi, 29 tahun, G1P0A0, usia kehamilan 37 minggu. Leopold: kepala di fundus (bokong), punggung kanan anterior. USG: presentasi bokong frank (dua kaki extended), AFI normal, plasenta posterior bukan previa. ECV 37+2 mg: sukses (kepala नीचे), tokolisis nifedipin 20 mg PO sebelum, betametason sudah 34 mg. ANC 38 mg: kepala terfiksasi, induksi persalinan, lahir normal bayi 3200 g, APGAR 9/10.

## Definisi & Klasifikasi

**Malpresentasi** = presentasi bukan **cephalic (kepala)** setelah 36 minggu.
**Malposisi** = presentasi cephalic tapi **posisi abnormal** (OP, OT, mentum anterior/posterior).

| Jenis | Definisi | Frekuensi (Term) |
|-------|----------|------------------|
| **Presentasi Bokong (Breech)** | Bokong/ kaki di pelvic inlet | 3-4% (frank 65%, complete 25%, footling 10%) |
| **Presentasi Samping (Transverse/Oblique)** | Sumbu janin horizontal/miring | 0,3-0,5% |
| **Presentasi Muka (Face)** | Ekstensi maksimal, muka presentasi | 0,1-0,2% |
| **Presentasi Dahi (Brow)** | Ekstensi parsial, dahi presentasi | 0,05% |
| **Malposisi Cephalic** | OP (Occiput Posterior), OT (Occiput Transverse), Mentum | OP: 5-10% (banyakan rotasi spontan ke OA) |

> **Sebelum 36 mg:** Malpresentasi umum (25% di 32 mg) → **banyakan rotasi spontan ke cephalic**. **Diagnosis pasti & intervensi setelah 36 mg.**

## Etiologi & Faktor Risiko

| Faktor | Malpresentasi Terkait |
|--------|----------------------|
| **Kehamilan ganda** | Bokong, samping (ruang terbatas) |
| **Multipara grandemultipara** | Otot uterus longgar, bokong/samping |
| **Polihidramnion** | Ruang gerak luas → bokong, samping, unstable lie |
| **Oligohidramnion** | Engagement sulit → bokong, defleksi |
| **Plasenta Previa / Low-lying** | Blok engagement kepala → bokong, samping |
| **Anomali Uterus** (Septum, Bicornuate, Unicornuate) | Ruang abnormal → samping, bokong |
| **Anomali Janin** (Anensefali, Hydrocephalus, NTD, Kontraktura) | Bokong, muka, samping |
| **KPD / PROM lama** | Engagement terbatas → bokong |
| **Tali pusat pendek / nuchal cord** | Membatasi rotasi |
| **Primipara** | OP (pelvis gynecoid + otat keras) |

## Diagnosis

### 1. Klinis (Leopold Maneuver) — **Screening Utama**
| Langkah | Temuan Bokong | Temuan Samping | Temuan Muka |
|---------|---------------|----------------|-------------|
| **1. Fundus** | Kepala keras, bulat, ballotable | Kepala di samping / tidak teraba fundus | Kepala tidak teraba / dahi+muka teraba |
| **2. Lateral** | Punggung keras di satu sisi, ekstremitas di sisi lain | Punggung anterior/posterior, kepala & bokong di sisi | Dahi/muka di anterior, occiput posterior |
| **3. Pawlik (Pelvic Inlet)** | **Bokong lunak, tidak ballotable, kaki teraba** | **Bahuan/bokong tidak engagement, sumbu horizontal** | **Muka/dahi teraba (bisa keliru bokong)** |
| **4. Pelvic Grip** | **Kepala di fundus, tidak engagement** | **Tidak ada bagian presentasi di pelvic inlet** | **Mentum/dahi teraba, occiput tinggi** |

### 2. USG (Konfirmasi & Detail)
- **Presentasi & Posisi** (cephalic/bokong/samping/muka/dahi)
- **Tipe Bokong:** Frank (hanuck extended), Complete (hanuck & lutut fleksi), Footling (1/2 kaki extended)
- **Janin:** EFW, biometri, anomali (hidrosefalu, NTD, kontrakutra, akromesomelik)
- **Plasenta:** Lokasi (previa?), grade
- **Cairan:** AFI (oligo/poli)
- **Tali pusat:** Nuchal cord, panjang
- **Pelvis Ibu (jika USG 3D/MR pelvimetri):** AP diameter, interspinous

### 3. Pemeriksaan VT (Jika USG Tidak Tersedia / Konfirmasi Intrapartal)
- **Bokong:** Teraba bokong lunak, genitalia, kaki, anus (tidak ada sutura/lelangit)
- **Muka:** Teraba muka (mata, hidung, mulut), **tidak ada sutura/lelangit** — beda dengan bokong
- **Dahi:** Teraba dahi (supraorbital ridge), sutura koronal, fontanel anterior
- **Samping:** Teraba bahu/kepala/bokong di samping, **tidak ada bagian presentasi di pelvic inlet**

> **Penting:** BEDAKAN **BOKONG vs MUKA** — keduanya tidak punya sutura. **Muka:** wajah teraba (mata, hidung, mulut), **Bokong:** genitalia/anus/kaki teraba.

## Tata Laksana Berbasis Jenis & UK

### A. Presentasi Bokong (Breech) ≥ 36 Minggu

#### 1. **External Cephalic Version (ECV) — First Line**
| Kriteria Kandidat ECV | Kontraindikasi ECV |
|----------------------|-------------------|
| **UK ≥ 36+0 mg** (ideal 36-37 mg) | **Plasenta Previa / Low-lying (< 2 cm)** |
| **Singleton** | **KPD / PROM** |
| **AFI Normal (5-25 cm)** | **Oligohidramnion (AFI < 5 / DVP < 2)** |
| **Janin Normal (tidak anomali, tidak IUGR berat)** | **Anomali Janin Mayor / IUGR < 10th % berat** |
| **Plasenta Bukan Previa** | **Kehamilan Ganda** (kontroversial, bisa ECV bayi 2) |
| **Maternal: Tidak kontraindikasi tokolisis/beta-agonist** | **Abrupsio / Perdarahan / Preeklampsia berat** |
| **Kehamilan Pertama / Multipara** (sukses ↑ multipara) | **Uterus Anomali (Septum, Bicornuate)** |
| | **Tali Pusat Pendek / Nuchal Cord Tebal** (USG Doppler) |
| | **Non-reassuring Fetal Status (NST/BPP abnormal)** |

**Prosedur ECV:**
1. **Pre-ECV:** NST reaktif, USG konfirmasi bokong & AFI, **tokolisis** (Nifedipin 20 mg PO / Terbutalin 0,25 mg SC / Salbutamol 200 mcg inhale / Atosiban IV), **Betametason** jika < 37 mg (sudah diberikan idealnya)
2. **ECV:** Push-pull bimanual di atas abdomen, monitoring USG real-time + NST kontinu
3. **Sukses Rate:** 50-60% (primipara 40%, multipara 70%)
4. **Pasca-ECV:** NST 30-60 menit, Anti-D jika Rh neg, monitoring 2-4 jam
5. **Komplikasi ECV (< 1-2%):** Bradycardia transien (umum, pulih), Abrupsio (0,5%), KPD (0,5%), Fetal distress butuh SC darurat (< 0,5%)

> **Jika ECV SUKSES → Persalinan Normal (Induksi 39-40 mg / Spontan)**
> **Jika ECV GAGAL / KONTRAINDIKASI → SC ELEKTIF 39+0 mg**

#### 2. **Persalinan Normal Bokong (Vaginal Breech Delivery) — TERBATAS**
**Indikasi Ketat (POGI/ACOG/RCOG):**
- Frank/Complete breech (TIDAK footling)
- EFW **2500-3800 g** (tidak makrosomia, tidak IUGR berat)
- **Pelvis Adekuat** (klinis/pelvimetri)
- **Kepala Fleksi** (mentum ke dada, bukan defleksi/extended)
- **SpOG Berpengalaman Vaginal Breech** + **Anestesi + Neonatologi + SC Standby**
- **Konseling & Informed Consent** ibu (risiko: kepala terjebak, asfiksia, trauma, mortalitas neonatal 2-3× SC)
- **No induction / augmentasi oksitosin** (kontraksi spontan saja)

**Manajemen Intrapartal (Breech Extraction Assisted):**
1. **Fase 1:** Monitoring ketat CFM, progress normal
2. **Fase 2 (Pengejanan):** **Hands-off the breech** sampai bokong & badan lahir (tingkat umbilikus) → lalu **Løvset / Mauriceau-Smellie-Veit / Bracht** untuk ekstraksi badan & kepala
3. **Kepala:** **Piper Forceps / Forceps Keilland / Mauriceau-Smellie-Veit maneuver** — **wajib dikontrol, tidak boleh tarik kepala bebas**
4. **Waktu:** Dari bokong lahir sampai kepala lahir **< 5-10 menit** (risiko asfiksia ↑ drastis > 10 menit)

> **Jika tidak memenuhi kriteria di atas / tidak ada operator berpengalaman → SC ELEKTIF**

#### 3. **SC Elektif (Standar Saat Ini)**
- **39+0 mg** (ACOG/POGI) — balance prematuritas vs risiko SC
- **Jika KPD / Persalinan Aktif sebelum 39 mg → SC Darurat**

### B. Presentasi Samping (Transverse/Oblique Lie)
- **TIDAK BOLEH Persalinan Normal** — sumbu janin horizontal, tidak bisa lahir vaginal
- **ECV Bisa Dicoba** (sukses rate ~ 40-50%) **JIKA:** Singleton, AFI normal, tidak anomali, tidak kontraindikasi
- **Jika ECV Gagal / Kontraindikasi → SC ELEKTIF 39 mg** (atau lebih awal jika KPD/kontraksi)
- **Darurat:** Jika KPD + samping → **SC DARURAT** (risiko prolaps tali pusat, abrupsio, ruptur uterus)

### C. Presentasi Muka (Face Presentation)
| Posisi Mentum | Prognosis Persalinan Normal | Tata Laksana |
|---------------|----------------------------|--------------|
| **Mentum Anterior (MA)** | **Bisa Normal** (ekstensi fisiologis, mentum rotasi ke simfisis → lahir) | Expectant, CFM, siap forceps/SC jika arrested |
| **Mentum Posterior (MP)** | **Tidak Bisa Normal** (mentum ke sakrum, tidak bisa rotasi anterior, kepala extended maksimal) | **SC Elektif 39 mg** / SC darurat jika aktif |
| **Mentum Transverse (MT)** | Sering rotasi ke MA (bisa normal) / MP (SC) | Monitoring, siap SC |

> **Diagnosis Muka vs Bokong:** VT → muka (mata, hidung, mulut) vs bokong (genitalia, anus, kaki). USG: profil wajah, ekstensi serviks.

### D. Presentasi Dahi (Brow Presentation)
- **TIDAK BOLEH Persalinan Normal** — diameter presentasi terbesar (mentovertikal 13,5 cm) > pelvic inlet
- **Sering Konversi:** Ke Muka (ekstensi lebih) → MA bisa normal / MP → SC, atau ke Vertex (fleksi) → normal
- **Tata Laksana:** Monitoring, jika persisten brow → **SC Elektif 39 mg** / darurat jika aktif

### E. Malposisi Cephalic (OP / OT)
- **OP (Occiput Posterior):** 5-10% term, **90% rotasi spontan ke OA** (anterior) saat fase aktif/pengejanan
- **Persistent OP (5-10% OP):** Pengejanan lama, laserasi derajat 3-4 ↑, vacuum/forceps ↑, SC ↑
- **Tata Laksana:**
  1. **Expectant + Posisi Maternal** (lutut-dada, sideways, forward-leaning) — gravitasi bantu rotasi
  2. **Manual Rotation** (VT, operator berpengalaman, CFM) — rotasi occiput ke anterior
  3. **Forceps / Vacuum Rotational** (Kielland / Vacuum dengan rotasi) — jika arrested descent + persistent OP
  4. **SC** — jika gagal rotasi / arrest pengejanan / maternal exhaustion / fetal distress

## Ringkasan untuk Dokter Umum

1. **Malpresentasi setelah 36 mg = butuh intervensi** (sebelumnya bisa rotasi spontan)
2. **Bokong ≥ 36 mg: ECV FIRST LINE** (sukses 50-60%, tokolisis, NST, USG monitoring)
3. **ECV Sukses → Normal. ECV Gagal/Kontraindikasi → SC Elektif 39 mg**
4. **Vaginal Breech HANYA JIKA:** Frank/Complete, EFW 2500-3800g, Fleksi kepala, Pelvis adekuat, Operator senior, Informed consent, SC standby
5. **Samping → SC (ECV boleh dicoba tapi SC backup)**
6. **Muka:** MA → bisa normal, MP/MT → SC
7. **Dahi → SC** (sering konversi ke Muka/Vertex, tapi jika persisten SC)
8. **OP:** Expectant + posisi maternal + manual rotation → Forceps rotasional / SC jika gagal
9. **USG WAJIB** sebelum ECV/keputusan: konfirmasi presentasi, tipe bokong, AFI, plasenta, anomali, EFW
10. **Konseling Ibu:** Risiko & benefit setiap opsi, informed consent tertulis
