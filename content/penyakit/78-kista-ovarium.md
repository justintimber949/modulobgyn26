# Kista Ovarium (Ovarian Cysts)

## Cerita Pembuka

Ny. Dewi, 30 tahun, G1P0A0, keluhan nyeri perut kiri bawah ringan. USG: Kista ovarium kiri 5×4 cm, **anekoik, dinding tipis, tidak ada septasi, tidak ada solid component, tidak ada vaskularitas**. Diagnosis: **Kista Folikuler (Fungsional)**. Manajemen: **Watchful waiting 6-8 minggu (2 siklus)** — Kista mengecil jadi 2 cm (regresi spontan). Selesai.

## Definisi & Klasifikasi

**Kista Ovarium** = **Kantung berisi cairan (atau jaringan) yang berkembang di dalam atau di permukaan ovarium.**

### Berdasarkan Etiologi

| Kategori | Contoh | Frekuensi |
|----------|--------|-----------|
| **Fungsional (Tidak Berbahaya, Regresi Spontan)** | **Kista Folikuler (2-8 cm, Anekoik), Korpus Luteum Kista (Dinding Tebal, Hemoragik)** | **70-80%** |
| **Neoplastik Jaringan** | **Teratoma (Dermoid)**, **Serous Cystadenoma**, **Mucinous Cystadenoma**, **Endometrioma**, **Fibroma**, **Tumor Borderline** | **15-20%** |
| **Neoplastik Ganas** | **Karsinoma Serous**, **Karsinoma Mucinous**, **Clear Cell**, **Endometrioid**, **Germ Cell Malignant**, **Sex Cord-Stromal** | **5-10%** (terutama post-menopause) |
| **Abses (Infeksi)** | **Abses Ovarium, Tubo-ovarian Abscess (TOA)** | Jarang |
| **Hidatid** | Echinococcus granulosus (daerah endemik) | Jarang |
| **Pregnancy-Related** | Korpus Luteum Kehamilan, Theca Lutein (HCG ↑), Luteoma | Jarang |

### Torsi Ovarium — **DARURAT (15-20% Kista Ovarium)**

## Diagnosis & Diferensial (USG — Gold Standard Non-Invasif)

### Pola USG Kista Ovarium

| Pola USG | Kemungkinan | Tindakan |
|----------|-------------|----------|
| **Anekoik, Dinding Tipis, Tanpa Septasi/Solid (Simple Cyst)** | **Kista Fungsional (Folikuler)** | **Follow-up 6-8 minggu** → Regresi spontan 70-90% |
| **Anekoik, Dinding Tebal (5-10 mm), Vaskularitas Dinding** | **Korpus Luteum Kista** | Follow-up 6-8 minggu → Regresi spontan (bisa 12 minggu) |
| **Hiperekoik Homogen "Ground Glass" (Dinding Tipis)** | **Endometrioma** | Follow-up atau Kistektomi (indikasi sama di bawah) |
| **Heterogen, Fatty/Hair/Teeth (R2 Sign)** | **Teratoma (Dermoid)** | Kistektomi (lihat modul #77) |
| **Multilokuler (Septated), Dinding Tipis** | **Serous/Mucinous Cystadenoma** | **Kistektomi Laparoskopik** (jika > 5-6 cm) |
| **Solid + Cystic, Vaskularitas ↑, Kompleks** | **Tumor Borderline / Malignant** | **Rujuk SpOG SEGERA** — PET-CT, Tumor Marker (CA-125, HE4, ROMA Index) |
| **Kompleks, Debris, Fluid-Debris Level** | **Hemorrhagic Cyst / Abses / Endometrioma Hemoragik** | **Follow-up 6-12 minggu** → Regresi hemorrhagic (1-3 siklus). Jika demam/WBC ↑: Abses → Antibiotik + Drainage/Rujuk |
| **Kista Besar (> 10 cm), Kompleks** | **Mucinous Cystadenoma / Karsinoma Mucinous / Teratoma** | **Rujuk SpOG** — Potensi ruptur/kompresi, butuh histopat |

### Marker Tumor (Jika Kompleks / Ragu Malignant)

| Marker | Kegunaan |
|--------|----------|
| **CA-125** | ↑ pada Karsinoma Epitel Ovarium (serous), Endometriosis, PID, Fibroid, Haid, Kehamilan — Spesifisitas rendah < 50 th |
| **HE4 (Human Epididymis Protein 4)** | ↑ pada Karsinoma Ovarium (lebih spesifik CA-125 untuk pre-menopause) |
| **ROMA Index (Risk of Ovarian Malignancy Algorithm)** | Kombinasi CA-125 + HE4 + Usia + Status Menopause — Spesifisitas Lebih Baik |
| **AFP** | Germ Cell Tumors (Teratoma Immature, Yolk Sac, Embryonal) |
| **β-hCG** | Germ Cell (Choriokarsinoma, Seminoma/Germinoma) |
| **LDH** | Germinoma |
| **Inhibin B** | Sex Cord-Stromal Tumors (Granulosa Cell) |
| **CEA** | Mucinous Cystadenocarcinoma |
| **SCC** | Karsinoma Sel skuama ovarium |

### IOTA (International Ovarian Tumor Analysis) Rules — **Membedakan Jinak vs Ganas**

| Rules | Kriteria |
|-------|----------|
| **Simple Rules (SR) — SR-B / SR-M** | **SR-B (Benign):** Unilocular, Anekoik, Solid < 7 mm, No Blood Flow, Acoustic Shadowing. **SR-M (Malignant):** Irregular solid, Papillations > 3 mm, Multilocular > 10 loculi, > 10 mm Blood Flow |
| **ADNEX Model** | Predicts risk Benign/Borderline/Malignant berdasarkan: Age, Size, Solid %, AC (Ascites), Color Score (Vaskularitas), Referral Center |
| **IOTA Criteria JINAK:** Cyst ≤ 10 cm, Unilocular/Multilocular ≤ 10 loculi, Anekoik/Minimal Echo, Dinding Tipis, No solid, No vascularity → **Follow-up Bukan Operasi** |

## Tata Laksana (Berdasarkan USG & Usia)

### A. Kista Fungsional (Simple Cyst < 5-8 cm, Anekoik, Dinding Tipis)

| Tindakan | Detail |
|----------|--------|
| **Watchful Waiting (6-8 Minggu / 2 Siklus Menstruasi)** | **Default untuk usia Reproduksi** — **70-90% regresi spontan** |
| **USG Ulang 6-8 Minggu** | Jika mengecil/hilang → Selesai. Jika membesar/unchanged > 3 siklus → pertimbangkan operasi |
| **Tidak Perlu Operasi Jika: Asimtomatik + Simple + Kecil + Menurun** | Jangan Over-Treatment! |

### B. Indikasi OPERASI (Kistektomi)

| Indikasi | Detail |
|----------|--------|
| **Kista > 5-8 cm Persisten (> 3-4 Siklus)** | Tidak regresi, risiko torsi ↑ untuk kista besar |
| **Kompleks: Septated + Solid + Vascular** | Curiga Borderline/Malignant → Rujuk SpOG |
| **Gejala: Nyeri Berat, Gangguan Fungsi (Bowel/Bladder)** | Kista besar kompresi → operasi elektif |
| **TORSIO (Akut):** Nyeri Hebat + Mual/Muntah + Massa Pelvis + USG: Whirlpool / Absen Doppler | **DARURAT: Laparoskopi/SC Untwisting + Kistektomi** |
| **Endometrioma > 4-5 cm** | Dysmenorrhea, Dyspareunia, Infertilitas, Endometriosis aktif |
| **Konseling Fertilitas + Kista > 3-4 cm** | Ingin IVF / Kehamilan segera → kistektomi dulu |
| **Post-Menopause: Kista Simple > 5 cm / Kompleks / CA-125 ↑** | Risiko malignant lebih tinggi → Rujuk SpOG |

### C. Teknik Operasi

| Pendekatan | Indikasi |
|------------|----------|
| **Laparoskopi Kistektomi** | **First-Line** — Kista < 10-12 cm, Tidak curiga malignancy, Usia muda |
| | **ENDBAG/Endobag untuk ekstraksi** (Hindari ruptur isi ke perut) |
| | **Hemostasis Parenchyma Ovarium: Bipolar / Harmonic / Suture** (Hindari koagulasi berlebihan → ischemia ovarium → AMH ↓) |
| **Laparotomi (Abdominal)** | Kista > 12-15 cm, Curiga Malignant, Kompleks, Ascites, Frozen Section Jika Ragu |
| | **Ovariopeksi (Ovaropexy)** jika ovarium masih viable setelah detorsi (torsi) |

### D. Kista Spesifik

| Tipe Kista | Khusus Manajemen |
|------------|-----------------|
| **Endometrioma** | **USG Spesifik: Ground Glass.** Kistektomi atau Drainase + Ablasi dinding (jika bilateral/besar/AMH rendah). Lihat Modul #73 Endometriosis |
| **Hemorrhagic Cyst** | **Follow-up 6-12 minggu** — 95% regresi spontan. Jika persisten > 12 minggu atau > 5 cm: pertimbangkan operasi (jarang) |
| **TOA (Tubo-Ovarian Abscess)** | **Antibiotik IV (Pip-Tazo / Ceftriaxone + Metronidazol) + Drainage (USG/CT-Guided Percutaneous) + Rujuk SpOG** — Laparoskopi jika gagal/resisten/ruptur |
| **Bilateral Kompleks / Multifokal** | **Karsinoma Epitel Ovarium atau Metastase (Krukenberg)** — PET-CT, Biopsy (Jika Curiga Karsinoma Primari), Konsul Onkologi |

## Tanda Keburukan (Red Flags → Rujuk SpOG SEGERA)

| Tanda | Implikasi |
|-------|-----------|
| **Ascites** | Malignant (Karsinoma Epitel) |
| **CA-125 > 200-350 U/mL (Usia > 50 Th)** | PPV Tinggi untuk Karsinoma Ovarium |
| **Kompleks: Solid + Cystic + Vascular** | Borderline / Malignant |
| **Bilateral Kompleks** | Malignant / Metastase / Krukenberg |
| **Umur > 50 Th + Kista Baru** | Risiko Malignant Lebih Tinggi |
| **Hidrops腹腔 (Ascites) + Massa Pelvik** | Karsinoma Epitel Ovarium |

## Follow-up Non-Operatif (Watchful Waiting)

| Waktu | Tindakan |
|-------|----------|
| **6-8 Minggu** | USG Ulang → Kista Regresi (Hilang/Mengecil) → **Selesai** |
| **3-6 Bulan** | Jika masih ada tapi tidak membesar → USG 6 bulanan |
| **12 Bulan** | Jika persisten < 5 cm + Simple + Asimtomatik → USG tahunan |
| **Kapan Harus Operasi:** Kista > 5-8 cm Persisten > 3-4 Siklus, Memperbesar, Kompleks, Gejala, CA-125 ↑ | |

## Ringkasan untuk Dokter Umum

1. **70-80% Kista Ovarium = Fungsional (Folikuler/Korpus Luteum)** — **Watchful Waiting 6-8 Minggu → 70-90% Regresi Spontan**
2. **USG: Anekoik + Dinding Tipis + Tanpa Septasi/Solid = Simple → Follow-up** — JANGAN OPERASI LANGSUNG Jika Asimtomatik + Kecil
3. **Kista > 5-8 cm Persisten (> 3-4 Siklus) / Kompleks / Gejala Berat / CA-125 ↑ → Operasi (Kistektomi)**
4. **TORSIO: Nyeri Hebat + Mual/Muntah + USG Whirlpool/Absen Doppler → DARURAT Laparoskopi**
5. **IOTA Rules:** Simple Rules / ADNEX Model — Bantu bedakan Jinak vs Ganas
6. **Red Flags (Rujuk SpOG SEGERA):** Ascites, CA-125 > 200-350, Kompleks Solid+Cystic+Vascular, Bilateral Kompleks, Usia > 50 Th + Kista Baru
7. **Operasi: Laparoskopi + Endobag + Hemostasis Ovarium (Hindari AMH ↓) — Laparotomi Jika > 12 cm / Curiga Malignant**
8. **Endometrioma Ground Glass → Lihat Modul #73**
9. **Follow-up Non-Operatif: 6-8 Minggu → 3-6 Bln → 1 Th → Tahunan Jika Persisten Simple Kecil**
