# Gangguan Ejakulasi (Ejaculatory Disorders)

## Cerita Pembuka

Pak Budi, 30 tahun, pekerja kantor, menikah 2 tahun, anak 1 (konsepsi spontan). Keluhan: **ejakulasi terlalu cepat (< 1 menit penetrasi) sejak menikah, stres, hindar seks, pasangan kecewa**. IIEF-5: 23/25 (Tidak ED). PEP (Premature Ejaculation Profile): **PEP Score 30 (PE Klinis)**. Riwayat: tidak DM/HT, tidak rokok, tidak obat rutin. Pemeriksaan: normal. **Diagnosis: Ejakulasi Prematur Primer (Lifelong) + Kecemasan Performa**. Manajemen: **Stop-Start + Squeeze Technique (Behavioral) + Dapoksetin 30 mg PRN (1-3 Jam Sebelum Seks) + Lidokain-Prilokain Krim 5% (Topikal 15-20 Min Sebelum, Dicuci) + Konseling Seksual Pasangan**. 8 Minggu: IELT (Intravaginal Ejaculatory Latency Time) dari 45 detik → 4 menit, PEP Score 12, kepuasan pasangan ↑.

## Definisi & Klasifikasi (ISSM / DSM-5 / ICD-11)

| Gangguan | Definisi |
|----------|----------|
| **Ejakulasi Prematur (PE / Premature Ejaculation)** | **Ejakulasi Yang Selalu/Hampir Selalu Terjadi Sebelum/Dalam 1 Menit Penetrasi Vaginal (Lifelong) ATAU ≤ 3 Menit (Acquired), Tidak Bisa Ditunda, Menimbulkan Kecemasan/Kelelahan/Keputusasaan** |
| **Ejakulasi Mundur (Retrograde Ejaculation)** | **Semen Masuk Ke Kandung Kemih (Bukan Keluar Uretral) Saat Orgasme — Orgasme Ada Tapi "Kering" (Volume < 0,5 mL / Tidak Ada)** |
| **Ejakulasi Terlambat (Delayed Ejaculation / DE)** | **Ketidakmampuan Konsisten Ejakulasi Meskipun Stimulasi Adekuat & Ereksi Baik, Butuh Waktu Lama (> 20-30 Menit) / Tidak Bisa Sama Sekali (Anejakulasi Situasional)** |
| **Anejakulasi** | **Tidak Ada Ejakulasi Sama Sekali (Spontan / Masturbasi / Vibrator) — Organik (Saraf, Obat, Anatomi) vs Psikogenik** |
| **Ejakulasi Nyeri (Dysorgasmia / Odynorgasmia)** | **Nyeri Perineum/Uretral/Testis/Prostat Saat/Sesudah Ejakulasi** |
| **Hematospermia** | **Darah Dalam Sperma (Merah Segar/Coklat) — Biasanya Benin Self-Limiting, Tapi Butuh Rule Out Patologi** |

## Epidemiologi

| Gangguan | Prevalensi | Puncak Usia |
|----------|------------|-------------|
| **PE (Premature Ejaculation)** | **20-30% Pria (Palting Gangguan Seksual Pria)** | Semua Usia (Primer: Remaja/Dewasa Muda; Sekunder: > 40 Th Bersama ED) |
| **Retrograde Ejaculation** | **0,3-2% (↑ Pasca TURP/RP/Diabetes/Obat)** | > 50 Th (Prostat Surgery, DM Neuropati) |
| **Delayed Ejaculation** | **1-4%** | > 40 Th (Obat SSRI, DM, Saraf, Psikogenik) |
| **Anejakulasi** | **< 1%** | Cedera Medula, RP, DM Lanjut, Obat Kuat Antipsikotik |
| **Hematospermia** | **1-5% (Insidental, Sering Tidak Dilapor)** | < 40 Th (Biasanya Benin), > 40 Th (Butuh Investigasi) |

## Etiologi & Patogenesis

### A. Ejakulasi Prematur (PE)
| Tipe | Etiologi |
|------|----------|
| **Primer / Lifelong (Konstitusional)** | **Neurobiologis: Serotonergik (5-HT1A/1B/2C) Hipofungsi → Threshold Ejakulasi Rendah, Genetik (Polimorfisme 5-HTTLPR), Hipersensitivitas Penis/Glans** |
| **Sekunder / Acquired** | **ED (Kecemasan "Lost Erection" → Buru-buru Ejakulasi), Prostatitis Kronik/CPPS, Hipertiroid, Prostat Hiperplasi, Psikogenik (Stres, Kecemasan Performa, Trauma Seksual, Hubungan Buruk), Obat (Rare)** |

### B. Ejakulasi Mundur (Retrograde)
| Penyebab | Mekanisme |
|----------|-----------|
| **Obat** | **Bloker Alfa (Tamsulosin, Silodosin, Alfuzosin — Relaksasi Leher Kandung), Antidepresan (Trikasiklik), Antipsikotik** |
| **Diabetes Mellitus** | **Neuropati Otonom (Saraf Hipogastrik/Pelvik) → Leher Kandung Tidak Tutup** |
| **Operasi** | **TURP, HOLEP, Prostatektomi Radikal (RP), Resesi Leher Kandung, Kolorektal Surgery (Nervi Hipogastrik)** |
| **Kelainan Kongenital** | **Ekstrofi Kandung, Epispadia, Valv Uretra Posterior** |

### C. Ejakulasi Terlambat / Anejakulasi
| Penyebab | Detail |
|----------|--------|
| **Obat (Sering!)** | **SSRI (Sertralin, Paroksetin, Fluksetin, Sitralopram, Eskitalopram — #1 Obat), SNRI, Trikasiklik, Antipsikotik, Opioid, Bloker Alfa, Finasteride, Bloker Beta** |
| **Saraf** | **Cedera Medula Spinalis (Suprasakral = Refleksik Bisa / Sakral = Arefleksik), Diabetik Neuropati, Sclerosis Multipel, Sirkumcisi Komplikasi, Operasi Panggul (Nervi Hipogastrik)** |
| **Hormonal** | **Hipogonadisme (Low T), Hipotiroid, Hiperprolaktinemia, Low TSH** |
| **Psikogenik** | **Kecemasan Performa, Trauma Seksual, Kecemasan Penghamilan, Hubungan Buruk, Masturbasi Gaya Khusus (Death Grip) → Kondisioning** |
| **Anatomi** | **Hipospadia, Ekstrofi, Stenosis Uretra, Ductus Ejaculatorius Obstruksi (Kista Muller, Infeksi)** |

### D. Hematospermia
| Penyebab | Frekuensi |
|----------|-----------|
| **Idiopatik / Benin (Self-Limiting)** | **70-80% (< 40 Th, Single Episode, Tidak Ada Gejala Lain)** |
| **Infeksi (Prostatitis, Uretritis, Epididimitis, Vesikulitis, TB)** | 10-15% |
| **Obstruksi / Kista (Kista Ductus Ejaculatorius, Kista Muller, Kista Vesikula Seminalis)** | 5% |
| **Trauma / Biopsi Prostat / Vasectomi / Radiasi** | 5% |
| **Neoplasma (Kanker Prostat, Vesikula Seminalis, Uretra, Kandung, Testis)** | **< 1% (Tapi Harus Dikeluarkan > 40 Th / Persisten / Berulang)** |
| **Sistemik (Hipertensi Maligna, Koagulopati, Amyloidosis)** | Jarang |

## Diagnosis & Workup

### 1. Anamnesis Terstruktur (Kunci Semua Gangguan)

#### **PE: PEP (Premature Ejaculation Profile) / IIEF-PE / AIPE**
- **IELT (Intravaginal Ejaculatory Latency Time)** — Stopwatch (Pasangan/Pasien Catat) — **Lifelong PE: < 1 Menit, Acquired PE: ≤ 3 Menit**
- **Kendalikan Ejakulasi? (Tidak Bisa = PE)**
- **Kecemasan/Kelelahan/Keputusasaan? (Ya = Distress = Diagnosis PE)**
- **Situasional / Semua Pasangan / Masturbasi Juga?**

#### **Retrograde: "Orgasme Ada Tapi Tidak Ada Air Maninya / Volume Sangat Sedikit" + Riwayat Obat/Operasi/DM**

#### **DE/Anejakulasi: "Butuh Waktu Sangat Lama / Tidak Bisa Ejakulasi Saat Seks Tapi Bisa Masturbasi / Vibrator" + Riwayat Obat (SSRI!), DM, Saraf, Psikogenik**

#### **Hematospermia: "Darah Di Sperma" + Usia, Frekuensi, Nyeri, LUTS, Riwayat Biopsi/Trauma, Obat (Antikoagulan)**

### 2. Pemeriksaan Fisik
| Area | Yang Dilihat |
|------|--------------|
| **Genitalia** | **Penis (Hipersensitivitas Glans PE), Testis (Volume, Konsistensi), Epididimis (Nodul/Tenderness), Varikocele** |
| **Prostat (DRE)** | **Ukuran, Konsistensi, Nodul, Tenderness (Prostatitis), Ekspresi Prostat (EPS untuk Mikroskopi/Kultur)** |
| **Saraf** | **Refleks Bulbokavernosus (S2-S4), Refleks Anus, Sensasi Perineum (Saddle)** |
| **Tiroid** | **Palpasi (Hipertiroid → PE, Hipotiroid → DE)** |
| **Vital** | **TD, BMI** |

### 3. Laboratorium
| Pemeriksaan | Indikasi |
|-------------|----------|
| **Uranalisis + Urin Post-Ejakulasi (Post-Ejaculatory Urinalysis)** | **WAJIB Retrograde — Cek Spermatozoa di Urin Post-Orgasme (Sentrifug 10 Menit, Mikroskopi)** |
| **Spermiogram (Analisis Sperma)** | **Infertilitas / Anejakulasi / Retrograde (Volume, Konsentrasi, Motilitas, Morfologi)** |
| **Testosteron Total, LH, FSH, Prolaktin, TSH, FT4** | **Hormonal (Hipogonadisme, Tiroid, Prolaktinoma)** |
| **Gula Darah Puasa / HbA1c** | **DM (Neuropati Otonom → Retrograde/DE/Anejakulasi)** |
| **Profil Lipid, Fungsi Hati/Ginjal** | **Komorbid / Obat Monitoring** |
| **PSA** | **> 40 Th / DRE Abnormal / Hematospermia Persisten** |
| **Kultur Urin / EPS / Sperma** | **Infeksi (Prostatitis, Uretritis, TB)** |
| **Koagulasi (PT, APTT, Trombosit)** | **Hematospermia + Antikoagulan / Koagulopati** |

### 4. Penunjang Lanjutan (Rujuk Urologi/Andrologi)
| Modality | Indikasi |
|----------|----------|
| **TRUS (Transrectal USG) / MRI Panggul** | **Kista Ductus Ejaculatorius / Kista Muller / Vesikula Seminalis / Obstruksi / Neoplasma** |
| **Urodinamika / Video-Urodinamika** | **Retrograde / Anejakulasi Neurogenik (Leher Kandung Dyssynergia)** |
| **Penile Biothesiometry / Vibratory Threshold** | **DE / Anejakulasi (Sensitivitas Penis / Glans) — Threshold Tinggi = Hiposensitivitas** |
| **Penile Vibratory Stimulation (PVS) / Electroejaculation (EEJ)** | **Anejakulasi (Infertilitas — Ambil Sperma untuk IUI/IVF/ICSI)** — PVS: Vibrator 100 Hz Glans, EEJ: Probe Rektal Elektrostimulasi |
| **Sitologi Urin Post-Ejakulasi (Retrograde)** | **Konfirmasi Spermatozoa di Urin** |
| **Kistoskopi** | **Hematospermia Persisten > 40 Th / Berulang / LUTS — Rule Out Tumor Uretra/Leher Kandung/Prostat** |

## Tata Laksana

### A. Ejakulasi Prematur (PE) — **Stepwise**

| Level | Terapi | Detail |
|-------|--------|--------|
| **1. Behavioral (First-Line, Non-Farmako)** | **Stop-Start (Semans) + Squeeze (Masters-Johnson)** — Latihan 3×/minggu, Pasangan Terlibat, **Pelvic Floor Muscle Training (Kegel) — Kontrak 3 Detik × 10 × 3×/Hari** | **Efektif 50-70% Jika Dilakukan Rutin + Pasangan Dukung** |
| **2. Topikal Anestetik (First-Line Farmako)** | **Lidokain-Prilokain 5% Krim/Spray (EMLA / Fortacin / Promescent) — Oles 15-30 Min Sebelum, DICUCI SEBELUM SEKS (Hindari Numb Pasangan)** | **IELT ↑ 2-6×, SE: Hiposensitivitas, Ereksi Turun (Pasangan/Pria), Alergi Jarang** |
| **3. SSRI On-Demand (Dapoksetin — Satu-Satunya SSRI Approved PE)** | **Dapoksetin 30 mg (Maks 60 mg) PRN 1-3 Jam Sebelum Seks** — **Half-Life Pendek (1,5 Jam), Onset Cepat, Tidak Akumulasi** — **SE: Nausea, Pusing, Diare, Insomnia, Syncope (Hindari Alkohol/Dehidrasi)** | **First-Line Oral Approved — TIDAK SSRI Lain (Paroksetin/Sertralin Daily = Off-Label, Butuh 1-2 Minggu Efek, SE Seksual Tetap)** |
| **4. SSRI Daily (Off-Label, Jika Dapoksetin Tidak Tersedia/Gagal)** | **Paroksetin 10-20 mg / Sertralin 50-100 mg / Fluksetin 20 mg — Daily, Butuh 1-2 Minggu Efek Maksimal** | **SE: Libido ↓, DE, Nausea, Bobot Naik — TAPI Efektif PE** |
| **5. PDE5i (Jika Komorbid ED)** | **Sildenafil/Tadalafil/Vardenafil — Bisa Bantu PE Sekunder ED (Kecemasan Ereksi)** | **Kombinasi Dapoksetin + PDE5i (Super P-Force dll) — Hati-Hati Hipotensi** |
| **6. Tramadol PRN (Off-Label, Second-Line)** | **Tramadol 25-50 mg PRN 2 Jam Sebelum** — **Opioid → Serotonin/Norepinephrine Reuptake Inhibitor** — **Risiko Kebiasaan, SE Opioid — Tidak First-Line** |
| **7. Konseling Seksual / CBT / Psikoterapi** | **Performance Anxiety, Trauma, Hubungan, Kecemasan Penghamilan** | **Wajib Jika Komponen Psikogenik Kuat** |

### B. Ejakulasi Mundur (Retrograde)

| Terapi | Indikasi |
|--------|----------|
| **Hentikan/Ganti Obat Penyebab (Tamsulosin → Silodosin Lebih Selektif? Atau Stop Bloker Alfa Jika Bisa)** | **First-Line Jika Obat-Induced** |
| **Impramin (Trikasiklik) 25-75 mg Malam / Klorfeniramin 4 mg 3× / Efedrin 25-50 mg 3× / Pseudoefedrin 60 mg 3×** | **Alpha-Agonis → Tonus Leher Kandung ↑ — Efektivitas 30-50% (Data Lama, RCT Terbatas)** |
| **Vibratory Stimulation (PVS) / Elektroejakulasi (EEJ) + IUI/IVF/ICSI** | **Infertilitas (Tujuan Ambil Sperma) — **Jika Fertilitas Diinginkan** |
| **Alkalinisasi Urin (Natrium Bikarbonat) Sebelum PVS/EEJ** | **Proteksi Sperma Dari Asiditas Urin** |

### C. Ejakulasi Terlambat / Anejakulasi

| Terapi | Detail |
|--------|--------|
| **Review & Hentikan Obat Penyebab (SSRI #1! → Switch Ke Bupropion / Mirtazapin / Agomelatin / Vortioksetin / TCA Dosis Rendah / Non-Farmako)** | **First-Line — Bupropion (NDRI) Paling "Bersih" Seksual** |
| **Testosteron Terapi (Jika Hipogonadisme: Low T + Gejala)** | **Gel/Injeksi — Libido & Orgasme Threshold ↑** |
| **Kabergolin (Jika Prolaktin ↑)** | **0,25-0,5 mg 2×/Mgg — Normalisasi Prolaktin → Orgasme Normalisasi** |
| **Sitologi Urin Post-Orgasme (Jika Retrograde Tersembunyi)** | **Rule Out Retrograde Sebagai Penyebab "Tidak Ada Ejakulasi"** |
| **PVS (Vibrator 100 Hz Glans/Penis) → EEJ (Rektal Probe) → Ambil Sperma untuk ART** | **Infertilitas — Jika Tujuan Anak** |
| **Konseling Seksual / Sensate Focus / CBT** | **Psikogenik (Death Grip, Kecemasan, Trauma)** |
| **Yohimbine / Bupropion / Amantadin / Sibutramin (Off-Label, Data Terbatas)** | **Second-Line Farmako DE** |

### D. Hematospermia

| Situasi | Tindakan |
|---------|----------|
| **< 40 Th, Single Episode, Asimtomatik, DRE Normal, PSA Normal** | **Reassurance (Benin Self-Limiting 80%), Observasi 4-6 Minggu** |
| **> 40 Th / Persisten > 1 Bulan / Berulang / LUTS / DRE Abnormal / PSA ↑ / Riwayat Kanker** | **TRUS / MRI Panggul / Kistoskopi / Biopsi Prostat (Jika PSA ↑ / DRE Abnormal) / Kultur Urin & Sperma** |
| **Infeksi (Prostatitis/Uretritis/Epididimitis)** | **Antibiotik 4-6 Minggu (Kuionolon / Doksisiklin / TMP-SMX) Berdasarkan Kultur** |
| **Kista / Obstruksi** | **TRUS-Guided Aspirasi / Marsupialisasi Kista Ductus Ejakulatorius (Histeroskopi/Transuretral)** |
| **Neoplasma** | **Onkologi: Prostat (RP/RT/Hormon), Vesikula Seminalis, Uretra, Kandung** |

## Ringkasan untuk Dokter Umum

1. **PE = Gangguan Seksual #1 Pria (20-30%) — Definisi: IELT < 1 Min (Lifelong) / ≤ 3 Min (Acquired) + Tidak Bisa Kontrol + Distress**
2. **Anamnesis Kunci: IELT (Stopwatch), Kendalikan?, Distress?, Situasional?, Obat?, ED?, Prostatitis?, Tiroid?, Psikogenik?**
3. **First-Line PE: Behavioral (Stop-Start + Squeeze + Kegel) + Topikal Anestetik (Lidokain-Prilokain 5% 15-30 Min Sebelum, Dicuci)**
4. **First-Line Oral: **Dapoksetin 30-60 mg PRN 1-3 Jam** (Satu-Satunya SSRI Approved PE) — SSRI Daily (Paroksetin/Sertralin) Off-Label Second-Line**
5. **Retrograde: "Orgasme Kering" + Obat (Tamsulosin/Silodosin #1), DM, Pasca Operasi Prostat → Urin Post-Ejakulasi Cek Spermatozoa**
6. **DE/Anejakulasi: **SSRI #1 Penyebab Obat** → Switch Bupropion/Mirtazapin/Agomelatin + Testosteron Jika Low T + PVS/EEJ Jika Infertilitas**
7. **Hematospermia: < 40 Th Single Episode = Reassurance (Benin 80%) | > 40 Th / Persisten / LUTS / PSA ↑ → TRUS + Kistoskopi + Biopsi Prostat (Rule Out CA)**
8. **Rujuk Urologi/Andrologi: Gagal First-Line, Infertilitas (PVS/EEJ/TESE), Obstruksi (Kista), Neoplasma, Saraf (Medula), Peyronie+ED+DE Kompleks**
9. **Konseling Pasangan + Sensate Focus + CBT = Wajib Semua Gangguan (Komponen Psikogenik Hampir Selalu Ada)**
