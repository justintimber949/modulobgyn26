# Insufisiensi Plasenta (Placental Insufficiency)

## Cerita Pembuka

Ny. Lina, 36 tahun, G1P0A0, usia kehamilan 32 minggu. Riwayat hipertensi kronik (terkontrol metildopa). ANC 32 mg: fundus tinggi 28 cm (kurang 4 cm), USG: EFW 1450 g (< 10 persentil), AFI 6 cm, Doppler UA: **AEDV (Absent End-Diastolic Velocity)**. β-hCG, PAPP-A trimester 1: rendah. Diagnosis: **IUGR simetris berat + Insufisiensi Plasenta berat (preeklampsia superimposed hipertensi kronik)**. Rawat inap, betametason 12 mg IM 2× 24 jam, MgSO4 profilaksis (preeklampsia), antihipertensi. USG harian Doppler UA. Hari ke-3: **REV (Reversed End-Diastolic Velocity)**. Keputusan: **SC darurat 32+3 mg**. Bayi lahir 1550 g, APGAR 5/8, masuk NICU. Bayi pulang hari ke-28 sehat.

## Definisi

**Insufisiensi Plasenta** = **kegagalan plasenta menyediakan oksigen & nutrisi yang cukup** untuk pertumbuhan & perkembangan janin normal, akibat **malperfusisi uteroplasesntal** (aliran darah maternal ke plasenta terganggu) dan/atau **malperfusisi fetoplasesntal** (aliran darah janin ke plasenta terganggu).

Ini adalah **patofisiologi dasar** dari:
- **IUGR (Intrauterine Growth Restriction)**
- **Preeklampsia (terutama early-onset < 34 mg)**
- **Abrupsio Plasenta**
- **Stillbirth (IUFD) tanpa anomali kongenital**
- **Preterm birth medis indikasi**

## Patofisiologi (Singkat)

| Mekanisme | Deskripsi |
|-----------|-----------|
| **Gagal invasi trofoblas (trimester 1)** | Sitotrofoblas tidak menginvasi arteri spiral maternal → arteri spiral **tidak remodelling** → tetap muscular, high resistance, low flow |
| **Malperfusisi Maternal** | Aliran darah ke intervillous space ↓ → hipoksia plasenta → stres oksidatif → pelepasan faktor anti-angiogenik (sFlt-1, sEng) → disfungsi endotel maternal → **preeklampsia** |
| **Malperfusisi Fetal** | Vili korial tidak berkembang normal → luas pertukaran ↓ → resistensi vena umbilical ↑ → **Doppler UA abnormal (AEDV/REV)** → asidosis janin |
| **Infark & Trombosis Plasenta** | Infark vili, trombosis vena umbilical, retikulum fibrin → fungsi plasenta ↓ lebih lanjut |

## Klasifikasi Berbasis Doppler (Praktis)

| Stadium | Doppler UA | Doppler UA/UV | Doppler MCA | CPR (MCA/UA) | Klinis |
|---------|------------|---------------|-------------|--------------|--------|
| **Normal** | Positif EDV | Normal | Normal | > 1,0 (atau > 5th percentile) | IUGR ringan / tidak |
| **Fase 1 (Kompensasi)** | **AEDV** | Normal/↑ | **Brain Sparing (PI MCA ↓ < 5th %)** | **< 1,0 (↓)** | IUGR sedang, preeklampsia early-onset |
| **Fase 2 (Dekompensasi)** | **REV** | **Pulsatile / A-reverse (UV)** | MCA normal/naik (loss brain sparing) | **<< 1,0** | **Kritis — Asidosis janin, butuh terminasi SEGERA** |
| **Fase 3 (Terminal)** | REV + UV pulsatile + venosa ductus abnormal | | | | **IUFD risk sangat tinggi** |

> **Brain Sparing Effect:** Janin mengalihkan aliran darah ke otak (MCA PI ↓) → CPR ↓. Tanda **awal** insufisiensi plasenta sebelum AEDV/REV.

## Diagnosis & Screening

### 1. Screening Trimester 1 (Prediksi Risiko Tinggi)
| Marker | Cut-off Risiko Tinggi | Aksi |
|--------|----------------------|------|
| **PAPP-A** | < 0,4 MoM | Aspirin 150 mg malam 12-16 mg, USG serial Doppler UA trimester 2 |
| **PlGF (Placental Growth Factor)** | < 0,4 MoM | Sama |
| **sFlt-1 / PlGF Ratio** | > 38 (trimester 1) / > 85 (trimester 2) | High risk preeklampsia early-onset |
| **UtA PI (Doppler Uterine Artery)** | Mean PI > 95th % / Notch bilateral | Aspirin, monitoring ketat |

> **Aspirin 150 mg malam mulai 12-16 mg hingga 36 mg** → **kurangi risiko preeklampsia early-onset 60-80%** (RCT: ASPRE, SPARK, dsb).

### 2. Diagnosis Klinis (Trimester 2-3)
| Pemeriksaan | Temuan Insufisiensi Plasenta |
|-------------|------------------------------|
| **Fundus Tinggi** | Kurang > 2 cm dari UK (atau tidak naik 2 minggu berturut) |
| **USG EFW** | < 10 persentil (IUGR) / < 3 persentil (berat) |
| **AFI** | ≤ 5 cm (Oligohidramnion) — tanda plasenta tua/insufisiensi |
| **Doppler UA** | **AEDV / REV** — **TANDA KEPARAHAN UTAMA** |
| **Doppler MCA** | PI < 5th % (Brain Sparing) / CPR < 1,0 / < 5th % |
| **Doppler UV (Umbilical Vein)** | Pulsatile / A-reverse → **TERMINAL** |
| **Doppler Ductus Venosus** | A-reverse / absent a-wave → **PRETERMINAL** |
| **Biophysical Profile (BPP)** | ≤ 6/10 (terutama gerakan/tonus/nafas) |

> [!warning] Red Flag
> **Doppler UA REV (Reversed End-Diastolic Velocity) = EMERGENSI OBSTETRI** — janin asidosis berat, risiko IUFD jam-jam/hari. **SEGERA TERMINASI (SC)** setelah betametason (jika < 34 mg & waktu permite) / langsung SC jika ≥ 34 mg / maternal tidak stabil.
> **Doppler UV Pulsatile / A-reverse** = **PRETERMINAL** — IUFD risiko sangat tinggi dalam 24-48 jam.

## Tata Laksana Berbasis Usia Kehamilan & Stadium Doppler

### A. Previabilitas / < 24 mg (Jarang, tapi bisa terjadi)
- Konseling: Prognosis sangat buruk, risiko IUFD tinggi, neonatologi tidak viabel
- Opsi: Expectant management ketat (rawat inap, Doppler harian) vs terminasi (jika legal/etis diperbolehkan)
- **Aspirin 150 mg** jika belum diberikan

### B. 24-27+6 mg (Viabilitas Terbatas)
| Stadium Doppler | Strategi |
|-----------------|----------|
| **Normal / Brain Sparing saja (MCA ↓, UA normal)** | Expectant ketat: Rawat inap, Doppler UA+MCA harian, USG pertumbuhan 2×/mgg, Betametason 12 mg 2× 24j, MgSO4 neuroproteksi. Target: mencapai 28-30 mg. |
| **UA AEDV** | Sama + **persiapan SC darurat kapan saja**. Evaluasi harian. Jika REV → SC segera. |
| **UA REV / UV Pulsatile** | **SC SEGERA** (setelah betametason 24-48 jam jika memungkinkan) — neonatal outcome 24-27 mg masih buruk tapi > IUFD. |

### C. 28-31+6 mg (Preterm Sedang)
| Stadium | Strategi |
|---------|----------|
| **AEDV** | Expectant ketat (rawat inap, Doppler harian, USG 2×/mgg, Betametason, MgSO4). **Target: 32-34 mg**. Jika REV / UV abnormal / BPP ≤ 4 / maternal indication → SC. |
| **REV** | **SC SEGERA** (setelah betametason 24-48 jam jika memungkinkan). Neonatal outcome 28-31 mg baik dengan NICU lengkap. |
| **UV Pulsatile / DV abnormal** | **SC SEGERA** — tidak menunggu betametason. |

### D. 32-33+6 mg (Late Preterm)
| Stadium | Strategi |
|---------|----------|
| **AEDV** | Expectant ketat (rawat inap/jalan ketat), Doppler 2-3×/mgg, USG mingguan, Betametason (jika belum). Target 34-36 mg. |
| **REV / UV abnormal** | **SC SEGERA** (neonatal outcome sangat baik 32+ mg). |

### E. 34-36+6 mg (Late Preterm)
| Stadium | Strategi |
|---------|----------|
| **AEDV** | Induksi/SC 34-36 mg (diskusi neonatalogi). Betametason jika < 34+6. |
| **REV / UV abnormal** | **SC SEGERA** — tidak butuh betametason (≥ 34 mg). |

### F. ≥ 37 mg (Term)
- **AEDV/REV** → **Induksi/SC SEGERA** — janin term toleransi asidosis lebih baik tapi risiko stillbirth tetap ada.
- **Normal Doppler tapi IUGR < 10th %** → Induksi 37-38 mg (ACOG/POGI).

## Monitoring Ketat (Expectant Management Protocol)

| Parameter | Frekuensi (AEDV) | Frekuensi (REV/Kritis) |
|-----------|------------------|------------------------|
| **Doppler UA + MCA + UV + DV** | **Harian** (rawat inap) | **6-12 jam** (rawat inap ICU) |
| **NST / BPP** | Harian | 6-12 jam |
| **AFI** | 2×/minggu | Harian |
| **USG Pertumbuhan** | Mingguan | 2×/minggu |
| **Lab Maternal (CBC, Hati, Ginjal, Koagulasi)** | 2×/minggu | Harian |
| **Betametason** | 12 mg IM 2× 24j (jika < 34+6) | Sudah diberikan / tidak perlu jika ≥ 34 |
| **MgSO4 Neuroproteksi** | Jika < 32 mg & planned delivery < 24j | Sama |

## Persalinan

| Kondisi | Rekomendasi |
|---------|-------------|
| **REV / UV abnormal / DV abnormal / BPP ≤ 4** | **SC Darurat** — janin tidak toleransi kontraksi |
| **AEDV (stabil) < 32 mg** | SC jika maternal/fetal indication, atau induksi **hanya jika serviks sangat matang & fetal monitoring kontinu** (risiko deselerasi tinggi) |
| **AEDV ≥ 32-34 mg** | Induksi **bisa dicoba** dengan monitoring kontinu (CFM), MgSO4, siap SC kapan saja |
| **Normal Doppler tapi IUGR < 10th %** | Induksi 37-38 mg (normal vaginal boleh) |

> **CFM (Cardiotocography) Continuus WAJIB** saat induksi/pengejanan IUGR + Doppler abnormal — risiko deselerasi variabel/late sangat tinggi.

## Pasca Persalinan & Neonatal

| Bayi IUGR/Insufisiensi Plasenta | Risiko | Monitoring |
|----------------------------------|--------|------------|
| **Hipoglikemia** | Glikogen rendah | Glukosa 1, 2, 3 jam → ASI dini |
| **Hipotermia** | Lemak cokelat rendah | Inkubator / skin-to-skin + topi |
| **Policitemia** (EPO ↑ hipoksia kronis) | Hct > 65% | Partial exchange transfusion jika sintomatik |
| **Asidosis metabolic** | Hipoksia kronis | Gas darah arteri/vena tali pusat — pH < 7,20 / BE < -12 = berat |
| **Nekrosis Enterokolitis (NEC)** | Perfusi usus terganggu | ASI hati-hati, monitoring abdominal |
| **Neurodevelopment** | Asidosis + hipoksia | Follow-up neurologi 2 th (Bayley, MRI jika indikasi) |

## Pencegahan (Primary Prevention)

| Intervensi | Target | Efektivitas |
|------------|--------|-------------|
| **Aspirin 150 mg malam 12-16 mg** | Risiko tinggi (PAPP-A/PlGF rendah, UtA PI ↑, riwayat preeklampsia/IUGR, hipertensi kronik, DM, nefropati, APS, kehamilan ganda, IVF, usia > 40, BMI > 35) | **Kurangi preeklampsia early-onset 60-80%, IUGR 20-30%** |
| **Kalsium 1-2 g/hari** | Asupan kalsium < 600 mg/hari | Kurangi preeklampsia 50% |
| **Kontrol BB & Aktivitas** | BMI < 30, olahraga 150 menit/mgg | Modest benefit |
| **Stop Rokok** | Semua ibu hamil | Kurangi IUGR 20-30% |
| **Kontrol Hipertensi/DM Prahamil** | Target TD < 130/80, HbA1c < 6,5% | Kurangi vaskulopati plasenta |

## Ringkasan untuk Dokter Umum

1. **Insufisiensi Plasenta = patofisiologi IUGR + Preeklampsia early-onset + Abrupsio + IUFD**
2. **Doppler UA adalah jendela utama:** Normal → AEDV → REV → UV abnormal = spektrum keparahan
3. **AEDV = monitoring harian ketat, target mencapai 32-34 mg (preterm) / 34-36 mg (late preterm) / induksi 37+ mg**
4. **REV / UV Pulsatile / DV Abnormal = SC SEGERA (emergensi obstetri)** — jangan tunggu betametason jika ≥ 32 mg / maternal tidak stabil
5. **Aspirin 150 mg 12-16 mg = PREVENSI UTAMA** untuk risiko tinggi — buktikan kurangi preeklampsia & IUGR
6. **CFM kontinu WAJIB** saat induksi/pengejanan IUGR + Doppler abnormal
7. **Bayi lahir:** Hipoglikemia, hipotermia, policitemia, asidosis, NEC — monitoring NICU ketat
8. **Follow-up neurodevelopment 2 th** — risiko delay kognitif/motorik
