# Karsinoma Serviks (Cervical Cancer)

## Cerita Pembuka

Ny. Sari, 42 tahun, G3P3A0, tidak pernah screening serviks. Keluhan: **perdarahan vagina setelah berhubungan seks (postcoital bleeding) seitan 3 bulan, leukorea berbau, nyeri punggung bawah**. Pemeriksaan spekulum: **serviks tumbuh ke luar (eksofitik), mudah berdarah, ukuran ~ 4 cm, menutup os eksternus**. IVA: **Positif (Lesi Asetowhite Lebar, Margin Tegas, Membesarkan ke Vagina)**. PAP Smear: **HSIL (CIN 3 / Carcinoma in Situ) dengan sel-sel invasive squamous cell carcinoma**. Biopsi serviks (punch biopsy): **Invasive Squamous Cell Carcinoma, Keratinizing, Poorly Differentiated**. USG TV + MRI Panggul: **Stadium IB2 (Tumor 4,5 cm, parametrium bebas, tidak ada hidronefrosis, limfa pelvik tidak besar)**. PET-CT: Tidak ada metastase jarak jauh. **Staging FIGO 2018: IB2**. Terapi: **Radical Hysterektomi Tipe C (Querleu-Morrow) + Pelvic Lymphadenektomi Bilateral + Ovariopeksi (Usia 42, Premenopause)**. Histopat: Tumor 4,2 cm, invasi stromal 22 mm, LVSI (+), Parametrium (-), Limfa Pelvik 0/28 (+). **Adjuvant: CCRT (Cisplatin 40 mg/m2 mingguan × 5 + EBRT 45-50 Gy) + Brachytherapy (HDR 6 Gy × 4 Fraksi ke Point A)**. 2 Tahun Follow-up: NED (No Evidence of Disease).

## Epidemiologi & Etiologi

| Parameter            | Data                                                                                                                                                      |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Insidensi Global** | **Kanker #4 Wanita** (604.000 kasus baru/tahun, 342.000 meninggal) — **> 85% di Negara Berkembang**                                                       |
| **Indonesia**        | **Kanker #2 Wanita (Stelah Payudara)** — ~ 36.000 kasus/tahun, ~ 21.000 meninggal/tahun (Globocan 2020)                                                   |
| **Usia Puncak**      | **45-55 Tahun** (Rata-rata Diagnosis 53 Th) — **Pra-Invasif (CIN) Puncak 25-35 Th**                                                                       |
| **Etiologi Utama**   | **HPV High-Risk (HR-HPV) — 99,7% Karsinoma Serviks** — **HPV 16 (50-60%), HPV 18 (10-15%), 31, 33, 45, 52, 58**                                           |
| **Kofaktor Risiko**  | Rokok (↑ 2-3×), Multipara (≥ 7), Imunosupresi (HIV ↑ 6×), OCP > 5 Th, Infeksi Koinfeksi (Klamidia, HSV-2), Status Sosial-Ekonomi Rendah, Kurang Screening |

## Patogenesis (HPV → CIN → Kanker)

1. **Infeksi HPV HR** → Ekspresi Onkoprotein **E6 (Degradasi p53) & E7 (Degradasi pRb)** → Siklus Sel Tak Terkendali, Apoptosis Terhambat, Genomik Instabilitas
2. **Infeksi Persisten (> 12-24 Bulan)** → Integrasi Genom HPV ke Kromosom Host → Ekspresi E6/E7 Konstitutif
3. **Lesi Pra-Kanker (CIN/CGIN):** CIN 1 (LSIL) → CIN 2/3 (HSIL) → **Carcinoma in Situ (CIS / AIS)** → **Kanker Invasif (Membobot Basal Membran)**
4. **Waktu Latensi:** **10-20 Tahun (HPV → CIN 3), 1-5 Tahun (CIN 3 → Invasif)** — **Jendela Screening Emas**

| Tipe                                                                | Persentase          | Karakteristik                                                                |
| ------------------------------------------------------------------- | ------------------- | ---------------------------------------------------------------------------- |
| **Squamous Cell Carcinoma (SCC)**                                   | **70-80%**          | Sel skuama keratinizing/non-keratinizing, koilositosis, invasi stro mal      |
| **Adenokarsinoma**                                                  | **15-25%** (↑ Tren) | Glandular: Endoservikal, Intestinal, Villoglandular, Clear Cell, Mesonephric |

## Diagnosis & Staging (FIGO 2018 — Berbasis Klinis + Imaging)

### 1. **Sitologi & Histopatologi (Diagnosis Pasti)**

| Pemeriksaan                                                            | Indikasi                                                                                         |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| **PAP Smear (Conventional / LBC)**                                     | Screening — Bethesda 2014: NILM, ASC-US, LSIL, HSIL, ASC-H, AGC, AIS, SCC                        |
| **HPV DNA Test (PCR / Hybrid Capture / Genotyping)**                   | Screening Primer (Usia ≥ 30 Th) / Triage ASC-US / Post-Terapi / Ko-testing                       |
| **VIA (Visual Inspection with Acetic Acid)**                           | Screening Sumber Daya Terbatas — Positif: Lesi Asetowhite, Margin Tegas, Dekat SCJ               |
| **Kolposkopi + Biopsi (Punch / Endocervical Curettage / LEEP / Cone)** | **Diagnosis Definitif** — Kolposkopi: Pola Mosaik, Punctuation, Atipik Vaskuler, Lesi Asetowhite |
| **Biopsi Serviks (Punch / Cone / LEEP)**                               | **Gold Standard Histopatologi** — Grading, LVSI, Margin, Tipe Histologis                         |

### 2. **Staging FIGO 2018 (Klinis + Imaging)**

| Stadium   | Definisi                                                                          | Imaging yang Diizinkan                                                 |
| --------- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **IA1**   | Invasi Stromal ≤ 3 mm, Lebar ≤ 7 mm                                               | Klinis + Histopat (Konisasi/LEEP)                                      |
| **IA2**   | Invasi Stromal > 3 mm - ≤ 5 mm, Lebar ≤ 7 mm                                      | Klinis + Histopat                                                      |
| **IB1**   | Tumor ≤ 2 cm, Terbatas Serviks                                                    | Klinis + USG TV / MRI                                                  |
| **IB2**   | Tumor > 2 cm - ≤ 4 cm                                                             | Klinis + MRI / CT / PET-CT                                             |
| **IB3**   | Tumor > 4 cm                                                                      | Klinis + MRI / CT / PET-CT                                             |
| **IIA1**  | Invasio Vagina Atas ≤ 2 cm, Parametrium Bebas                                     | Klinis + MRI                                                           |
| **IIA2**  | Invasio Vagina Atas > 2 cm, Parametrium Bebas                                     | Klinis + MRI                                                           |
| **IIB**   | **Invasio Parametrium (Unilateral/Bilateral)**                                    | **MRI (Gold Standard Parametrium)**                                    |
| **IIIA**  | Invasio Vagina Bawah 1/3, Tanpa Hidronefrosis                                     | Klinis + MRI                                                           |
| **IIIB**  | **Invasio Pelvic Wall ATAU Hidronefrosis / Ginjal Non-Fungsi (Ureter Obstruksi)** | **MRI + USG Ginjal / IVU / CT Urografi**                               |
| **IIIC1** | **Metastase Limfa Pelvik (Unilateral/Bilateral)**                                 | **MRI / CT / PET-CT (Limfa ≥ 1 cm / SUV ↑)**                           |
| **IIIC2** | **Metastase Limfa Para-Aortik (Unilateral/Bilateral)**                            | **PET-CT / CT / MRI (Limfa ≥ 1 cm / SUV ↑)**                           |
| **IVA**   | **Invasio Vesika / Rektum (Biopsi Positif) ATAU Metastase Limfa Inguinal**        | **Sistoskopi + Biopsi / Proktoskopi + Biopsi / Klinis Limfa Inguinal** |
| **IVB**   | **Metastase Jarak Jauh (Paru, Hepar, Tulang, Otak, Limfa Suprakavikula)**         | **PET-CT (Gold Standard) / CT Thoraks/Abdomen + Bone Scan**            |

> **Perubahan Kunci FIGO 2018:** Staging **Menggunakan Imaging (MRI/PET-CT) Diizinkan** — **IIIC1/IIIC2 (Limfa Pelvik/Para-Aortik) Baru**, **Limfa Inguinal = IVA** (Dulu IIIB).

### 3. **Imaging (WAJIB Sesuai Stadium)**

| Stadium      | Imaging Wajib                                                       | Imaging Opsional                                                     |
| ------------ | ------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **IA1-IA2**  | Histopat (Konisasi) — Tidak Butuh Imaging Rutin                     | USG TV / MRI (Jika Ingin Fertilitas)                                 |
| **IB1-IIA1** | **MRI Panggul (Gold Standard Local Staging)**                       | USG TV (Jika MRI Tidak Tersedia)                                     |
| **IIA2-IVA** | **MRI Panggul + CT Thoraks/Abdomen/Pelvis ATAU PET-CT (Preferred)** | USG Ginjal (Hidronefrosis), Sistoskopi/Proktoskopi (Jika Klinis IVA) |
| **IVB**      | **PET-CT (Whole Body)**                                             | CT Thoraks/Abdomen + Bone Scan + MRI Otak (Jika Gejala)              |

## Tata Laksana (Sesuai Stadium & Kondisi Pasien)

### **Stadium Pra-Invasif (CIN / AIS)**

| Lesi                             | Manajemen                                                                                                                                                                                                         |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CIN 1 (LSIL)**                 | **Observasi 12-24 Bulan (Regresi 60-90%)** — Kolposkopi + HPV Test 12 Bulanan. Jika Persisten 2× → Ablasi/Eksisi.                                                                                                 |
| **CIN 2/3 (HSIL) / AIS**         | **Eksisi (LEEP / Cold Knife Cone) — Gold Standard** — Margin Negatif WAJIB. **Ablasi (Krioterapi / Termokoagulasi / Laser) — HANYA JIKA: Lesi Kecil, Tipe 1/2 Kolposkopi, Margin Negatif Dipastikan, Tidak AIS**. |
| **AIS (Adenocarcinoma In Situ)** | **Cold Knife Cone (CKC) — Preferred (Margin Lebih Jelas vs LEEP)** — Histerektomi Jika Selesai Keturunan / Margin Positif / Persisten.                                                                            |

### **Stadium Invasif Awal (IA1-IB1) — Fertilitas Preservation Possible**

| Stadium & Kondisi      | Opsi Utama                                                                                      | Alternatif (Fertilitas)                                                                                                                                 |
| ---------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **IA1 (LVSI -)**       | **Konisasi (LEEP/CKC) Saja** — Margin Negatif → Observasi                                       | Konisasi (Jika Ingin Fertilitas)                                                                                                                        |
| **IA1 (LVSI +) / IA2** | **Radical Hysterektomi Tipe B (Querleu-Morrow) + Pelvic Lymphadenektomi**                       | **Radical Trachelectomi (Vaginal/Abdominal/Laparoskopik/Robot) + Pelvic Lymphadenektomi** — Jika Tumor ≤ 2 cm, LVSI -, Margin Negatif, Ingin Fertilitas |
| **IB1 (≤ 2 cm)**       | **Radical Hysterektomi Tipe C1/C2 + Pelvic Lymphadenektomi ± Para-aortik (Jika Risiko Tinggi)** | **Radical Trachelectomi + Pelvic Lymphadenektomi** — Kriteria Ketat: ≤ 2 cm, LVSI -, Margin Negatif, Usia < 40-45, Ingin Anak                           |

> **Adjuvant (Pasca Operasi) — Sedgwick Criteria / Risk Factors:**
>
> - **Low Risk (Tidak Perlu Adjuvant):** IA1 LVSI-, IA2 LVSI-, IB1 LVSI- & Tumor < 2 cm & Margin Negatif & Limfa Negatif
> - **Intermediate Risk (RT Saja / CCRT Pertimbangkan):** LVSI +, Ukuran > 2 cm (IB1), Invasio Stromal Dalam > 1/2, Margin Dekat (< 3-5 mm) — **RT Pelvik (EBRT 45-50 Gy) ATAU CCRT (Cisplatin + RT) — OUTPORT Trial: CCRT Lebih Baik DFS**
> - **High Risk (CCRT WAJIB — Peters/GOG 263):** **Margin Positif, Parametrium Positif, Limfa Positif** — **CCRT (Cisplatin 40 mg/m2 Mingguan × 5-6 + EBRT 45-50 Gy) + Brachytherapy Boost (HDR 6-7 Gy × 4 Fraksi ke Point A / LDR 20-25 Gy)** — **Standard of Care**

### **Stadium Lanjut Lokal (IB2-IIA2, IIB, IIIA, IIIB, IIIC1, IIIC2) — CCRT Primary (Definitive)**

| Stadium                         | Terapi Utama                                                                                                              | Detail                                                                                                                                                                                                                                                     |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **IB2, IB3, IIA1, IIA2**        | **CCRT (Primary) ATAU Radical Hysterektomi + Adjuvant CCRT (Jika Risk Factors)**                                          | **CCRT Preferred (Non-Inferior OS, Kurangi Morbiditas Operasi Besar)** — **Cisplatin 40 mg/m2 IV Mingguan × 5-6 Siklus + EBRT 45-50 Gy (Pelvik + Para-aortik Jika IIIC2) + Brachytherapy (IC/IS/HDR) Boost ke Point A (Total Dose Point A 80-90 Gy EQD2)** |
| **IIB, IIIA, IIIB**             | **CCRT Primary (Definitive)**                                                                                             | **Sama di Atas** — Brachytherapy WAJIB (Intrakaviter + Interstisial Jika Parametrium Tebal)                                                                                                                                                                |
| **IIIC1 (Limfa Pelvik +)**      | **CCRT + EBRT Termasuk Field Para-aortik (Jika Limfa Para-aortik Tidak Di-Sampling / PET-CT Negatif Tapi Risiko Tinggi)** | **Extended Field RT**                                                                                                                                                                                                                                      |
| **IIIC2 (Limfa Para-aortik +)** | **CCRT + Extended Field RT (Pelvik + Para-aortik)**                                                                       | **Sistemik Terapi (Imunoterapi) Dipelajari (KEYNOTE-A18, NRG-GY002)**                                                                                                                                                                                      |

### **Stadium IVA (Invasio Vesika/Rektum / Limfa Inguinal)**

- **CCRT Primary (Definitive) — Jika Invasio Minimal & Pasien Fit** — Outcome Mirip IIIB
- **Pelvic Exenteration (Anterior / Posterior / Total) — Jika Residual/Recurrent Pasca CCRT / Invasio Masif / Fistula** — **Morbiditas Tinggi, Kualitas Hidup Butuh Stoma (Urostomi/Kolostomi) + Rekonstruksi Vagina**

### **Stadium IVB (Metastase Jarak Jauh) — Paliatif / Sistemik**

| Terapi                                                                        | Indikasi & Evidensi                                                                                                                  |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| **Kemoterapi Platinum-Based (Cisplatin/Carboplatina + Paklitaksel)**          | **First-Line Standard** — GOG 204: Cisplatin-Paclitaxel = Non-Inferior Kombinasi Lain, Lebih Sedikit Tox                             |
| **Bevacizumab (Anti-VEGF) 15 mg/kg IV 3 Mingguan + Kemoterapi**               | **GOG 240: OS ↑ 3,7 Bln (17,0 vs 13,3) — Standard of Care First-Line Metastatik/Recurrent**                                          |
| **Pembrolizumab (Anti-PD-1) 200 mg IV 3 Mingguan + Kemoterapi ± Bevacizumab** | **KEYNOTE-826: OS & PFS Signifikan ↑ (CPS ≥ 1) — FDA Approved 2021, Standard of Care First-Line Metastatik/Recurrent PD-L1 CPS ≥ 1** |
| **Pembrolizumab Monoterapi (Line 2+)**                                        | **KEYNOTE-158: ORR 12-14% (CPS ≥ 1) — Line 2+ Setelah Kemoterapi**                                                                   |
| **RT Paliatif (Tulang, Otak, Paru, Kompresi Medula)**                         | Gejala: Nyeri, Fraktur, SVC Syndrome, Hemopti, Obstruksi                                                                             |
| **Best Supportive Care (Nyeri, Nutrisi, Psikososial, Hospice)**               | Stadium Terminal / Performance Status Buruk (ECOG 3-4)                                                                               |

## Follow-up Pasca Terapi (Kuratif)

| Waktu                               | Pemeriksaan                                                                  |
| ----------------------------------- | ---------------------------------------------------------------------------- |
| **3 Bulan Pasca CCRT/Operasi**      | **PAP/HPV + Kolposkopi + USG TV + MRI Panggul (Baseline)**                   |
| **Setiap 3-6 Bulan (2 Th Pertama)** | Anamnesis, Pemeriksaan Fisik (Spekulum + Bimanual + Rektal), PAP/HPV, USG TV |
| **Setiap 6-12 Bulan (Th 3-5)**      | Sama + CT Thoraks/Abdomen/Pelvis / PET-CT (Jika Risiko Tinggi)               |
| **Tahunan (Th > 5)**                | PAP/HPV, USG TV, Pemeriksaan Fisik                                           |

**Recurrence:** ~ 30-40% Stadium IB2-IVA (Mayoritas 2 Th Pertama) — **Lokal (Vagina/Pelvik) > Jarak Jauh**. **Salvage: Operasi (Exenteration) / Re-RT (Jika Belum Max Dose) / Sistemik (Kemo/Imuno/Beva).**

## Pencegahan (Prevention)

### **Primer: Vaksinasi HPV**

| Vaksin                       | Tipe HPV                                                          | Usia Target                                                     | Jadwal                                                                               |
| ---------------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| **Bivalent (Cervarix)**      | 16, 18                                                            | **9-14 Th (2 Dosis 0, 6 Bln) / 15-26 Th (3 Dosis 0, 1, 6 Bln)** | 0, 6 Bln (2 Dosis) / 0, 1, 6 Bln (3 Dosis)                                           |
| **Kuadrivalen (Gardasil-4)** | 6, 11, 16, 18                                                     | Sama                                                            | Sama                                                                                 |
| **Nonavalen (Gardasil-9)**   | **6, 11, 16, 18, 31, 33, 45, 52, 58**                             | **9-14 Th (2 Dosis) / 15-45 Th (3 Dosis)**                      | Sama                                                                                 |
| **Efektivitas**              | **> 90% Pencegahan CIN 2/3 & Kanker (HPV 16/18/Nonavalent 90%+)** | **Catch-up Wanita 27-45 Th: Individual Clinical Decision**      | **WHO Target 2030: 90% Vaksinasi Gadis 15 Th, 70% Screening 35 & 45 Th, 90% Terapi** |

### **Sekunder: Screening (Deteksi Dini Pra-Kanker & Kanker Awal)**

| Metode                                  | Target Usia                                              | Interval                   | Keunggulan                                                                         |
| --------------------------------------- | -------------------------------------------------------- | -------------------------- | ---------------------------------------------------------------------------------- |
| **HPV DNA Test (Primary Screening)**    | **30-65 Th (WHO: 30, 45 Th Minimal 2× Hidup)**           | **5-10 Tahun (Negatif)**   | **Sensitivitas Tertinggi (90-95% CIN 3+), Objectif, Otomatis, Self-Sampling Bisa** |
| **Ko-testing (HPV DNA + PAP)**          | 30-65 Th                                                 | 5 Tahun (Keduanya Negatif) | Spesifisitas > HPV Saja, Tapi Mahal & Kompleks                                     |
| **PAP Smear (LBC Preferred)**           | 21-29 Th (PAP Saja) / 30-65 Th (Jika HPV Tidak Tersedia) | **3 Tahun (Negatif)**      | Murah, Tersedia Luas, Spesifisitas Tinggi                                          |
| **VIA (Visual Inspection Acetic Acid)** | **Sumber Daya Terbatas / Usia 30-50 Th**                 | **1-3 Tahun (Negatif)**    | **Murah, Real-Time, See-and-Treat (Ablasi Langsung Jika Positif & Eligible)**      |
| **Self-Sampling HPV**                   | Semua Usia Screening                                     | Sama HPV Klinis            | **Jangkau Wanita Tidak Datang Klinik, Sensitivitas Setara Clinician-Collected**    |

> **Algoritma Screening Indonesia (Perkeni/POGI/Kemenkes):**
>
> 1. **Usia 30-65 Th: HPV DNA Primary (5-10 Th) → Positif → Triage: PAP/Genotyping 16/18/Kolposkopi**
> 2. **Usia 21-29 Th: PAP Smear (3 Th) → ASC-US/LSIL → HPV Triage / Kolposkopi**
> 3. **VIA: Jika HPV/PAP Tidak Tersedia (Puskesmas/Wilayah Terpencil) — Positif → See-and-Treat (Krioterapi/Termoablasi) ATAU Rujuk Kolposkopi/Biopsi**

## Ringkasan untuk Dokter Umum

1. **Kanker Serviks = #2 Wanita Indonesia, #4 Global — 99,7% HPV HR (16/18 Dominan) — PENCEGAHAN TOTAL BISA (Vaksin + Screening)**
2. **Gejala Klasik: Postcoital Bleeding + Leukorea Berbau + Nyeri Punggung** — **JANGAN ABU-ABU, PERIKSA SPEKULUM!**
3. **Diagnosis: PAP/HPV DNA Screening → Kolposkopi + Biopsi (Gold Standard) → Staging FIGO 2018 (Klinis + MRI/PET-CT)**
4. **Staging Baru FIGO 2018: IIIC1 (Limfa Pelvik), IIIC2 (Limfa Para-aortik), IVA (Limfa Inguinal) — Imaging WAJIB**
5. **Terapi: IA1 LVSI- = Konisasi Saja | IA1 LVSI+/IA2/IB1 = Radical Hysterektomi Tipe B/C + LND (Atau Trachelectomi Jika Fertilitas) | IB2-IVA = CCRT Primary (Cisplatin + EBRT + Brachy) | IVB = Sisteminik (Cisplatin-Paclitaxel + Beva + Pembro Jika CPS ≥ 1)**
6. **Adjuvant Pasca Operasi: Intermediate Risk = RT/CCRT | High Risk (Margin+/Param+/LN+) = CCRT WAJIB**
7. **Follow-up: 3-6 Bulanan 2 Th, 6-12 Bulanan 3-5 Th, Tahunan > 5 Th (PAP/HPV, USG, MRI, CT/PET-CT Selektif)**
8. **PREVENSI: VAKSIN HPV 9-14 Th (2 Dosis) / Catch-up 15-45 Th (3 Dosis) + SCREENING HPV DNA 30-65 Th (5-10 Th) / PAP 21-29 Th (3 Th) / VIA Sumber Terbatas — WHO 90-70-90 TARGET 2030**
