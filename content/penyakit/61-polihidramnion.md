# Polihidramnion (Polyhydramnios)

## Cerita Pembuka

Ny. Sari, 32 tahun, G2P1A0, usia kehamilan 30 minggu. Keluhan: perut cepat besar, sesak napas saat tidur, edema kaki. Fundus tinggi 38 cm (UK 30 mg). USG: AFI 28 cm (normal 5-25), DVP 10 cm. Janin: EFW 1600 g (P75), tidak ada anomali struktural terlihat. OGTT 75 g: GDM (FPG 98, 1-jam 195, 2-jam 165). Diagnosis: **Polihidramnion ringan-sedang sekunder GDM**. MNT + metformin 500 mg 2×. Kontrol mingguan AFI. 34 mg: AFI 22 cm (membaik). 37 mg: induksi, lahir bayi 3400 g, tidak hipoglikemia.

## Definisi & Klasifikasi

**Polihidramnion** = **volume cairan amnion > persentil 95** untuk usia kehamilan.

| Metode USG                        | Normal  | Polihidramnion Ringan | Polihidramnion Sedang | Polihidramnion Berat |
| --------------------------------- | ------- | --------------------- | --------------------- | -------------------- |
| **AFI (Amniotic Fluid Index)**    | 5-25 cm | **24-30 cm**          | **30-35 cm**          | **> 35 cm**          |
| **DVP (Deepest Vertical Pocket)** | 2-8 cm  | **8-10 cm**           | **10-12 cm**          | **> 12 cm**          |

> **Insidensi:** ~1-2% kehamilan. **60-70% idiopatik** (tidak ditemukan sebab). Semakin berat → semakin tinggi yield etiologi.

## Etiologi (Differential Diagnosis)

| Kategori        | Penyebab                                                      | Mekanisme                                     |
| --------------- | ------------------------------------------------------------- | --------------------------------------------- |
| **Idiopatik**   | Tidak ditemukan sebab                                         | Multifaktorial, mungkin genetik/epigenetik    |
| **Maternal**    | **Diabetes (GDM/DM) — #1 identified cause**                   | Glukosa janin ↑ → poliuria janin → cairan ↑   |
|                 | Penyakit autoimun (SLE, APS)                                  | Inflamasi plasenta, vaskulopati               |
|                 | Rh isoimmunisasi / Aloimunisasi                               | Anemia janin → high output failure → cairan ↑ |
|                 | Preeklampsia (jarang, biasanya oligohidramnion)               | -                                             |
| **Fetal/Janin** | **Anomali GI: Atresia esofagus, duodenal, PIH**               | Tidak bisa menelan cairan amnion → akumulasi  |
|                 | **Anomali SNC: Anensefali, spina bifida, hidrosefalu**        | Disautonomia → poliuria / tidak menelan       |
|                 | **Anomali Kardiovaskuler** (Transposisi, Ebstein)             | High output cardiac failure                   |
|                 | **Anomali Kromosomal:** Trisomi 21, 18, 13, Triploidi         | Multi-organ                                   |
|                 | **Sindrom:** Beckwith-Wiedemann, Bartter, Donnai-Barrow       | Genetik                                       |
|                 | **Tumur:** SCT (Sacrococcygeal Teratoma), CPAM, Neuroblastoma | High output / AV shunt                        |
|                 | **Infeksi Kongenital (TORCH)**                                | Hepatosplenomegali, anemia, high output       |
|                 | **Kehamilan Ganda (TTTS)**                                    | Donor-recipient imbalance                     |
| **Plasenta**    | **Korioangiokoma** (tumor vaskular plasenta)                  | AV shunt → high output janin                  |
|                 | Plasenta percreta/increta (jarang)                            | -                                             |

## Diagnosis & Workup

### 1. USG (Diagnosis Utama)

- **AFI** (4 kuadran) atau **DVP** (single pocket) — **AFI lebih sensitif untuk polihidramnion diffuse, DVP untuk lokal**
- **Biometri Janin:** EFW, AC, HC, FL — cari IUGR/Makrosomia
- **Anatomi Detail (Level II/III):** **WAJIB** — GI (perut, hati, usus), SNC (otak, wajah), Jantung (4-chamber, OT, LVOT, aorta, ductus), Ginjal/mata air, Sumsum, Ekstremitas
- **Doppler:** UA, MCA, DV — cari anemia (MCA-PSV > 1,5 MoM), high output (MCA-PI rendah, DV abnormal)

### 2. Workup Etiologi (Stepwise)

| Tahap                                                                         | Pemeriksaan                                                                                                                               |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| **1. Maternal**                                                               | **OGTT 75 g (GDM/DM)**, HbA1c, TSH, FT4, ANA, anti-dsDNA, ACA, anti-β2GPI, TORCH IgG/IgM, Rh & antibody screen                            |
| **2. Fetal (USG Lanjut)**                                                     | USG detail anatomi (Genetik/SpOG KFM), Echo fetal (jika anomali jantung / polihidramnion berat), MRI Fetal (jika anomali SNC/GI kompleks) |
| **3. Invasif (Jika Anomali / Berat / IUGR / Polihidramnion Berat Idiopatik)** | **Amniosentesis: Karyotip / CMA (Chromosomal Microarray) / PCR TORCH / Viral panel** — risiko KPD 0,1-0,3%                                |
| **4. Khusus**                                                                 | **TTTS (Twins):** Quintero staging, Doppler UA/MCA/DV serial, USG 2 mingguan                                                              |

> **Yield Etiologi:**
>
> - Ringan (AFI 24-30): Idiopatik 70-80%, GDM 15%, Anomali 5-10%
> - Sedang (30-35): Idiopatik 50%, GDM 20%, Anomali 20-25%
> - Berat (> 35): Idiopatik 20-30%, Anomali 40-50%, GDM 15%, Lainnya 10%

## Tata Laksana

### A. Polihidramnion Ringan (AFI 24-30 / DVP 8-10) — **Mayoritas Idiopatik/GDM**

| Tindakan            | Detail                                                                                           |
| ------------------- | ------------------------------------------------------------------------------------------------ |
| **Konseling**       | Prognosis baik, 90% outcome normal jika tidak ada anomali                                        |
| **Screening GDM**   | OGTT 75 g (jika belum), HbA1c                                                                    |
| **Monitoring USG**  | AFI + Biometri + Doppler **2 mingguan** hingga 36 mg, lalu mingguan                              |
| **Terapi Maternal** | Jika GDM: MNT + Metformin/Insulin → sering AFI normalisasi                                       |
| **Aktivitas**       | Normal, hindari supin panjang, tarikan napas dalam jika sesak                                    |
| **Persalinan**      | **Expectant hingga 39-40 mg** jika stabil, induksi 39-40 mg (hindai stillbirth risiko sedikit ↑) |

### B. Polihidramnion Sedang (AFI 30-35 / DVP 10-12)

| Tindakan                     | Detail                                                                                                                                                                                                                                                                       |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Workup Lengkap**           | USG detail anatomi Level II/III, OGTT, TORCH, Autoimun, Rh Ab                                                                                                                                                                                                                |
| **Rujuk SpOG KFM**           | Untuk monitoring ketat & evaluasi anomali                                                                                                                                                                                                                                    |
| **Monitoring**               | USG AFI + Biometri + Doppler **mingguan**                                                                                                                                                                                                                                    |
| **Amnioreduksi (Terapi)**    | **Jika maternal symptomatic (sesak, nyeri, tidak tidur, atelectasis) ATAU preterm labor risiko tinggi** — ambil 1-2 L cairan (target AFI < 24 / DVP < 8), bisa berulang. Risiko: KPD 1-2%, abrupsio, infeksi, preterm labor                                                  |
| **Indomethacin (Off-label)** | **Indomethacin 50-100 mg PO/rectal 6-8 jam × 48-72 jam** → mengurangi produksi urine janin (COX inhibitor) — **KONTRAINDIKASI > 32 mg** (premature closure ductus arteriosus, nekrosis enterokolitis, oligohidramnion). Hanya < 32 mg, symptomatic, tidak bisa amnioreduksi. |

### C. Polihidramnion Berat (AFI > 35 / DVP > 12)

| Tindakan                  | Detail                                                                                                                                                                  |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Workup Maksimal**       | USG Detail + Echo Fetal + MRI Fetal + Amniosentesis (Karyotip/CMA/PCR)                                                                                                  |
| **Rawat Inap**            | Jika symptomatic / preterm labor / maternal respiratory compromise                                                                                                      |
| **Amnioreduksi Berulang** | Target AFI 20-24, bisa 2-3×/minggu. **Indikasi utama: maternal symptoms + preterm prevention**                                                                          |
| **Terminasi Kehamilan**   | Jika anomali letal (anensefali, trisomi 13/18, PIH berat, SCT besar dengan high output failure) — **konseling genetik, etik, hukum**                                    |
| **Timing Persalinan**     | **37-38 mg** (balance prematuritas vs stillbirth/maternal morbidity) — individu                                                                                         |
| **Mode Persalinan**       | Normal boleh jika janin cephalic, tidak makrosomia berat, tidak distress. **SC jika:** presentasi abnormal, makrosomia > 4000-4500g (DM), distress, maternal indication |

## Komplikasi

| Maternal                                                    | Fetal/Neonatal                                            |
| ----------------------------------------------------------- | --------------------------------------------------------- |
| **Preterm Labor / KPD** (uterus overdistension)             | **Preterm Birth** (risiko utama)                          |
| **Abrupsio Plasenta** (dekompresi cepat pasca KPD/lahir)    | **Malpresentasi** (bokong, transverse — ruang gerak luas) |
| **Perdarahan Postpartum** (atonia uterus)                   | **Anomali Kongenital** (jika etiologi anomali)            |
| **Sesak Napas / Atelectasis / Emboli Amnion**               | **Makrosomia** (jika DM) → Distosia Bahu                  |
| **Uterine Rupture** (jarang, uterus tipis)                  | **Poliuremia / Hipoglikemia** (DM)                        |
| **Stillbirth** (risiko ↑ 2-4× jika berat/idiopatik > 36 mg) | **Asfiksia / HIE** (kombinasi preterm + komplikasi)       |

## Ringkasan untuk Dokter Umum

1. **Polihidramnion = AFI > 24 cm / DVP > 8 cm** — klasifikasi ringan/sedang/berat
2. **60-70% Idiopatik** — tapi **semakin berat, semakin tinggi yield anomali/DM**
3. **WAJIB:** USG Anatomi Detail + **OGTT 75 g (GDM #1 identified cause)** + TORCH/Autoimun/Rh
4. **Ringan:** Monitoring 2 mingguan, terapi GDM, expectant hingga 39-40 mg
5. **Sedang:** Mingguan monitoring, rujuk SpOG KFM, amnioreduksi jika symptomatic
6. **Berat:** Rawat inap, workup maksimal (Echo, MRI, Amnio karyotip/CMA), amnioreduksi berulang, terminasi 37-38 mg / SC jika indikasi
7. **Amnioreduksi:** Tarik 1-2 L, target AFI < 24, risiko KPD/abrupsio/infeksi/preterm
8. **Indomethacin HANYA < 32 mg** untuk reduksi produksi urine janin (off-label)
9. **Persalinan:** Waspada malpresentasi, abrupsio pasca KPD, PPH, preterm
10. **Kehamilan Ganda (TTTS):** Rujuk SpOG KFM segera — laser fetoskopik indikasi
