# Infertilitas

## Cerita Pembuka

Pasangan Budi (32 th) & Sari (29 th), menikah 2 tahun, belum punya anak. Siklus Sari teratur 28-30 hari. Budi: spermogram count 12 jt/mL, motilitas 30% (oligoasthenospermia ringan). Sari: HSG tuba paten bilateral, USG normal. Diagnosis: infertilitas tidak jelas sebab (unexplained) + faktor sperma ringan. Direncanakan IUI stimulasi letrozol 3 siklus. Siklus ke-2: hamil. Lahir bayi sehat 38 minggu.

## Definisi

Infertilitas adalah **ketidakmampuan mencapai kehamilan klinis** setelah **12 bulan** berhubungan seksual teratur (2-3×/minggu) **tanpa kontrasepsi**. Pada usia ibu ≥ 35 tahun, evaluasi dimulai setelah **6 bulan**.

## Klasifikasi

| Jenis        | Definisi                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------ |
| **Primer**   | Belum pernah hamil                                                                         |
| **Sekunder** | Pernah hamil (termasuk aborsi/ektopik) tapi sekarang tidak bisa hamil lagi                 |
| **Absolut**  | Faktor yang tidak bisa diperbaiki (agenesis uterus, azoospermia non-obstruktif, menopause) |
| **Relatif**  | Faktor yang bisa ditata (oligospermia, anovulasi, tubal factor ringan)                     |

## Etiologi (Aproksimasi Proporsi)

| Faktor                                        | Persentase |
| --------------------------------------------- | ---------- |
| **Faktor tubal/peritoneal**                   | 30-35%     |
| **Faktor ovulasi**                            | 20-25%     |
| **Faktor sperma**                             | 30-35%     |
| **Faktor serviks/uterus**                     | 5-10%      |
| **Tidak jelas sebab (unexplained)**           | 10-15%     |
| **Lainnya (immunologis, genetik, lifestyle)** | < 5%       |

> Catatan: Sering **multifaktorial** (misal: tubal factor + male factor).

## Evaluasi Dasar (Workup Infertility)

### 1. Anamnesis & Fisik

- Usia, lama menikah, frekuensi hubungan, riwayat kehamilan/aborsi, riwayat PID, operasi pelvis, obat, kebiasaan (rokok, alkohol, BMI)
- Pemeriksaan fisik: BMI, tanda virilisasi, tiroid, payudara, genitalia

### 2. Evaluasi Ibu (Wajib)

| Pemeriksaan          | Tujuan                                                                                               |
| -------------------- | ---------------------------------------------------------------------------------------------------- |
| **Spermogram suami** | **PALING PENTING & TERMUDAH** — lakukan dulu sebelum workup ibu mahal                                |
| **Ovulasi**          | BBT, OPK (LH surge), progesterone hari 21, USG serial folikul                                        |
| **Tuba & Uterus**    | **HSG** (gold standard non-invasif) atau **Laparoskopi + Chromopertubation** (gold standard invasif) |
| **Reservar ovarium** | AMH, AFC (USG), FSH hari 3                                                                           |
| **Hormon**           | TSH, Prolaktin, TSH, AMH, FSH/LH hari 3, Testosteron jika hirsutisme                                 |

### 3. Evaluasi Suami

- **Spermogram** (2×, jarak 2-4 minggu) — WHO 2021 criteria:
  - Volume ≥ 1,5 mL
  - Konsentrasi ≥ 16 juta/mL
  - Total motilitas ≥ 40% (progresif ≥ 32%)
  - Morfologi normal ≥ 4% (strict criteria)
- Jika abnormal → rujuk androlog/urologi

## Tata Laksana Berbasis Faktor

### Faktor Ovulasi (Anovulasi/PCOS)

1. **Letrozol 2,5-5 mg hari 3-7** (pilihan utama — live birth rate > klomifen)
2. **Klomifen sitrat 50-150 mg hari 3-7** (alternatif)
3. **Gonadotropin (rFSH/hMG)** — jika gagal oral, butuh monitoring ketat (risiko OHSS & multikelamin)
4. **Metformin** — tambahan jika insulin resistance (PCOS)
5. **Trigger hCG 5.000-10.000 IU** saat folikel ≥ 18 mm → timed intercourse / IUI 36-40 jam

### Faktor Tubal

- **Proksimal block:** HSG terapetik / histeroskopi kanulasi / IUI bypass
- **Distal block (hydrosalpinx):** **Salpingektomi laparoskopik** sebelum IVF (meningkatkan LBR 2×)
- **Bilateral block berat:** **IVF** (bypass tuba)

### Faktor Sperma

| Severitas                                | Tata Laksana                   |
| ---------------------------------------- | ------------------------------ |
| Ringan (TMS > 10 jt post-wash)           | IUI 3-6 siklus                 |
| Sedang (TMS 5-10 jt)                     | IUI + stimulasi / IVF          |
| Berat (TMS < 5 jt / asteno/terato berat) | **IVF-ICSI**                   |
| Azoospermia                              | TESE/PESA + ICSI / Donor sperm |

### Unexplained Infertility

1. **Expectant management** 6-12 bulan (jika usia < 32 th, durasi < 2 th)
2. **IUI + stimulasi ringan (letrozol)** 3-4 siklus
3. **IVF** jika gagal IUI atau usia ≥ 35 th / durasi > 3 th

### Endometriosis

- Stadium I-II: IUI + stimulasi / IVF
- Stadium III-IV: Laparoskopi eksisi + IVF (jika infertilitas > 2 th / usia > 35 th)

> [!warning] Red Flag
> **Usia ibu ≥ 38 th / AMH < 1 ng/mL / AFC < 5** → **Langsung IVF**, jangan buang waktu IUI. Setiap bulan berharga.
> **Hydrosalpinx bilateral** → **Salpingektomi dulu** sebelum IVF (embryo transfer rate naik dari 30% jadi 50%+).

## Prognosis & Kapan Rujuk IVF

| Kriteria                                           | Rujuk IVF Segera |
| -------------------------------------------------- | ---------------- |
| Usia ibu ≥ 38 th                                   | Ya               |
| AMH < 1 ng/mL / AFC < 5                            | Ya               |
| Tubal factor berat bilateral                       | Ya               |
| Male factor berat (TMS < 5 jt)                     | Ya               |
| Endometriosis stadium III-IV + infertilitas > 2 th | Ya               |
| Gagal IUI 3-4 siklus (usia < 35)                   | Ya               |
| Unexplained > 3 th / usia > 35 th                  | Ya               |

## Komplikasi Tata Laksana

- **OHSS (Ovarian Hyperstimulation Syndrome)** — gonadotropin, PCOS
- **Kehamilan ganda** — IUI + stimulasi (8-15%), IVF (tergantung jumlah embryo transfer)
- **OHSS berat** → ICU, ascites, tromboemboli, AKI
- **Kehamilan ektopik** — risiko ↑ setelah IVF/IUI (2-5%)

## Ringkasan untuk Dokter Umum

1. **Spermogram dulu** — murah, cepat, 30-35% kasus male factor
2. **Infertilitas = pasangan** — jangan cek ibu dulu tanpa cek suami
3. **Usia ibu = faktor prognostic #1** — ≥ 35 th evaluasi 6 bln, ≥ 38 th langsung IVF
4. **Letrozol > Klomifen** untuk induksi ovulasi
5. **Hydrosalpinx → salpingektomi sebelum IVF**
6. **IUI max 3-4 siklus** — jika gagal, evaluasi IVF
7. **Konseling psikologis** — infertilitas = stress besar, support system krusial
