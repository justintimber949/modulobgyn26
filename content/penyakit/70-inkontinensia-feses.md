# Inkontinensia Feses (Fecal Incontinence)

## Cerita Pembuka

Ny. Ani, 38 tahun, G2P2A0, keluhan "tidak tahan BAB saat urgency, kadang bocor gas/tinja encer saat batuk" seitan 1 tahun pasca persalinan bayi ke-2 (bayi 3900 g, episiotomi derajat 2, vacuum). Riwayat: tidak ada penyakit IBD, tidak operasi anus. Pemeriksaan: tonus anus lemah (digital rectal exam), endoanal USG: **defek sphincter ani internus & eksternus anterior (12-3 jam)**. Manometri anus: tekanan istirahat rendah, tekanan squeeze rendah. Diagnosis: **Inkontinensia Feses post-obstetrik (sphincter defect)**. Terapi: PFMT + biofeedback 3 bulan + loperamide PRN. Membaik 60%. Dilanjutkan sakral neuromodulasi (PTNS trial positif) → permanent InterStim. Gejala membaik 85%.

## Definisi & Klasifikasi

**Inkontinensia Feses (FI)** = **ketidakmampuan menahan tinja/gas** hingga mencapai toilet yang sesuai, mengganggu kualitas hidup.

| Tipe (Berdasarkan Konsistensi Tinja - Bristol Stool Form Scale) | Definisi |
|---------------------------------------------------------------|----------|
| **Inkontinensia Tinja Padat (Solid FI)** | Tidak tahan tinja padat (Bristol 1-3) |
| **Inkontinensia Tinja Encer (Liquid FI)** | Tidak tahan tinja encer/diare (Bristol 5-7) |
| **Inkontinensia Gas (Flatus Incontinence)** | Tidak tahan gas (sering awal gejala) |
| **Inkontinensia Urgensi (Urge FI)** | Dorongan BAB mendadak kuat, tidak sempat ke toilet |
| **Inkontinensia Passif / Tidak Sadar (Passive FI)** | Tinja/gas keluar tanpa disadari (tidak ada urgency) |
| **Inkontinensia Campuran** | Kombinasi di atas |

### Skor Keparahan: **Wexner / Cleveland Clinic Florida (CCFI) Score** (0-24)
| Variabel | Skor 0 | Skor 1 | Skor 2 | Skor 3 | Skor 4 |
|----------|--------|--------|--------|--------|--------|
| Frekuensi Tinja Padat | Tidak pernah | < 1/bln | 1/bln | 1/mgg | ≥ 1/hari |
| Frekuensi Tinja Encer | Tidak pernah | < 1/bln | 1/bln | 1/mgg | ≥ 1/hari |
| Frekuensi Gas | Tidak pernah | < 1/bln | 1/bln | 1/mgg | ≥ 1/hari |
| Penggunaan Popok/Pad | Tidak | Kadang | Sering | Selalu | - |
| Pengaruh Hidup | Tidak | Sedikit | Sedang | Besar | Sangat Besar |
| **Total ≥ 9 = Moderat-Berat** | **Total ≥ 14 = Berat** | | | | |

## Epidemiologi & Faktor Risiko

| Faktor Risiko | OR / Mekanisme |
|---------------|----------------|
| **Persalinan Vaginal (Terutama Instrumental, Episiotomi Derajat 3-4, Bayi > 4000g)** | **#1 Risiko** — Trauma otot puborektalis & sphincter ani (OTASIS), pudendal nerve injury |
| **Usia / Menopause** | Hipestrogenisme → atrofi mukosa & otot, kolagen ↓ |
| **Kebiasaan: Konstipasi Kronik & Straining** | Neuropati pudental (stretch injury), megarektum, desensitisasi |
| **Operasi Anorektal** (Hemoroidektomi, Fistulektomi, Fisurektomi, LIS) | Kerusakan sphincter iatrogenik |
| **Penyakit Inflamasi Usus (IBD: Crohn, UC)** | Peradangan, fibrosis, urgency, operasi |
| **Neurologis** (Stroke, MS, Parkinson, Spinal Cord Injury, DM Neuropati) | Denervasi sphincter & pelvic floor |
| **Radioterapi Pelvik** | Fibrosis, vaskulopati, atrofi otot |
| **Obesitas** | Tekanan intra-abdomen ↑ |
| **Kehamilan Ganda / Multipara Grandemultipara** | Trauma kumulatif |

## Diagnosis

### 1. Anamnesis Terstruktur
| Pertanyaan Kunci | Tujuan |
|------------------|--------|
| **Jenis bocoran:** Gas / Tinja encer / Tinja padat / Campuran | Tipe & keparahan |
| **Pola:** Urgensi (mendadak butuh toilet) vs Passif (tidak sadar, bocor saat aktivitas) | Urge vs Stress vs Passive |
| **Frekuensi & Volume:** Harian / Mingguan / Bulanan, Volume (kencing vs tinja) | Skor Wexner |
| **Konsistensi Tinja (Bristol Scale)** | Diare vs Konstipasi vs Normal |
| **Riwayat Persalinan:** Jumlah, instrumental, episiotomi derajat, BB bayi | Etiologi obstetrik |
| **Riwayat Operasi Anorektal / IBD / Radioterapi / Neurologis** | Etiologi sekunder |
| **Obat:** Laxatif, Antidiare, Opioid, Antikolinergik, Metformin, SSRI | Iatrogenik |
| **Kualitas Hidup (FIQL / Wexner / CCFI)** | Baseline & Outcome |

### 2. Pemeriksaan Fisik
| Pemeriksaan | Temuan Khusus |
|-------------|---------------|
| **Inspeksi Perineum/Anus** | Luka bekas episiotomi/operasi, skin tags, fistula, prolaps rektal (rektosel), atrofi mukosa |
| **Digital Rectal Exam (DRE)** | **Tonus istirahat (resting tone = sphincter internus)**, **Tonus squeeze (squeeze tone = sphinter eksternus + puborektalis)**, **Sensasi rektal**, **Massa/impaksi feses**, **Refleks anokutaneus (saddle)** |
| **Valsalva / Batuk** | Prolaps rektal / retokel / perineal descent |
| **PFM Assessment (Vaginal/Rectal)** | Koordinasi, kekuatan, endurance |

### 3. Investigasi Pendukung
| Pemeriksaan | Indikasi | Apa yang Dilihat |
|-------------|----------|------------------|
| **Endoanal USG (3D/2D) — Gold Standard Anatomi** | **WAJIB SEBELUM OPERASI / Diagnosis Ragu** | **Defek Sphincter Ani Internus (IAS) & Eksternus (EAS)** — lokasi (jam), panjang, kedalaman, atrofi otot puborektalis |
| **Anorectal Manometri — Gold Standard Fungsi** | **WAJIB SEBELUM OPERASI / Diagnosis Ragu / Neurogenik** | Tekanan istirahat (IAS), Tekanan squeeze (EAS+Puborektalis), RAIR (Rectoanal Inhibitory Reflex), Kapasitas rektal, Komplians, Sensasi (first urge, urge defecation, toleransi), Balloon expulsion test |
| **Defekografi (MRI / Fluoroscopic)** | Prolaps rektal kompleks, intususpesio, retokel, enterocele, dyssynergia | Anatomi dinamis defeakasi |
| **Pudendal Nerve Terminal Motor Latency (PNTML)** | Neuropati pudental (bilateral > 2,2 ms / unilateral > 2,0 ms) | Prediktor outcome operasi (neuropati = outcome lebih buruk) |
| **Stool Diary + Bristol Scale** | Baseline konsistensi & frekuensi | Konservatif: atasi dire/konstipasi dulu |
| **Kolonoskopi / Sigmoidoskopi** | Darah tinja, anemik, risiko kolorektal, IBD | Rule out neoplasia/IBD |

## Tata Laksana Bertahap (Stepwise Algorithm)

### Tahap 1: Konservatif (First-Line) — **Semua Kasus Mulai Dari Sini**

| Intervensi | Target | Detail |
|------------|--------|--------|
| **Normalisasi Konsistensi Tinja (Bristol 3-4)** | **PALING PENTING** | **Diare:** Loperamide 2 mg awal lalu 1 mg per BAB encer (max 16 mg/hari) / Difenoksilat / Kolestiramin (bile acid malabsorption) / Probiotik. **Konstipasi:** Serat 25-30 g/hari (psyllium, metilselulosa), air 2-3 L, laxatif osmotik (PEG, laktulosa), hindari stimulan (senna, bisakodil) kronik |
| **Pelvic Floor Muscle Training (PFMT) + Biofeedback** | **Level 1A Evidence** | **Koordinasi PFM + Sphincter** — kontraksi squeeze + lift (bukan bearing down), endurance 10 detik × 10 reps × 3 set/hari. **Biofeedback (manometri/EMG/balloon)** — visualisasi kontraksi, koreksi bearing down. Minimal **3-6 bulan supervised fisioterapis pelvic floor** |
| **Scheduled Defekasi (Bowel Training)** | Regulasi pola | Toilet setelah makan (gastrocolic reflex), posisi optimal (kaki di atas stool, lutut > pinggang), waktu 10-15 menit, tidak straining |
| **Lifestyle** | BB normal, aktivitas fisik, stop rokok, atasi batuk kronik | Pendukung |
| **Skin Care** | Barrier cream (zinc oxide, dimethicone), pembersihan lembut, hindari sabun keras | Prevent dermatitis |

> **Response Rate Tahap 1: 20-50% clinical improvement, 10-20% cure** — tergantung etiologi & keparahan.

### Tahap 2: Farmakologi & Device (Second-Line) — **Jika Gagal Tahap 1 ≥ 3-6 Bulan**

| Obat/Device | Indikasi | Dosis/Cara |
|-------------|----------|------------|
| **Loperamide (Antidiare)** | **Urgency / Liquid FI dominan** | 2 mg awal, lalu 1 mg per BAB encer, max 16 mg/hari. Bisa scheduled (2-4 mg 2×/hari) jika pola reguler |
| **Kolestiramin / Kolesevelam** | Bile Acid Diarrhea (BAD) / Post-kolektomi / Post-terminal ileum reseksi | 4 g 1-3×/hari (campur air), ambil terpisah obat lain 1-2 jam |
| **Bulking Agent (Soluble Fiber: Psyllium, Metilselulosa)** | Tinja terlalu encer / tidak teratur | 5-10 g 1-2×/hari + air banyak |
| **Anal Plug / Insert** | Passive FI / Gas incontinence | Device silikon/foam masuk anus, ganti 12 jam — adherence rendah |
| **Estrogen Topikal Rektal/Vaginal** | Atrofi postmenopause | Krim/Suppos 0,5-1 mg 2×/minggu |

### Tahap 3: Intervensi Minim Invasif / Injeksi (Third-Line)

| Prosedur | Indikasi | Outcome |
|----------|----------|---------|
| **Sphincter Bulking Injection (Silicone, Carbon-coated beads, Dextranomer/HA - NASHA/Dx, Autologus Fat)** | **Passive FI / Minor Sphincter Defect / High Risk Operasi / Usia Lanjut** | **50-70% improvement short-term**, butuh repeat 12-24 bln, migrasi/abses risiko |
| **Sacral Neuromodulation (SNM / InterStim) — Gold Standard Refraktter** | **Gagal Tahap 1-2, Tidak Anomali Anatomi Mayor / Neuropati** | **Test Phase (PTNS / Percutaneous Tibial Nerve Stimulation 12 sesi ATAU Temporary Lead 2 minggu) → Jika > 50% improvement → Permanent Implant**. **Success 70-85% (> 50% reduction episodes), 40-50% remission**. Batteries 5-7 th. |
| **PTNS (Percutaneous Tibial Nerve Stimulation)** | Alternatif SNM (lebih murah, non-invasif) | 30 menit × 12 sesi mingguan, lalu maintenance bulanan. Outcome mirip SNM tapi kurang durable |

### Tahap 4: Operasi (Fourth-Line) — **Anomali Anatomi Mayor / Gagal Semua Di Atas**

| Prosedur | Indikasi | Teknik | Outcome |
|----------|----------|--------|---------|
| **Sphincteroplasty (Overlapping / End-to-End)** | **Defek Sphincter Eksternus (EAS) Anterior (12-3 jam) — Post-Obstetrik** | **Overlapping (Parks) — Gold Standard**: Mobilisasi ujung EAS, tumpang tindih medial, sutur non-absorba (PDS/Prolene) 2-0/3-0. **End-to-End** jika defek kecil/tepi tajam. | **70-80% improvement 1 th, 50-60% 5-10 th**. Faktor buruk: Neuropati pudental, IBD, Radioterapi, Usia > 60, Defek IAS bersamaan |
| **Graciloplasty (Dynamic Graciloplasty)** | Gagal sphincteroplasty / Defek total sphincter / Neurogenik | Transposisi otot gracilis ke anus, stimulator implantabel | 50-60% improvement, komplikasi tinggi (infeksi, pain, device failure) |
| **Artificial Bowel Sphincter (AMS 800 / Neosphincter)** | Total sphincter loss / Gagal semua | Cuff perianal, pompa skrotum/labia, reservoir perut | 60-70% kontinensia, **revisi 30-50% 5 th** (erosie, infeksi, malfunction) |
| **Stoma (Kolostomi / Ileostomi End)** | **Last Resort: Gagal Semua, Kualitas Hidup Sangat Buruk, Paliatif** | Kolostomi sigmoid end / loop | **Kualitas hidup sering MEMBAIK drastis** (kontrol penuh), tapi stoma care needed |

## Kondisi Khusus: Inkontinensia Feses Post-Obstetrik (OASIS Follow-up)

| Waktu | Tindakan |
|-------|----------|
| **Pasca Persalinan (Jika Episiotomi Derajat 3-4 / OASIS)** | Endoanal USG + Manometri **6-12 minggu pasca** (baseline) |
| **6-12 Bulan Pasca** | Evaluasi gejala (Wexner), PFMT adherence, USG/Manometri ulang jika gejala |
| **Kehamilan Berikutnya** | **SC Elektif 38-39 mg** (hindari trauma berulang) ATAU **Vaginal dengan perlindungan** (manual perineal protection, episiotomi mediolateral terkontrol, hindari instrumental) — **Konseling Risiko Recurrence 15-30%** |

## Ringkasan untuk Dokter Umum

1. **FI = Tidak tahan gas/tinja** — Tanya tipe (Urgency vs Passif), konsistensi (Bristol), frekuensi, Wexner Score
2. **WAJIB Normalisasi Konsistensi Tinja (Bristol 3-4)** — Diare: Loperamide; Konstipasi: Serat + Osmotik — **Ini 50% Kasus Membaik Saja**
3. **PFMT + Biofeedback (Fisioterapis Pelvic Floor) 3-6 Bulan** — First-line Level 1A
4. **Investigasi Sebelum Operasi:** **Endoanal USG (Anatomi) + Manometri (Fungsi) + PNTML (Neuropati)** — WAJIB
5. **Gagal Konservatif → SNM (InterStim) Gold Standard** — Test phase dulu (PTNS / Temporary lead)
6. **Defek Sphincter Anterior (Post-Obstetrik) → Sphincteroplasty Overlapping** — Outcome 70-80% 1 th, turun 5-10 th
7. **Neuropati Pudental / IBD / Radioterapi / Usia Lanjut → Outcome Operasi Lebih Buruk** → Pertimbangkan SNM / Bulking / Stoma
8. **Kehamilan Berikutnya Post-OASIS:** SC Elektif 38-39 mg direkomendasikan (hindari trauma berulang)
9. **Stoma = Last Resort Tapi Kualitas Hidup Sering Membaik Drastis** — Jangan takut tawarkan
