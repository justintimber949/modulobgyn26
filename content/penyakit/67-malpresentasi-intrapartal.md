# Malpresentasi & Malposisi Intrapartal

## Cerita Pembuka

Ny. Ani, 29 tahun, G3P2A1, usia kehamilan 39 minggu. Persalinan spontan, serviks 8 cm, kepala janin sudah engaged tapi persisten occiput posterior (OP) seitan 2 jam tanpa progres. Nyeri punggung hebat, pengejanan tidak efektif. Operator memutuskan: **Manual Rotation** (tangan sterile menggeser occiput dari posterior ke anterior) → succeed → kepala rotasi ke OA → **Forceps Kielland** untuk membantu penurunan → lahir bayi 3400 g, APGAR 8/10. Selamat tanpa komplikasi.

## Definisi

**Malpresentasi** = Presentasi selain **cephalic (kepala)** setelah **36 minggu kehamilan**.
**Malposisi** = Presentasi **cephalic** tapi **posisi abnormal** (Occiput Posterior / Occiput Transverse).

| Kategori | Subtipe | Insidensi Term |
|----------|---------|---------------|
| **Breech (Bokong)** | Frank (extended), Complete (flexed), Footling (single/both) | 3-4% |
| **Transverse (Samping)** | Shoulder, Oblique | 0,3-0,5% |
| **Face** | Mentum Anterior, Mentum Posterior, Mentum Transverse | 0,1-0,2% |
| **Brow** | Persisten (tidak rotasi ke Face/Vertex) | < 0,1% |
| **Persistent OP** | Occiput Posterior tidak rotasi ke OA | 5-10% (90% rotasi spontan) |

## Tatalaksana Intrapartal (Berbasis Jenis & Kondisi)

### A. Presentasi Bokong (Breech) — Intrapartal

#### **PERSALINAN NORMAL BOKONG — KRITERIA KETAT**

| Syarat Wajib | Detail |
|--------------|--------|
| **Tipe** | Frank atau Complete (TIDAK Footling!) |
| **BB Janin** | 2500-3800 g (Ideal 2500-3500 g) |
| **Kepala Fleksi** | Mentum ke dada (X-ray/USG jika ragu) |
| **Pelvis Adekuat** | Klinis atau pelvimetri |
| **Operator** | SpOG berpengalaman vaginal breech + SC standby |
| **Fasilitas** | GA (General Anestesi) tersedia + Neonatologi + Tim Resusitasi |
| **Persetujuan** | Informed Consent (risiko: kepala terjebak, asfiksia, trauma, mortalitas neonatal 2-3× SC) |
| **Kontraksi** | SPONTAN (Tidak ada induksi oksitosin!) |

#### **Teknik Persalinan Vaginal Bokong (Assisted Breech Delivery)**

| Tahap | Teknik | Detail |
|-------|--------|--------|
| **1. Bokong Lahir Spontan** | Hands-off | Tunggu hingga bokong lahir ke tingkat umbilikus spontan (kontraksi + pengejanan ibu) — **JANGAN DIPACU** |
| **2. Badan Bokong Lahir** | **Løvset Maneuver (Rotasi)** | Pegang kedua kaki, putar 180° (bokong posterior → anterior → terbangun) untuk melahirkan bahu posterior → lalu putar kembali 180° untuk bahu anterior |
| | **Mauriceau-Smellie-Veit (Bantu Badan)** | Jari telunjuk kedua tangan di supraorbital ridge & jari tengah di maxilla → bantu ekstensi kepala sambil tangan lain menekan bahu posterior ke bawah |
| **3. Kepala Terjebak** | **Piper Forceps** | **Forceps khusus untuk kepala bokong** — kedua blade dimasukkan di bawah kepala yang sudah terdesendi (tunggu sampai kepala turun ke pelvic cavity!) — **TIDAK BOLEH TRAKSI SEBELUM BLADE TERPASANG BAIK** |
| | **Mauriceau-Smellie-Veit + Traksi** | Jika Piper tidak tersedia |
| **4. Tali Pusat** | **Pelepasan** | Setelah badan lahir → cek nuchal cord → jika terjebak → lepas, jika pendek → lepaskan dari serviks |
| **5. Durasi Kritis** | **< 5-10 menit** dari bokong lahir sampai kepala lahir | **Jika > 10 menit → Asfiksia ↑↑** — Traksi terkontrol + SC Darurat |

> **TRAKSI = TRAKSI TERKONTROL** (ke arah bawah lalu naik saat kepala membelah) — bukan traksi kuat!

#### **Bila Syarat Tidak Terpenuhi → SC ELEKTIF / DARURAT**

### B. Presentasi Samping (Transverse/Oblique) — Intrapartal

| Situasi | Manajemen |
|---------|-----------|
| **Tidak KPD & Belum Persalinan Aktif** | **ECV 36-37 mg** → Jika gagal: SC elektif 39 mg |
| **KPD / Persalinan Aktif** | **SC DARURAT SEGERA** — Risiko: Prolaps tali pusat, abrupsio, ruptur uterus |
| **Jika SC tidak memungkinkan (Remote area)** | **Internal Podalic Version + Breech Extraction** (Hanya jika singleton, operator senior, GA, darah siap) |

### C. Persistent Occiput Posterior (OP)

| Situasi | Manajemen |
|---------|-----------|
| **OP fase aktif (serviks < 7 cm)** | Expectant + posisi maternal (lutut-dada, miring) → banyak rotasi spontan |
| **OP fase pengejanan + Progres Buruk** | **Manual Rotation** → Jika sukses: forceps/vakum OA. Jika gagal: |
| | **Forceps Rotational (Kielland / Neville-Barnes)** → Operator senior |
| | **Vacuum Rotational (Kiwi / Bird)** → Lebih aman dari forceps untuk rotasi |
| | **SC Darurat** → Jika gagal rotasi / arrest / distress |
| **Persistent OP + Engaged + Progres** | **Forceps Kielland (Rotational) ATAU Vacuum Rotational** → Jika gagal: SC |

### D. Presentasi Muka

| Posisi | Manajemen |
|--------|-----------|
| **Mentum Anterior (MA)** | **Bisa lahir vaginal** — Expectant + monitoring. Forceps jika progres buruk. |
| **Mentum Posterior (MP)** | **SC Elektif 39 mg** (tidak bisa rotasi ke anterior, kepala extended maksimal) |
| **Mentum Transverse (MT)** | Monitoring → sering rotasi ke MA (bisa normal) → Jika persisten: SC |

### E. Presentasi Dahi (Brow)

- **Tidak bisa lahir vaginal** (diameter presentasi terbesar 13,5 cm > pelvic inlet)
- **Sering konversi** ke Face (MA) atau Vertex (fleksi) → bisa lahir vaginal jika konversi
- **Jika persisten:** SC Elektif / Darurat

## Ringkasan untuk Dokter Umum

1. **Malpresentasi Intrapartal = Keputusan Cepat: Bisa Vaginal atau SC?**
2. **Bokong Vaginal HANYA JIKA:** Frank/Complete, EFW 2500-3800g, Fleksi Kepala, Pelvis Adekuat, Operator Senior, SC standby, GA tersedia
3. **Bokong TIDAK bisa Vaginal:** Footling, BB < 2500g/> 3800g, Kepala Extended, Pelvis Tidak Adekuat → SC ELEKTIF
4. **Persistent OP:** Manual Rotation → Forceps/Vakum Rotational → SC Jika Gagal
5. **Samping → SC (ECV boleh dicoba sebelum SC elektif)**
6. **Muka MA → Bisa normal. MP/MT → SC**
7. **Dahi → SC**
8. **Kunci Sukses Vaginal Bokong:** "Hands-off bokong, Hands-on kepala" + Operator Berpengalaman + SC standby + < 5-10 menit kepala lahir
