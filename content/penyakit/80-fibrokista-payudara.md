# Fibrokista Payudara (Fibrocystic Change / Benign Breast Disease)

## Cerita Pembuka

Ny. Ani, 35 tahun, G1P1A0, keluhan: **kelenjar payudara kaku & nyeri (mastalgia siklik) seitan 6 bulan, terutama 1 minggu sebelum haid**. Pemeriksaan: **Bilateral, multiple lump kecil-kecil (nodularitas difus), bisa digerakkan, tidak melekat ke kulit/dinding dada, nyeri tekan difus**. USG: **Multiple kista anekoik kecil (0,5-1,5 cm) bilateral, BIRADS 2**. FNAB kista terbesar: **Cairan jernih, sitologi: sel epitel apokrin + makrofag apokrin (tidak ada atipia)**. Diagnosis: **Fibrokista Payudara (Fibrocystic Change) + Mastalgia Siklik**. Manajemen: **Reassurance (Bukan Kanker), Bra Pendukung, Hindari Kafein/Methylxanthine, Vit E 400 IU + B6 100 mg, NSAID saat nyeri, FU 6 bulanan**. 3 bulan: nyeri ↓ 80%, kista stabil.

## Definisi & Patogenesis

**Fibrokista Payudara** = **Perubahan Jinak Non-Proliferatif & Proliferatif** pada jaringan payudara sebagai respons terhadap fluktuasi hormon (Estrogen-Progesteron) setiap siklus menstruasi — **Bukan Penyakit, Tapi Variasi Normal "Andropause" Payudara**.

| Komponen Histologis                                   | Deskripsi                                                                                        | Risiko Kanker                                                                       |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| **Non-Proliferatif**                                  | **Kista Sederhana, Fibrosis, Adenosis Sclerosing, Epithelial Hyperplasia Biasa**                 | **Tidak Meningkatkan (RR 1.0)**                                                     |
| **Proliferatif Tanpa Atipia**                         | **Usual Ductal Hyperplasia (UDH), Sclerosing Adenosis Kompleks, Papilloma Soliter, Radial Scar** | **Sedikit Meningkatkan (RR 1.5-2.0)**                                               |
| **Proliferatif Dengan Atipia (Atypical Hyperplasia)** | **Atypical Ductal Hyperplasia (ADH), Atypical Lobular Hyperplasia (ALH)**                        | **Meningkatkan Signifikan (RR 4-5×)** — **Butuh Follow-up Ketat / Chemoprevention** |

> **Epidemiologi:** **50-60% Wanita Usia 20-50 Th** punya temuan fibrokista (klinis/USG/histopat) — **Palingan Umum "Penyakit" Payudara**. Puncak 30-40 Th. Postmenopause: regresi (kecuali HRT).

## Gejala & Tanda

| Gejala                            | Karakteristik                                                                                                            |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| **Mastalgia Siklik (Nyeri Haid)** | **#1 Keluhan** — Bilateral, difus, berat/tertekan, **minggu sebelum haid → membaik saat haid**, usia 30-40 Th            |
| **Mastalgia Non-Siklik**          | Tidak berkaitan siklus, unilateral/lokal, usia > 40 Th, bisa dari dinding dada (kostokondritis)                          |
| **Lump / Benjolan (Palpabel)**    | **Multiple, Bilateral, Kecil (0,5-2 cm), Lentur, Bisa Diggeser, Nyeri Tekan** — Bukan massa soliter keras tidak bergerak |
| **Nipple Discharge**              | **Bilateral, Multi-Duct, Warna Jernih/Kuning/Hijau/Coklat (Bukan Darah)** — Fisiologis / Duct Ectasia                    |
| **Kaku & Bengkak Siklik**         | Payudara terasa penuh & kaku premenstruasi                                                                               |

## Diagnosis & Workup

### 1. Klinis (Anamnesis + Pemeriksaan)

- **Siklik + Bilateral + Multiple Nodularitas Difus + Bisa Diggeser + Nyeri Tekan = Fibrokista Khusus (Clinical Diagnosis Cukup)**

### 2. USG (First-Line Imaging)

| Temuan USG                                                                                | BIRADS                         | Signifikansi                               |
| ----------------------------------------------------------------------------------------- | ------------------------------ | ------------------------------------------ |
| **Multiple Kista Anekoik Kecil (< 2 cm), Dinding Tipis, Tanpa Solid, Tanpa Vaskularitas** | **BIRADS 2 (Benign)**          | **Kista Sederhana — Fibrokista Khusus**    |
| **Kista Kompleks (Septasi Tipis, Debris, Dinding Sedikit Tebal)**                         | **BIRADS 3 (Probably Benign)** | Follow-up 6 Bulan (Risiko Malignancy < 2%) |
| **Massa Solid Hiperekoik, Margin Tegas, Orientasi Paralel Kulit, Tanpa Vaskularitas**     | **BIRADS 3**                   | **Fibroadenoma** (Lihat Modul #81)         |
| **Massa Solid Irregular, Margin Tidak Tegas, Vaskularitas ↑, Mikrokalsifikasi**           | **BIRADS 4/5**                 | **Curiga Malignancy** → Biopsi WAJIB       |

### 3. Mammografi (Usia ≥ 40 Th / Screening)

- **Konsistensi: Heterogen / Scattered Fibroglandular** — Normal varian
- **Kalsifikasi: Benign (Coarse, Popcorn, Rim, Lucent-centered, Dystrophic, Milk of Calcium, Suture, Vascular, Round/Punctate Diffus)** → BIRADS 2
- **Kalsifikasi: Suspicious (Pleomorfik, Fine Linear, Branching, Segmental, Clustered)** → BIRADS 4/5 → Biopsi Stereotaktik

### 4. FNAB / Core Needle Biopsy (Jika Ragu / BIRADS 3-4)

| Indikasi                                                           | Target                                                      |
| ------------------------------------------------------------------ | ----------------------------------------------------------- |
| **Kista Kompleks / Recurrent / Bloody Aspiration**                 | Sitologi Cairan / Histopat Core                             |
| **Massa Solid BIRADS 3 (Follow-up Tidak Mampu / Pasien Khawatir)** | Core Biopsy (Lebih Akurat FNAB)                             |
| **Mikrokalsifikasi Suspicious**                                    | Stereotaktik Core Biopsy (Vacuum-Assisted)                  |
| **ADH / ALH pada FNAB/Core**                                       | **Excisional Biopsy (Operasi) untuk Rule Out DCIS/Invasif** |

## Tata Laksana

### A. Reassurance & Edukasi (Dasar Semua Kasus)

- **"Ini Bukan Kanker, Bukan Tumor, Tapi Variasi Normal Jaringan Payudara Merespons Hormon"**
- **Natural History: Naik Turun Ikut Siklus, Regresi Postmenopause (Kecuali HRT)**

### B. Manajemen Gejala (Mastalgia & Nyeri)

| Intervensi                                                              | Dosis & Bukti                                                                                      | Catatan                                        |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| **Bra Pendukung (Sports Bra / Bra Tidak Underwire)**                    | **First-Line, Non-Farmako** — 80% merasa nyaman                                                    | Gunakan 24/7 saat nyeri hebat, tidur pakai bra |
| **NSAID Topikal (Diclofenac Gel 1% 3-4×/hari)**                         | **Efektif, Aman, Minimal Sistemik**                                                                | First-Line Farmako                             |
| **NSAID Oral (Ibuprofen 400-600 mg / Mefenamat 500 mg 3×)**             | Saat Nyeri Hebat (Premenstrual)                                                                    | Maks 5-7 hari/siklus, PPI jika risiko gastrik  |
| **Vitamin E (400 IU/hari) + Vitamin B6 (100 mg/hari)**                  | **Evidensi Moderat (RCTs)** — Nyeri ↓ 30-50%                                                       | Aman, Murah, Coba 3 Bulan                      |
| **Gamolenic Acid (Evening Primrose Oil 3-4 g/hari)**                    | Evidensi Lemah, Bisa Coba                                                                          | Alternatif                                     |
| **Hindari Kafein & Methylxanthine (Kopi, Teh, Coklat, Minuman Energi)** | **Banyak Pasien Laporkan Membaik** — Mekanisme: Methylxanthine → cAMP ↑ → Prolaktin Sensitivitas ↑ | **Coba Eliminasi 2-3 Bulan**                   |
| **Diet Lemak Rendah + Serat Tinggi**                                    | Estrogen Eksogen ↓                                                                                 | Dukungan Umum                                  |

### C. Manajemen Kista (USG-Guided)

| Situasi                                                        | Tindakan                                                                                                                                                                          |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Kista Sederhana Anekoik < 3 cm, Asimtomatik**                | **Tidak Perlu Aspirasi** — Follow-up USG 6-12 Bulan                                                                                                                               |
| **Kista > 3 cm / Nyeri / Kosmetik Ganggu**                     | **Aspirasi USG-Guided (FNA)** — Cairan Jernih/Kuning/Hijau: Buang. **Cairan Berdarah: Sitologi WAJIB**. Jika Kista Hilang Total → Selesai. Jika Rekuren 2× → Pertimbangkan Eksisi |
| **Kista Kompleks (Septasi/Debris/Dinding Tebal)**              | **Core Biopsy / Vacuum-Assisted Biopsy** Rule Out Neoplasia                                                                                                                       |
| **Kista Rekuren / Multi-lokulasi / BIRADS 3 Persisten > 2 Th** | **Eksisi Lump (Lumpektomi) Elektif**                                                                                                                                              |

### D. Manajemen Nipple Discharge

| Jenis                                                              | Tindakan                                                                                                                       |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| **Bilateral, Multi-Duct, Non-Bloody (Jernih/Kuning/Hijau/Coklat)** | **Reassurance + Follow-up 6-12 Bulan** — Fisiologis / Duct Ectasia                                                             |
| **Unilateral, Single-Duct, Spontan, Bloody / Serosanguinolent**    | **USG + Ductografi (Galaktografi) / MRI Payudara** → **Mikrodoktotomi / Eksisi Saluran (Hadfield) Jika Papilloma / Neoplasia** |
| **Bilateral + Bloody**                                             | **Bilateral Workup (USG + Mammografi)** — Sistemik (Prolaktin, TSH, Obat) vs Bilateral Papilloma                               |

### E. Follow-up (Surveillance)

| Kondisi                                                   | Interval                                                                                                                                                                                        |
| --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Klinis Fibrokista Khusus (Tanpa Massa Dominan)**        | **Klinis 6-12 Bulan, USG Tahunan (Usia 30-40), Mammografi 2 Tahunan (≥ 40 Th)**                                                                                                                 |
| **Kista Sederhana BIRADS 2**                              | **USG 12 Bulan (Bisa Dihentikan Jika Stabil 2×)**                                                                                                                                               |
| **Kista Kompleks BIRADS 3**                               | **USG 6 Bulan × 2 Tahun → Jika Stabil → 12 Bulan**                                                                                                                                              |
| **Biopsy: UDH / Sclerosing Adenosis / Papilloma Soliter** | **Klinis + USG 6 Bulan × 2 Th, Mammografi Tahunan**                                                                                                                                             |
| **Biopsy: ADH / ALH (Atypical Hyperplasia)**              | **Klinis + USG + Mammografi 6 Bulan SELAMANYA** — **Chemoprevention: Tamoxifen 20 mg/hari (Premenopausal) / Raloxifen 60 mg/hari (Postmenopausal) 5 Tahun (RR Kanker ↓ 50%)** — Konsul Onkologi |

## Diferensial Diagnosis (Yang Harus Dikeluarkan)

| Kondisi                | Beda Kunci                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Fibroadenoma**       | Massa Soliter, Tegas, Lentur, Bisa Diggeser ("Mouse"), USG: Hiperekoik, Margin Tegas, Paralel Kulit                |
| **Karsinoma Payudara** | Massa Soliter, Keras, Tidak Bergerak, Margin Tidak Tegas, Kulit Peau d'Orange, Retraksi Puting, Limfa Aksila Keras |
| **Phyllodes Tumor**    | Cepat Membesar (> 2-3 cm/bln), Bisa Raksasa, USG: Heterogen, Lobo-lobo, Vaskularitas ↑                             |
| **Abses/Mastitis**     | Nyeri Akut, Eritema, Panas, Demam, Fluktuasi (Abses)                                                               |
| **Fat Necrosis**       | Riwayat Trauma/Operasi, Massa Keras, Bisa Mirip Kanker, USG: Minyak Cystic / Hiperekoik dengan Shadowing           |

## Ringkasan untuk Dokter Umum

1. **Fibrokista = Variasi Normal (50-60% Wanita), Bukan Penyakit** — **Reassurance #1 Terapi**
2. **Gejala Utama: Mastalgia Siklik + Multiple Nodularitas Difus Bilateral + Nyeri Tekan**
3. **USG: Multiple Kista Anekoik Kecil = BIRADS 2 (Benign) → Tidak Perlu Biopsi**
4. **Manajemen: Bra Pendukung + NSAID Topikal/Oral + Vit E 400 IU + B6 100 mg + Hindari Kafein**
5. **Kista > 3 cm / Nyeri → Aspirasi USG-Guided (Cairan Berdarah → Sitologi WAJIB)**
6. **Nipple Discharge Bilateral Non-Bloody = Fisiologis. Unilateral Single-Duct Bloody = Rujuk (Papilloma/Kanker)**
7. **Atypical Hyperplasia (ADH/ALH) = Risiko Kanker 4-5× → Surveillance Ketat 6 Bulanan + Chemoprevention (Tamoxifen/Raloxifen)**
8. **Red Flag: Massa Soliter Keras Tidak Bergerak, Peau d'Orange, Retraksi Puting, Limfa Keras → Biopsi SEGERA**
